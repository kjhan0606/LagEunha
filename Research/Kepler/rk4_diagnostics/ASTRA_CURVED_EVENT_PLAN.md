# Astra: 곡선 전달 적분의 사건 분리와 양의 여집합 조립

2026-10-21. 기존 astra_planning_review의 묶음 평가를 기록한다. 운전자가
구현한다. 실패한 직접 구간 검사기의 반복이나 차수/분할 한도 증가는 하지 않는다.

현재 저장된 실제 map, 속도, 밀도, 압력과 가중치 조건을 그대로 사용한다.
먼저 원래 작은 닫힌 라게르 셀 시험에서 면 교점, 접선, 꼭짓점의 역상을
직접 격리한다. source 경계와의 교점만 찾으면 source 내부의 작은 셀을
놓칠 수 있으므로 target 꼭짓점과 반지름 극값을 반드시 포함한다.
구간 Newton과 경계/미분의 부호를 사용하고, 배제하지 못한 상자는 보존한다.
고정 탐색 예산을 넘기면 실패 증거를 남긴다. 샘플링만으로 후보를 지우지 않는다.

사건 상자 사이에서는 실제 경계 곡선을 추적하고 양의 적분을 수행한다.
정상적인 경계 이동의 전체 범위를 미해결 영역으로 계산하지 않는다.
사건 상자와 계수/표현 오차에 따른 띠만 별도로 상계한다. 접선에서 분모에
floor를 넣거나 근을 버리지 않는다. source, topology, quadrature, gluing
오차를 분리하며 Gauss 차이만으로 겹침의 완전성을 주장하지 않는다.

source 전체 현재 모멘트를 기준으로 outgoing 겹침을 한 번씩 계산한다.

    target_j = source_j - sum_(k!=j) outgoing_jk
                          + sum_(i!=j) outgoing_ij

같은 겹침 기록을 양쪽에 사용한다. 자기 셀의 실제 양의 여집합을 보존하고
음의 물리 적분점, 독립 에너지 저장고, 열 보충을 만들지 않는다. 질량행렬의
양성과 모멘트의 셀별 절대 오차를 확인한다. 원래 IC나 이전 target 적분값을
현재 source 상태로 대체하지 않는다.

공유 경계의 작은 차이는 정확한 C0 연속성의 증명이 아니다. 공통 연속 표현을
만들 경우 원래 packet은 보존하며 위치/1차 미분 및 gluing 모멘트 오차를
별도 계상한다. 그렇지 않으면 틈/겹침의 최악 오차를 남긴다.

순서: 같은 작은 셀 시험(면적 1e-11, 기존 질량/K 기준) → 실제 24셀 W0
→ 기존 비영 가중치 pattern → coarea Jacobian과 한 번의 유한 weight solve.
이 묶음에서 시간 진화나 압축을 시작하지 않는다. 이후 cold-feasible 압축,
본체의 sparse/matrix-free 연결, 충격파와 t6/8/10, 최장 GIZMO 검증으로 간다.

W0 환원: 유한한 고정 mu에 대해 가능한 해군에서 W→0이면
M(W)+mu W=m0로부터 M→m0이다. 임의의 유한 map에서 M(0)=m0가 자동으로
성립하지 않는다. mu→∞만으로 이 환원을 증명하지 않으며 flux를 덮어쓰지 않는다.
