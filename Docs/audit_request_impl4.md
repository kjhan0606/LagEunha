# 감사·결정 요청 (Astra, 4차): 관문 F 실패 — 면 상태 Q의 전단 소산

작성: 2026-10-03. 직전: `Docs/audit_impl3_astra.md`. 기록: `Docs/design_astra_audit.md`(마지막 절).

## 3차 지시 반영 (bb57293, 7c0b6d9)
- `GFS_HG_SPLIT`: HG(dt/2) → RK4(HG 없음) → HG(dt/2).
  - 모드는 소유 셀, 전역 ID별로 합친 ℓ, A₀ = ρ_f h W, b, κ = γ(γ−1)(1−u)^{γ−1}/m로 이루어진다.
  - 모드마다 s = ln(q₀/q)에 대한 ds/dt = αC(q, U(s))를 RK4로 적분한다(Δs ≈ 0.25가 되도록 부분 단계 수를 정하고 최대 4096).
  - v −= (r₀ − r₁)ℓ/(αm), U += (r₀² − r₁²)/(2α), 엔트로피 적분에 ln(U₁/U₀)를 더한다.
  - 소유 셀 ID와 면 순으로 정렬한 뒤 정방향 τ/2, 역방향 τ/2로 적용한다. 모드는 x_n과 x_{n+1}의 사전 평가에서 만든다.
- 재시도 트랜잭션: 전용 실패 플래그, 엔트로피 적분 기록은 수락 뒤에만, 고정 dt에서 재시도가 필요하면 실행을 멈춘다.
- 사전 평가 dt에 0.1% 여유를 두었다. 여유가 없으면 HG 절반 단계 뒤 CFL이 1e-6 수준 작아져 거의 매 단계 재시도가 났다. **이 여유의 타당성도 감사해 달라.**

## 결과
`Docs/design_astra_audit.md` 마지막 절 참조. 요약하면 다음과 같다.
- 관문 C(Sod)는 유지된다.
- **관문 F(Gresho 128², t=1)는 실패**이다: L1 0.0736, 회전핵 −13.8%. HG 없는 면 Z + minmod도 0.0594 / −11.8%로 실패했고, HLLC는 0.0329 / −5.6%이다.
- 소산은 Q가 약 70%, HG가 약 30%이다.
- 면 기하 dt가 전단으로 셀이 늘어나며 1.1e-4에서 1.4e-5로 줄었다.
