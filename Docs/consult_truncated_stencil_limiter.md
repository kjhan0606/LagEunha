# 자문 요청 (14차): 자유표면(잘린 stencil) 셀에서 제한자의 극값 오판

작성: 2026-10-01. 원칙은 같다(패치·임의 조정값 금지, 입자 = 생성점, 셀 생성 유지, 바닥값 1e-6 유지, DTETA 미사용).

## 증거

### 1. 차가운 전단 띠 (곡률 없음): Kepler 가장자리 잡음 재현
- `EUNHA_IC=vacslab`, |x−3|<0.75, Δ=1/16, ρ=1, P=1e-6, v_y = S(x−3), S=−4.24(r=0.5 Kepler 전단률), y 주기, 양옆 진공. 원판 경계 ρ=Δ, 2패스 LSF, 앵커 제한 + 면 중심 ρ·P 양성, `EUNHA_REC_TCOMMON=1`, HLLC. 빌드 `d2c9773`.
- 가장자리 열 rms(v_x): t=1에 1.9e-3(약 1.5c), t=19에 1.5e-2. 띠 중앙은 t=1에 1e-16에서 t=19에 0.24로 오염. 가장자리 열이 전단 속도를 최대 15% 잃음(Kepler 각운동량 손실과 같은 현상). KH 말림 없음(y 균일 줄무늬). S=0 대조군은 잡음 없음.

### 2. 씨앗: 제한자가 선형장 기울기를 0으로 만듦
- 호출 0(정사각 격자)은 재구성이 완벽(점프 0).
- 첫 RK 단계에서 격자가 미끄러져 대각선 면(d=1.38Δ, A=0.07–0.95Δ)이 생긴다. **가장자리 열과 둘째 열 사이 면 전부**에서 재구성 점프가 셀 점프의 정확히 절반(예: −0.1825 → −0.0913, 약 70c)이다. 가장자리 열끼리, 둘째–셋째 열 면은 정상.
- 스냅샷의 저장된 기울기: 가장자리 입자 192개 중 53개가 dv_y/dx = 0 (정답 −4.24, 다른 열은 −4.24). α_vy=0.
- 해석: 가장자리 셀은 바깥 이웃이 없어 선형장에서도 자기 값이 이웃 중 극값이다(V_min = V_i). 같은 가장자리 열 이웃은 값이 같다. 그 이웃 앵커로의 외삽 δ가 반올림 수준이라도 V_min 쪽을 향하면 (V_min − V_i)/δ = 0이 되어 α=0. Barth–Jespersen의 0/δ 퇴화가 잘린 stencil에서만 일어난다. 가장자리 쪽은 1차 재구성이 되어 면에 셀 점프 절반이 남고, 차가운 기체에서 P* ≫ P로 잡음과 운동량 손실이 시작된다.
- Kepler 64²에서도 가장자리 고리 평균 α=0.55, 50%가 0.5 미만.

코드: `Exam/exam.c` `updateDenW2Pressure2DBlend`의 av_mode==5 제한자(TVD_LIMIT, `gfs_lim_anchor_on`, `gfs_lim_smooth_on`), 면 루프 재구성(`gfs_rec_tcommon_on`).

## 질문

1. 해석이 맞는가? 다른 설명(예: 가장자리 LSF 기울기 편향 −4.217 대 −4.24, 원판 경계 셀 기하)이 더 맞는지.
2. 원칙적인 제한자 형태는? 후보:
   - (a) 쌍별 판정: 각 면 j에 대해 앵커 값이 [min(q_i,q_j), max(q_i,q_j)] 안에 있는지만 검사(Hopkins 부록 B와의 관계). q_i=q_j인 면의 0/δ 퇴화는 남는가?
   - (b) 0/δ 퇴화 처리: δ가 그 면의 해상 가능한 변화(예: 기울기·거리로 정해지는 반올림·절단 오차) 이하면 무시. 임의 ε 없이 정의할 수 있는가?
   - (c) 진공 경계에서의 범위 정의: 원호 쪽 바깥에 값이 없으므로 극값 판정에서 원호 방향을 제외하거나, 셀 자신의 외삽을 경계값으로 쓰는 방식.
   - (d) 기타(Venkatakrishnan류 연속 제한, 매끄러움 판정 기반).
   충격·진공 팽창에서 양성과 단조성을 해치지 않으면서 선형장을 정확히 보존하는 형태를 권고해 달라.
3. 검증 순서와 판정 기준(전단 띠 → Sod/진공 팽창 → Kepler).
