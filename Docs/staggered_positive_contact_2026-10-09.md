## 2. 변경 내용

수신 셀 C_i의 질량을 다음과 같이 계산한다.

`m_i(w) = sum_a rho_a * area(C_i(w) intersection D_a)`

D_a는 이번 스텝에서 실제로 이동한 물질 조각이다. 이 적분 질량이 초기의 고정 목표
질량과 일치하도록 Newton 풀이를 한다. 한 가중치를 0으로 고정해 게이지를 제거하고,
작은 시험대에서는 질량 적분의 중심 유한차분 Jacobian과 감쇠 Newton을 사용한다.
면적이 아닌 질량을 직접 제약하며, 목표 질량 합과 물질 질량 합이 맞지 않으면 중단한다.

상태는 여전히 양의 밀도와 내부에너지, 선형 속도를 가진 다각형 조각이다.
밀도가 다른 조각은 한 셀 안에서도 구분해서 유지한다. 속도장은 양쪽에서 같으므로
생성점의 물리 속도가 접촉면에서도 모호하지 않다. 생성점을 이동시킬 때 조향하지 않는다.

반복 교집합의 조각 수 증가를 피하기 위해, 물리 상태가 완전히 같은 조각들의 합집합이
볼록한 경우에만 합친다. 합집합과 볼록껍질의 대칭차 면적, 조각의 중복 면적,
합치기 전후 모든 원시 모멘트 차이를 검사한다. 비볼록한 영역·구멍·떨어진 조각을
볼록껍질로 채우는 것은 거부한다. 부동소수점 한도 내의 기하 차이는 수치 오차로
기록한다. 일반 해법에서는 비볼록 영역을 그대로 유지할 수 있는 표현이 필요하다.

## 3. 시험 정의와 범위

- 동일한 불규칙 3²·4² 초기 생성점(seed 731).
- 초기 접촉면: `x+0.23 y=0.53`.
- 밀도: 한쪽 1, 다른 쪽 2 또는 100.
- 양쪽 `v=(0.2+1.1 y,0)`, `P=0.6`, `gamma=5/3`.
- 접촉면과 경계는 같은 물질 흐름을 따른다.
- 압력 구배와 속도 발산이 0이므로 이 수송은 해당 Euler 접촉 해와 일치한다.
  해석해는 오차 진단에만 쓰며, 상태나 가중치를 초기화하는 데 사용하지 않는다.
- 셀 내부 밀도를 평균내어 상태를 덮어쓰지 않는다. 접촉면 위치와 원시 모멘트를
  해석적 이동 결과와 비교한다.

이는 **비균일 밀도 수송 관문**이다. 압력 구배에 의한 가속, 압력 일, 충격, 중력,
일반 비선형 속도장, 유한 R의 응력 닫힘을 아직 해결하지 않았다.
고정 질량은 셀 적분 질량이며 생성점에 붙은 뉴턴 점질량과의 동등성은 주장하지 않는다.

## 4. 완료한 정적 검사

1. 두 영역의 밀도가 1:4일 때 각 셀의 목표 질량을 1.25로 두었다.
   해의 셀 면적이 **0.6875, 0.3125**가 되는 것을 확인했다.
   면적을 같게 맞추는 풀이와 구별되는 비균일 밀도 적분 검사이다.
2. 떨어진 두 조각을 합치려 하면 비볼록/불연속 지지 영역으로 판정하여 거부한다.

2개 검사 통과, 계산부 0.031초. 로그인 노드에서 스레드 1·nice 19·timeout 30초로
수행한 작은 정적 검사이다. 시간 진화는 Slurm 계산 노드에만 제출했다.
기존 양의 수송 정적 검사 3개도 새 Slurm 작업에서 함께 다시 실행하도록 했다.
