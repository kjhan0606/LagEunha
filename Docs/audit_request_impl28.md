## 27차 이후 결과
1. 27차 결함 수정 완료(부호 넓이 역전 검사, fallback 전무, 장부 복구, 주기 모서리 정규화). 압력 저장소 경계(F=Σ(P_T−P0)∂A/∂x, E=KE+Σ(u+P0A)+Φ)로 감쇠·동결 제거: 64² 차가운 원반 **23궤도**(드리프트 2.5–3.4e-3/시간, 압력 잡음 1.17% 일정, R_b 3.6/4.8 동일, 경계 넓이 변화 0, 거부 0). 끝은 안쪽 뜨거운 배경(60시간 포화 무질서)의 sliver 견고성. 배경 성장률 0.16(경계 무관).
2. **2차 재배치(선형 재구성+BJ+공통 θ, S≥S_old; θ<1 1%)는 성장을 키움**: 배경 0.30(1차 0.16), 뜨거운 원반 0.19(0.165), 차가운 원반 드리프트 4e-3(2.5e-3). 재배치 차수는 치유가 아님(DAE 플럭스 차수와 같은 패턴).
3. **평면 전단 상자는 널**: Couette(저장소 경계)·완전 주기 사인 프로파일 모두 압력 요동 1e-14, 심은 모드 정확 유지 — 직선 행의 미끄러짐은 삼각형 넓이를 정확히 보존.
4. **구동원 확정**: Kepler 원반의 영역 압력 잡음 rms = (1.1–1.2)·d/(8R)가 R=0.3–3.2 전 구간에서 성립 → 곡선 고리를 가로지르는 삼각형의 현–호 넓이 진동(sagitta d²/8R; 진동수 ~ 미끄러짐 속도/d ∝ R|Ω′|). 즉 "선형 요소가 곡선 전단의 물질 부피를 보존하지 못하는 기하 오차"가 강제력이고, 뜨거운 가스의 압력 응답과 결합해 선형 성장(∝c_s²/d 정도, 전단률 무관, flip 필요). Voronoi의 "미끄러짐 → 부피 요동"과 같은 뿌리.

## 질문
1. **기제 닫기**: 강제 진폭 d/8R·진동수 ∝ Ω′에서 성장률이 전단률과 무관하고 c_s²/d 정도로 나오는 규모식을 유도할 수 있는가(파라메트릭 강제의 공진 폭이 진동수에 둔감? 지연 압력 응답?). R 의존성(강제 진폭 ∝ 1/R인데 R=0.41과 0.84에서 같은 성장률)은 어떻게 설명되는가. 필요한 최소 추가 측정.
2. **치유 가능성(원칙 내)**: 입자=생성점·조향 금지·에너지 보존 아래에서 현–호 오차를 없애거나 줄이는 정식화가 있는가 — (a) 곡률 보정 영역 부피(예: 고차 요소/곡선 변), (b) 영역 부피를 입자 궤적의 정확한 발산(2차 플럭스)으로 추종하는 DAE형(25차에서 닫힌 경로와 어떻게 다른지), (c) D(변분 복원력)가 이 구동원을 건드리는가(아닐 것으로 보임), (d) 그 외. 각각의 보존 장부와 예상 비용.
3. **B의 판정**: 차가운 Kepler 원반(c_s/d 0.07)에서 드리프트 2.5e-3/시간(e-fold ≈ 80궤도)과 압력 잡음 1%는 100궤도 목표에 허용되는가. 우주론(뜨거운 가스는 미끄러짐이 드묾, 은하 원반·충격 후류는 전단)에서 이 불안정이 실제 위험인지 판단 기준을 제시하라. Voronoi TCF(성장률 1.1 c_s/d)보다 c_s/d·(c_s/d)배 느린 것의 의미.
4. **C 착수 여부**: 위 판정을 전제로, 27차 관문(기하·재배치 관문, 경계 계약) 중 무엇이 아직 열려 있고, 현 Python 증거로 C 연구 분기 설계를 사용자에게 제안해도 되는가. 제안한다면 범위(1D→2D 주기→Kepler)와 합격 기준을 갱신하라.
