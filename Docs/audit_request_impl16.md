## 15차 지시 구현과 검증
- (가) 압축 게이트 혼합 `GFS_QBP_CHI`(02c0a96): q_in = (1−χ)δ_QBP + χ du_cell, χ = min(1, [−θ]₊/‖S‖_F), 셀 쌍에 max.
  - Sod t=0.1(QBP + 3차 + χ): 64²는 L1 0.0249/0.0741/0.0383, 최소 간격 0.277/0.195h(t=0.05/0.1). **128²는 0.0127/0.0403/0.0178, 0.195/0.136h, 1401단계**(3차만 쓰면 0.064h, 3348단계). 256²는 t=0.05에 0.0065/0.0209/0.0091, 0.136h(t=0.1 결과 대기). 에너지 ≤ 1e-7, 재시도 0.
- (나) 원호 HG `GFS_HG_ARC`(ba2568a, c4cc1f3): sub_build가 원호를 NULL 이웃으로 받는다. 정확한 원호 넓이·1차 모멘트, 일반 꼭짓점 야코비안(보로노이 꼭짓점: hg_vjac Ji−I; 이등분선·원 교점: Jn(Δ−Rn)ᵀ/(Jn·Δ)), 원호 성분 모드 ξ = log(B/W), 분리 적분 전용, 원호 셀에서 bulk·b′ 제외.
  - 검증: 원호 없는 셀에서 일반 경로와 기존 닫힌 식의 dc 차이 ≤ 1.1e-15. C와 Python 기준(`Docs/arc_hg/arcgeom.py`, 유한차분 대비 1e-6)의 원호 ξ 차이 3.5e-15, 기울기 차이 3.2e-9(셀 400개). 원호 셀 2010–2047개, 모드 2010–2149개, 실패 0. 에너지 −1.1e-8.
- 재시작: 1스레드에서 비트 일치를 검증했다(`RestartTest_25af6f1`).

- 원판 반지름 민감도(이전 세대, 고리 IC): ρ = 0.7/1.0/1.5에서 붕괴 시작이 t ≈ 45/51/58이고 성장률은 같다.
- t≈50 RHS 분해(QBP 2차판): 가역 압력힘의 반경 성분이 v_r과 양의 상관(+0.26 ~ +0.51)이고, Q 힘은 음의 상관이다. 가장자리 압력은 내부의 2.4–6.4배이다. 데워진 가장자리 층의 압력 주도 성장이다.
- QBP 잔차 분해(t≈1.8): 가장자리 q_in은 대부분 한쪽 적합 오차이다. 3차 적합 후 가장자리 H_Q/U는 0.016 → 0.004(내부는 100배 이상 감소).
- 원호 HG는 가장자리 가열을 1.4–1.6배 늘렸고 붕괴를 t≈42에서 34.8로 앞당겼다.
- Gresho 128²(QBP 3차): t=0.75에 0.0421/−7.5%(2차와 같다). 감속은 Voronoi 부피 불일치(D2 진단)가 원인이며 이번 처방과 무관하다.

## 운전자 판단
차가운(마하 약 900) 원판의 진공 가장자리에서는 쌍 붙음을 누르는 소산(Q, HG)이 가장자리를 데우고, 데워진 층이 압력 주도로 불안정해진다. 소산을 줄이면 쌍이 붙고(t≈42), 늘리면 가열로 무너진다(t≈35). 지금까지의 처방은 붕괴 시점만 옮겼다.
