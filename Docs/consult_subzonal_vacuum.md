# 자문 요청 (28차): 아영역 Φ의 진공 경계 처리 + 충격 뒤 엔트로피 흩어짐

작성: 2026-10-02. 관련: `Docs/subzonal_derivation.md`(3.2, 서명), `Docs/subzonal_c_results.md`, `Docs/consult_disc_role*.md`(27차), 코드 `Exam/exam.c` `GFS_SUBZONE`(`sub_build`, `sub_eval`).

## 현재 구현의 임시 처리
원호·상자(`VORO_CELLBOX`, 기본 5Δ)·벽 변이 하나라도 있는 셀은 Φ_i = 0이다(`sub_build`가 0 반환). 셀이 이런 변을 얻거나 잃는 순간 Φ_i가 통째로 켜지고 꺼지므로 퍼텐셜이 불연속이다.

## 결과
- **Sod 2D(진공 없음):** 통과. 아영역 없이는 t=0.028에 붕괴했다. L1이 HLLC보다 좋다(ρ 0.0138 대 0.0146, P 0.0205 대 0.0246). 상자 변 셀 0, ΣdΦ + Σv·F = 2e-17.
- **Noh 2D(주기 상자, 유입 −r̂, P₀=1e-6, t=0.2):** 아영역이 붕괴(TCF만이면 t=0.053)를 막았다. 그러나
  - 총에너지 −6.1e-4이다. 주기 상자에서 상자 가장자리가 비어 진공이 생기고 상자 변 셀이 ~970개/단계가 되며, Φ가 켜고 꺼진다.
  - 충격 뒤 엔트로피 흩어짐 std(ln K) = 0.45(HLLC 0.20), 밀도 std 3.5(HLLC 1.7)이다. 속도 잡음은 HLLC와 같거나 작다(v_r std 0.007–0.020). 격자 방향 4겹 성분은 작다(0.006).
- **Hill 회전 격자(원판 없음, 30궤도, 2차 Q + Z_H):** 아영역 없이 ×1.002, dv/c 0.006이었는데, 아영역을 넣으면 ×1.23, dv/c 0.256으로 나빠졌다. 가장자리 상자 변 셀은 118개/단계이다.

## 문제
1. **불연속:** 셀 단위로 Φ를 켜고 끄면 에너지가 깨지고 충격을 준다.
2. **진공 쪽 편향:** 상자 변·원호로 닫힌 가장자리 셀은 진공 쪽 부분까지 셀에 포함된다. 그래서 중심 c_i가 진공 쪽으로 치우치고, Φ를 그대로 적용하면 가장자리 생성점을 진공 쪽으로 끈다(인위적 팽창).
3. 27차 결론과 같은 뿌리이다: 입자 위치만으로 진공과 저밀도를 구별할 수 없고, 상자 변도 숨은 원판이다.

## 대안 후보
- (A) **둘레 가중:** Φ_i → w_i Φ_i, w_i = 1 − L_cap,i/L_i(진공 변의 둘레 비율). 진공 변은 길이 0에서 생기므로 연속이다. w를 위치 미분에 포함해야 한다. 부분적으로 진공에 닿은 셀의 중심 편향은 남는다.
- (B) **진공 변을 질량 0 아영역으로:** 진공 변 fan의 기준 질량 M_f = 0, 나머지 아영역 질량을 m_i로 다시 정규화한다. 기준 c_i를 "유체 부분"의 중심으로 정의해야 하는데 그 정의가 문제이다.
- (C) **기준점을 중심 대신 다른 점으로**(예: 쌍 면만으로 정의한 점). 아핀 불변성을 잃을 수 있다(Fable 1판 지적).
- (D) 진공 경계 셀에서는 Φ 대신 다른 hourglass 처방을 쓴다.
- (E) 자유 표면 추적 Ω(t)(27차 Astra 권고)와 결합: C_i ∩ Ω(t)에서 Φ를 정의한다.
