# 자문 요청 (Astra, 26차): 엇갈림(영역 중심) 정식화 — 설계 검토와 C 구현 계획

작성: 2026-10-09. 근거: `Docs/staggered_verification_2026-10-09.md`, `Docs/polybnd/stagP.py`, 25차 답신, 5.9절(A·C 기각).

## 결과 요약
- 영역 중심 정식화(Delaunay 삼각형 영역, 정확한 물질 부피, −∇U 힘, flip 시 겹침 재배치)는 비진공 Kepler 원반에서 **모든 파장의 셀 규모 모드 성장을 없앴다**(64² 8궤도, 96² 5궤도; 성장률 ≤1e-3, 엔트로피 드리프트 2–4e-5, 압력 잡음 1%). Voronoi 생성점 방식(0.55), 매끄러운 부피(0.47), 잔차 소산(0.17–0.22), DAE(가중치 성장)와 대비된다.
- 남은 문제: (1) 뜨거운 안쪽 배경(c_s/d ≳ 0.7, 강한 전단)의 잔여 성장 0.15–0.2(c_s² 이상으로 감소; c_s/d 0.23에서 0.02–0.03), (2) 무질서 뒤 재배치 견고성(얇은 영역 압력 폭주, 겹침 없는 새 영역의 대체 경로가 질량 생성), (3) 충격·Gresho·Sod 미검증, (4) 프로젝트 틀(입자=생성점, TCF, 에너지 보존)과의 정합.

## 질문
1. **정식화 검토:** (a) 입자 관성 m_a 고정(t=0의 ⅓Σm_T)과 영역 질량의 재배치가 운동량·각운동량 보존과 양립하는가(힘은 −∇U로 쌍대칭이라 보존되지만 관성 정의의 임의성). (b) 겹침 재배치는 질량·내부에너지를 보존하지만 **엔트로피는 혼합으로 증가**한다 — 이것이 "엔트로피 비감소 소산"으로 정당화되는가, 그 크기(관측 2–4e-5/10시간)의 규모식. (c) 스텝 내 연결 고정·스텝 끝 재배치 vs 단계마다 재배치의 차이. (d) 재배치의 수렴 차수와 100궤도 누적.
2. **잔여 배경 성장의 기제:** 영역 부피가 정확한 물질 부피인데 왜 뜨거운 전단 영역에서 성장이 남는가(재배치 잡음의 씨앗 + 1차 혼합의 '수치 점성'? flip 순간 영역 압력의 불연속?). 판별 시험을 제시하라. 원반 조건(c_s/d≈0.07)으로의 외삽이 타당한가.
3. **견고성:** 얇은 영역(세 점 공선 근접)의 압력 폭주와 겹침 실패에 대한 원칙적 규칙(영역 병합? 최소 넓이 아래 영역의 열역학 변수 이웃 흡수? 재배치 실패 시 보존 유지 규칙). 질량 생성 대체 경로는 금지.
4. **충격:** 영역 중심 Lagrangian 방식의 표준(Wilkins/Caramana)에 따르면 영역 Q(인공점성)가 필요하다. TCF의 Q/QBP를 영역 형식으로 옮기는 원칙과, Sod·Gresho에서의 검증 순서.
5. **프로젝트 틀과의 관계:** 입자=생성점은 유지되나 Voronoi 셀은 더 이상 열역학 부피가 아니다(밀도 진단·출력·중력 질량 배정 등에만). 이것이 사용자 원칙(입자=생성점, 조향 금지, 에너지 보존, Laguerre 목표)과 양립하는가. Laguerre 가중치가 이 틀에서 할 역할이 남는가.
6. **C 구현 계획:** 현재 코드(Voronoi 면 루프, TCF, RK4 블렌드, GPU 밀도, 재시작)에서 무엇을 재사용·추가·폐기해야 하는지, 최소 구현 단계(1D→2D 주기→Kepler)와 각 단계의 합격 기준.
결론 먼저, 한국어, 근거는 파일 위치로.
