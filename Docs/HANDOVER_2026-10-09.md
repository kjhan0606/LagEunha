## 0. 한 줄 요약

목표는 "입자 = 생성점"을 지키면서 총에너지를 정확히 보존하고 Kepler 원반 100궤도·우주론 상자를 견디는 Voronoi/Laguerre 입자 유체 해법이다. 2026-10-08에 근본 원인을 확정했다: **이웃 고리가 초음속으로 미끄러질 때 Voronoi 셀 부피(=열역학 부피)가 요동하고, 그 압력 요동이 복원력이 약한 셀 규모 접선 모드를 선형으로 키운다**(성장률 ≈1.1 c_s/d, 전단률 무관, 미끄러짐 필요). 가중치(Laguerre-DAE)·매끄러운 부피·잔차 소산은 모두 정량적으로 기각됐다. 2026-10-09에 **엇갈림(Delaunay 영역 중심) 정식화**가 차가운 Kepler 원반에서 처음으로 셀 규모 성장을 없앴고(8궤도, 성장률 ≤1e-3), Sod·Gresho도 통과했다. 남은 것은 뜨거운 전단 가스의 잔여 성장(∝c_s², flip 재배치 되먹임), 시험대 경계의 견고성, 그리고 C 구현 설계다. 사용자 결정은 **"B(엇갈림) → D(변분 복원력)"** 순서이며, C 설계 착수는 아직 승인 전이다.

### 3.5 시험대 경계 문제 (중요, 반복된 오판의 원인)
Python Kepler 시험대의 파탄(기준 t≈28, 중력×4 t≈12, 중력×¼ 없음, 차가운 배경 64² t=16.5)은 **전부 R≈2.3–2.8의 회전 감쇠 영역(2.5–2.9)과 동결 벽**에서 시작해 안쪽으로 번진다(감쇠 전단이 Kepler의 3배). 초기엔 안쪽 배경 무질서로 오판했다. 처음 주기 상자판에서는 IC 불규칙성이 만든 얇은 삼각형(<0.005d², 한 고리의 연속 세 점)의 압력 폭주(P/P₀ 10²–10⁵)였다. 조치: 바깥 균일 고리·비주기·동결, 동결 hull 사이 퇴화 sliver만 정적 초기 상태 허용(`stagSod`의 벽과 동형), 그리고 상자 8·감쇠 2.5→3.6(전단 ≈ Kepler)의 넓은 감쇠(§5). C 코드의 동결 R≥2.5 경계도 같은 종류의 미끄러지는 벽임을 기억할 것.

## 4. 미해결 문제와 열린 질문

1. **뜨거운 전단 가스의 잔여 성장**(c_s/d ≳ 0.5에서 0.1–0.2/시간, ∝c_s²/d 정도, 전단률 무관, flip 필요). Astra 27: 기제는 재배치·압력력·운동의 결합(반복 연산자 증폭; 지연 압력 응답 가설)이며 규모식 미확정. 개선 후보: **2차(선형 재구성) 재배치 + 공통 θ 블렌드 제한**, 판별은 작은 전단 주기 상자의 선형 응답. 우주론의 뜨거운 가스는 미끄러짐이 적지만 전단 영역(은하 원반·충격 뒤)은 해당될 수 있다.
2. **재배치 견고성**: 얇은 영역(세 점 근접 공선)과 겹침 실패(질량 불일치 1e-3–1e-2). Astra 26 규칙: 바닥값으로 숨기지 말고 스텝 거부·국소 재삼각분할·보존적 거시영역 병합(m·U 합산 후 K 재계산). 미구현.
3. **매끄러운 흐름의 소산 바닥**: Gresho KE 손실 17%(2.4회전)·원반 1e-3 드리프트의 뿌리는 재배치 1차 투영. 2차 재배치가 1번과 함께 해결할 가능성.
4. **정식화의 열린 점**(Astra 26): 입자 관성 m_a 고정 vs 재배치 질량 — 자가중력·운동량 배분 규칙 필요; Voronoi 밀도는 진단용으로만; 재시작에 영역 상태(연결 키, m_T, K_T, 장부) 별도 저장.
5. **C 코드 기준선의 한계**: 현 TCF는 Kepler 기준 시험에서 배경이 t≈5에 무질서(§2.3). TCF 자체 개선으로는 §3.1 구동원을 못 없앤다.
6. **100궤도 미검증**: Python 최장 8궤도. 96²(≈5궤도) 결과만 선형 외삽하면 100궤도 ⟨K⟩ 변화 0.04–0.2%(Astra 26 규모식).
7. **D(변분 복원력, OT/Brenier형)**: 사용자 순서상 B 뒤. B가 성립하면 보류 가능성이 크지만 1번이 남으면 재검토.
