# 자문 요청 (15차): 쌍 구간 제한자의 충격 넘침과 가장자리 잔여 성장

작성: 2026-10-01. 원칙은 같다(임의 조정값 금지, 입자 = 생성점, 셀 생성 유지, 바닥값 1e-6 유지, DTETA 미사용).

## 구현 (`258413b`, 14차 권고)
`EUNHA_LIM_PAIR=1`: 셀 전체 단조 α를 쓰지 않는다. 각 쪽 앵커 값 q_i + g_i·a를 면별로 [min(q_i,q_j), max(q_i,q_j)]에 클램프한다. 앵커에서 면 중심까지는 쌍 평균 기울기의 공통 증분을 쓰고, ρ나 P에서 양성을 깨면 그 증분을 양쪽에서 뺀다. 면 중심 ρ·P 양성을 위한 셀 기울기 축소는 유지한다. `EUNHA_REC_TCOMMON=1`, 앵커 제한, LSF, 2패스, 원판 경계와 함께 쓴다.

## 결과
- 차가운 전단 띠(S=−4.24, P=1e-6, 64² 간격): 가장자리 rms(v_x)가 1.9e-3에서 2.3e-5(t≈1–2), 1.5e-2에서 3.3e-4(t≈19–20)로 줄었다. 띠 중앙 오염은 0.24에서 1.2e-6. 가짜 팽창이 사라졌다. 다만 가장자리 v_y 이탈이 9.7e-5(t=2)에서 1.0e-2(t=20)로 느리게 자란다(이전 0.49).
- Kepler 64²(진공판): t=24까지 r<0.5 질량 0(이전에는 t≈16부터 떨어짐). 가장자리 rms(v_r)/v_K는 t=26에 6.9e-3(이전 2.5e-2). 여전히 자란다. t=60까지 실행 중.
- 진공 팽창(ρ=P=1 띠): 열별 위치·속도가 기존 앵커 제한과 거의 같다(가장 바깥 열 지연 3.6Δ).
- **Sod(γ=5/3, 128, t=0.1)**: L1 ρ 0.0144, P 0.0243(기존 0.0146, 0.0246), u 0.0478(기존 0.0447). **충격 바로 뒤 속도 넘침**이 +0.13(기존 +0.04, 정답 u*=0.84). 희박파·접촉면은 비슷하다.
