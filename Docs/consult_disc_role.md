# 자문 요청 (27차): 원판(`EUNHA_VORO_RHO`)의 역할 — 시험용 진공 경계로 써도 되는가, 우주론에서는 빼도 되는가

작성: 2026-10-02. 관련: `Docs/tcf_g3_diagnosis.md`, `Docs/gfs_scheme3_formulation.md`(원판 경계 표, 커밋 497cd88·95dcd37), `Docs/consult_critique_knobs*.md`, 코드 `Exam/exam.c`(`voro_disc_radius`, `voro2d_restrict_disc`, `VORO_ARC_EDGE`).

## 원판의 정의
- 셀 i = (Voronoi 셀 C_i) ∩ B(x_i, ρ), ρ = `EUNHA_VORO_RHO`·Δ(Δ = 초기 격자 간격, 현재 1).
- 잘린 부분은 원호 면(진공, P=0)이다. 유체 영역은 원판들의 합집합 ∪_k B(x_k, ρ)이다.
- 셀 생성(반평면 깎아내기)은 그대로 두고 후처리로만 자른다. W=0, CPU 전용이다.
- 도입 목적: 진공과 맞닿은 가장자리 입자의 셀이 진공 쪽으로 끝없이 커지는 것(또는 계산 상자 끝까지 뻗는 것)을 막는다.
- TCF 변분 정식에서 원호는 생성점과 함께 움직이는 면이다. 원호의 힘과 일은 쌍 힘과 교환식에 흡수된다(G1 서명).

## 이번에 드러난 문제
1. **내부 셀도 잘린다.** 회전 격자의 Hill 띠는 전단 때문에 주기적으로 모든 셀이 동시에 위상을 바꾼다. 그 직후 셀이 바늘이 되고(A/d≈4), 먼 이웃 간격이 약 2Δ가 되면 내부 셀 끝이 가짜 진공 원호로 바뀐다. 쌍 면이 2개만 남아 LSF 기울기가 깨지고(−4.24 → 0 → ±2e6), 재구성 점프와 소산 폭발로 이어진다. 원판이 없으면 이 씨앗은 없다.
2. **밀도 하한.** V ≤ πρ²이므로 고립 입자의 밀도 하한은 m/(πρ²)이다. ρ=Δ에서 ≈0.32ρ₀, 2Δ에서 ≈0.08ρ₀이다. 사용자 지적: 초음속 팽창이나 우주의 저밀도 영역(void)에서는 밀도가 크게 떨어질 수 있으므로, 고정 하한은 일반 해법이 될 수 없다.
3. **비등방과 저밀도의 혼동.** 원으로 자르기 때문에, 길쭉한 셀(비등방)이 저밀도 셀처럼 잘린다.

## 사용자 제안
**시험(Hill 띠, Kepler 진공 고리, 진공 판 희박파 등 진짜 진공이 있는 문제)은 원판으로 하고, 우주론 시뮬레이션(공간을 채운 주기 상자)에서는 원판 없이 해도 되는가?**

## 질문
1. **원판의 역할은 인위적인가?** 물리적·수학적으로 정당한 자유 표면 모형인가, 아니면 셀을 묶기 위한 수치적 장치인가? 문헌(SPH/MFM의 커널 크기 상한, alpha shape, AREPO·Voronoi 자유 표면 처리, 입자 기반 자유 표면 모형)과 비교해 달라.
2. **시험은 원판, 우주론은 원판 없이 — 이 이원화는 정합한가?**
   - (a) 같은 solver가 두 정의에서 같은 연속 극한으로 수렴하는가?
   - (b) 시험 결과(G3, Kepler, 진공 판)가 원판 없는 우주론 경로의 검증이 되는가, 아니면 원판 경로만 검증하는가?
   - (c) 우주론 주기 상자에서는 모든 셀이 이웃으로 닫히니 원판이 정말 불필요한가? 극단적 void나 초음속 팽창에서 셀 상자(`VORO_CELLBOX`)가 같은 역할(숨은 하한)을 하는지 점검해 달라.
3. **ρ의 의미와 선택.** ρ는 물리 매개변수(분해 가능한 최소 밀도)인가, 수치 매개변수(격자 간격)인가? ρ=Δ와 2Δ의 득실(내부 바늘 절단 대 가장자리 확산), 해상도 수렴 시 ρ의 척도(ρ ∝ Δ인가 고정인가)를 판단해 달라.
4. **내부 셀 절단을 막는 정합한 정의.** 전역 길이 척도 없이 진짜 진공 틈과 저밀도·비등방 셀을 구별할 수 있는가? 예: 진공과 실제로 맞닿은 셀만 닫기, 입자의 국소 이웃 간격에 맞춘 ρ_i, 질량 기반 ρ_i = √(m_i/(π ρ_floor)). 각각에서 변분 구조(원호가 생성점과 함께 움직임, ρ_i가 위치에 의존하면 생기는 추가 힘), 에너지 보존, 하한 문제를 평가해 달라.
5. **TCF와의 관계.** G1 서명의 원호 흡수 조건(Σ A e + N = 0, 원판+W≠0 공유 면 불일치)이 위 대안들에서도 유지되는가?
6. **권고:** 시험과 production(우주론)에서 각각 무엇을 쓰고, 논문에는 원판을 어떻게 서술해야 하는가(인위적 장치로 명시 대 모형으로 정당화).
