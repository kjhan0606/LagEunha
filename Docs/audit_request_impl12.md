# 설계 요청 (Astra, 12차): 한쪽 stencil 경계에서 매끄러운 곡률 극값을 자르는 속도 제한

작성: 2026-10-04. 직전: `Docs/audit_impl11_astra.md`, 결과는 `Docs/audit_request_impl11.md`의 "결과" 절.

## 사실
- 11차 투영 스칼라 제한자(GFS_LIM_PROJ)는 회전 불변이다(입자별 H_Q 차이 1e-9). 그러나 Kepler 진공 가장자리 셀 204개 전부의 속도 기울기를 0으로 만든다. 가장자리 H_Q/U는 0.33에서 1.02로, 고리 2는 0.0066에서 0.85로 늘었다.
- 원인: 회전 흐름에서 면 법선 투영 v·e는 곡률 때문에 면 중점에서 매끄러운 극값이다. 이웃이 한쪽뿐인 가장자리 셀에서는 "이웃 범위 밖 새 극값 금지" 기준이 정확한 선형 재구성을 자른다. 기존 성분별 제한자는 축 근처 44개 셀에서만 같은 일이 생긴다.
- TCF에서 재구성은 Q의 minmod 입력 du_rec와 tcf_Z(재구성 상태)에 들어간다. 가역 힘에는 들어가지 않는다.
- Kepler 전단에서는 |du_cell|/c = 7–20이라 minmod가 거의 항상 du_rec를 고른다. 가장자리 열은 du_rec의 오차에 정비례한다.

## 요청
문턱 없이, 회전 불변이며, 한쪽 stencil(진공 경계)에서 매끄러운 곡률 극값을 자르지 않고, 충격에서는 단조성을 지키는 방법을 하나 선택해 구현 가능한 수식으로 달라. 후보는 다음과 같다.
- (1) 극값 판정에 국소 2차 적합(곡률)을 쓰는 매끄러움 인식 제한. 코드의 `EUNHA_LIM_SMOOTH` 경로를 평가하라.
- (2) Q의 입력을 재구성 점프 대신 곡률에 강한 양으로 바꾼다. 예: b′형 비아핀 잔차의 면 법선 성분과 du_cell의 minmod, 또는 2차 정합 재구성.
- (3) 기타.
각 후보의 Sod(관문 C) 영향, Gresho 영향, Kepler 가장자리 H_Q 예상, 시험 순서(회전 불변 → Kepler 가장자리 RHS → Sod → Gresho → Kepler 장기)를 제시하라.
읽기 전용, 한국어, 결론 먼저.
