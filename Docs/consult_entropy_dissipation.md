# 자문 요청 (18차): 엔트로피 변수 K와 HLLC 면 소산의 정합한 정의

작성: 2026-10-01. 원칙은 같다(패치·임의 조정값 금지, 입자 = 생성점, 셀 생성 알고리즘 유지, 바닥값 1e-6 유지, DTETA 미사용). 사용자가 (A) 엔트로피 변수 + 소산 장부 방향을 승인했다.

## 증거
- Hill 띠(회전 격자 37°, Ω₀=2.83, P=1e-6)에서 내부에너지 모드(SEDOV_PHASE1: ie = E − KE 경로)는 E_int가 궤도당 일정 비율로 자라(e-폴딩 약 3.5궤도) 24–30궤도에 띠가 흩어진다. 같은 설정의 **엔트로피 모드(`GAS entropy_mode=1`, P = Kρ^γ, ρ = m/V 기하 부피, av_mode 5에서 dK=0)**는 격자 잡음이 약 0.2c(rms v_x 내부 3e-4)에서 30궤도 내내 포화하고 띠가 유지된다.
- 시간간격(dt3 계수) 절반이면 내부에너지 모드의 가열이 4–6배 줄어든다. 총에너지 RK 잔차와 면 쌍 장부는 무시 가능하다.
- 면 속도 공식(½Δv·e − Δv·(c−m)/d)은 오프라인 수치 미분과 2e-6 이내로 일치한다. 그러나 `GFS_VOL_AUDIT`는 회전 격자에서 RK 장부 부피와 실제 셀 부피의 차이가 장부값과 같은 크기(스텝당 1–2%, 가끔 20–46%)임을 보인다. 정렬 격자에서는 1e-7.
- 남은 판별: 엔트로피 모드는 (i) 장부 부피와 기하 부피의 불일치에 의한 가짜 PdV와 (ii) HLLC 소산 가열을 둘 다 없앤다.

## 설계 질문
엔트로피 모드에서 단열 부분은 기하 부피로 정확하다. 남은 것은 HLLC 소산을 dK에 넣는 정의다. (W=0, 면 법선 n은 i→j, u = v·n, w는 면 법선 속도, P*는 면의 Riemann 압력)

**셀 정의.** q_i = −Σ_f (P*_f − P_i) A_f (w_f − u_i). 그러면 KE + I의 쌍 합이 −P* A w로 상쇄되어 총에너지가 정확히 보존된다(시간 적분 제외). 그러나 셀마다 부호가 정해지지 않는다. 현재 코드(`dK_diss < 0 → 0`)처럼 음수를 자르면 차가운 흐름에서 잡음이 정류되어 가열이 된다.

**면 대칭 정의.** D_f = A_f (P*_f − P̄_f)(u_L − u_R), 양쪽에 ½씩. 음향 근사(Z 같음)에서 P* = P̄ + ½Z(u_L − u_R)이므로 D_f = ½A Z (u_L − u_R)² ≥ 0. 그러나 총에너지 잔차가 A (P_i − P_j)(ū − w)로 남는다(Voronoi 면 중심에서 w = ū − Δv·(c−m)/d).

## 질문
1. 어느 정의가 정합한가? 둘을 결합하는 형태(예: 면별 소산 D_f ≥ 0를 정의하고, 총에너지 잔차를 가역 부분의 기준 압력 선택으로 없애기, P_ref,f를 어떻게 잡으면 쌍 합이 정확히 0이 되는가)가 있는가?
2. 재구성된 면 상태(u_L, u_R, P_L, P_R)와 셀 값 중 무엇으로 D_f를 정의해야 하는가? HLLC의 비대칭 Z, 이른 진공 분기(Δu > c에서 P*=1e-30), 2점 Gauss 면에서는?
3. RK4 단계마다 K를 dK로 적분하고 P = Kρ^γ를 기하 부피로 다시 계산하는 현재 구조에서, 시간 적분상 주의할 점(K 양성, 바닥값 1e-6과의 관계, 충격에서의 정확도)은?
4. 검증 계획: Hill 띠(회전 격자) 장기 안정, Sod(충격 가열·L1), 진공 팽창, Kepler 64²·256². 총에너지 잔차를 어떻게 장부화할지.
