# 자문 요청 (8차): 진공 경계 정식화 — 안 (가)와 안 (나)

작성: 2026-10-01. 사용자 원칙: 패치 금지, 물리·수학적으로 정합한 solver, 입자 = 생성점(생성점을 셀 중심으로 옮기지 않음). 이전 답: `Docs/consult_edge_reconstruction_reply_astra.md`(7차, "진공 경계를 먼저 정식화하라").

## 1. 측정 (7차 이후, `Docs/analyze_edge_faces.py`, 커밋 `ca0f1f3`)

GIZMO 입자판 Kepler, 1랭크 CPU. 가장 안쪽 고리(0.49 ≤ r < 0.53)의 면을 "면 중심이 입자 쌍 축에서 벗어난 거리 / d"로 나눠 법선 압력 토크를 쟀다(힘 호출 1회당).

| 오프셋/d | 면 수 | P*/P 중앙값 | 토크 (H) | 토크 (1) |
|---|---:|---:|---:|---:|
| < 0.25 | 48 | 0.02 | +1e-8 | +3e-7 |
| 0.25–0.75 | 80 | 0.20 | −1.5e-5 | −2.3e-5 |
| ≥ 0.75 (셀 상한으로 잘려 진공 쪽으로 뻗은 긴 옆면) | 48 | 5.4 | **−6.4e-5** | **−7.4e-5** |

- t≈0.1 가장 안쪽 고리의 각운동량 손실 가운데 약 80%를 긴 옆면이 만든다.
- 재구성은 셀 값 법선 점프를 5.5배만 줄인다(내부는 10–100배).
- (H)의 VPH 접선 토크는 법선 토크의 0.4%(t≈0.1), 1–3%(t≈5)다.
- t≈5에는 입자들이 안쪽으로 밀려 들어오고 격자가 흐트러져, 손실이 일반 면으로 퍼진다.

## 2. 두 안

**안 (가): 셀 상한(`VORO_CELLBOX`, 생성점 중심 정사각형, 한 변 5Δ)을 물리적 자유표면으로 본다.**
- 잘린 변을 진공 면으로 보고 부피율과 `−P dV` 일 장부에 넣는다((H)에는 이미 넣었다: 생성점과 함께 강체 이동, `v_i·A n`).
- 가장자리 셀은 진공 쪽으로 상한 정사각형까지(지금은 약 2.5Δ) 뻗는다. 필요하면 상한 크기의 물리적 의미를 정한다.

**안 (나): 셀 상한은 계산상의 절단이고, 유체 영역 Ω(t)를 따로 정의한다(사용자가 선택한 방향).** 제안하는 구체안은 다음과 같다.
- 각 입자에 반경 `R_i = sqrt(W_i + ρ²)`인 원판 B_i를 두고 `Ω = ∪ B_i`(ρ는 전역 상수)로 정의한다.
- 셀은 `V_i = |C_i ∩ B_i|`(C_i는 Laguerre 셀)이다.
- 주장: x ∈ C_i ∩ B_j이면 `|x−x_i|² − W_i ≤ |x−x_j|² − W_j ≤ ρ²`이므로 x ∈ B_i다. 따라서 `C_i ∩ Ω = C_i ∩ B_i`, `Σ V_i = |Ω|`가 정확하다(restricted power diagram, 알파 형상과 같은 구조).
- 내부 셀은 ρ > (내부 셀 외접 반경)이면 바뀌지 않는다. 정사각 격자 간격 Δ면 ρ > Δ/√2이다. 제안값은 ρ = Δ다.
- 원호 변은 진공 면이다(P*=0, 힘 없음). 원호의 법선 속도는 `v_i·n + Ṙ_i`, `Ṙ_i = Ẇ_i/(2R_i)`이고, 이것을 부피율과 일 장부에 넣는다.
- 구현은 원판을 정N각형(N≈64)으로 근사해 지금의 정사각형 상한 자리에 넣는다. 정확한 원호 교집합은 나중 단계로 둔다.
- 기존 `VORO_CELLBOX`는 계산상 상한으로 남긴다(ρ보다 크게).

## 3. 질문

1. **두 안을 비교해 달라.** 입자 = 생성점, Lagrangian 질량 고정, 에너지 항등식(§3, D_f), (H) DAE(`V(x,W) = V^T`)와의 정합성 기준으로 판단해 달라. 가장자리 셀 부피, 긴 옆면, 재구성과 제한자, Riemann 문제 관점에서 각 안의 장단점을 짚어 달라.
2. **안 (나)의 구체안 검증.**
   - (a) 위 포함 관계 증명이 맞는가? W가 변할 때 `R_i² = W_i + ρ²`가 요구되는 이유(ρ가 전역 상수여야 하는지, 국소 ρ_i이면 무엇이 깨지는지)를 짚어 달라.
   - (b) 원호 변의 부피율 `∮(v_i·n + Ṙ_i)dA`와 에너지 장부. 원호에서 P*=0으로 둘 때 `−P_i dV`의 원호 몫은 어떻게 되는가? 힘이 없는데 일이 있는 것이 정합한가? (자유표면의 등엔트로피 팽창으로 해석 가능한가?)
   - (c) (H) DAE와의 결합: V가 W에 의존하는 방식이 바뀐다(원판 반경도 W에 의존). Jacobian ∂V/∂W에 원호 항이 추가되는가? DAE 투영과 Ẇ 해에 어떤 변경이 필요한가?
   - (d) 기울기(LSF)와 제한자: 원호 변은 이웃이 없으니 지금처럼 건너뛰면 되는가, 아니면 진공 상태를 경계조건으로 넣어야 하는가?
   - (e) N각형 근사의 오차와 문제점. 회전 불변성은 어떤가? 방향을 입자마다 같게 두어야 하는가?
   - (f) ρ의 선택 원리. 입자 질량과 목표 밀도로 정해야 하는가, 격자 간격 비례로 충분한가? 우주론(해상도가 공간에 따라 다른 경우)으로 일반화하려면 무엇이 필요한가?
3. **권고:** 어느 안으로 가야 하며, 구현 순서는? 문헌(restricted power diagram, alpha shape, 자유표면 Voronoi/Lagrangian 방법, GIZMO의 진공 경계 처리 등)이 있으면 근거로 달아 달라.
