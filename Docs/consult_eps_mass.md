# 자문 요청 (21차): Kepler 시험의 연화 길이 ε와 입자 질량 배치

작성: 2026-10-02. 사용자 질문: **ε를 다르게 해야 하는지, 그리고 입자 질량을 다르게(Σ에 비례) 하는 것이 맞는지** 판단해 달라. 목적은 GIZMO(Hopkins 2015 §4.2.4, MFM)와의 공정한 비교이다. 사용자 원칙은 같다(입자 = 생성점, 셀 생성 알고리즘 유지, 조향 금지, 패치 금지, 총에너지 보존, 바닥값 1e-6).

## 논문과 원래 코드
- 논문: Σ(식 34) = 0.01 + (r/0.5)³ (r<0.5), 1 (0.5≤r≤2), [1+(r−2)/0.1]⁻³ (r>2), P=1e-6, γ=5/3. 퍼텐셜 Φ = −(r²+ε²)^(−1/2), V_c = r(r²+ε²)^(−3/4). ε 값은 없음. 각주 24: 최소 Σ와 부드러운 가장자리, 연화 퍼텐셜은 수치 발산 방지용이며 "작은 값이면 정성적으로 같은 결과". 입자 방법은 −2<x,y<2에 256² 격자를 깔고 "밀도 분포에 맞도록 입자를 제거". GIZMO는 개별 시간간격, CourantFac 0.025, 엔트로피 전환, DesNumNgb 20(예제 설정).
- 공개 GIZMO 코드의 시험 함수 `GravAccel_KeplerianTestProblem`은 연화 없이 0.35<r<2.1에서 점질량, r≤0.35에서 g = (r/0.35)² − (0.35−r)/0.35(r<0.216에서 척력), r≥2.1에서 가둠. 주석은 "bounded and softened". 논문과 다른 판일 수 있다.
- 사용자의 원래 LagEunha Kepler 코드: 식 (34), Plummer ε=0.1, 상자 [0,6]² 균일 격자, **질량 = Σ × 격자 셀 부피**, R<2.5만 진화.

## 이 코드의 결과 (64², 간격 1/16)
| IC / 힘 | 결과 |
|---|---|
| 식 (34), 질량 ∝ Σ, ε=0.01 | 중심 근처 입자(r≈0.04, 공전 주기 0.06) 때문에 dt 1e-3 → 1e-4, 가열 r<0.15에서 시작, t≈0.5 폭주 |
| 같은 질량, Σ에 맞춰 솎아냄(GIZMO식) | 구멍 입자 간격 약 10Δ. Voronoi 셀이 거대해져 원반 가장자리 셀과 바탕 셀이 넓은 전단을 받음. t<0.75에 원반 내부 압력 4만 배, 즉시 붕괴 |
| 식 (34), 질량 ∝ Σ, **ε=0.1**, 기본 수치(면 중심 제한) | dt 3.6e-3 안정. 그러나 **구멍(r<0.5)에서 가열 시작**(t=2–6에 전체 내부에너지의 94–99%), t≈8–10에 구멍 기체 재배치, **t≈12–14(r=1 기준 2궤도)에 원반 붕괴** |
| 같은 IC, 중력만(유체 끔) | 모든 입자 원궤도 유지(원반 반경 오차 7e-11, 연화 핵 1e-6, 에너지 오차 5e-9). 그러나 차등 회전으로 가까운 쌍이 생겨 Voronoi 셀 밀도 m/V가 원반에서 0.25–4배로 출렁임(입자 위치는 정확) |
| 진공판(0.5≤r≤2만, ε=0.01), 이번 세션의 수치 덧댐 | 64²에서 안쪽 가장자리 붕괴 t≈40–52, 256²에서 t≈60 |

진단(§26.2–26.3, Hill 띠): 흐름에 비스듬한 격자가 전단으로 바늘 셀로 퇴화 → 재구성 잡음 약 0.2c → HLLC 소산 가열 → 음속 증가 → 잡음 증가.

## 질문
1. **ε:** 이 코드(전역 시간간격, Voronoi)에서 ε를 어떻게 정해야 정합하고 공정한가? 논문 "작은 값이면 무관"을 근거로 원반(r≥0.5)에 영향이 작은 범위에서 키우는 것(예: 0.1–0.2)이 타당한가? 연화 핵 안 각속도(Ω≈ε^−1.5)가 구멍 기체의 격자 퇴화를 가속하는 문제와 어떻게 균형을 잡아야 하나?
2. **입자 질량:** Voronoi 이동 격자에서 식 (34)를 표현할 때 균일 간격 + 질량 ∝ Σ(AREPO식)와 같은 질량 + 솎아냄(GIZMO식) 중 무엇이 정합한가? 같은 질량 방식이 Voronoi에서 실패한 이유(거대 셀)는 근본적인가? 중간안(예: Σ에 따라 간격을 바꾸는 격자, 즉 입자 수 밀도 ∝ Σ^α)이 있는가?
3. 구멍 기체(질량은 작지만 원반과 같은 해상도)가 원반 붕괴를 주도하는 것이 시험의 본질인가, 표현 방식의 인공물인가? GIZMO와 비교할 때 무엇을 같게 맞춰야 하는가(밀도장, 입자 배치, 시간간격, 엔트로피 전환)?
4. 권고 구성과 그 근거.
