**결론: 구현 1차 감사는 통과 보류입니다.** HG의 핵심 미분·힘–열 장부와 면 상태 Z는 제한된 내부 셀 조건에서 맞습니다. 그러나 **공유 면과 셀 부피의 불일치**, **설계와 다른 시간 간격**, **퇴화·경계 셀 처리 누락** 때문에 설계 1–5단계 완료에는 서명할 수 없습니다. Sod 결과는 유망하지만 전체 관문 통과로 확정하기에는 증거가 부족합니다.

대상은 `/tmp/lageunha-push`, `LagEunha`, HEAD `98d4829`입니다. 요청서·설계서·양측 감사 기록·관련 코드와 기준 스크립트를 검토했습니다. 파일을 변경하지 않았으며, 작은 정적 수식 검사만 수행했습니다. C 동역학 결과는 재실행하지 않았습니다.

**수정이 필요한 사항**

1. **[P1] `shf_common`은 에너지 교환을 대칭화하지만, 설계의 공유 기하를 구현하지 않습니다.**

   [설계서](/tmp/lageunha-push/Docs/design_astra.md:385)는 사후 교집합을 명시적으로 금지합니다. 그런데 [구현](/tmp/lageunha-push/Exam/exam.c:597)은 독립적으로 만든 양쪽 면의 교집합을 취하고, 상대 면을 찾지 못하면 길이를 0으로 만듭니다. 셀 부피·중심은 [기존 다각형](/tmp/lageunha-push/Exam/exam.c:4143)에 남고, HG도 교집합 이전 면 길이를 사용합니다. 따라서 힘·열역학·HG가 같은 기하를 참조하지 않습니다.

   이를 [기존 cap 기하](/tmp/lageunha-push/Docs/subzonal_checks/cap2d.py:29)로 정적 검증했습니다. 상자 변 5, 생성점 `(0,0)`, `(1.8,1.1)`, 초기 밀도 1, 압력 `(1,2)`인 비퇴화 두 셀에서:

   - 교집합 TCF 힘: `(-5.8500, -3.5750)`
   - 실제 셀 에너지의 유한차분 힘: `(-5.29782, -6.73115)`
   - Q=HG=0, 속도 `((1,0),(0,0))`에서도 셀별 `U̇ + P V̇ = (0.18406, 0.36812)`

   차분 간격을 바꿔도 유지됩니다. 속도를 반전하면 마지막 잔차도 음수가 됩니다. **총에너지 교환의 상쇄만으로 셀별 단열성·엔트로피 조건은 보장되지 않습니다.** 이 반례는 독립 cap 경로에 대한 것이며, 완전 주기 분할 전체가 틀렸다는 뜻은 아닙니다.

   공통 면과 닫힌 셀을 함께 구성해야 합니다. 주기 영역에서 한쪽 면이 없다는 사실을 곧바로 진공으로 해석해서는 안 됩니다.

2. **[P1] 실제 시간 간격은 정정된 `Δt_geom`도 아닙니다.**

   [현재 코드](/tmp/lageunha-push/Exam/exam.c:8030)는 셀 음속으로
   `2·Courant·d/(c_i+c_j−min(0,Δv·e))`와 `0.1d/|Δv|`를 계산합니다. 설계의 **면 음속 `c_if`와 높이 `h_if`**를 사용하는 제한이 아닙니다. HG의 `C+qC′`에 대응하는 제한·진단도 추가되지 않았습니다.

   [RK 중간 단계](/tmp/lageunha-push/Exam/exam.c:13338)에서 새로 얻은 `dt`는 현재 단계의 재시도에 사용되지 않으며, [고정 dt](/tmp/lageunha-push/Exam/exam.c:13262)는 CFL을 초과해도 경고만 하고 적용됩니다.

   스펙트럼 제한을 무조건 진단으로만 내리는 정정에도 서명하지 않습니다. [기존 로그](/tmp/lageunha-push/Docs/design_audit_scripts/audit_pair3_64.log:2)는 질량비 64에서 Mach 10·100에도 `dE=8e-3, 2.3e-2`를 기록합니다. 극단 Mach 1000만의 문제가 아닙니다. 실제 면 기하 제한, 단계 거부·반분, 감쇠 안정성 검증이 필요합니다.

3. **[P1] HG의 순위 결손 처리가 설계 및 Python 기준과 다릅니다.**

   [C 구현](/tmp/lageunha-push/Exam/exam.c:780)은 determinant 문턱 아래에서 **셀의 HG 전체를 끕니다.** 설계는 QR/SVD 처리를 요구하며, Python 기준은 `pinv`를 사용합니다.

   또한 꼭짓점 Jacobian 실패, stencil 누락, 면 상태 부적합을 일부 경로에서 조용히 건너뜁니다. `SHF_K=64`, `HG_MAXS=512` 초과도 명시적 실패가 아닙니다. 따라서 현재 `skip=0`만으로 모든 면과 미분이 정상 처리됐다고 판단할 수 없습니다. 순위 처리와 누락 진단을 보완해야 합니다.

4. **[P1, 경계 시험 진입 전] 원호·벽 HG와 면 상태 중심이 미완성입니다.**

   [HG 호출부](/tmp/lageunha-push/Exam/exam.c:8117)는 cap·원호 셀을 제외하고, `sub_build`는 벽 고스트가 있는 셀을 제외합니다. 이는 설계의 경계 미분·고스트 연쇄 요구를 충족하지 않습니다.

   [cen_poly](/tmp/lageunha-push/Exam/exam.c:661)는 원호를 현으로 연결한 다각형 중심을 계산합니다. 원형 분절 모멘트가 없어 원호 셀의 면 상태 Z에 필요한 중심과 다릅니다. 경계가 없는 내부 HG 시험은 평가할 수 있지만, **HG를 켠 자유 표면·Hill 띠·Kepler는 아직 승인 대상이 아닙니다.**

5. **[P1] `GFS_PERIODIC_COMPLETE`는 단계별 완전성 관문이 아닙니다.**

   [기하 패스](/tmp/lageunha-push/Exam/exam.c:3792)마다 계수를 초기화하지만, 실패 검사는 [단계 종료 진단부](/tmp/lageunha-push/Exam/exam.c:13850)에 있습니다. 중간 RK 단계의 실패를 모두 잡지 못하며, 부피 합은 출력만 하고 오차 기준을 강제하지 않습니다. 탐색 이웃은 늘려도 작업 상자는 고정입니다.

   매 기하 구성 직후 `cap=0`, `|ΣV/Vbox−1|<10⁻¹²`를 검사하고, 재구성 또는 단계 실패로 처리해야 합니다. 기록의 “한쪽 면 약 21개/단계는 퇴화”도 면 길이·잔차 증거 없이 확정할 수 없습니다.

6. **[P2] 적용 조합과 진단이 실제 계산을 충분히 보호하지 않습니다.**

   [HG 래퍼](/tmp/lageunha-push/Exam/exam.c:9464)는 한 rank와 공유 면만 요구합니다. `SEDOV_PHASE1` 없이도 `die += v·F+H`를 실행할 수 있는데, 내부에너지 경로에는 `H`만 더해야 합니다. 지원 모드를 강제하거나 에너지 경로를 분기해야 합니다. Φ·조향 등 금지 조합도 명시적으로 거부해야 합니다.

   [면 상태 비율](/tmp/lageunha-push/Exam/exam.c:7794)은 `10⁻¹²`로 조용히 절삭됩니다. 이는 양성 실패를 숨기므로 발생 횟수와 원인을 기록해야 합니다. 또 면 덤프는 실제 `Zq` 대신 이전 `tcf_Z`를 출력하고, [엔트로피 적분 진단](/tmp/lageunha-push/Exam/exam.c:8255)은 HG 열을 포함하지 않습니다.
