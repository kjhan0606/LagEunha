## 발견 및 수정

최초 전체 발견 실행 JR: 111개 테스트 모듈, 388개 검사 중 2개 오류.

1. 공통 초기조건 함수 `adaptive_moment_batch.setup`과 도메인 설치 함수가 모듈 전역의
   경계조건을 변경한다. 전단류 검사가 이전 테스트의 정지 경계조건을 물려받으면
   잘못된 경계 Riemann 문제로 비양의 HLLC star pressure 오류가 났다.
   해당 검사는 자신의 전단류 경계조건을 명시하고 종료 시 이전 설정을 복원한다.
   도메인 설치를 직접 사용하는 다른 검사도 cleanup을 추가했다.
2. Python만 복사한 검증 스냅샷에는 OpenMP 공유 라이브러리가 없었다.
   원래 C 소스를 함께 보존하고 lageunha에서 `gcc -O3 -shared -fPIC -fopenmp`로 빌드했다.
   OpenMP 검사를 건너뛰지 않는다. 해당 검사에서 환경변수 변경도 복원한다.

첫 수정 JS에서는 간접 호출인 `setup`의 설정 누수를 모두 다루지 못해 1개 오류가 남았다.
JR/JS 실패 로그는 보존했다. 최종 JT는 위 전단류 fixture 수정까지 포함한다.
추가 실행기 `run_verification_suite.py`는 각 테스트 종료 때 도메인 함수 및 환경변수를
복원하고, 역순 실행과 JSON 결과 출력을 지원한다. 검사 선택/허용 오차는 변경하지 않았다.
