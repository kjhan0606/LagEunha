# 자문 요청 (4차): 혼합형 (H)의 C 이식 설계 — 가이드라인

작성: 2026-09-30. 사용자 지시: 입자 = 생성점 Laguerre 유체에서 물리적·수학적으로 정합한 self-consistent solver를 찾을 것. 패치식 대응 금지(한도, 바닥값, 벌점 추가로 증상을 막지 말 것).

배경 문서: `Docs/gfs_scheme3_formulation.md` §3(정식 F), §19(H), §21–22(자문 루프 합의: `W = h²ω`, 엔트로피 명제), §24(GIZMO Kepler: Green–Gauss와 열린 셀). 1–3차 자문 답은 `Docs/consult_*`에 있다.

## 1. Phase A: 지금 구현하는 것 (C, CPU 유체 경로, 1랭크, 기본 꺼짐 `GFS_SCHEME_H=1`)

기존 `GFS_DYN_W2` 배관(W를 RK4 상태로 적분하는 `gfs_dynw2_set`, 면 속도의 `(Ẇ_i−Ẇ_j)/2d` 항, 실제 면 속도로 일 계산)을 재사용한다.

- **W 법칙(단계마다):** `K Ẇ = rhs`, `K`는 면 가중치 `A/(2d)`의 그래프 라플라시안이고 Jacobi-PCG로 푼다(평균 0).
  ```text
  rhs_i = Σ_f A u*_f − Σ_f A(ũ_f + ρ_f) + (V_vor,i − V^T_i)/τ_V + (V^T_i − V_i)/τ_C
  V̇^T_i = Σ_f A u*_f + (V_vor,i − V^T_i)/τ_V
  ```
  - `u*`는 셀 상태 HLL 평균(`hll_star_state`)으로 계산한다. 목표 정의일 뿐이며, 에너지는 어떤 Ẇ에서도 정합하다.
  - `V_vor ≈ V − K W`(∂V/∂W = K의 선형화)로 두어 추가 테셀레이션을 피한다.
  - V^T는 두 번째 RK4 상태다.
- **힘:** `f_ij = −A[P* n + (P_j − P_i) t/d]`. `P*`는 면 압력 전체(HLLC, 극단 HLL, 쌍 압력 포함)이고, t는 앵커(`φ = ½ + ΔW/2d²`) 기준 면 중심의 이탈이다.
- **에너지(SEDOV_PHASE1 총에너지율):** `die_i += v_i·f − P_i A w_f + θ_i D_f`.
  - `w_f = ũ + ρ + δ`는 실제 면 중심 속도다.
  - `D_f = A[(P_i−P_j)δ + (P* − P̃)(u_i−u_j)]`, `P̃ = φP_j + (1−φ)P_i`
  - `θ`는 재구성 상태의 좌우 Godunov 몫 비율이다.
- 기울기는 LSF(`gradient_method=1`), 셀 상한은 5Δx, η=0.06이다.
- 유효성(`|ΔW| < d²`)은 Phase A에서 **보장하지 않고 측정만** 한다.

## 2. 질문

1. **Phase A의 식과 배치에 결함이 있는가?** 특히 다음을 봐 달라.
   - (a) 셀 상한으로 **열린 셀**(이웃 없는 면, 힘·일 없음)에서 VPH 에너지 항등식이 깨지는 양은 `P_i v_i·Σ_cap A n` 수준이다. P=10⁻⁶이면 무시해도 되는가? 원리적으로는 잘린 면을 어떻게 다뤄야 정합한가(잘린 면은 생성점과 함께 강체 이동, 진공 면 압력 0)?
   - (b) `u*`를 목표에서 셀 상태 HLL로 쓰고, 힘에서는 MUSCL+HLLC `P*`를 쓰는 불일치가 원리적으로 문제인가?
   - (c) 쌍 압력을 `P*`에 포함한 채 D_f를 계산해도 되는가?
   - (d) `V_vor ≈ V − KW` 선형화가 W가 커질 때 문제인가?
2. **Phase B: 유효성을 구조적으로 보장하는 W의 적분 방법**
   - 합의된 매개화는 `W_i = h_i² ω_i`, `|ω_i| ≤ ½(1−δ)`, `h_i ≤ min_j d_ij`(Fable 4라운드의 매끄러운 하계)다.
   - 원하는 Ẇ*(위 LS 해)를 받아 ω를 어떻게 적분해야, **(i) 상한을 넘지 않고, (ii) 에너지 기장이 실제 Ẇ = h²ω̇ + 2hḣω로 정확하며, (iii) 유한 시간 특이점(예: tanh 포화에서 ξ̇ → ∞)이 없는가?**
   - 후보: `ω = ω_max tanh ξ`, ω̇를 사영하는 방법(상한 근처에서 바깥 방향 성분만 0), ω-공간 LS에 대칭계 `DKD` 사용 등. 각각의 장단점과 권고를 달라.
   - 사영은 "패치"인가, 아니면 제약된 동역학의 정당한 정식인가? 판단 근거를 달라.
3. 이 설계에서 1랭크 제약(전역 PCG)을 넘어 MPI와 개별 시간간격으로 갈 때의 구조적 장애를 짧게 짚어 달라.
