충격면 셀에서 Φ/U_cell 최대 10–14%(Sod·Noh), 전체 ΣΦ/ΣU = 0.1%. Φ는 충격 구조에 국소적으로 참여하지만 도약과 위치를 바꾸지 않는다. 평탄부에서 속도 잔류 < 1e-4로 **보존 퍼텐셜의 되튐은 Q가 완전히 흡수**했다(1D에서는 minmod Q=0 면이 문제 되지 않음).

§6 정지 거리 추정 d/2h ~ M^{−2/γ}는 정적 단일 쌍 가정이라 지나치게 비관적이다. 실제로는 압축이 수 셀에 걸쳐 진행되며 c가 ρ^{1/3}로 커져 Q 가열이 따라붙으므로 M≈770에서도 0.175 h에서 멈췄다.

**2차 Q 제안(엔트로피 부호·연속성 양립):**

  δ = minmod(Δu_rec, Δu_cell), a = ¼(γ+1)|δ|, **Z = ρ̄ [ a + √(a² + c̄²) ]**, Q = Z δ.

정확 2-충격 Hugoniot의 임피던스(Wilkins 1980)이다. δ→0에서 ρc, 강한 충격에서 ½(γ+1)ρδ²(vNR). Z≥0이고 δ·Δu_cell≥0이므로 Q·Δu_cell≥0, 0 근처 연속, 문턱 없음. TCF의 Davis HLLC Z_eff는 강한 극한에서 이와 같은 꼴이므로 사실상 이미 포함돼 있지만, solver 분기(압력비·진공 판정·Roe fallback)와 무관하게 하한을 보장하려면 위 식을 Z_eff의 바닥으로 두는 것을 권한다.

## 3. §9 답변

1. **장부·P_i^0**: 정확하다. 1D에서 F=−∇U, K̇=H^Q/G로 세 변형 모두 dE/dt≈1e-7(유한차분 한계) 확인. 단 𝓗 dM 항은 2D에서만 검증된다.
2. **기본 변형**: **(나)**. 1D에서 (나)와 (나′)는 모든 지표가 잡음 범위에서 같다. (나)는 매개변수가 없고 장벽이 실제 EOS 압력이다. (나′)를 쓰면 **Φ^lin을 셀 내부에너지에 넣어야 한다**(c_i² = γK_iρ_i^{γ−1}로 U_i = K_i G_i(x) 꼴). c²를 동결한 별도 퍼텐셜은 s가 변할 때 보존이 깨진다. 일반 EOS에서는 어느 쪽도 K 역산이 1D 근 찾기이므로 (나′)의 "역산 자명" 장점은 이상기체에 한한다.
3. **충격**: 압축 셀에서 기준을 바꾸는 식의 스위치는 **불필요**하다(위 결과). 2차 항은 **필요**하되 충돌 방지가 아니라 Δt·가열 효율을 위해서다(선형 Z만으로도 (나)는 충돌하지 않는다). 형태는 위 Wilkins Z.
4. **C¹ 결여**: 1D에서는 flip이 없어 검증 불가. 총에너지를 적분하고 U=E−KE로 복원하면 에너지는 정확하고 비용은 엔트로피 장부 오차로 나타난다. 2D Sod/Hill에서 flip률×힘 점프×Δt를 계측해 TCF 소산 가열보다 작으면 수용. Astra의 모멘트형 Φ는 장벽이 없어 단독으로는 Noh 첫 충돌을 못 막는다 — 대안이 아니라 보조.
5. **빠진 시험**: (i) 1D Noh(여기서 수행; 선형 Z 대비로 Δt 비교 포함) (ii) 질량∝밀도 Sod(2D 진단 설정; 1D에서 재현됨) (iii) 2D 경사 충격(글래스 격자)에서 Φ/U와 벽 가열 (iv) 균일 압력 불규칙 격자의 Φ 힘 크기(G2 보완) (v) 충격 뒤 K의 홀짝 패턴(엔트로피는 라그랑주적이라 감쇠 기제가 없다 — Noh 벽 근처 밀도 패턴의 원인) (vi) Hessian 기반 Δt vs 간격/c CFL 비교(1D에서는 CFL 0.25·min gap/(c+|Δv|)로 안정).
