작성: 2026-10-01. 원칙은 같다(패치·임의 조정값 금지, 입자 = 생성점, 셀 생성 유지, 바닥값 1e-6 유지, DTETA 미사용).

### 2. 내부에너지의 지수 성장 (모든 실행 공통)
| 실행 | E_int | e-폴딩 |
|---|---|---:|
| Hill 띠, 회전 격자 | 1.4e-5 → 2.1e-2 (t=0 → 40), 8.3 (t=67) | 약 3.0궤도 |

| 좁은 고리 A | 1.8e-5 → 7.4e-3 (t=0 → 360) | 약 3.4궤도 |

- 총에너지(운동 + 내부 + 조석/중심 퍼텐셜)는 1e-3 이내로 보존. 단계 바닥 주입은 누적 2.5e-3으로 무시 가능. 증가한 운동·내부에너지는 퍼텐셜(띠·원반의 퍼짐)에서 온다.
- Hill 띠에서 rms(v_x)/c ≈ 0.8, 0.3, 0.4 (t=13, 31, 44). 잡음이 음속을 따라간다.

## 가설
격자 재연결 잡음 δu ∝ c → HLLC 소산 가열률 ∝ ρ δu² Ω ∝ c² Ω ∝ E_int Ω → dE_int/dt ∝ Ω E_int → 궤도당 일정한 지수 성장. 정렬 격자는 재연결이 없어 잡음·가열이 없다. Kepler에서는 데워진 가장자리가 진공으로 밀려 침식되고, 결국 붕괴한다.
