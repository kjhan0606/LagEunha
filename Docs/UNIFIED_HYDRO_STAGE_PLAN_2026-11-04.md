# 차원 공통 유체역학 개발 단계

사용자가 2026-11-04 확장한 목표는 contact 오차의 원인 규명, 같은 기법의
1D/2D/3D 적용, 자기일관성과 단순성, 동등한 GIZMO 실행시간의 2배 이하,
그리고 같은 기법에 의한 2D 시험 재수행이다. 이 문서는 진행 계획이다. 최신 결과와 제한은
UNIFIED_HYDRO_PROGRESS_2026-11-04.md에 기록한다.
전체 목표는 아직 완료되지 않았다.

## 확정한 출발점

1D 정지 contact의 기하·질량·에너지 초기화 불일치는 33개 C 대조
계산으로 확인했다. CONTACT_1D_CAUSAL_AUDIT_2026-11-04.md에 기록했다.
이 결과는 Kepler 전단 오차나 생성된 충격 contact 전체를 해결했다는
뜻이 아니다.

계획은 Astra에 한 번 검토받았다. 운전자가 구현한다.
첫 공통 후보는 W=0, 진화 중 고정질량, 조향 없는 변분 압력이다.
rho=m/V, P=(gamma-1)U/V와 실제 기하 미분 B=dV/dx를 사용한다.
힘은 B^T P, 열일은 -P Bv다. 차원별로 다른 압력법을 쓰지 않는다.
정확 단열 체적 갱신은 유한 시간간격의 정확 총에너지 보존과 구분한다.

동적 가중치는 위치 기하 이외의 체적 일을 발생시키므로
별도 일반화 일·에너지 폐쇄식 없이 추가하지 않는다.
일반 fixed-mass와 equal-mass는 구분한다.

## 영모드와 소산에 관한 결정 조건

1D W=0 내부 셀에는 V_i=(x_(i+1)-x_(i-1))/2이므로 교대 생성점
변위와 속도가 체적 연산자의 영모드가 된다. 따라서 bulk compression
q(rho,c,Vdot/V)만으로 생성점 접근을 막을 수 있다고 가정하지 않는다.
먼저 작은 교대모드 감사로 한계를 확인한다. 체적 양수성 외에
생성점 순서와 최소 간격을 검사한다.

보존적 face-normal pair 소산은 후보지만 단순 접근 조건은 Kepler
전단에서도 활성화될 수 있다. 기존 재구성을 사용한 affine-exact
접근 잔차를 평가한다. 선형 전단, 고주파 압축, 곡률 있는 원운동의
소산을 함께 측정하기 전에 채택하지 않는다.
bulk AV 위에 임시 복원력과 문제별 계수를 계속 추가하지 않는다.
Re=infinity는 물리점성 0이며 Euler shock의 수치적 엔트로피 생성은
별도로 기록한다.

초기 공통 적분은 global KDK를 목표로 한다. 기존 block2는 한 랭크,
Kepler 고정 polygon 조건과 비동기 교환 한계를 갖는 별도 기준선이다.
충격 검증 없이 같은 block2를 새 공통 solver로 부르지 않는다.

## 속도 및 실행 규칙

같은 기준이라면 기존 약 3.339배의 시간을 2배 이내로 줄이려면
추가 약 1.67배 가속이 필요하다. 미수렴 해나 다른 출력량의 실행을
빠른 결과로 집계하지 않는다. geometry, force, transfer, MPI, I/O,
accepted/rejected steps 및 실제 dt를 분해한다.
독립 시험은 동시에 실행하고 구현이나 build에 의존하는 시험은
검증된 빌드가 준비된 뒤 실행한다. 장기 계산은 통과한 solver에만 쓴다.
/scratch는 사용하지 않는다. 계산과 새 소스 checkout은 /gpfs에 둔다.
