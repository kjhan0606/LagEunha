# 감사·설계 요청 (Astra, 10차): TCF 내부에너지 교환의 갈릴레이 불변성 위반

작성: 2026-10-04. 배경: Kepler 진공 고리(고리 IC, 원판 ρ=1)에서 TCF가 이전 세대 코드보다 2배 이상 빨리 안쪽 가장자리가 무너진다. 인수인계 `Docs/HANDOVER_2026-10-04.md` 5.2절.

## 측정
1. **가장자리 덤프** (9f5ce00, 면 Z Q + HG 분리, call 200(t≈1.8)과 1120(t≈10)). 고리별 순간 변화율 ÷ U:
   - Q 열: 안쪽 가장자리 고리 k=0,1에서 0.33/0.42, 내부 2–7e-3, 바깥 가장자리 3e-3. 가장자리 |du_rec|/c는 0.24/0.15, 내부는 0.008–0.02이다(du_cell/c ≈ 7–12, 전단 때문). 관측된 가열률(ln10/10 ≈ 0.23)과 맞는다.
   - 가역 교환 dE_rev와 −P dV_geom(`tcf_dV`)의 차이: k=0 −14.6, k=1 +17.8, 내부 ±2e-2, 바깥 가장자리 −0.6/+0.45. 셀 부피는 거의 변하지 않는데(정확 궤적 오차 < 1%) 가역 교환이 고리 0과 1 사이에서 U의 15배/시간 규모로 에너지를 옮긴다.
2. **갈릴레이 시험** (`/gpfs/kjhan/LagForce/TCF_galilean_9f5ce00`): 32² 글래스, P = 1 + 0.5x, Q=0, 균일 병진 UX, 첫 RHS 덤프. (dE_rev + P dV)/U 내부 셀 평균은 UX=0, 10, 100에서 0, −2.68, −26.8이다(UX에 정비례, 셀 간 산포 거의 없음). dV = 0이다. 즉 **균일 병진에서 dE_i = F_i·V**(F_i = 셀 i의 압력힘)이다. 총합은 0이고 이음매 셀이 반대 부호를 받는다.

## 운전자 분석
현 식 dE_i = −A[(P_j u_i + P_i u_j)/2 + (P_j v_i − P_i v_j)·t/d + Q(u_i + u_j)/2]는 면마다 정확히 F·v를 상쇄하도록(닫힘 조건 Σ A e = 0 없이) 고른 분할이다. 그러나 셀별로는 −P_i dV_i/dt가 아니다. 병진에서 dE_i = F_i·V로 갈릴레이 불변이 아니며, 가역 과정인데도 셀 엔트로피가 바뀐다. Kepler에서는 궤도 속도(≈1.4)가 음속(1.6e-3)의 약 900배이고, 원판으로 닫은 가장자리 셀은 압력이 내부의 약 0.54배이다. 그래서 가장자리 고리 사이에 거대한 가짜 교환이 생긴다.

갈릴레이 불변이고 셀별로 정확한 형태는 dE_i^rev = −P_i dV_i/dt이다. dV_i/dt는 그 셀의 정확한 기하 미분(면 항 + 원호/cap 항)이다. 이때 Σ_i P_i dV_i/dt = −Σ F·v가 되려면 힘 F가 같은 V(x)의 정확한 음의 기울기여야 하고, 원호를 포함해야 한다. 닫힌 셀(주기 상자)에서는 현 F가 정확한 기울기이므로 dE_i = −P_i dV_i/dt로 바꾸면 에너지와 셀 엔트로피가 모두 보존된다. 원판 원호가 있는 셀은 원호 항의 힘과 dV를 함께 정의해야 한다.

## 질문

2. 수정 설계: (a) 닫힌 셀에서는 dE_i = −P_i dV_i/dt로 바꾸고, (b) 원판 원호 셀에서는 V_i(x)의 정확한 미분(원호가 생성점과 함께 강체 이동)에 맞춘 힘과 dV. 장부, 반올림, RK4 정확도를 포함해 구현 가능한 수식으로 달라. Q 열은 별도로 유지.

## 정정 (운전자, Astra 10차 답신 후)
진단 1·2는 틀렸다. `dte`는 셀의 **총에너지** 변화율이다. 내부에너지 변화율은 `dte − v·F`이다. 다시 계산한 결과는 다음과 같다.
- 갈릴레이 시험: (dte − v·F + P dV)/U가 UX = 10, 100 모두 정확히 0이다. 갈릴레이 불변이다.
- Kepler 가장자리 덤프: (dU − H_Q + P dV)/U 잔차는 모든 고리에서 ≤ 4e-14이다. 가역 부분은 셀별로 정확히 −P dV이다. 가장자리 가열은 **전부 Q 열**이다(k=0: dU/U 0.324 대 H_Q/U 0.326, k=1: 0.421 대 0.422, t≈10에는 0.141 대 0.141).
남은 원인은 가장자리 셀의 큰 재구성 속도 점프(|du_rec|/c = 0.24, 내부 0.008–0.02)가 만드는 Q 열이다.
