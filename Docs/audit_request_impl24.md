# 자문 요청 (Astra, 24차): 원판 절단 없이 진공 고리(및 일반 자유표면)를 닫는 기하 구성 — 설계 선택

작성: 2026-10-08. 배경: 사용자 결정 A(DAE 보류, W=0 TCF 기준선 동결 `tcf-w0-baseline-2026-10-08`). 23차 답신 §2 "인공 원호가 남지 않도록 기하와 이웃 탐색을 완전하게 구성하는 것이 우선". 관련 이력: 8차(`consult_vacuum_boundary*`: 셀상자(가) 대 원판(나) → (나) 선택), 11차(원호 경계 상태), 27차(`consult_disc_role*`: 원판은 정합한 수치 경계 모형이지만 물리 자유표면 아님; 고립 입자 V≤πR² 반례; Hill 띠에서 **내부 셀도 잘려** 가짜 원호·바늘 셀·LSF 붕괴의 씨앗).

## 문제
- 고리 IC에서 안쪽 가장자리 입자는 볼록 껍질 위에 있지 않다(오목). 원판이 없으면 안쪽 가장자리 Voronoi 셀은 구멍을 가로질러 반대편 입자와 면을 이루며 거대해진다(측정값은 아래 §측정). 바깥 가장자리 입자는 볼록 껍질 위에 있어 셀이 무한하다.
- 원판(ρ·Δ)은 이것을 막지만 (i) 절대 길이 문턱, (ii) 내부 셀 절단(Hill 띠), (iii) 원호에는 이웃이 없어 W·QBP·HG·보안 반경 등 모든 장치가 특수 처리를 요구, (iv) 고립 입자 팽창 불가.
- 사용자 원칙: 입자=생성점, 조향 금지, 임의 문턱 최소화, 에너지 보존, Kepler(진공 고리)와 우주론(주기 상자, 진공 없음) 모두에 적용.

## 측정 (Python, 96² 고리 IC, 원판 없음)
| 고리 | 원판 없는 Voronoi 셀 부피 V/d² | 가장 먼 꼭짓점 거리/d | 볼록 껍질 위 |
|---|---|---|---|
| 0 (안쪽 가장자리) | 4.8 | 8.5 (구멍 중심 R=0.5까지 뻗음) | 아니오 |
| 1, 2, 22 (내부) | 1.00 | 0.6–0.7 | 아니오 |
| 23 (바깥 가장자리) | 무한(5 상자에서 183) | 80 | 예 |
원판(ρ=d)을 쓰면 고리 0은 V≈1.0 d²(원호 포함)로 닫힌다.

## 후보
1. **거울 유령 생성점(ghost):** 자유표면 입자 i마다 국소 바깥 법선 n_i 방향으로 거리 ℓ_i(국소 이웃 간격에서 결정)에 유령 x_i + ℓ_i n_i를 두어 이등분면으로 셀을 닫는다. 유령은 부모와 강체 이동(W도 거울). 유령 면의 쌍 힘은 P_ghost=0(진공)으로 TCF에 그대로 들어간다(−A·½P_i e, 바깥 밀기 = 자유표면 가속). 모든 장치(QBP 기울기, HG 코너 야코비안, 보안 반경, DAE 라플라시안)가 일반 면과 동일하게 동작한다. 쟁점: 자유표면 판정(셀 크기/무게중심 편차 문턱 또는 Delaunay 껍질·알파 형상), 법선·거리 규칙(ℓ_i = 이웃 평균 간격 → 절대 문턱 없음), 고립 입자의 팽창(ℓ_i가 이웃 간격을 따라 커짐).
2. **계층 주변 매질:** 진공을 매우 희박한 실제 입자(ρ≈1e-4 ρ₀, 가장자리 근처는 고리 간격과 같은 간격으로 계층화)로 채워 분할을 완전하게 만든다. 인공 경계가 전혀 없고 우주론과 같은 코드 경로. 쟁점: 희박 매질과의 상호작용(압력비 1e-4의 면), 입자 수, "진공 고리" 시험 정의와의 관계(GIZMO 비교는 Σ 바닥값 0.01 판이 따로 있음).
3. **원판 유지 + 결함 수정:** 절단을 자유표면 판정 셀에만 적용(내부 셀 보호), 원호에 유령 상태(P=0)와 W 거울을 부여. 쟁점: 여전히 절대 반경 문턱, 고립 입자 상한.
4. 기타 Astra 제안.
