### 가중치 문제의 수학적 근거와 범위

주어진 유계 밀도와 목표 질량에 대해 Laguerre 질량 제약을 Kantorovich 쌍대 최적화로
표현할 수 있다. 제곱거리 비용은 서로 다른 생성점에서 Reg/Twist 조건을 만족한다.
밀도와 목표의 총질량이 같을 때의 capacity 존재 문제는
[Kitagawa–Mérigot–Thibert, 정리1.1과 따름정리1.2](https://arxiv.org/pdf/1603.05579)의
설정에 들어간다. 이 근거는 **주어진 밀도의 가중치 문제**에 한정된다.
밀도 자체가 가중치·모멘트 닫힘과 얽힌 기존 일반 유체 문제의 해 존재를 증명하지 않는다.
또한 조각별 불연속 밀도의 generalized Newton 선택에 해당 논문의 매끄러운
Newton 수렴률을 그대로 적용하지 않는다.

### 구현과 검사

`transported_density_capacity.py`는 양의 convex 조각과 STRtree로 교차 질량을 계산한다.
내부 면에 대해 `c_ij=∫face rho ds/(2|r_j-r_i|)`인 희소 graph Laplacian을 사용한다.
조각의 공유 변을 면이 통과할 때 interval을 먼저 분할해 중복 합산을 막고,

면이 실제로 움직인 trial의 교차 질량과 양의 셀 조건을 다시 확인하는 damping을 한다.

### 비선형 Euler 정확 압축파

선형 음파 근사 오차를 피하기 위해 1D 등엔트로피 simple wave를 2D 상자에 넣었다.
`u0(x)=.02 sin^4(pi*(x-.2)/.4)`(.2<x<.6), 바깥0.
`c=1+(gamma-1)u/2`, `rho=c^(2/(gamma-1))`, `P=.6 rho^gamma`, gamma=5/3.
특성족 `x=xi+[1+(gamma+1)u0(xi)/2]t`의 역을 풀어 충격 이전의 비선형 정확해를 얻는다.
`u-2c/(gamma-1)`가 일정한 simple wave의 근거는
[Oxford 압축성 유동 강의](https://people.maths.ox.ac.uk/hewitt/publications/wcf.pdf)를 참고했다.
코드에서 Euler 보존식의 미분 잔차와 해석적 시간 미분을 독립 검사했다.
특성 교차/상자 경계 도달 전에만 참조를 허용한다.

초기화와 채점에만 정확해를 사용한다. 시간 RHS는 현재 수치6모멘트의 양의 연속

생성점은 수치 유체 속도, 셀질량은 원 배열 그대로이다.
