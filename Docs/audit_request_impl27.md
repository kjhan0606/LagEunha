## 26차 이후 결과 요약
1. 26차 권고 반영: fallback 제거(질량 생성 금지), 스텝 거부+하위 스텝, Σ m ln K 장부, flip 압력 점프 진단, 바깥 동결.
2. 2D Sod 64²: L1 ρ 0.0057(Q+ψ), 0.0085(Q 없음; 재배치가 소산 대행, S_remap 8배), 32→64² ≈1차 수렴, 에너지 1e-10. Gresho 64² t=3: L1 vφ 0.054(Q+ψ)/0.062(Q 없음)/0.048(c₂만), KE/KE₀ 0.83 — **KE 손실은 Q 유무와 무관**(Q를 빼면 재배치 혼합이 같은 양을 소산).
3. 잔여 성장의 판별(심은 모드 0.03d, 64²): 전단률 ×2·×½ → 성장률 불변(0.13, 0.22); 원반을 뜨겁게(P×100, c_s=배경과 동일) → 0.165(배경과 동일); c_s 0.21 → 0.006–0.03; c_s 0.068(원반) → ≈1e-3; **강체 회전(미끄러짐 없음) → 0.0300 정확 유지; 정지 → 유지, 재배치 0**; 96²에서 c_s/d를 64²와 맞추면 ≈0.08(64² 0.11–0.16, 96² 기준 0.17); dt/2 → −12%. 즉 rate ≈ c_s^1.8–2 × (d 의존), flip 필요조건, 전단률 무관.
4. 파탄은 전부 시험대의 회전 감쇠 영역(전단 Kepler의 3배)+동결 벽(R 2.3–2.8)에서 시작(기준 t≈28, 중력×4 t≈12, 중력×¼ 없음). 안쪽 배경 모드는 진폭 ~4에서 무해 포화. 넓은 감쇠(상자 8, 2.5–3.6) 장기 실행 진행 중(t=12 정상).

## 질문
1. **기제**: 연결 고정 구간은 해밀토니안이라 지수 성장이 없고, 강체·정지에서 성장 0이다. 전단이 주기적으로 일으키는 flip과 1차 겹침 재배치가 어떻게 **선형 지수 성장**(진폭 무관, 깨끗한 e-배)을 만드는가? (a) flip 순간 영역 압력의 불연속이 시간 주기 구동(파라메트릭)이 되는가, (b) 1차 재배치의 수치 확산이 특정 모드에서 반확산(음의 점성)으로 작용하는가, (c) 다른 가설. rate ∝ c_s²·d(전단률 무관)를 설명하는 규모식을 제시하고, 그 식을 판별할 최소 시험을 지정하라(가능하면 1D/주기 전단 상자 수준).
2. **2차 보존 재배치**: 옛 영역에서 ρ·e(또는 ρ·s)의 선형 재구성(최소제곱 기울기 + 단조 제한)을 새 영역과의 정확 겹침으로 적분하는 방식의 (a) 보존·엔트로피 비감소 조건(ΔS≥0이 자동이 아님 — 단조 제한으로 보장되는가), (b) 1번의 되먹임을 실제로 줄이는지에 대한 예측, (c) Gresho KE 손실(17%, Q 무관)과 원반 드리프트(1e-3)도 함께 줄어야 하는지. 대안(ALE형 플럭스 재배치, 영역 분할 후 합치기)과 비교.
3. **얇은 영역·겹침 실패 규칙**(26차 §3의 구체화): 질량 불일치 1e-3–1e-2는 겹침 적분의 누락인지(정밀도) 실제 비피복인지 판별법; 보존적 거시영역 병합의 상태 정의(m·U 합산, 넓이 합집합, 관성 m_a 재배분?)와 되돌리기 규칙; "역전 영역" 발생 시 스텝 거부 외의 원칙적 처리.
4. **미끄러지는 동결 벽**: 회전 유체가 동결 입자에 접하면(시험대 감쇠 영역, C의 R≥2.5 동결) 영역이 계속 전단되어 sliver가 쌓인다. 영역 중심 정식화에서 외부 경계(정지 저장소, 주기, 자유 표면)를 어떻게 정의해야 하는가? Kepler 100궤도 시험에 적합한 경계 구성(감쇠 폭, 동결 대신 압력 저장소 등)을 지정하라.
5. **입자 관성과 자가중력**: m_a 고정(t=0의 ⅓Σm_T) vs 재배치 영역 질량 m_T. 우주론 자가중력에서 중력원·관성 질량을 일관되게 정의하는 규칙(예: m_a = ⅓Σ_T∋a m_T를 매 스텝 갱신하면 운동량 보존이 깨지는가; 영역 질량을 중력원으로 쓰고 입자 관성은 별도로 두는 방식의 에너지 장부).
6. 위 결과로 **C 설계 착수(26차 §6 계획)**를 사용자에게 제안할 수 있는 상태인가, 아니면 2차 재배치·경계 규칙을 Python에서 먼저 닫아야 하는가. 결론 먼저, 한국어, 근거는 파일 위치로.
