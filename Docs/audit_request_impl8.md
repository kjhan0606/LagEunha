# 설계 결정 요청 (Astra, 8차): 쌍 제동에는 선형 항이 필요, Gresho는 선형 항에 민감

작성: 2026-10-04. 직전: `Docs/audit_impl7_astra.md`. 결과: `Docs/design_astra_audit.md` 마지막 절.

## 사실
- 법칙 (i)(음향 항 없음)은 쌍 시험(Mach ≥ 10)과 Sod에서 실패했다(0.033h, 단계 8배).
- 법칙 1(음향 + Hugoniot)은 쌍과 Sod를 통과했지만 Gresho t=0.75에서 −8~−9%이다.
- HG(아영역 ξ 잔차, 음향 계수)는 Gresho에 무해했지만(Q=0+HG가 HLLC 수준) 쌍 Mach 10을 막지 못했다.

## 운전자 제안 (iv): 2차 정합 기울기로 b′ 잔차를 만든다
7차 분석: 정확한 끝점 기울기를 쓰면 δ_f = d³/12 e·∂³_e v + O(d⁵)이고, O(h²)는 선형 QR 적합 오차 E_i = O(h∇²v)에서 온다.
- 기울기 G_i를 같은 2-hop stencil의 **가중 2차 LSQ 적합**(1, y, y⊗y의 6열 QR)의 선형 계수로 얻는다. 그러면 E_i = O(h²∇³v)이고, δ_f는 매끄러운 장에서 O(h³)이다. 2차 속도장에서도 δ_f = 0이다(사다리꼴 공식이 2차에 정확하고 적합도 정확).
- 계수는 법칙 1(음향 + Hugoniot, 면 상태 Z)을 유지한다. 쌍 제동은 법칙 1과 같다(두 셀 국소 모드는 2차 적합으로도 설명되지 않는다).
- 매끄러운 흐름의 음향 열은 O(h³)에서 O(h⁵)로 줄어든다. 기울기 꺾임 띠(r = 0.2, 0.4)에는 O(h)가 남는다.
- 위험: 2차 적합의 순위(6열)가 2-hop stencil(보통 18–30점)에서 충분한지, 조건수, 주기 영상 처리. 순위가 결손이면 그 셀은 선형 적합으로 대체하지 않고 진단한다(또는 지시를 따른다).
- bulk는 선형 적합 그대로 둔다(아핀 압축 감지). HG는 유지 또는 제거를 비교한다.

## 질문
1. (iv)의 정합성과 예상 차수가 맞는가? 쌍 제동이 법칙 1과 같다는 주장이 옳은가(2차 적합이 쌍 접근 모드를 일부 흡수하는가)?
2. 순위 결손·조건수 처리 규칙.
3. 대안이 있으면 지시하라. 예: 가역 부분에 쌍 복원력을 주는 정식(이전 아영역 Φ는 Gresho에서 전단 탄성으로 실패).
4. 시험 순서. 2D 기준 코드에서 연산자 시험(2차 장 δ = 0)과 쌍 시험 → C → Sod → Gresho 순으로 제안한다.
