# 현재 코드의 시간의존 Laguerre 가중치(w2) 구현 감사 (2026-10-08, 읽기 전용, HEAD 기준)

사용자 요청: "DAE 재개 전에 현재 코드의 동적 가중치 구현을 물리/알고리즘 관점에서 정밀 조사." 조사자: Claude(서브에이전트), 모든 주장은 파일:줄.

## 1. 기하
- 면 위치: `wfrac_ij = clamp(1/2 + (W_i−W_j)/(2d²), 0.05, 0.95)` (voro.h:262–265 `getwfrac`); 면은 x_i에서 e 방향 `wfrac·d` (voro.c:285–288, 209). 클램프 없으면 정확한 radical axis, exam.c의 앵커 `fact1=½(1+ΔW/d²)`(voro_eunha.c:86, exam.c:6652, 8646)와 일치.
- **클램프 효과**: 대칭(clamp(1−φ)=1−clamp(φ))이라 두 셀은 같은 면을 봄(분할 정합). 그러나 클램프된 면에서 ∂V/∂W=0이 되어 DAE/DYN_W2가 가정하는 `∂V/∂W=½L_{A/d}`(exam.c:9565–9570, 9640)와 면속도 `δ=(Ẇ_i−Ẇ_j)/(2d)`(6656–6667, 8655)가 틀림. GPU 커널도 같은 클램프(exam_gpu.cu:1956–1957).
- `drad2`(voro.c:1228–1242): 클램프 전 radical 거리²로 이웃 정렬·종료 → 클램프 면에서 잘라야 할 이웃을 건너뛸 수 있음(추정). 2D `maxdist2` 초기값 차원 불일치(voro.c:1207).
- `w2ceil` 두 정의: voro `min_j(d²+W_j)`(voro.c:1184–1196, 정확한 "생성점이 자기 셀 안" 상한)는 **미사용**(exam.c:12360, 12808, 13267 주석); exam은 최근접 거리²(W=0 기준)로 덮어씀(1936–1937, 2084–2090).
- 이웃 탐색: 3×3 블록 + 확장(4655–4663 등); 보안 반경 `voro_sec_short`는 W=0 기준 2R_v(4283–4298). Laguerre에서는 `φd<R_v` 기준이 필요(HANDOVER:140).
- 원판 닫힘 `EUNHA_VORO_RHO`는 "W=0, CPU 전용"; `GFS_DYN_W2`면 exit(4181–4205). 공통 반지름 분할 정확성은 W=0에서만 증명.

## 2. 가중치 동역학
- 공통 RK4: 스텝 시작 `w2old=w2; w2backup=w2`(14209–14210); 매 단계 `w2=w2backup` 복원(14420, 14491, 14562, 14633). 첫 호출 `av_mode==5 && kappa==0`이면 w2 전부 0 리셋 `[KAPPA_GUARD]`(14258–14275) — 재시작 W도 지움.
- 정적 모드(kappa>0): `getw2forHydroParticle` mode 0–8(1493–1627), `applyW2Controls` 바닥→이완→변화율→천장(1636–1671); 매 단계 상태에서 재계산(4336–4359, 14688–14695); 면속도 지연항 `(√W−√W_old)/dt_old` c_s 클램프(voro_eunha.c:87–101).
- `GFS_W2_LINEAR`(119–139, 13809–13850): 스텝당 한 Ẇ, 정확한 (Ẇ_p−Ẇ_q)/(2d).
- `GFS_DYN_W2`(방식 3) `gfs_dynw2_solve`(9263–9461): 단계마다 LL 재구성 직후·힘 전(10272–10276). 면별 `b_f=2d(v*−n·ū−rot)+ΔW·ḋ/d`(9372), `a_f=A·ratio`(9371), 장벽 `|ΔW|>(1−2δ)d²`면 a_f×1000(9375–9381); 라플라시안 Jacobi-PCG 1e-10/2000(9398–9430); dt 한계(9449–9458, 14367–14368); `gfs_dynw2_set`(10166–10218): `W=w2backup+cΔt·k`, **min W=0 평행이동**, `w2old=w2`.
- `GFS_SCHEME_H` Phase A `gfs_schemeH_solve`(9800–10164): 상태 V^T(9462–9475), `kvt=ΣA u*+capr+(V_vor−V^T)/τ_V`(9806, 10003); `½L Ẇ = ΣA(u*−ũ−ρ_f)+(V_vor−V^T)/τ_V+(V^T−V)/τ_C`(9800–9808, 9983–10004); V_vor은 **W=0 두 번째 테셀레이션**(9893–9903); u*는 극단면 HLL/그 외 MUSCL HLLC(9906–9961); 연결성분별 영평균(10020–10027); dt 한계 없음.
- `GFS_H_OMEGA`(9481–9563, 10050–10135): `W=h²ω`, h=(R_1^-p+Σφ d^-p)^-1/p(p=8); ω가 RK4 상태; 활성집합 PCG, |ω|≥om_max(0.4) 고정/해제.
- `GFS_H_DAE` `hq_project`(9565–9574, 9674–9797): 매 단계 시작(K1 14307–14309; K2–4 14422–14424 등) 밀도 계산 전 ω 상자 안에서 V(x,W)=V^T Newton(PCG 1e-10/2000, 역추적 6, 외부 8, tol 1e-9·ΣV). 잔차 평가마다 **전체 테셀레이션 재구성**(`hq_geom` 9583–9672). 도달 불가 셀은 step_start에 `V^T:=V`(9785–9789). τ_C=0. **그 뒤 `gfs_schemeH_solve`가 여전히 Ẇ(dyn_wd)를 풀어 힘·에너지의 δ로 씀 → δ ≠ 실현된 dW/dt**(추정: 열역학 부피율 불일치).
- 저장/복원: `w2backup`는 W_n만; `dyn_wd/dyn_k/hq_vt0/hq_vts/hq_om0/hq_oms/hq_h`는 정적 배열(1380, 9463–9465, 9488–9489). 덤프는 입자 구조체만(11977) → V^T, ω, Ẇ 미저장; 재시도 래퍼(14085–14160)도 정적 배열 미복원.

## 3. 힘과 에너지
- 면속도 `uradix_ui`(8307)=`get2dUpqradRk4`(voro_eunha.c:69–106) + DYN_W2 `(Ẇ_p−Ẇ_q)/(2d)`(6656–6667) + 회전항(6630–6654, 7249, 8308–8315).
- 방식 H 힘·에너지(8641–8687): `f_i=−P*A n−A(P_j−P_i)t/d`, `t=c_f−(x_i+φd e)`; `dte_i=v_i·f_i−P_i A w_f+θD_f`, `D_f=A[(P_i−P_j)δ+(P*−P̃)(u_i−u_j)]`, `P̃=φP_j+(1−φ)P_i`. "어떤 Ẇ에서도 총에너지 보존" 주장(exam.c:295–303; formulation.md:138–142, 263 수치 5e-10) — 조건: 두 셀이 같은 A,n,t,δ,P*를 보고 각 셀이 닫힘(ΣA n=0, capr 9880–9884).
- `GFS_E_AUDIT`(6472–6485)의 hyd=0 조건은 공통 압력·면속도 가정이라 방식 H에는 D_f 포함 잔차로만 검사 가능.
- 엔트로피: D_f 부호 미정(`hq_dpos/hq_dneg` 8667–8687, 10249–10252); 문서는 D_f≥0을 별도 제약으로 요구(formulation.md:18, 175, 185).

## 5. 결함·한계
1. CUDA W 리셋(dba29db는 updateDen만 우회); DYN_W2에서 `w2ceil` 갱신 경로 부재.
2. 셀별 독립 테셀레이션 → 두 셀이 다른 면을 볼 수 있음.
3. DYN_W2 유효성 dt 한계는 구성상 Zeno(Fable).
4. 벌점 장벽 ×1000이 라플라시안 조건수 악화.
5. getwfrac 클램프 vs `∂V/∂W=½L` 가정 불일치.
6. voro `w2ceil` 미사용.
7. DAE 비용: 단계당 최대 8×7 테셀레이션(추정).
8. KAPPA_GUARD가 재시작 W 삭제; 정적 상태 배열 미저장.
9. voro.c:1207 차원 불일치.

## 6. 현 TCF/원판/가장자리 스택에서 DAE를 재개하려면
1. TCF 금지 해제 + Z/Q 구성을 Laguerre 앵커 φd·P̃로 재유도(추정).
2. 원판 닫힘 W≠0 확장: 분할 정확성 재증명, 원호의 ∂V/∂W 기여를 hq_geom에 추가(현재 f.a는 이웃 면만 9633–9641).
3. 보안 반경 Laguerre화: `φd<R_v` 또는 W≥0 평행이동 이용 `d<R_v+√(R_v²+max W)`(추정).
4. getwfrac 클램프: 야코비안·δ에서 ∂V/∂W=0으로 다루거나 ω 상자(om_max<½)로 도달 불가를 보장하고 클램프를 진단으로.
5. δ와 사영의 정합: dyn_wd 대신 사영된 W의 실제 단계 차분을 δ에(formulation.md:796).
6. 공유 기하 `GFS_SHARED_GEOM`을 DAE·힘 경로에도.
7. 상태 저장/복원: hq_om0/hq_vt0/dyn_wd를 덤프·재시도 래퍼에; KAPPA_GUARD에 예외.
8. GPU: 커널 kappa 규칙에 분기 또는 CPU 전용 명시.
9. 비용: hq_geom 1회 + 야코비안 고정 준-Newton(추정).
