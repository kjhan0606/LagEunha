# 케플러 모멘트 유체 결합 — 남은 구현

공식 정의는 HANDOVER_2026-10-09.md §2.2 그대로 유지한다. rho=1(r=.5..2),
공회전 배경rho=.01, 균일P=(gamma−1)(5gamma/2)1e-5, spline rc=.5,
황금비 위상 균일 고리192², 중심 생성점 없음, R>=2.5 동결,100궤도.
실제 공식 IC는 [0,6]², 중심(3,3)이다. binary 식별 정보는 같은 이름 JSON 참조.

## 완료한 결합

- LH: 현재2D 아핀/이차 속도 표본에 중력 kick 연결. 원래 m/q/Q 유지,
  p/D/Pi/E 동시 갱신, QR 잔여 공분산. quadrature–원시모멘트 불일치 및
  Pi 부동소수점 completion을 측정·제한하며 eigenvalue clipping 없음.
  전체422개 검사 통과.
- LJ: 중력 half-kick→기존 양의 midpoint 유체수송→half-kick 연결.
  균일 자유낙하의 움직이는 셀 및 Egas+Epotential 보존 검사 통과.
  전체423개 회귀 검사 통과. 이는 공식 원반 검증이 아니다.

## 다음 필수 구현

1. 동결 경계 계약을 명시적으로 연결한다. Exam/exam.c의 gfs_kepler_frozen은
   매 단계 현재 위치에서 r>=Re를 판정한다. 각 RK 단계에서 x/y/vx/vy/ie/K
   증분을 모두0으로 만들고 tessellation의 이웃으로 남긴다(14426행 등).
   현재 모멘트 모델에서는 외부 동결 셀의 생성점·가중치·원시모멘트·primary
   factor를 보존하고, 활성 셀만 물질 생성점 속도로 진화시키는 계약이 필요하다.
   audit_geometry_rates를 진화에 전용하지 말고 정식 frozen mask를 구현한다.
2. 활성 셀의 질량 방정식만 풀고 동결 weight-rate=0을 Dirichlet 조건으로 둔다.
   활성–동결 면의 버린 반대쪽 P/E/L 변화는 외부 저장소 교환 장부에 기록한다.
   동결 셀 geometry가 바뀌어 고정 m/q/Q가 불가능해지면 실패로 남긴다.
   임의 밀도 수리 또는 reference 상태 강제 주입으로 숨기지 않는다.
3. 중력 kick도 같은 단계 동결 mask를 존중해야 한다. 동결 factor의 gauge까지
   불필요하게 다시 만들지 않는다. 활성 생성점 조향0은 따로 검사한다.
4. 공식 초기장 적분: 원형 rho 불연속(r=.5,2)을 적분 구간에서 분리한다.
   단순 고정 Cartesian quadrature로 경계를 건너면 m/q/Q 오차가 섞인다.
   각 convex polygon을 중심 기준 polar ray bounds로 적분하고, 꼭짓점 각도와
   r=.5,2,rc 교차각에서 구간을 분할하는 방법을 우선 검토한다. 양의 quadrature,
   독립 고차 적분, 전체 질량/에너지/각운동량을 확인한다.
5. 동일 물리 정의의 작은 해상도 제어 시험→시간/공간 수렴→공식192²·100궤도.
   냉각 내부에너지가 매우 작으므로 Pi completion과 열에너지 상대 오차를
   별도로 측정한다. Egas+integral(rho*Phi)의 수송/경계/중력 장부 및 조밀
   이동면 질량 경로를 검사한다. 자유낙하나 시험입자를 원반 통과로 대체하지 않는다.

## 09:26 구현 갱신

위1–3의 동결 mask·활성 질량 sparse solve·외부 교환 장부·중력 동결 처리를
구현하고 LO427개 검사를 통과했다. 위4의 분할 polar 초기 적분과 공식 배치
재현은 LP431개 검사로 확인했다. 공식 배치를 바꾸지 않은246셀 보조 첫 단계는
LQ에서 반복 꼭짓점 입력 때문에 초기 적분에서 실패했고, LR 수정 검사가 진행 중이다.
공식100궤도, 전체 퍼텐셜 수송 장부 및 냉각 상태 장기 오차는 여전히 남아 있다.


LR 수정 회귀432개 통과 후 IC 생성까지 완료했다. 첫 유체 RHS는 활성–활성
면의 재구성 진공으로 실패했고, LS에서 중력 전에도 재현했다. LT/LU의 n32/n64
제어가 진행 중이다. LS에 실패 면·물리 참조·초기 상태 hash를 저장했다.
다음은 해상도별 첫 RHS/냉각 에너지/퍼텐셜 장부를 비교하는 일이다. 현재
압력 solver의 진공 지원은 별도 미완료 사항이며, 고해상도에서 회피되는 것과
일반 진공 Riemann 해법의 검증을 구분해야 한다.
