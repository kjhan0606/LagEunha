# TCF 유도 (1단계 초안, 관문 G1 검토용)

작성: 2026-10-02. 계획: `Docs/plan_thermo_compatible_flux.md`. 이 문서는 고정 질량 생성점 + 기하 부피에서 총에너지 보존과 엔트로피 부등식을 함께 만족하는 면 법칙을 유도한다. 먼저 W=0(Voronoi)에서 유도하고, Laguerre(W≠0)로의 확장 조건을 정리한다.

## 1. 반이산 계

셀 k: 질량 m_k(고정), 위치 x_k, 속도 v_k, 기하 부피 V_k(x)(반평면 깎아내기가 정하는 셀, W=0), 내부에너지 U_k, 엔트로피 변수 s_k.
상태방정식: U_k = U(m_k, V_k, s_k), P_k = −∂U/∂V|_s. 이상기체에서 U_k = m_k K_k ρ_k^{γ−1}/(γ−1), ρ_k = m_k/V_k이다.

## 2. 가역 부분: 변분(라그랑주) 유도

**라그랑지안:** L = Σ_k ½ m_k |v_k|² − Σ_k U(m_k, V_k(x), s_k), s_k는 고정.

**운동방정식:** m_i dv_i/dt = −Σ_k ∂U_k/∂x_i = Σ_k P_k ∂V_k/∂x_i.

**에너지와 엔트로피:**
- E = Σ ½ m v² + Σ U는 정확히 보존된다(반이산).
- dU_k/dt = −P_k dV_k/dt(기하 부피 그대로)이고, 각 셀의 엔트로피가 정확히 일정하다.
- **§1.4(계획서)의 R_f 문제가 생기지 않는다.** 면이 물질과 다르게 움직여 생기는 부피 교환은 각 셀의 자기 압력으로 계산된 가역 일이 되고, 그 차이는 힘(∂V/∂x)이 운동에너지로 정확히 주고받는다.

**Voronoi 면 기하 미분**(Serrano & Español 2001; Heß & Springel 2010 VPH). 면 f=(i,j)의 길이 A, 중심 c, 단위 법선 e=(x_j−x_i)/d, 중점 m=(x_i+x_j)/2, 면 위 오프셋 t = c − m(e에 수직)이라 하면 다음이 성립한다.

  ∂V_i/∂x_j = A [ e/2 − t/d ],   ∂V_j/∂x_i = A [ −e/2 − t/d ],   ∂V_i/∂x_i|_f = A [ e/2 + t/d ]

(G1 정정, Fable 수치 검증: 유한차분과 5e-7 일치. 면 속도로 쓰면 w = ū + (v_i−v_j)·t/d, Springel 2010 식 33과 같음.) 병진 불변은 Σ_k ∂V_i/∂x_k = 0이고, Σ_k ∂V_k/∂x_i = 0은 총부피 보존이다. 주기 상자에서는 둘 다 성립하지만 **원판 제한 셀에서는 총부피 보존이 깨진다**(원판이 생성점과 함께 움직임). 원호 면은 ∂V_i/∂x_i에만 들어가며 원래 변분 힘 기여는 P_i N_i, N_i = ∫_arc n ds(= 현 법선 적분)이다. **정리된 쌍 힘 −A[P̄e + (P_j−P_i)t/d]를 쓰면 원호 힘 P_i N_i는 이미 포함되어 있으므로 다시 더하면 이중 계산이다**(Astra G1). 반면 부피 변화에는 반드시 dV_i/dt = Σ_j A w_f + v_i·N_i를 포함한다.

**쌍 힘:** 정리하면 셀 i가 면 f에서 받는 힘은 다음과 같다.

  F_i^rev(f) = −A [ P̄ e + (P_j − P_i) t/d ],  P̄ = ½(P_i + P_j)   (G1 정정; 코드 `hq_ftx` 부호와 일치)

- 첫 항은 평균 압력의 법선 힘이고, 둘째 항은 압력 차이와 면 오프셋에 비례하는 접선 힘이다. **이 가역 힘은 중심력이 아니다**(접선 성분). 그래도 각운동량은 셀 합계로 보존된다.
- 이 꼴은 (H)의 힘 f = −A[P* n + (P_j−P_i)t/d](§25, `ac363fc`)에서 P*를 P̄로 바꾼 것과 같다.
- 쌍 반대칭이므로 운동량이 보존된다. **각운동량도 정확히 보존된다**(G1 정정): V_k가 전체 회전에 불변이므로 Σ x_i×F_i = Σ_k P_k ∂V_k/∂θ = 0. 면별 토크는 0이 아니지만 셀 합계로 사라진다. 주기 상자에서는 회전 대칭이 없어 보존되지 않는다.

**에너지 장부:**
- dU_i/dt = −P_i dV_i/dt이고, dV_i/dt = Σ_f ∫_f w ds(기하)이다.
- 총에너지 dE/dt = Σ_i v_i·F_i^rev − Σ_k P_k Σ_i ∂V_k/∂x_i·v_i ≡ 0은, 힘과 일에 같은 P_k를 쓰는 한 항등식이다. **면별로는 상쇄되지 않고**(면 잔차 −A(P_i u_i − P_j u_j)), Σ_f A e_f = 0으로 셀 단위에서만 사라진다(G1 정정). 셀 루프 안에서 모든 면(원호 포함)을 합하면 된다.
- 숨은 가정(G1): 가역 힘에는 **셀 값 P_i, P_j만** 쓴다. 재구성 압력을 쓰면 항등식이 깨진다. 재구성은 Q_f에만 들어간다.

## 3. 비가역 부분: Riemann 소산

**소산 압력:** 면마다 Q_f를 정의한다.
- 법선 힘에 더한다: F_i += −A Q_f e, F_j += +A Q_f e.
- 소산 열은 반씩 나눈다: dU_i/dt += ½ A Q_f (u_i − u_j), dU_j/dt += ½ A Q_f (u_i − u_j). 여기서 u = v·e이다.

**보존과 엔트로피:**
- 총에너지: v_i·(−A Q e) + v_j·(A Q e) + A Q (u_i−u_j) = 0으로 정확히 보존된다.
- 엔트로피: 각 셀의 T dS = ½ A Q_f (u_i − u_j)이다. **Q_f (u_i − u_j) ≥ 0이면 면마다, 셀마다 비음수**이다(절삭이 필요 없다).

**Q_f의 정의 (선택지, 검토 대상):**
- (a) 재구성 상태의 Riemann 해: P_c ≡ P*(p_L, p_R, Δu=0), Q_0 = P*(Δu_rec) − P_c. 정확 Riemann 해와 코드 HLLC의 Davis 주 분기에서 P*는 Δu의 단조 함수라 Q_0와 Δu_rec의 부호가 같다(solver 전체의 단조성은 (a′) 참조).
- (a′) Astra G1 정정: 엔트로피 증명에 필요한 것은 Q·Δu_cell ≥ 0이다. 따라서 Z_eff = Q_0/Δu_rec ≥ 0, **Q = Z_eff · minmod(Δu_rec, Δu_cell)**로 정의한다(문서의 clip 식과 동등, 0 근처 연속). 단조성은 정확 Riemann 해와 코드 HLLC의 Davis 주 분기에서 확인되지만, 실제 solver의 압력비 분기·이른 진공 판정·Roe fallback·압력 바닥까지 포함한 단조성·연속성은 별도로 확인해야 한다. 또한 P̄ + Q_0 ≠ p*이므로 "HLLC 수준의 소산"이 "HLLC와 같은 충격 해"를 뜻하지 않는다. 충격 정확도는 4단계 시험으로만 판정한다.
- (b) (조건부 주장) 선형 정확 재구성과 규칙적인 해상도 계열을 가정하면 매끄러운 흐름에서 Δu_rec = O(h²)이다(선형장에서 0). 일반적인 매끄러운 장에는 재구성 오차가 남고, 격자 규모 속도 잡음은 Δu_rec에도 남을 수 있다. 잡음 진폭 δv가 해상도와 함께 줄지 않으면 가열은 ρcδv²/h로 커질 수 있다(F2).
- (c) 보장 범위: Z_eff가 유한하고 비음수이면 **Q·Δu_cell ≥ 0**이다(반이산 엔트로피 비음수). 엄격한 Q > 0(압축 면에서 실제 소산)은 두 점프가 같은 부호로 압축(Δu > 0, u_i > u_j)이고 Z_eff > 0일 때만이다. Z_eff ≥ 0 자체는 solver 전체의 단조성이 확인돼야 보장된다. 부호가 다르면 minmod로 Q = 0이 되어 **충격 소산도 보장되지 않는다.** 0 근처 연속성에는 Z_eff의 유한하고 연속적인 극한과 영분모 처리가 필요하다. 충격 정확도는 4단계 시험으로만 판정한다.

## 4. 시간 적분과 에너지 정합
- RK4 단계마다 같은 면 상태로 F^rev, Q_f, dU를 계산한다.
- 총에너지를 RK로 적분하고, U = E − KE로 복원한다(현 SEDOV_PHASE1과 같다). 또는 U를 직접 적분해 E 잔차를 장부에 기록하는 방식을 비교한다.
- 완전 이산 엔트로피 양성은 보장되지 않으므로, 단계 바닥값 발동과 셀별 음의 T dS를 계측한다.

## 5. Laguerre(W≠0)로의 확장 조건
- V_k = V_k(x, W)이므로 라그랑지안 힘은 F_i = Σ_k P_k ∂V_k/∂x_i가 되고, 앵커 φ = ½ + (W_i−W_j)/(2d²), a = x_i + φde, t = c − a로 두면 ∂V_i/∂x_i|_f = A[φe + t/d]이고 쌍 힘은 **F_i(f) = −A[P̃ e + (P_j−P_i)t/d], P̃ = (1−φ)P_i + φP_j**이다(G1, 코드 `Ptil`과 일치).
- W 일은 Σ_f A(P_i−P_j)(Ẇ_i−Ẇ_j)/(2d)이다. 에너지 조건은 **단일 스칼라 제약 g·Ẇ = 0, g_l = Σ_{f∋l} A(P_l−P_j)/(2d)**로 충분하다(원하는 Ẇ를 g에 직교 투영). 또는 W에 운동항을 주는 정합한 역학을 쓴다.
- W가 시간에 따라 바뀌면 일 Σ_k P_k (∂V_k/∂W_l) Ẇ_l이 생긴다.
  - 위치 힘과 dU_i = −P_i dV_i를 유지하면 dE/dt = −g·Ẇ이다. **에너지 보존 조건은 g·Ẇ = 0이다**(원하는 Ẇ를 g에 직교 투영). 더 강한 조건 g_l = Σ_k P_k ∂V_k/∂W_l = 0(모든 l)은 W를 자유 무관성 좌표로 둘 때의 정류 조건이며, 에너지 보존에 필요하지 않다.
  - 원판 제한과 W≠0을 함께 쓰면 공유 면의 양쪽 절단이 일치하지 않아 하나의 A, t를 전제한 쌍 힘과 g 식을 그대로 쓸 수 없다. "정적 Laguerre에서 성립"은 공유 면이 일치하는 유효한 분할에서만 승인된다.
- 정적 Laguerre(W 고정)의 총에너지 교환식(공유 면이 일치할 때): Ė_{i,f} = −A[φP_j u_i + (1−φ)P_i u_j + (P_j v_i − P_i v_j)·t/d + Q(u_i+u_j)/2] (Astra 재서명 검토).
- 1단계 결론: **공유 면이 일치하는 유효한 분할에서 W를 고정하면 위 유도가 성립**한다. 동적 W는 g·Ẇ = 0 아래에서만 정합하다. **2단계 구현은 W=0으로 제한한다.**

## 6. 기존 코드와의 관계
- §2의 가역 힘은 (H)의 VPH 접선 힘과 같은 구조이다. (H)는 P*(HLLC)를 중심 압력 자리에 써서 가역과 비가역을 섞었다. TCF는 둘을 분리한다(P̄ + Q_f).
- 기존 av_mode 5(HLLC) 경로: 힘 −A P* n, 에너지 −A P* w(총에너지 보존). 이 경로는 VPH 접선 힘이 없어, 면이 물질과 다르게 움직일 때 생기는 R_f가 엔트로피 장부에 섞인다(§1.4). 또한 P*의 가역·비가역이 분리되지 않는다.

## 8. G1 검토 기록
- **Fable (2026-10-02): 조건부 승인.** 접선항 부호 정정, 면별 상쇄 문구 정정, 각운동량 정확 보존, 원호 면 처리, P_c ≡ P*(Δu=0)와 연속형 Q, Laguerre P̃와 g·Ẇ=0 조건을 반영했다(위 본문).
  - 위험(Astra G1이 정정): **"VPH 힘의 0차 오차"는 틀린 진단이다.** 내부 셀에서 균일 압력이면 F_i=0이고, 선형 압력 P_i = P_0 + b·x_i이면 불규칙 셀에서도 F_i = −V_i b로 정확하다(Heß & Springel 부록 A). 실제 위험은 (가) 전단이 불규칙 셀의 부피를 바꾸는 것(선형 속도장 v = v_i + L(x−x_i)에서 dV_i/dt = V_i tr L − 2Σ_f A_f t_f·L e_f; tr L=0이어도 0이 아님) → EOS를 통한 실제 압력 잡음, (나) 부피를 바꾸지 않는 변위 모드(규칙 격자의 Nyquist 모드)에 복원력이 약하거나 없음(Heß & Springel이 shape correction으로 다룬 문제)이다. 격자 규모 속도 잡음 δv가 해상도와 함께 줄지 않으면 소산 가열은 ρ c δv²/h로 오히려 커질 수 있다(F2).
  - G2 추가 시험: 불규칙 정지 격자(내부 셀 또는 주기계) + 균일 압력에서 |F_i| = 0; 선형 압력장에서 F_i + V_i b가 기하·반올림 오차 수준인지; 선형 전단의 셀 부피 변화; Nyquist 모드 복원력; 재구성 점프와 가열률의 해상도 수렴.
  - 독창성: VPH + Riemann 소산 자체는 선행 연구(Caramana–Burton–Shashkov–Whalen 1998 compatible hydro, Inutsuka 2002, Heß & Springel 2010, Hopkins 2015 MFM 등)가 있다. 독창성은 (가) 고정 질량 생성점에서 가역/비가역 분리로 R_f가 변분 구조로 소멸함을 보인 것, (나) Laguerre W 동역학의 에너지 정합 조건, (다) 자유 표면(원호) 셀의 변분 처리, (라) Kepler 진공 고리 검증에 둔다. 서술은 "compatible hydro를 Laguerre 생성점으로 확장"이 안전하다.
- **Astra (2026-10-02): 반이산 변분 구조 승인, 정정 후 재서명.** 반영: 원호 힘 이중 계산 주의와 부피 변화의 원호 항, VPH "0차 오차" 진단 정정(선형 압력 힘은 정확; 실제 위험은 전단 부피 잡음과 Nyquist 모드), Q = Z_eff·minmod(Δu_rec, Δu_cell), solver 전체 단조성 확인 필요, 충격 정확도 미보장, (b)는 조건부 주장, 동적 W 조건 정리, 원판+W≠0 불일치, 가역 힘은 비중심력.
  - 반대칭 총에너지 교환식(W=0, 면당 한 번 계산해 양쪽에 반대 부호): **Ė_{i,f} = −A[(P_j u_i + P_i u_j)/2 + (P_j v_i − P_i v_j)·t/d + Q(u_i+u_j)/2], Ė_{j,f} = −Ė_{i,f}.** 구현에서 −AΠw 대신 이 식을 쓴다.
  - 독창성: Duque 2023(Voronoi·power diagram·Lagrangian 역학 통합)도 있다. 독창성은 고정 질량·생성점 일치·조향 금지 제약 아래의 구체적 호환 법칙(공유 자유 경계, 동적 W 포함), 잡음과 충격을 함께 다루는 검증된 Q, Kepler 진공 고리 수렴 성과에 둔다.
