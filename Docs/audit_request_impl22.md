# 자문 요청 (Astra, 22차): 가역 셀 규모 불안정의 원인과 Laguerre 동적 가중치(DAE)의 재개 여부

작성: 2026-10-08. 직전: `Docs/audit_impl21_astra.md`, `Docs/laguerre_weight_history_2026-10-08.md`.
사용자 질문: "가역 불안정의 원인을 Laguerre 동적 가중치가 해결할 수 있는가? DAE를 재개할지 결정하자."

## 1. 사실 (Python 기준 모형 `Docs/polybnd/`, C와 일치 확인됨; 192² 고리, 압력 ×100 = c_s/d 0.41)
A. 소산을 모두 끈 가역 실행에서 각 고리에 **접선(종파) 모드**가 지수 성장한다. 고리마다 m이 다르고(고리 1 m42, 고리 5 m60 ≈ 0.4N, 파장 2.3–2.6셀) 이웃 고리와 상관이 없다. 반경 변위는 접선의 2%.
B. 기제 시험(고리 1에 m42 종파를 심고 성장률 측정, `mech.py`):

   | 시험 | 조건 | 성장률/시간 |
   |---|---|---|
   | B | 기준 | 0.45 (c_s/d 0.41) |
   | E | 해상도 절반 | 0.22 (c_s/d 0.21) |
   | C | 접선 힘 항 (Pj−Pi)t/d 제거 | 0.45 |
   | F | dt 절반 | 0.45 |
   | G | 강체 회전(미끄러짐 없음) | **0** |
   | H / I | 전단률 ×2 / ×½ | 0.45 / 0.40 |
   | J | 심은 진폭 1/10 | 0.40 (선형) |
   | K | 긴 파장 m10(11셀) | 0.27 |
   | **M** | **압력만 물질 부피로 계산**(dV^T/dt = Σ A ½(u_a+u_j)·e; 힘·기하 Voronoi) | **0.03** (t≤4; 원호 운동학 누락으로 중단, 재실행 중) |
   | L | 접선 선형 전파(η=1e-6 d, FD 야코비안) | t≤5에서 진동, 순성장 ≈0.1 (판정 보류, 진행 중) |

C. 정적 분산 관계(`disp.py`, `lagdisp.py`; 압력 힘만; 단위 c_s²/d²): 접선 모드의 ω²는 연속체 (kd)²가 아니라 1D Voronoi 사슬 sin²(kd)를 따른다. 192² 고리 1: m10 0.21(연속체 0.33), m30 0.72(2.9), m42 0.37(5.8), m53 0.067(9.2), 나이퀴스트(올바른 위상) 0.12(9.9). 이웃 고리를 간격의 0–90% 옮겨도 변화 0.7%(모두 양수).
D. 정적 Laguerre 시험(`lagdisp.py`, 40²·96²): 물질 부피 압력 + 부피 제약 가중치(DAE형)의 복원력은 **모든 파장에서 Voronoi와 같다**(나이퀴스트 0.116 대 0.117). 유한한 복원력은 OT/Brenier형 무게중심 힘(복원 비율 0.3–1.7)뿐이다.
E. 히스토리 재검토(`laguerre_weight_history_2026-10-08.md`): DAE(방식 H-DAE, bd300f9)는 Kepler t=3에서 dLz 5e-7(W=0: 1.2e-4), Gresho L1 절반으로 가장 좋았고, 보류 이유는 "가장자리 침식을 못 건드린다"였다. 그 침식의 원인은 2026-10-07에 진공 원호 셀의 QBP 기울기 오차로 확정·수정됐다(EDGE_INNER=3). 구조적 한계로 확인된 것: 전단에서 물질 부피 추종 W의 |ΔW|/d² 무한 증가와 유효성 포화(셀 34%), 2D 자유도(면 3N 대 Ẇ N−1), 부피 상쇄 W-일의 엔트로피 부호.

## 2. 운전자의 잠정 해석
- 성장의 **구동원**은 이웃 고리의 초음속(c_s의 100배) 미끄러짐이 만드는 Voronoi 부피·압력 요동이다(G, M). 홀수–짝수 분리(C, D)는 복원력이 약한 모드가 가장 빨리 자라게 하는 **모드 선택** 요인이지 원인이 아니다(K).
- 성장률이 c_s/d에 비례하고 전단률에 무관한 것은, 기하적 변조 깊이가 O(1)이고 응답 시간이 음향 시간이기 때문으로 본다(미증명).
- 압력을 물질 부피로 계산하면 구동원이 사라지므로(M), 입자=생성점을 유지하면서 물질 부피를 추종하는 **Laguerre-DAE가 원인을 직접 제거**할 수 있다. 단 |ΔW| 포화 문제가 남는다.

## 3. 질문
1. 1–2의 증거가 "구동원 = Voronoi 부피 요동"을 확정하는가? 빠진 대안 설명(예: 면 운동학의 비매끄러움(flip) 자체, Doppler 공명)이 있으면 지정하고 판별 시험을 제시하라. L이 선형 성장을 보이지 않는다면 어떻게 해석해야 하는가.
2. DAE가 이 구동원을 제거하는 데 **필요한 추종 정도**는 얼마인가? 포화(|ΔW| < d²)가 있어도 성장률을 c_s/d에서 (예컨대) 궤도 시간 역수 이하로 낮추는 데 충분한가. ΔW 필요량의 규모 추정을 달라(요동 rms 19–32%, 셀 34% 포화 자료 활용).
3. 재개한다면 자기정합 정식화의 조건: (a) 에너지 보존(W-일의 장부, TCF와의 결합 g·Ẇ=0), (b) W-일의 엔트로피 부호 문제의 처리, (c) 유효성과 도달 불가 셀 규칙(V^T := V)의 원칙적 정의, (d) 진공 원호 셀과 W의 결합(원호 W-일을 받을 힘이 없다는 이전 발견), (e) Laguerre 보안 반경. 어떤 순서로 무엇을 먼저 검증해야 하는가.
4. 대안 비교: 면의 중점 정의를 바꾸는 방법(예: 면 상태/열역학 변수를 면·영역 중심에 두는 엇갈림 정식화)이 홀수–짝수 분리와 구동원을 함께 다룰 수 있는가. 무게중심 힘(OT/Brenier)은 "입자=생성점, 조향 금지" 원칙과 양립하는가(힘은 작용량에서 나오지만 형태는 무게중심 복원).
5. 결정 권고: DAE 재개 / 보류 / 다른 방향. 결론 먼저.
