# Reynolds 수로 지정하는 점성 응력과 내부 회전

## 사용자 의도와 현재 상태

사용자가 Reynolds 수 Re를 뜻한다고 명시했다. 임의의 회전 감쇠나 이웃 회전속도 마찰 규칙을 도입하는 요청이 아니다. 기준 Uref,Lref와 Re로 nu=Uref Lref/Re를 지정하고 속도 변형률로 Newtonian 응력을 계산한다. 수치 Re 값과 기준척도는 아직 정해지지 않았다. Re=infinity는 점성 없는 기준이다. 기존 실행을 변경하지 않는다.

현재 연구 코드 Docs/polybnd/kinetic_factor_rhs.py는 fp에 ps*n, fe에 ps*sm을 넣고, D 면 수송에 outer(point,fp)를 사용한다. 압력 힘 F와 중심 모멘트 H를 모은 뒤 H+=PV I, Ddot+=Pi+PV I로 체적항을 넣는다. A=solve(S,H).T와 a0=F/m-A c로 Pi의 힘 기여를 갱신한다. 즉 압력 토크를 전달할 자리는 이미 있지만 일반 점성 응력/유한 Re 구성식은 이 경로에 구현되어 있지 않다. 이는 Python 연구 경로에 대한 확인이며 생산 CUDA 경로 구현 여부의 결론은 아니다.

## 부호와 반드시 함께 변경할 항

sigma=-p I+tau, 외향 법선 n, D_ab=int rho x_a v_b dV를 사용한다. ALE 이동 면 속도 w에 대해:

- 운동량의 외향 플럭스: rho v ((v-w)·n) - sigma n.
- 총에너지 외향 플럭스: E ((v-w)·n) - v·sigma n. 점성 부분은 -v_face·tau n이며 두 셀이 같은 면 값과 적분점을 공유해야 한다.
- D의 면 플럭스: x outer 운동량 플럭스.
- D의 체적항: Pi - int sigma^T dV = Pi + int p I dV - int tau^T dV.
- 중심 힘 모멘트 H 역시 면의 int (x-c) outer sigma n에서 int sigma^T dV를 뺀 값을 사용한다. 기존 +PV I에 대응하는 점성항은 -int tau^T dV이다.

면에 tau n만 더하고 D/H 체적항을 생략하면 균일한 응력에서도 잘못된 내부 변형이 발생한다. 일정한 대칭 응력에 대해 닫힌 다각형에서 면 힘은0, 면 모멘트는V sigma^T이고 체적항과 정확히 상쇄되어야 한다. 이 항등식이 첫 구현 검증이다.

대칭 응력의 체적항은 반대칭 부분이0이므로 내부 각운동량 변화에는 면 토크와 수송이 남는다. 총 각운동량은 궤도 성분과 내부 성분의 합으로 검사한다. 회전에너지는 Pi에 포함된 운동에너지의 분해이며 E에 다시 더하지 않는다.

## 구성식과 에너지

3차원 Newtonian 유체의 평면 흐름으로 해석할 경우 tau=2 mu [sym(grad v)-(div v) I/3]+zeta (div v) I, mu=rho nu를 사용한다. 진정한 2차원 구성식의 1/2 계수와 혼동하지 않는다. 3차원 확장 목표상 먼저 평면 3차원 구성식을 명시적으로 채택할지 결정하고 기록해야 한다. 현재 평면 Pi만으로 추적하지 않는 z방향 잔류 운동의 의미도 점검해야 한다.

강체 회전은 sym(grad v)=0이므로 전단 응력이0이다. 선형 전단은 응력이 생기며, 일정 응력의 무한/주기 영역 내부에서는 힘의 발산이0이어도 점성 발열 tau:grad v가 존재한다. 총에너지 플럭스, Pi 갱신, U=E-tr(Pi)/2 사이에 소산을 한 번만 반영해야 한다. 단순 affine 힘 맞춤이 일반 비균일 응력에서도 이 발열을 올바르게 재현하는지는 아직 검증되지 않았다.

## 다음 구현 및 검증 기준

1. Uref,Lref,Re,bulk viscosity와 구성식 차원을 명시하는 설정. Re는 셀 크기에 따라 재정의하지 않는다.
2. 같은 면의 공통 tau, v_face로 힘/토크/일을 조립하고 D/H 체적항을 함께 구현한다.
3. 닫힌 다각형 일정 응력 상쇄, 강체 회전 무응력, 선형 전단 발열, 두 셀 운동량/총각운동량/총에너지 수지를 검사한다.
4. Python 참조와 OpenMP/CUDA/MPI의 동일 입력/면 합산을 대조한다. 현재 구현 완료를 의미하지 않는다.
5. 비점성 기준과 지정 Re를 분리하여 역사적 Kepler t6–10 및 이후 장시간을 검증한다. 유한 Re에서의 물리적 각운동량 수송을 비점성 원궤도 오차로만 판단하지 않는다.

기존의 가중치/고정질량 조건 및 무조향 조건은 계속 적용한다. 기존 짧은 연구 결과는 장시간 생산 코드 검증을 대신하지 않는다.

## 사용자 확정: 케플러 Re=infinity

사용자가 케플러는 무한대 Re로 지정했다. 케플러에서 nu=0 및 bulk viscosity=0으로 두어 Newtonian 점성 응력을0으로 한다. 내부 회전/변형 자유도, 압력 토크, 보존적 수송은 계속 유지한다. 물리 점성을 켜서 원반 붕괴를 억제하는 방향으로 변경하지 않는다. 수치 소산이0임을 뜻하지 않으며 그 효과는 별도로 측정해야 한다.

newtonian_stress_moments.py에 KEPLER_REYNOLDS=infinity와 구성식/면·체적 모멘트 참조 함수를 추가했다. 현재 진화 RHS에는 연결하지 않았다. 유한 Re 선형 전단은 구성식의 발열 검증용으로만 사용한다. 기존 실행 파일/설정은 변경하지 않았다.
