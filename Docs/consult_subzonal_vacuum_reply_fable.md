## 2. 권고 식

모든 변 종류를 하나로 묶는 항등식: B_f(p)는 p에 아핀이므로
  **B_f(c) = W_f − ½ δ·N_f**, δ = c − x_i, N_f = ∫_f n ds(원호는 현의 법선벡터), ΣN_f = 0 ⇒ ΣM_f = m.
  ρ_f/ρ_i = 1 − δ·N_f/(2W_f) (직선 변이면 h_f(c)/h_f(x), 원호면 1 − δ·N_chord/(Rs)).
따라서 `sub_eval`에 필요한 것은 W_f, N_f, V, J(원호는 원형 분절 면적·1차 모멘트 추가)와 꼭짓점 야코비안뿐이다.

꼭짓점 v = 이등분선(i,j) ∩ 제약 g: A = [dᵀ; gᵀ], d = x_j − x_i,
  상자 선(법선 n 고정, x_i와 병진): ∂v/∂x_i = A⁻¹[(v−x_i)ᵀ; nᵀ], ∂v/∂x_j = A⁻¹[(x_j−v)ᵀ; 0].
  원호(|v−x_i|=R): g = n_r = (v−x_i)/R, 같은 꼴. 상자 모서리 꼭짓점: ∂v/∂x_i = I.
  벽 ghost: x_g = Refl(x_i)이므로 `MAX_INDEX`에서 0 반환 대신 ∂x_g/∂x_i = 반사행렬로 연쇄.
접선 접촉(원호가 면에 스칠 때) A가 특이 — 힘 유계성은 별도 확인(Astra 지적과 일치).

가중 w, 사영 (P), (B)는 모두 불필요하거나 불연속(P는 cap 출현 시 기준점이 점프)이다. 장부는 `die += v·F_Φ + dΦ`가 **die가 dE/dt인 RK4E 경로에서만** 옳다 — ie를 직접 적분하는 경로면 dΦ만 더해야 한다.

## 4. 엔트로피 흩어짐

| | std lnK | std lnP⁰(셀) | std lnP̂(간격) | std ρ/4 |
|---|---|---|---|---|
| cell(2차 Q) | 0.035 | 0.004 | 0.160 | 0.021 |
| sub(Z_H) | 0.060 | 0.076 | 0.045 | 0.018 |

CFL 0.1, N=400, β=2, 다른 seed 모두 같은 비(≈1.7). κ=0.5/0.25/0.1은 0.081/0.069/0.055 — 단조 개선 없음. **1D에서 이미 재현되며 시간적분·Q 강도·해상도와 무관**하다. 등질량+무작위 간격이면 cell의 0.067은 γ·std(lnρ_pre)와 정확히 일치 — 즉 cell 모형은 전충격 밀도 잡음을 Hugoniot로 통과시킨 "정답 수준"이고, sub가 그 위에 0.025~0.05를 더 만든다.

기제: sub(엇갈림)에서 평형 조건은 간격 압력 (K_i+K_{i+1})ρ_g^γ = 상수이지 셀 압력이 아니다. 홀짝 K 패턴은 **힘에 보이지 않는 영모드**라 충격면에서 생성돼도 선택압이 없다. cell 모형은 같은 잡음을 홀짝 ρ(pairing)로 바꿔 놓는다 — 2판에서 본 붕괴 기제의 뒷면이다. 따라서 Φ의 "저장·방출"이 K 잡음을 만드는 것이 아니라, 잡음이 앉는 변수가 다르다. 단 셀 압력 P⁰의 7.6% 잡음이 Q·재구성에 들어가므로 2D에서 되먹임(한계기 발동→mm=0 면 증가→감쇠 감소)이 가능하다.

2D 추가 배가(0.45/0.20 vs 1D 1.7)의 유력 원인은 mm=0 면(26–50%)에서 감쇠되지 않는 Φ 진동이 다른 면·다른 셀의 Q로 흘러 열이 떠도는 것이다. 정합한 처방 — **Φ에 켤레인 hourglass 점성**: ξ_f = ln(B_f(c)/W_f) = ln(ρ_f/ρ_i)(Bravais 격자의 모든 아핀 운동에서 0, 균일 압축·병진·회전·균일 전단에서 0),
  Q_f = −Z_f h_f ξ̇_f, Z_f = ρ_f c_f;  F_a += Σ_f Q_f W_f ∇_a ξ_f;  H_i = Σ_f Z_f h_f W_f ξ̇_f² ≥ 0.
∇ξ는 `sub_eval`에 이미 있는 dB(중심 연쇄)·dW(꼭짓점) 기울기이고, Σ_a F_a·v_a = −H_i가 셀별로 정확하다(열이 모드가 사는 셀에 남음). 문턱 없음. Z_H는 mm=0 면을 못 다루고 QLAW=2는 감쇠를 줄이므로 기대하지 말 것(Astra 동의). 1D의 1.7배는 이것으로 줄지 않는다 — 그것은 엇갈림 구조의 대가이며 P⁰ 대신 면 아영역 압력 ½(P_{i,f}+P_{j,f})을 Q·재구성에 넘기는 것이 유일한 정합한 완화책이다. 인공 전도는 접촉면을 희생하므로 권하지 않는다.
