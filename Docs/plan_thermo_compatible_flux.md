# 계획: 고정 질량·Laguerre 생성점에 맞춘 열역학 호환 면 유속 (TCF)

작성: 2026-10-02. 사용자 결정: 이 방향으로 간다(Astra 23차 권고). 독창성은 "고정 질량 입자 = 생성점 + Laguerre 기하"에서 면 유속을 유도하고, 총에너지 보존·엔트로피 부등식·각운동량 보존·선형장 정확성을 함께 만족시키는 데 있다(가역 힘은 비중심력이다).

## 0. 원칙과 배경

**사용자 원칙**
- 패치 금지, 근본 원인 해결
- 입자 = 생성점, 조향 금지, 반평면 셀 생성 유지
- 부피는 기하가 정함
- 총에너지 정확 보존
- 단계 압력 바닥값 1e-6 유지, Kepler DTETA 미사용
- 비교 기준: GIZMO MFM 진공 고리(§26.4)

**문제 (§26.2–26.3, 22·23차 자문)**
- 전단에서 셀 부피 잡음(rms ln ρ ≈ 0.45)이 생기고, 그것이 압력 잡음과 속도 잡음(≈0.3c)으로 이어집니다.
- HLLC 소산이 이를 열로 바꿉니다(궤도당 0.2–0.35).
- 총에너지는 보존되지만, 운동에너지에서 열로의 전환이 수치적입니다.
- Laguerre 부피 정규화는 |ΔW|<d² 한계로 실패했습니다(셀 34% 포화).

**목표:** 가역 일(변분 VPH 힘, 비중심력이지만 각운동량은 셀 합계로 보존)과 비가역 소산을 하나의 면 법칙 안에서 분리합니다.
- 매끄러운 흐름에서는 소산이 재구성 점프에만 걸리도록 합니다(선형장에서 0). 격자 규모 속도 잡음에 대한 소산 감소는 보장되지 않으며 시험으로 판정합니다(F2).
- 충격에서는 올바른 엔트로피 생성을 내게 합니다.
- 어디서나 총에너지는 정확히 보존합니다.

## 1. 이론 (1단계): 이산 항등식과 면 법칙 유도

### 1.1 표기
- 셀 i: 질량 m_i(고정), 생성점 위치 x_i, 속도 v_i, 기하 부피 V_i(x, W)
- 내부에너지 U_i, 압력 P_i = (γ−1)U_i/V_i
- 면 f=(i,j): 길이 A_f, 단위 법선 n(i→j), 기하 면 법선 속도 w_f(x). W=0이면 w(x) = n·v̄ − Δv·(x−m)/d이고, Laguerre면 (Ẇ_i−Ẇ_j)/(2d)가 더해집니다. u_i = v_i·n.

### 1.2 기하 (정확)
- dV_i/dt = Σ_f ∫_f w ds (+ 원호면 기여). 닫힌 다각형이므로 Σ_f A_f n_f = 0이고, 따라서 dV_i/dt = Σ_f ∫_f (w − u_i) ds.

### 1.3 면 법칙 일반형
면마다 하나의 압력 Π_f(s)를 둡니다. 면 위 적분점에서 정의할 수 있습니다.
- 운동량: m_i dv_i/dt = −Σ_f ∫_f Π_f n ds. 쌍 반대칭이므로 운동량이 보존됩니다.
- 총에너지: dE_i/dt = −Σ_f ∫_f Π_f w ds. 쌍 반대칭이므로 **정확히 보존**됩니다.
- 내부에너지: dU_i/dt = dE_i/dt − v_i·m_i dv_i/dt = −Σ_f ∫_f Π_f (w − u_i) ds
- 엔트로피 생성 (T_i dS_i = dU_i + P_i dV_i):
  T_i dS_i/dt = −Σ_f ∫_f (Π_f − P_i)(w − u_i) ds

### 1.4 쌍 합과 핵심 장애
면 f에 대해 i쪽과 j쪽의 합은 다음과 같습니다(Astra 18차와 일치).

  σ_f ≡ −∫_f [(Π−P_i)(w−u_i) − (Π−P_j)(w−u_j)] ds = ∫_f (Π − P̄)(u_i − u_j) ds + ∫_f (P_i − P_j)(w − ū) ds   (Astra G1 부호 정정; σ_f는 T_i dS_i + T_j dS_j)

- 첫 항 D_f: Π와 평균 압력의 차이가 압축과 결합한 것으로, 소산입니다.
- 둘째 항 R_f: 셀 압력 차이와 "면이 물질과 다르게 움직이는 정도"(w−ū)가 결합한 것입니다. Voronoi 면은 물질면이 아니므로(전단에서 w−ū ∝ Δv·(x−m)) 이 항은 부호가 정해지지 않습니다. **고정 질량 + 기하 부피 정식의 고유 항**이고, 매끄러운 흐름에서도 0이 아닙니다.
- σ_f=0(엔트로피 보존)을 단일 Π로 맞추면 Π_ec = P̄ + (P_i−P_j)(ū−w)/(u_i−u_j)가 되어 Δu→0에서 특이합니다. **단일 면 압력으로는 일반적인 엔트로피 보존이 불가능합니다.**

### 1.5 해결 방향 (G1 결과, `Docs/tcf_derivation.md`)
- **(A) 변분 가역 힘:** 라그랑지안 L = Σ½mv² − ΣU(V_k(x))에서 F_i = Σ_k P_k ∂V_k/∂x_i를 얻습니다. 면별로는 F_i(f) = −A[P̄e + (P_j−P_i)t/d](셀 압력만 사용)이고, 각 셀이 자기 압력으로 정확히 단열 변화하므로 R_f 문제가 생기지 않습니다. 초안의 "단일 압력 + 합 0인 열 재배분"은 쓰지 않습니다.
- **(B) 소산:** −A Q e, Q = Z_eff·minmod(Δu_rec, Δu_cell), 열은 반씩 배분합니다. Z_eff = Q_0/Δu_rec는 유한하고 비음수여야 하며(Δu_rec→0에서 극한값, 영분모 처리), 그때 Q·Δu_cell ≥ 0으로 반이산 엔트로피 생성이 비음수입니다. Z_eff ≥ 0은 solver 전체의 단조성 확인(G2 항목)에 달려 있습니다.
- **(C) 시간 적분:** RK4 단계마다 같은 면 상태로 힘·일을 계산합니다. 완전 이산 양성은 보장되지 않으므로 계측합니다.

**관문 G1:** Astra와 Fable이 유도를 검토해 서명합니다. (A)가 불가능하다고 판명되면 §5의 F1로 갑니다.

## 2. 구현 (2단계) — 기본 꺼짐 스위치 `GFS_TCF=1`
- **위치:** `exam.c` 면 루프의 av_mode 5 분기. 기존 HLLC 경로는 그대로 둡니다.
- **계산:**
  1. 재구성 상태(기존 2패스 LSF + 공통 접선 + 쌍 구간 제한)를 그대로 씁니다.
  2. 면 적분점(중점 또는 2점 Gauss)마다 P_c, Q_f, w를 계산합니다.
  3. (G1, **W=0으로 제한**) 가역 힘은 변분형 F_i(f) = −A[P̄e + (P_j−P_i)t/d](셀 압력만 사용), 소산 힘 −A Q e, Q = Z_eff·minmod(Δu_rec, Δu_cell)(Z_eff 유한·비음수, Δu_rec→0 극한과 영분모 처리; Z_eff<0이 나오면 0으로 두지 말고 [TCF] 경고로 기록해 solver 단조성 결함으로 다룸). 총에너지 교환은 면당 한 번 반대칭식 Ė_{i,f} = −A[(P_j u_i + P_i u_j)/2 + (P_j v_i − P_i v_j)·t/d + Q(u_i+u_j)/2]로 계산합니다. **원호 면: 이 교환식과 쌍 힘에 원호의 힘과 일이 이미 흡수되어 있으므로, 총에너지 우변에 −P_i v_i·N_i를 따로 더하지 않습니다.** 원호 항 v_i·N_i는 기하 부피 변화와 내부에너지·엔트로피 진단에만 넣습니다. 내부에너지는 E−KE로 얻습니다. Laguerre(정적 W)로 넓힐 때는 힘에 P̃, 교환식에 φP_j u_i + (1−φ)P_i u_j를 함께 적용합니다.
  4. 엔트로피 장부(진단): D_f, R_f, 셀별 T dS를 면 단위로 기록합니다.
- **정리:** `dK_diss` 절삭(음수→0)은 TCF 경로에서는 쓰지 않습니다. HLLC 음속은 재구성 상태의 음속으로 바꾸고(12·15차 지적), 이른 진공 분기는 정확한 진공 조건으로 바꿉니다. 둘 다 TCF 스위치 안에서만 적용합니다.
- **진단 출력:** `[TCF]` 줄. 스텝별 ΣD_f, Σ|R_f|, 셀별 T dS 음수 비율, 총에너지 잔차(외력 일 포함), 바닥 발동

**관문 G2 (단위 시험, 실행 수 분).** 반이산 항등식(한 스텝의 우변)과 시간간격 수렴을 구분합니다.
- 반이산 항등식(우변 한 번 계산, 반올림 수준이어야 함):
  1. 불규칙 정지 격자(내부 셀 또는 주기계) + 균일 압력: |F_i| = 0
  2. 선형 압력 P = P_0 + b·x: F_i + V_i b가 기하·반올림 오차 수준
  3. 임의 속도장에서 셀 우변의 Σ_i Ė_i = 0(외력 일 제외), 면 교환식의 쌍 반대칭
  4. 소산 Q=0이면 셀마다 Ė_i − v_i·m_i a_i + P_i dV_i/dt = 0(엔트로피 생성 0); Q≠0이면 셀마다 ½ΣAQΔu ≥ 0
  5. 갈릴레이 불변: 균일 속도를 더해도 우변(힘, 내부에너지 변화율)이 같음
- solver 단조성: 재구성 상태 표본에서 P*(Δu)가 Δu에 대해 단조인지(압력비 분기, 이른 진공 판정, Roe fallback, 압력 바닥 포함), Z_eff ≥ 0인지
- 시간 수렴(RK4, 반올림 수준을 요구하지 않음), 같은 종료 시각에서 dt를 절반씩 줄여 비교:
  - 가역 시험(**Q = 0**): 총에너지 잔차와 셀 엔트로피 변화 S_i(t) − S_i(0)가 시간 차수대로 줄어드는지
  - 소산 시험(Q ≠ 0): 엔트로피 오차 S_i(t) − S_i(0) − ∫₀ᵗ (1/2T_i) Σ_f A_f Q_f Δu_cell dt가 시간 차수대로 줄어드는지
  - 단계 바닥값 발동에 따른 변화는 별도로 기록

## 5. 실패 시 돌아가는 방법
| 경우 | 대응 |
|---|---|
| **F1** 1단계에서 (A)가 불가능(R_f를 가역 교환으로 둘 수 없음) | R_f를 셀 단위 엔트로피 장부에 그대로 둡니다(부호 불명, 해상도와 함께 감소하는지 확인). 소산 D_f ≥ 0만 보장하는 약한 형태로 2단계를 진행하고, Hill 띠에서 R_f의 몫을 측정합니다. 필요하면 Astra·Fable과 재설계합니다 |
| **F2** 3단계 실패(회전 Hill 띠에서 가열 지속) | 소산 원천이 재구성 점프인지 실제 생성점 속도 차인지 면별 기록으로 가릅니다. Fable 진단대로 실제 속도 차라면, 매끄러운 흐름에서 Q_f를 줄이는 매끄러움 판정(Caramana형, 선형장 0)을 검토합니다. 문턱값 도입은 사용자 승인 후에 합니다 |
| **F3** 4단계 실패(충격 오차) | 충격 셀에서 Q_f 법칙을 HLLC 소산과 일치시키는 조건을 유도합니다. 그래도 안 되면 TCF는 매끄러운 흐름 전용으로 두고, 충격 판별의 정합한 형태를 재검토합니다 |
| **F4** 전체 실패(합리적 기간 안에 G1–G3 미통과) | 기준선(아래 태그)으로 돌아갑니다. 사용자에게 (라) GIZMO식 엔트로피 전환을 "총에너지 비보존을 명시한 타협안"으로 쓸지, Laguerre 연구를 별도로 이어갈지 결정을 요청합니다 |
