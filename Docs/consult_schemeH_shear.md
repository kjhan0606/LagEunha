# 자문 요청 (5차): (H)의 W가 차가운 전단 원반에서 자라는 원인 — 구조인가 구현인가

작성: 2026-09-30. 사용자 원칙: 패치 금지, 물리·수학적으로 정합한 self-consistent solver. 이전 답: `Docs/consult_schemeH_c_design_reply_astra.md`.

## 1. 구현 상태 (브랜치 `claude/gizmo-kepler-particle-ic`, 로컬 `c749d3a`)

- `GFS_SCHEME_H=1`로 (H)를 C CPU 경로에 넣었다(`Exam/exam.c`의 `gfs_schemeH_solve`, 면 루프의 `(H): anchor` 블록, 잘린 면 블록).
- 이번 작업에서 고친 결함:
  1. **CUDA 빌드에서 `det2d_dpqRK4_GPU`가 κ 규칙으로 w2를 0으로 덮어써 W가 한 번도 적용되지 않았다.** 기존 Grokbot `GFS_DYN_W2`도 같다. 이제 `GFS_DYN_W2`에서는 CPU판(`det2d_dpqRK4`)을 쓴다.
  2. 잘린 면 부피율에서 면적이 빠졌다(`voro2D_norm`은 단위 법선). 귀하의 권고대로 잘린 면(생성점과 함께 강체 이동, 진공)의 `v_i·A n`을 에너지 `−P_i A w`와 V^T 목표율 양쪽에 넣었다.
- 수정 후 에너지 장부는 맞는다(8스텝 dE 3e-6, 면 장부 불일치 1e-6). V^T는 V를 1% 안에서 따른다.

## 3. 나의 해석 (검증해 달라)

1. **선형 속도장 `v = Gx`에서** Voronoi 면 중심의 법선 속도는 `ũ + ρ`이다. `ρ = −t·G n`(코드의 `voronoi_face_rotation`)이다. 물질 속도는 `v(c)·n = ũ + n·G t`다. 대칭부(변형률 S)에서는 둘의 차가 `2 t·S n`이고, 반대칭부(회전)에서는 0이다. 따라서 **전단(변형)이 있으면 Voronoi 셀은 물질 부피를 따르지 않는다.** 정규 격자에서는 t≈0이라 상쇄되지만, 잘린 가장자리 셀은 t가 크고 한쪽 부호라 체계적이다.
2. 현 목표 `u*`는 쌍 중점 방향 셀 상태의 HLL 평균 속도다. 이 값에는 `n·G t`가 없어 물질 부피율도 Voronoi 부피율도 아니다(가장자리에서 1차 오차). **u*를 힘의 P*와 같은 MUSCL 면 중심 재구성 상태에서 얻으면**(귀하의 1(b) 권고) 매끄러운 흐름에서 `u* → v(c)·n`, 즉 물질 부피율이 된다.
3. 그러나 물질 부피를 끝까지 추종하는 것은 Gallouët–Mérigot(2018)의 반이산 OT 라그랑주 방식과 같다. 지속적인 전단에서 물질 영역은 늘어나지만 셀은 볼록하게 남는다. 그래서 필요한 가중치 차는 **변형률 × 시간에 비례해 무한히 자라고**, 생성점이 자기 셀 밖으로 나간다(입자 = 생성점 가정 위반). (G)가 전단에서 발산한 것과 같은 구조로 본다.
4. 그러면 (H)의 τ_V는 임의 상수가 아니라 **국소 변형 시간에 묶여야** 한다. 예: `τ_V = c/|S|`이면 평형 부피 편차가 `~ c`로 유계다. 이것이 정합한 정식인지, "상수 튜닝 + 패치"인지 판단해 달라.
