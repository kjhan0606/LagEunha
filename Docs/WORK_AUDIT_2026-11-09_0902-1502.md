## 결론

사용자의 반복 지적은 타당하다. 실제 계산과 수정은 있었지만, 이미 답한 glass 질문에 계속 답하면서 같은 그림을 반복했고, 국소 재구성 결함을 고치는 탐색을 길게 이어갔다. 이 기간 새 재구성 후보 중 기본 방법으로 채택할 만한 공통 물리 개선은 확보하지 못했다. 전체 6시간을 동일 계산의 반복 또는 무작업으로 표현하는 것도 사실과 다르다.

## 4. 확인된 진행상의 문제

1. **이미 답한 질문을 반복했다.** 자동 진행 뒤 최신 작업의 결론 대신 같은 glass 설명과 그림을 재전송했다. 사용자가 연구가 몇 시간째 제자리라고 판단할 충분한 이유다.
2. **과거 기각 이력을 충분히 적용하지 못했다.** `common_velocity_pair_20261109_v1/decision.json`은 "Unbounded common-speed preservation repeats a historical rejected projection"이라고 명시한다. 새 scalar 조합으로 다시 시험했지만 Blast 밀도 L1이 4.11%→9.93%, 충돌 충격파가 0.345%→0.804%로 나빠져 기각됐다. 이는 새 성공 성과가 아니다.
3. **국소 수학적 조건 개선을 연구의 우선 목표로 너무 오래 삼았다.** 면 소멸 불연속은 실제 결함이다. 하지만 그것을 없애면 냉전단 가열이나 Sedov 형상이 해결된다는 인과 증거는 없었다. 연속성을 개선한 첫 후보는 전단 열증가를 거의 바꾸지 않았고 Gresho 운동량 오차가 4.08%→4.32%로 악화됐다. 이후 후보도 국소 검사 통과 뒤 충격파에서 실패하거나 형상을 악화시켰다.
4. **시간스텝 감소로 고칠 수 없는 오류도 내부 retry를 반복했다.** log+tangent의 동일 초기 scalar fit 실패는 12차례 반복됐다. 몇 초 규모의 낭비이므로 여섯 시간 정체의 주원인과는 구분한다. 오류 분류 개선 대상으로 기록하며 감사 중 새 패치를 추가하지 않는다.
5. **완료·미완료와 방법 계보를 더 분명히 보고했어야 한다.** 새 후보의 1D/strip 통과를 기존 P 바이너리의 검증으로 이전할 수 없다. 보존 통과, 최종 시간 도달, 형상·정확도 통과는 서로 다른 판정이다.

## 5. 실제 본체에 남은 변경과 종료할 탐색

재구성 후보는 격리 경로에 보존돼 있으며 기본 하이드로로 채택하지 않았다. 이 기간 본체에는 실제 셀 부피를 쓰는 Sedov 초기화 지원과 검증된 검색범위 자동 확장 수정이 남았다. 후자의 두 파일 `Exam/NativeU64/exam.c`, `gfs_material_ssprk2_native.inc`는 adoption.json의 after 해시와 일치한다. 물리식·질량·시간간격·압력/일 연산자를 바꾸는 수정은 아니다. 진행 중 RT 실행 파일도 교체하지 않았다.

최신 vertex 후보의 최종 Sedov 밀도 L1은 glass 7.21%→11.25%, regular 10.94%→15.66%였다. 이 후보는 기각 완료이고 추가 shear/Gresho/KH/RT/3D 시험이나 구제 보정을 하지 않는다. 이전 log/tangent·bounded 후보도 재개하지 않는다.

현재 우선순위는 기존 방법의 남은 2D 종료시각·밀도 형상·정합된 기준해 비교와 실제 성능 평가다. 국소 연속성 결함은 미해결로 남기되, 이를 먼저 완벽히 해결해야 모든 2D 검증을 할 수 있다는 추가 선행 조건으로 사용하지 않는다. 기존 실패를 다시 시험하려면 무엇이 달라져 결론이 달라질 수 있는지 먼저 명시해야 한다.

보고는 이전 보고 이후의 새 결과·실패·실제 상태 변화만 전한다. 옛 그림은 비교가 필요하거나 사용자가 요청할 때만 보여 주고 과거 결과임을 적는다. 새 결과가 없으면 같은 설명을 반복하지 않는다. 2D 완료 전 3D를 시작하지 않는다. 이 감사는 전체 연구 완료나 속도 목표 달성을 뜻하지 않는다.
