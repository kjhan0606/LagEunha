# 자문 요청 (29차): 아영역 Φ의 전단 탄성 문제, 대안 (가)·(나), 상자 변의 공유 면 어긋남

작성: 2026-10-02. 관련: `Docs/subzonal_derivation.md`(§10–11 포함), `Docs/subzonal_hg_review_{astra,fable}.md`, `Docs/consult_subzonal_vacuum_reply_{astra,fable}.md`, `Docs/subzonal_c_results.md`. 코드 `Exam/exam.c` `GFS_SUBZONE`.

## 새 결과
1. **Gresho 소용돌이(128², 주기 상자, t=1):**
   - L1(v_φ): HLLC 0.033, TCF 0.036(쌍 붙음 때문에 dt 2.7e-5로 느림), TCF + Φ + Z_H 0.319, 2차 Q + Φ + Z_H 0.321.
   - Φ판에서는 소용돌이가 점점 멈춘다. r 0.1–0.2에서 v_φ = 0.766(t=0.25), 0.620(0.5), 0.155(1.0)이고, 정확해는 0.78이다. 바깥쪽(0.3–0.4)은 0.24에서 0.35로 빨라진다(각운동량이 바깥으로 이동).
   - 총에너지는 1543단계 근처에서 dt가 2.7e-4와 1.4e-4 사이를 오가며 부호를 바꿔 −3.9e-4까지 쌓였다. Φ 장부(ΣdΦ + Σv·F)는 ~1e-17이고 상자 변 셀은 0이다. Φ 강성에 비해 시간 간격이 큰 적분 오차로 추정한다.
   - 해석: 회전 차이가 있는 흐름에서 격자가 비틀려 생성점이 셀 중심에서 O(h) 벗어나고, 중심 기준 Φ가 이를 되돌리려는 탄성으로 작용해 흐름을 붙잡는다.
2. **상자 변의 공유 면 어긋남(자유 표면 판, P=1, Q=0, `EUNHA_VORO_RHO` 없음):**
   - TCF만으로도 총에너지가 −3.8e-3이고 dt와 무관하다(1e-3, 2.5e-4에서 같음). 아영역을 켜도 −3.0e-3이다.
   - 첫 우변의 면 기록에서 A > 1e-6h인 면 중 한쪽에만 있는 면은 0개, 길이가 어긋난 면은 228개이다. 모두 가장자리 셀(|x−3| = 0.71–0.74, 판 반폭 0.75)에 있다. 셀마다 자기 상자(`VORO_CELLBOX`, 5Δ, 생성점과 함께 이동)로 공유 면을 다르게 자르기 때문이다.
   - 길이 ~1e-10인 퇴화 면의 어긋남(회전 격자의 4점 공원 배치, voro.c의 EPS 처리)은 에너지에 무관하다.
   - Noh(주기 상자, 가장자리 진공)의 −1.5e-4도 Courant와 무관하므로 같은 원인으로 본다.
3. **hourglass 점성 검토(§10):** Rayleigh 장부는 승인됐다. 그러나 무질서 격자에서는 전단에도 작용한다(Fable: Kepler 궤도당 8% 가열 추정). 최소제곱 아핀 필터 ξ̇^na = Σ∇̃ξ·v로 고치면 모든 아핀장에서 0이 된다. 면 아영역 상태 임피던스는 1D 엔트로피 흩어짐을 0.060에서 0.043으로 줄였다.

1. **(가) 아핀 수송 기준:** Φ의 기준(중심 c_i 대신)을 국소 아핀 흐름과 함께 움직이게 정의할 수 있는가? 예: 기준 질량 비율 β_f = M_f/m_i를 상태 변수로 두고 β̇_f를 최소제곱 아핀 운동에서 정의하거나, 셀마다 기준 변형 텐서를 들고 다니는 방식. 변분 구조(위치만의 퍼텐셜이 아니게 되면 에너지 보존은?), 위상 변화 처리, 전단 흐름에서 Φ가 쌓이지 않는지, 쌍 붙음(Sod) 복원력이 남는지를 평가해 달라.
