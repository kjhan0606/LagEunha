# 자문 요청 (19차): 총에너지 보존을 강제한 채 기하 보존 법칙(GCL)을 정확히 맞추는 구성

작성: 2026-10-01. **사용자 결정(새 원칙): 최종 목표는 Laguerre 방식이며, 총에너지 보존은 무조건 강제한다.** 엔트로피 변수로 갈아타 보존을 깨는 방식(18차 질문의 전제)은 채택하지 않는다. 다른 원칙은 같다(패치·임의 조정값 금지, 입자 = 생성점, 셀 생성 알고리즘 유지, 바닥값 1e-6 유지, DTETA 미사용, 부피는 기하가 정함).

## 진단 요약 (Docs/gfs_scheme3_formulation.md §26.2)
- Hill 띠(37° 회전 격자, Coriolis+조석력)에서 내부에너지 모드는 궤도당 일정 비율로 가열되어 붕괴한다. 엔트로피 모드(P = Kρ^γ, ρ = m/V 기하)는 격자 잡음 약 0.2c에서 30궤도 포화.
- 가열은 시간간격에 강하게 의존(dt3 계수 절반 → 4–6배 감소). 총에너지 RK 잔차·면 쌍 장부는 무시 가능.
- 면 법선 속도 공식 w_n = e·v̄ − Δv·(x−m)/d(W=0)는 오프라인 수치 미분과 2e-6 이내 일치. 그러나 RK4 단계별 Σ_f A_f(w_f − v_i·n)의 가중합(장부 부피)과 다음 스텝의 실제 셀 부피 변화의 차이가 회전 격자에서 장부값과 같은 크기(`GFS_VOL_AUDIT`). 회전 격자는 스텝의 89%에서 RK 단계 사이 위상 변화(입자의 13%).
- 현재 에너지 경로(SEDOV_PHASE1): dE_i/dt = −Σ_f P*_f A_f w_f(쌍 상쇄, 총에너지 보존), I = E − KE, P = (γ−1) I / V_geom.

## 해석
압력·밀도는 실제 기하 부피로, 일은 RK 장부 부피로 계산되어 그 차이가 매 스텝 무작위 부호의 가짜 PdV가 된다. 차가운 기체에서는 그것이 음속 수준의 압력 잡음이 되고 소산되어 열로 쌓인다.

## 구성 후보 (총에너지 보존 유지)
**(1) 스텝 단위 면 swept volume.** 총에너지 갱신을 E_i^{n+1} = E_i^n − Σ_f P̄*_f ΔV_f로 한다. ΔV_f는 스텝 동안 면 f가 쓸고 간 실제 면적(쌍 반대칭이므로 총에너지 정확 보존), P̄*_f는 RK 단계 P*의 가중 평균. 운동량은 기존 RK4. 그러면 P*가 균일할 때 ΔI_i = −P ΔV_i(기하)로 정확히 맞는다(Σ_f A_f n_f = 0). 위상 변화(면 생성·소멸) 때 ΔV_f의 정의가 문제다.
**(2) 교집합 기반 쌍 교환 부피.** ΔV_ij = |C_i^{n+1} ∩ C_j^n| − |C_j^{n+1} ∩ C_i^n|. 반대칭이고 Σ_j ΔV_ij = ΔV_i(같은 영역의 분할이면 정확). 위상 변화와 무관하게 정의된다. 원판 합집합 경계(진공)에서는 영역 자체가 변한다. 계산 비용(다각형 교집합).
**(3) RK 단계별 GCL.** 각 단계에서 장부 부피율을 다음 단계 기하와 정확히 맞추는 시간 적분(예: 기하 부피를 상태변수로 두고 V_i를 장부로만 진화, 또는 단계별 부피 차분으로 일을 정의).
**(4) 기타.**
