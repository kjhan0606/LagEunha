# 설계 위임 (Astra): Voronoi 생성점 = 입자 정식의 hourglass·쌍 붙음, 전단 정합성, 진공 경계, 시간 간격 — 구현 가능한 단일 설계서

작성: 2026-10-02. 사용자 지시: "자문과 의견 제시가 핑퐁식으로 오가니 Astra에게 설계를 맡겨라." 이번에는 검토가 아니라 **설계서 한 편**을 요청한다. Claude는 이 설계서를 그대로 구현하고, 관문 결과만 보고한다.

## 반드시 지킬 원칙 (사용자)
- 입자 = 생성점. 질량은 고정, 부피는 기하(반평면 깎아내기 Voronoi, 장차 Laguerre)가 정한다.
- 운동학적 조향은 금지한다(생성점 속도 = 물질 속도). 보존력이나 소산력은 허용한다.
- 총에너지는 반이산에서 정확히 보존한다(필수). 셀별 엔트로피는 비음수이다.
- 증상 대처, 문턱값, 임의 스위치는 쓰지 않는다. 매개변수가 필요하면 물리적 근거와 함께 명시한다.
- 한 번에 하나씩 바꾸고, 관문으로 검증한다.
- `Voro/voro.c`의 EPS 처리는 손대지 않는다.
- 최종 목표는 Kepler 진공 고리(GIZMO MFM 비교, 100궤도 이상)와 우주론 주기 상자이다.

## 지금까지의 사실 (근거 문서)
- TCF(`Docs/tcf_derivation.md`, G1 서명): 변분 가역 힘(셀 압력), Q = Z·minmod(Δu_rec, Δu_cell), 반대칭 에너지 교환. G2 통과(`Docs/tcf_g2_results.md`).
- G3 실패 진단(`Docs/tcf_g3_diagnosis.md`):
  - 회전 격자 Hill에서 소산이 잡음을 만든다(Q=0이면 깨끗).
  - 원판(ρ=Δ)이 내부 바늘 셀을 자른다.
  - 2차 Q(QLAW=2)는 원판이 없을 때 30궤도 가열을 ×1.002로 줄였다.
- Sod 실패(`Docs/tcf_sod_diagnosis.md`): 셀 부피 라그랑지안의 에너지 0 홀짝 모드(1D에서 F_i = (P_{i−1} − P_{i+1})/2). 쌍 붙음으로 dt가 붕괴한다.
- 아영역 Φ(`Docs/subzonal_derivation.md` 3.2 서명, §10–11 조건부; 결과 `Docs/subzonal_c_results.md`):
  - Sod 2D 통과(L1이 HLLC보다 좋음), Noh에서 붕괴를 막음.
  - 그러나 Gresho에서 소용돌이가 멈춘다(L1 0.32 대 0.033). 중심 기준 Φ가 전단을 붙잡는 탄성으로 작용한다.
  - 엔트로피 흩어짐이 2배이다.
  - Sedov 에너지 오차 +1.5e-2(벽 고스트 셀은 Φ 제외, 원인 미확정).
- hg 점성(§10): 장부는 승인. 아핀 필터가 필요하다(Fable). 면 아영역 상태 임피던스가 엔트로피 흩어짐을 줄인다.
- 진공 경계(27–29차): 원판은 수치 경계 모형이다. 상자 변(`VORO_CELLBOX`, 5Δ)은 숨은 원판이고 공유 면을 셀마다 다르게 잘라 **TCF 에너지가 dt와 무관하게 샌다**(자유 표면 판 −3.8e-3, Noh −1.5e-4). 같은 반지름 원판은 W=0에서 정합한 분할이다.
- 자문 원문: `Docs/consult_*`, `Docs/*review*`, `Docs/consult_subzonal_shear_reply_astra.md`. Fable의 1D·2D 실험 스크립트: `Docs/subzonal_checks/`.
- 코드: `Exam/exam.c`(`GFS_TCF`, `tcf_ok`, `tcf_pstar`, `GFS_TCF_QLAW`, `GFS_TCF_ZH`, `GFS_SUBZONE`, `sub_build`, `sub_eval`, `voro2d_restrict_disc`, `VORO_CELLBOX`, `exam2d_vph_rk4_int_blend`).

## 설계서에 담을 것
1. **선택과 근거:** hourglass·쌍 붙음을 무엇으로 막는가((가) 아핀 수송 기준 Φ, (나) 아핀 필터 점성, 둘의 결합, 다른 안). 전단 흐름(Gresho, Kepler)에서 해를 바꾸지 않는 조건과, 충격(Sod, Noh, Sedov)에서 쌍 붙음을 막는 조건을 함께 만족하는 구체적 정식.
2. **수식 전체:** 퍼텐셜·힘·켤레력(이력 상태가 있으면 그 수송과 켤레력), 소산력과 열, 셀별 에너지·엔트로피 장부, 위상 변화 처리(remap 포함), 원판 원호·상자 변·벽 고스트에서의 정의. 구현자가 추가 유도 없이 코드로 옮길 수 있는 수준.
3. **진공 경계와 공유 면:** 주기 영역(상자 변 비활성화 조건), 자유 표면(공통 Ω(t) 또는 원판 합집합), 공유 면을 한 번 계산해 양쪽에 쓰는 구조. 기존 TCF 교환식과의 관계.
4. **Q:** 임피던스 정의(Z_eff, Z_H, 면 아영역 상태), minmod와 QLAW=2 중 무엇을 기본으로 할지.
5. **시간 간격:** 강성과 점성 안정 조건을 실용적으로 계산하는 방법.
6. **구현 순서와 스위치 이름**(기본 꺼짐), 각 단계의 **관문**(정량 기준). 시험은 G2 항등식, Sod·Noh(유입 경계 정의 포함)·Sedov, Gresho, Hill 회전 격자, 자유 표면 판, Kepler 진공 고리 64²·256².
7. **실패 시 되돌아갈 경로**와 최종 서술(논문에서 무엇을 주장할 수 있는가).

필요한 계산(유도 확인)은 해도 되지만 저장소 파일은 바꾸지 않는다. 한국어로 쓰고, 결론(선택한 설계)을 먼저 둔다. 분량 제한은 없으나 구현 가능한 명세를 우선한다.
