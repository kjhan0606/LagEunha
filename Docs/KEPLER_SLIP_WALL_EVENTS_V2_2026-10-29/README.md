# Native wall events v2: preserved global IDs

V2 extends the frozen [v1 event controller](../KEPLER_SLIP_WALL_EVENTS_NATIVE_2026-10-29/README.md) without changing its physical RHS, collision law or timestep policy. `EVENTS_V1_TO_V2.patch` is a zero-context patch against v1 `Exam/gfs_wall_events.inc`; the complete replacement include and unchanged dense polynomial header are also stored here. `BUILD.json` pins the native source and executable hashes. Apply the v1 reconstruction first, then this patch or the complete v2 include. V1 remains frozen and available.

The immutable accepted ID set is separate from per-trial visitation stamps. IDs may have gaps and native records may reorder. Every validated trial must have the original count, exactly one occurrence of each original ID and exactly the original mass per ID. Allocation range/overflow checks precede indexing. The direct lookup supports IDs below `INT_MAX` and an extent below `8*N+1024`; it does not claim arbitrary sparse 56-bit ID support. Visitation generations avoid clearing the entire lookup at every RHS.

Every normal or searched-safe-prefix acceptance now explicitly checks the final native coordinates against the polygon, independently of the dense root proposal. The contact path retains its existing complete endpoint/corner checks before any impulse. Unresolved outside endpoints roll back and reduce the interval; there is no clamping or steering.

`UNIT_RESULTS.json` covers analytic impacts plus gapped/reordered/duplicate/substituted IDs, changed masses, unreasonable ID range, visitation-generation wrap, both no-root endpoint acceptance paths and exact rollback. These tests execute the actual include with MPI/geometry/cache adapters. `NATIVE_GLOBAL_ID_AUDIT.json` provides separate real GPU evidence: unchanged compact-ID v1/v2 results, a forced gapped-ID retry, and a physical crossing through t=48.4 with IDs relabeled as `2*old_ID+7`. After inverse relabeling, every stored record byte except the runtime next pointer, and the full restart footer, matches exactly. Both collision runs pass the existing local physical gates.
