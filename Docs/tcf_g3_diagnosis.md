# TCF 관문 G3 실패 진단 (2026-10-02)

자문: `Docs/consult_g3_failure.md`와 Astra·Fable 답신. 실행 디렉터리: `/gpfs/kjhan/LagForce/G3*`.

## 결과
1. **G3:** 회전(37°) Hill 띠 30궤도에서 기준선(HLLC)의 내부에너지는 ×5.2e4, TCF는 ×1.2e6이다. 정렬 격자는 두 방식 모두 ×1이다. TCF의 반이산 장부는 정확하고(면 교환 합 ~1e-15, zneg = cellneg = 0), 총에너지 오차 4.6e-2는 격렬해진 뒤 커진 RK4 절단 누적이다.
2. **잡음은 소산 항이 만든다.** `GFS_TCF_Q0=1`(가역 힘만)에서는 회전 격자 내부가 8궤도 동안 rms ln ρ ~1e-7, dv/c ~3e-4에 머물렀다. 완전한 격자는 선형 전단에서 아핀 변형만 하므로 합동으로 유지된다. 가장자리 잡음(~0.2)은 안으로 번지지 않았다.
3. **접선 힘은 증폭원이 아니다.** 4.06궤도 체크포인트에서 분기했을 때 섭동 KE 성장률(ln, 궤도당)은 완전 TCF 0.71, 접선 힘 제거 4.76(즉시 폭주), HLLC 0.22였다. 고정 dt 2e-3과 CFL dt는 같은 결과를 냈다.
4. **씨앗 1 — 원판이 내부 바늘 셀을 자른다.**
   - 회전 격자는 전단 때문에 주기적으로 모든 셀이 동시에 위상을 바꾼다(topo_chg 6726/6726).
   - 그 직후 셀이 바늘이 되고(A/d ≈ 4), 먼 이웃의 이등분선(0.0625)이 원판 반경 ρ = Δ = 0.063을 넘는다. 셀 끝이 진공 원호로 잘려 내부 셀에 쌍 면이 2개만 남는다.
   - LSF 행렬이 특이해진다. 속도 기울기가 −4.24(정확)에서 중앙값 0으로, 이어 ±2e6으로 바뀐다.
   - |Δu_rec/Δu_cell|이 ~1e-12에서 0.5–1로 커지고, 면 열이 1e-11에서 5e-3으로 뛴다. 제한자를 바꿔도(pair 제거, 기본 제한자) 같다.
   - 원판 모형에서 유체 영역은 원판 B(x_k, ρ)의 합집합이므로, 이웃 간격이 2ρ를 넘으면 내부에 진공 틈이 생긴다. ρ = Δ는 전단된 격자에서 너무 작다. ρ는 시험 정의이므로 바꾸려면 사용자 승인이 필요하다.
5. **씨앗 2 — 자유 표면 잡음이 소산을 통해 안으로 번진다.** 원판 없이 실행하면 잡음이 궤도 0.5에 가장자리(|x| 0.65–0.75)에서 ~0.1c로 생긴다. 0.45–0.55 구간은 궤도 3.7, 0.15–0.3 구간은 궤도 9에 커진다. Q=0이면 번지지 않는다.
6. **공통 고리.** 면 열 ½A·Z·minmod(Δu_rec, Δu_cell)·Δu_cell에서 Δu_cell은 평균 전단이고, 셀 규모 마하수는 |Δu_cell|/c ≈ 100이다. 재구성 오차가 c의 1%만 되어도 큰 소산 충격이 된다. TCF는 엔트로피 부등식 때문에 이를 한 부호로 정류한다(Fable).

## 판단
- 접선 항과 제한자는 원인이 아니다. t=0 재구성은 정확하다(|Δu_rec|/c ≤ 7e-13).
- 처방 후보: Fable의 2차 Q 법칙 Q = Z·Δu_rec·clamp(Δu_rec/Δu_cell, 0, 1). 열은 Z·Δu_rec²(r ∈ [0,1]) 또는 Z·Δu_rec·Δu_cell(r > 1)로 비음수이고, 문턱값이 없으며, 충격(r ≈ 1)에서는 현 TCF와 같다.
- 원판 반경 문제는 사용자 결정 사항이다.
