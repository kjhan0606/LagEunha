# 자문 요청 (9차): 원판 경계 + (H) DAE 결합 (2단계) 정식 검증

작성: 2026-10-01. 사용자 원칙: 패치 금지, 정합한 solver, 입자 = 생성점. 이전 답: `Docs/consult_vacuum_boundary_reply_astra.md`(8차).

## 0. 1단계 결과 (방식 (1), W=0, 원판 ρ=Δ, `497cd88`, GIZMO 입자판 Kepler 1랭크, DTETA 없음)

- 원판 없는 방식 (1)은 t=6–8에 원반이 붕괴했다. 원판을 넣으면 **t=13.8(r=1 기준 2.2궤도)까지 붕괴가 없다.** 총 dLz/Lz₀는 −4.6e-8, dE는 6e-6이고, dt는 CFL을 유지했다.
- t≈0.1 가장 안쪽 고리: 긴 옆면이 0개가 되었고, 토크는 원판 없을 때의 1/8(−1.2e-5/호출)이다.
- 가장 안쪽 입자의 j/j_K는 t=5에 0.977, t=13에 0.915, t=15에 0.850이다. 원판 없는 (H) DAE는 t=8.4에 0이었다.
- 남은 느린 손실은 일반 면에서 온다(t≈5, −2.5e-4/호출). 진공 경계조건은 아직 기울기와 제한자에 넣지 않았다.

사용자 확인: W에는 물리적 의도가 없다. "대략 두 입자 거리보다 작아야 한다"는 기준만 있었다(= Laguerre 유효성).

## 1. 제안 정식 (2단계)

- `R_i² = W_i + ρ²`(W 절대값, 기준은 아래 2), `B_i = {x : p_i(x) ≤ ρ²}`, `V_i = |C_i ∩ B_i|`.
- **부피율 (Reynolds 수송):** `V̇_i = Σ_f A_f w_f + v_i·∮_arc n ds + ℓ_i Ṙ_i`, `Ṙ_i = Ẇ_i/(2R_i)`.
  - 면은 원판에 잘린 구간이고, `w_f = ũ + ρ_rot + δ`에서 회전 항 ρ_rot은 잘린 구간의 중심 오프셋 t로 계산한다(면 위에서 법선 속도가 선형이므로 잘린 구간 평균 = 잘린 중심값).
  - ℓ_i는 노출된 원호 길이다.
- **Jacobian:** `∂V/∂W = ½ L_{A/d} + diag(ℓ_i/(2R_i))`. 노출 원호가 있으면 상수 방향이 영공간이 아니다.
- **W 기준(게이지):** 사용자 확인대로 W의 절대값에 물리적 의미가 없으므로, 진공 경계가 있는 연결 성분에서는 **DAE `V(x,W) = V^T`가 W의 절대값까지 정한다**고 본다. 진공 경계가 없는 성분(원판이 셀을 자르지 않는 경우)은 기준이 결과에 영향이 없으므로 `min W = 0` 등으로 둔다.
- **힘:** 내부 면은 `f = −A[P* n + (P_j − P_i)t/d]`(A, t는 잘린 면 값)이고, 원호는 P*=0이라 힘이 없다.
- **에너지:** `dU_i = −P_i V̇_i + θ_i D_f`.

## 2. 유도하다 발견한 문제: 원호의 W 몫 일

§3의 항등식을 따라가면 총에너지 변화는 다음과 같다.

```text
Σ_i (v_i·F_i + U̇_i) = Σ_f D_f(내부 쌍, 상쇄) − Σ_i P_i v_i·(Σ_face A n + ∮_arc n ds) − Σ_i P_i ℓ_i Ṙ_i
```

- 셀이 닫혀 있으면 괄호 안은 0이다.
- 남는 `−Σ_i P_i ℓ_i Ṙ_i`를 받아 줄 힘이 없다. W가 자유표면을 진공 쪽으로 밀 때 셀 내부에너지는 `P dV`만큼 줄지만, 그 에너지가 운동에너지로 가지 않는다.
- 연속체의 자유 팽창에서는 내부 압력 기울기가 가장자리 가스를 가속해 내부에너지가 운동에너지로 바뀐다. 여기서는 W 운동이 입자 운동량과 결합돼 있지 않다.
- 1단계(Ṙ=0)에서는 이 항이 없다. 원호가 입자와 함께 강체 이동하기 때문이다.
