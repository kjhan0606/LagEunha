## 비용 개선

기존 스칼라 residual 반복은 질량 제약 해의 유한차분 미분을 구하면서
동일한 면 기하와 플럭스를 여러 번 평가한다. 기존 첫 사례의 면 평가 횟수는2866회였다.
`predicted_spacetime_flux.rate`에 해석적 가중치 미분 Jacobian을 추가했다.

내부 면 i,j의 계수는 `c=면길이*구적가중치*유효밀도/(2*생성점거리)`이다.
유효밀도는 각 양의 속도 표본의 upwind 활성 여부에 따라 계산한다.
정규화 시간 기준 질량 플럭스의 가중치 미분은 대각 -c, 비대각 +c의
그래프 Laplacian 형태이다. 경계 면은 내부 가중치 미분에 의존하지 않는다.
전체 열 합은 0이며 가중치 gauge 영공간을 유지한다.

기존 static 유량 검사에 중앙차분 Jacobian 대조와 열 합0 검사를 추가해 통과했다.
수송 부호가 정확히0일 때 미분은 기존 transport의 대칭 1/2 규약을 따른다.
`instantaneous_weight_path.run`에는 analytic 선택 인자를 추가했고 기본은 기존 방식이다.
같은 미분 입력에 대한 residual/Jacobian 평가를 공유한다. 실제 가속비는 아직 미측정이다.
