# 자문 요청 (Astra, 25차): 가중치 경로의 최종 판정 — 깨끗한 비진공 설정의 DAE 결과

작성: 2026-10-09. 근거: `Docs/dae_periodic_verification_2026-10-09.md`(표·결론), `Docs/polybnd/daeP.py`, 23차 답신(`audit_impl23_astra.md`), 평활 부피 기각(`HANDOVER §5.7`).

## 상황
- 사용자 결정: 가중치(Laguerre) 경로를 열어 두고, 비진공·주기 설정에서 DAE를 재판정.
- 결과(위 문서): 2차 보존 플럭스 DAE는 구동원을 초기 10–40배 억제하지만 |ΔW|/d²가 배경에서 ≈0.1/시간, 원반에서 ≈0.03/시간으로 세속 성장해 t≈10에 한계에 닿고 억제력을 잃는다. 중점 운동학 DAE는 억제도 없고 가중치도 폭주. 원호·동결 경계·전이 불균형을 모두 없앤 설정이다.
- 평활 부피 변분 정식화(U(Ṽ), 커널 평균)는 성장률 ∝ η^−2로 100궤도에 η≈15가 필요해 기각.
- 가역 불안정의 성장률 ≈1.1·c_s/d는 Python·C에서 반복 확인됨(전단 필요, 전단률 무관).

## 질문
1. 23차의 "플럭스 정확도는 필요조건이지 충분조건이 아니다"가 이번 자료로 확정되는가? |ΔW| 성장률 0.03–0.1/시간(64², d=0.094)이 해상도·플럭스 차수에 따라 어떻게 변할지의 규모 추정(f≈0.066 가정과의 비교).
2. 가중치 경로를 **닫을지**, 아니면 남은 구체 후보가 있는지: (a) 기하 부피 평균을 따르는 가중치(저역 통과) — τ_V 시험은 구동원 복귀로 실패, (b) 가중치를 물질 부피가 아니라 "미끄러짐 요동만" 상쇄하도록 정의하는 방법(요동 성분과 세속 성분의 분리가 가능한가), (c) 그 외.
3. 가중치 없이 구동원(기하 부피에 대한 압력의 즉시 반응)을 끊는 다른 길: (a) 압력을 셀이 아니라 **면/영역**(엇갈림)에 두는 정식화, (b) 체적 변화의 시간 적분을 **입자 자신의 궤적**으로 정의(예: dV/dt = V ∇·v의 ∇·v를 보존형 고차 플럭스로 — 이는 DAE의 V^T와 같으나 가중치 없이 V^T를 직접 압력에 쓰고 기하 부피는 힘의 ∂V/∂x에만 쓰는 비변분 정식; 에너지 보존의 조건), (c) 생성점 조향 없이 셀 기하를 규칙화하는 방법이 원리적으로 존재하는가.
4. 결정 권고(결론 먼저): 어느 길을 다음에 Python으로 검증해야 하는가.
