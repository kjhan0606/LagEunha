# Same-parent Q1 thermal precision comparison

H200 job 439819 requests one H200 and eight CPU threads and is independent of running job 439375. It was pending for `QOSGrpGRES` at submission. It starts from the preserved accepted t=10 Q1 checkpoint, uses the experimental thermal64 bounded-wall candidate, and advances to t=10.1 with exactly the same timestep cap as the completed single-precision half control. The only planned full output is one approximately 52 MB endpoint. The original t10 state and all prior simulations remain intact.

The accompanying analysis checks same IDs, masses, W0, timing and cap, absence of energy injection, tagged positive U64/V64 and float mirrors. It compares incremental entropy in core and disk using the authoritative double payload; the initial double volume comes from the separately audited Ada zero-time promotion, so cross-GPU geometric roundoff remains a limitation. The single-precision comparison is a certified prior result. This is a short diagnostic from an already damaged state, not proof of long-time stability, elimination of inherited core error or a formal convergence order. No result is claimed while the job is pending or running.
