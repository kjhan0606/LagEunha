# 아영역 압력 (나) 검토 — Fable (2026-10-02)

## 결론 (먼저)

**조건부 승인.** (나)는 정합한 보존력이고 hourglass 모드를 제거하며 조향이 아니다. 단, 초안의 세 군데를 고쳐야 한다. (i) §5의 셀별 장부 식이 틀렸다(−Σ e·… 가 아니라 **+Σ h_{i,f} ṁ_{i,f}**, h = e + P/ρ 비엔탈피). (ii) L은 위상 변화에서 **C⁰이지만 C¹이 아니다**(힘이 유한 점프, 2D 수치로 확인: 국소 힘의 ~5%). 초안 §7-1의 "C¹"은 성립하지 않는다고 적어야 한다. (iii) 셀 압력 P_i는 반드시 **P(ρ_i, s_i)** 로 정의해야 하며 (γ−1)U_i/V_i로 쓰면 Φ가 열압력으로 새어 들어가 바늘 셀에서 가짜 압력이 생긴다.

## (1) 수학적 검증

**1D에서 (나)는 질량이 위치 함수가 아니다.** 1D 셀의 중심은 항상 셀 중점이므로 h_f(c_i) = V_i/2, 따라서 **m_{i,f} = m_i/2 (고정)**, ρ_{i,L} = m_i/d_{i−1,i}, ρ_{i,R} = m_i/d_{i,i+1}. ∂m/∂x = 0이다. 그러므로 1D 시험으로는 ∂m/∂x 항과 위상 연속성을 검증할 수 없다 — 2D가 필수다.

**복원 강성.** 홀짝(Nyquist) 모드 x_i → x_i + (−1)^i δ에 대해 F_i = −(4ρc²/Δ)δ, 즉 **k_Nyq = 4ρc²/Δ, ω_Nyq = 2c/Δ**. 16셀 주기 사슬 Hessian으로 확인: 셀 부피 라그랑지안의 Nyquist 강성 = −5e-8(0), (나) = 6.6667 = 4ρc²/Δ 정확히 일치. 분산 관계도 k(q) = (4ρc²/Δ) sin²(qΔ/2)와 전 모드에서 일치(5자리). 유한차분 힘과 P̂_{i−1/2} − P̂_{i+1/2}의 차이 2e-9.

**Φ_i ≥ 0, 최솟값.** Σ_f V_{i,f}(x_i) = V_i이고 질량가중 평균 비부피가 v_i이므로, e(v)가 v에 대해 볼록(∂²e/∂v² = ρ²c² > 0)이면 Jensen으로 Φ_i ≥ 0. 등호 조건은 모든 f에 대해 h_f(x_i) = h_f(c_i) — 평행하지 않은 변이 둘 이상이면 **x_i = c_i 유일**. 수치: 격자 Φ = 0(정확), ±0.25 간격 교란 격자 Φ_min = 1.0e-3 > 0, ΣΦ/Σm e = 1.4%. 중요한 따름정리: **Bravais 격자의 Voronoi 셀은 중심대칭이므로 균일 전단을 받아도 c_i = x_i, Φ ≡ 0**. 균일 전단 자체는 Φ 힘을 만들지 않는다.

**위상 변화 연속성.** 4×4 주기 Voronoi에서 생성점 하나를 flip을 가로질러 이동: U 점프 = 기울기×2ε(ε→0에서 0으로 수렴, 연속). 그러나 dU/ds 왼쪽 −0.12549, 오른쪽 −0.13234, **점프 −6.86e-3 (ε=1e-4→1e-7에서 수렴, 진짜 불연속)**. 같은 구성에서 셀 부피 U는 기울기 점프 3e-5(잡음, C¹), 2계 미분만 1.05→0.98 점프. 원인: V_{i,f} = ½A_f h_f는 꼭짓점이 변을 따라 미끄러질 때 1차로 변하고(T_{i,f} ↔ T_{i,g} 면적 이동), flip에서 꼭짓점 속도가 불연속이다. x_i = c_i이면 가중치가 같아 상쇄되므로 점프가 사라진다. 결론: **힘은 유계이고 조각별 연속, 에너지는 연속 → 반이산 보존은 유지되나 RK4 국소 차수가 flip에서 1차로 떨어진다.** 초안 §3의 "ρ_{i,f} 유한, 연속"은 맞다(A_f → 0에서 질량·부피가 함께 0).

## (2) 1D에서 알려진 방식과의 관계

(나)의 1D 퍼텐셜은 간격별로 재배열된다: U = Σ_gap [½m_i e(m_i/d_i, s_i) + ½m_{i+1} e(m_{i+1}/d_i, s_{i+1})]. 균일 m, s이면 **정확히 von Neumann–Richtmyer 엇갈림 격자**(zone = 간격, 질량 m, 압력 P(m/d_i), 노드 속도 = 생성점 속도)이고, 힘 F_i = P̂_{i−1/2} − P̂_{i+1/2}, P̂ = (P_{i,R} + P_{i+1,L})/2. 불균일 s에서는 zone 압력을 두 반질량 압력의 평균으로 쓰는 변형이다. Caramana–Shashkov와는 1D에서 **동일**(고정 m_i/2, 완전 비선형 압력판). CS의 선형화 δp = c²(ρ_s − ρ_z)와는 선형 차수에서 같은 강성.

## (3) 오류와 장부

**정확한 셀별 장부**: U_i = Σ_f m_{i,f} e(ρ_{i,f}, s_i)에서 ∂(m e(m/V))/∂m = h, ∂/∂V = −P이므로

  dU_i/dt = Σ_f [ h_{i,f} ṁ_{i,f} − P_{i,f} V̇_{i,f} ],  Σ_f ṁ_{i,f} = 0.

초안 §5의 "−Σ e(ρ_{i,f})…" 는 부호와 변수(e가 아니라 h) 모두 틀렸다. 실용적 구현: dU_i/dt = Σ_j (∂U_i/∂x_j)·v_j(U_i는 i와 Voronoi 이웃에만 의존)를 쓰면 Σ_i dU_i/dt = −Σ_j F_j·v_j가 항등식이라 **반대칭 면 분해 없이 총에너지가 정확**하다. 기존 "dU_i = −P_i dV_i"는 더 이상 성립하지 않는다.

**가역성·엔트로피**: s_i 고정에서 U_i(x, s_i)는 상태함수이므로 Φ는 가역 저장이 맞다. 소산 ½AQΔu는 ds_i = ½AQΔu/(m_i T̄_i), T̄_i = Σ m_{i,f}T(ρ_{i,f}, s_i)/m_i ≥ 0 — 셀별 비음성 유지. 이상기체에서 K_i = (γ−1)U_i / Σ_f m_{i,f} ρ_{i,f}^{γ−1}로 선형 역산 가능. **P_i = K_i ρ_i^γ 로 Q·재구성에 넘겨야 한다**(결론 (iii)). 분리(Q는 셀 평균, Φ는 가역)는 양립한다.

## (4) 전단 흐름·숨은 조향

Φ ~ ½ m c²(ε/h)². 균일 전단 격자는 Φ = 0이므로 위험은 **무질서(글래스) 구성**과 **차등 전단**이다. 정지 글래스(ε/h ~ 0.25)는 Φ/U ~ 1.4% → 음속 진동 후 Q로 1회성 가열 ~1%. 차등 전단에서 평형 ε/h ~ |∇v|h/c(셀 가로 전단 Mach), Φ/U = O(h²) → 해상도와 함께 소멸, 유효 점성 ~ρch(ε/h)² ≪ Riemann Q. Kepler 바늘 셀에서는 ε/h가 O(1)일 수 있어 측정 필수. 조향 여부: 생성점 속도 = 물질 속도, 보존력, 병진 불변(ΣF = 1e-9 확인) → **운동학적 조향이 아니다**. 다만 CVT가 힘 평형점이므로 격자 규모에서 Lloyd와 같은 방향으로 역학을 바꾼다는 점은 솔직히 적어야 한다(CS도 동일). CFL: ω_max가 c/Δ → 2c/Δ로 2배, 바닥은 Δt < min_f h_f(x_i)/c_{i,f}(Sod 붙음 셀에서 10배 감소, 붕괴는 아님).
