# TCF Sod 실패 진단 (2026-10-02)

## 현상
- Sod(128², 주기 상자, 계면 x=L/4·3L/4, γ=5/3, 질량 ∝ 밀도)에서 TCF(minmod Q, 2차 Q 모두)는 t≈0.0283에 시간 간격이 1e-15로 붕괴해 멈춘다. 기존 HLLC는 214단계로 t=0.1까지 간다.
- 에너지 장부는 정확하다(dE 3e-7, zneg=0, cellneg=0).
- 붕괴하는 것은 접촉 불연속 근처의 가벼운(바깥 기체) 입자 두 열(x≈0.2231, 0.2234)이다. t=0.014부터 간격이 정상 간격 7.8e-3의 1/10인 8e-4로 붙어 있었고, t≈0.026부터 다시 다가와(상대 속도 0.14) 충돌한다.

## 면 기록 (t=0.026, 쌍 6558–6559)
- Δu_rec = 0.137, Δu_cell = 0.140, Z = 0.137, Q = 0.0187: 소산은 켜져 있다.
- 셀 압력 0.326 / 0.150, 부피 3.4e-5 / 6.0e-5. 생성점이 각자 셀의 한쪽 끝에 있다.
- 상대 감속도 ≈ 13.6이므로 정지 거리는 v²/2a ≈ 7.2e-4이다. 남은 간격 2.7e-4보다 크므로 충돌한다.

## 원인: Voronoi 부피 라그랑지안의 에너지 0 모드(hourglass, 홀짝 분리)
- 1D에서 V_i = (x_{i+1} − x_{i−1})/2이므로 F_i = A(P_{i−1} − P_{i+1})/2이다. 자기 압력 P_i가 자기 힘에 들어가지 않는다.
- 홀수 번째 생성점만 같은 거리 δ만큼 옮기면 모든 V가 그대로이다(정확한 에너지 0 모드).
- 셀 평균 압력은 생성점이 셀 안 어디에 있는지 모른다. 쌍 붙음을 막는 것은 소산 Q뿐이고, Q는 거리에 무관하게 유한하다.
- 이는 G1에서 Astra가 경고한 위험 (나)(부피 보존 변위 모드의 복원력 부족)이며, VPH(Heß & Springel 2010)가 shape correction으로 다룬 문제이다.

Caramana–Shashkov(1998)의 아영역 질량·압력을 Voronoi/Laguerre 셀로 확장한다. 유도는 `Docs/subzonal_derivation.md`에 있다.
