## 2. 이번에 바꾼 이산 상태

독립적으로 적분한 원시 모멘트 대신 각 조각의
`(다각형, rho>0, u>0, b, B)`를 상태로 보관한다. 속도는 `v(x)=b+B x`이다.
`u`는 내부에너지 밀도이며 운동에너지와 분리되어 있다.

한 수송 단계:

1. 기존 상태에서 생성점의 점별 속도를 계산한다. 중심점 재배치나 조향은 없다.
2. 각 물질 조각을 자유 비행시킨다. `F=I+dt B`, `s=dt b`일 때
   `x_new=F x_old+s`, `rho_new=rho/det(F)`, `u_new=u/det(F)`이고,
   `B_new=B F^{-1}`, `b_new=b-B_new s`이다. `det(F)<=0`이면 실패 처리한다.
3. 이동한 양의 밀도 분포를 기준으로 **스텝 끝의 셀 질량**이 초기 목표 질량과
   같도록 가중치를 푼다. 순간적인 가중치 변화율을 RK4로 적분하지 않는다.
4. 이동한 조각과 수신 셀의 교집합을 만들어 모든 원시 모멘트를 다시 적분한다.
   질량 재정규화, 압력 floor, 음의 고유값 절단, 운동에너지의 열 전환은 하지 않는다.
5. 기증 조각과 수신 셀 각각의 면적 덮임, 재분배 전후 모멘트 보존을 검사한다.
   `rho,u,b,B`가 완전히 같은 조각에 한해서만 하나의 셀 다각형으로 합친다.
   합치기 전후의 모멘트 차이도 따로 기록한다.

삼각형별 양의 3점 적분 규칙은 2차 다항식까지 정확하다. 잔여 공분산은
`R = sum m_k (v_k-vbar-Bfit(x_k-c))(...)^T` 형태로 계산한다.
따라서 양의 분포의 Gram 행렬을 직접 구하며, `T-Bfit S Bfit^T`를 뺄 때 생기는
상쇄 오차와 구분할 수 있다. 두 방식의 고유값을 모두 출력한다.
유한한 R을 가진 조각을 하나의 선형 속도로 투영하지 않는다.

## 3. 이번 구현의 범위와 제약

- 시간 진화는 **균일 밀도·균일 압력·선형 전단** 패치에 한정한다.
  `v=(0.2+1.1 y,0)`, `rho=1`, `P=0.6`, `gamma=5/3`이다.
- 이 경우 `B^2=0`, `B b=0`, `det(F)=1`이므로 자유 비행이 정확한 Euler 해이다.
  상태를 매 스텝 실제로 이동한다. 해석해는 갱신에 주입하지 않고 진단에만 쓴다.
- 가중치 풀이의 질량 적분은 이동한 밀도가 균일하다는 검사 아래 `rho*면적`으로
  계산한다. 실제 교집합으로 얻은 질량을 별도로 확인한다. 비균일 밀도의 동적
  capacity 문제는 구현하지 않았으며, 그런 입력은 거부한다.
- 경계도 같은 선형 물질 흐름을 따른다. 일반 경계 조건을 해결한 것이 아니다.
- 공간적으로 달라지는 압력의 힘·일, 충격, 중력, 유한 R의 동적 응력 닫힘은
  미구현이다. 일반 압축 흐름에서 위 자유 비행만으로는 Euler 해법이 되지 않는다.
- 정확 유리수 교집합 대신 부동소수점 다각형 교집합을 쓴다. 덮임·보존 오차를
  기록하고 한도를 넘으면 중단한다. 아주 가는 조각과 장시간 누적은 별도 관문이다.
- 고정 질량은 **셀에 적분된 질량**이다. 생성점 속도와 셀 평균 속도는 일반적으로
  다르며, `p_i=m_i*생성점속도`인 점질량 역학을 증명한 것은 아니다.
- 이번에는 선형 전단 수송을 정확히 수행하므로, 통과하더라도 일반 문제의 시간
  정확도가 RK4 이상이라고 말할 수 없다. 앞선 두 오차 원인을 분리하는 검사이다.

## 4. 완료한 정적 검사

`test_positive_transport_patch.py`, 3개, 계산부 0.029초.
로그인 노드에서 스레드 1·nice 19·timeout 30초로 실행한 작은 대수/재분배 검사이다.
시간 진화는 로그인 노드에서 실행하지 않았다.

1. 일반 선형 자유 비행의 질량·운동량·각운동량·운동에너지·수동 내부에너지 보존,
   물질점 속도 보존, 선형 속도 잔차 검사.
2. 서로 다른 밀도·속도·내부에너지의 두 조각을 한 셀로 재분배:
   모멘트 보존, 서로 다른 조각 유지, 유한 양의 잔여 공분산 유지.
3. 물리 상태가 동일한 두 조각의 합치기: 모멘트 오차 검사.

2번은 정적 재분배 검사이며, 비균일 밀도 유체의 시간 진화 통과를 뜻하지 않는다.
