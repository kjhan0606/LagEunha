# 자문 요청 (17차): RK4 단계 사이의 면 위상 변화와 시간간격 의존 가열

작성: 2026-10-01. 원칙은 같다(패치·임의 조정값 금지, 입자 = 생성점, 셀 생성 알고리즘 유지, 바닥값 1e-6 유지, DTETA 미사용).

## 증거 (Hill 띠, 37° 회전 격자, Ω₀=2.83, P=1e-6; 16차 자문의 재현기)
| 구성 | 12궤도 E_int | 24궤도 E_int | e-폴딩 |
|---|---:|---:|---:|
| 쌍 구간 제한자 | 2.7e-3 | 0.60 | 약 2.2궤도 |
| + 마름모 범위 제한(i, j, k₊, k₋ 값 범위) (`94cbc1d`) | 8.4e-4 | 2.6e-2 | 약 3.5궤도 |
| + 2점 Gauss 면 적분 | 7.0e-4 | 1.9e-2 | 약 3.6궤도 |
| 마름모 + **dt3 계수 0.1 → 0.05** (`11a8e68`) | **2.3e-4** | **4.1e-3** | 약 4.2궤도 |

- Courant 0.4 → 0.2는 결과가 같았다(시간간격을 상대속도 조건 dt3 = c·d/|Δv|가 정함). dt3 계수를 절반으로 하면 스텝 수가 5226 → 6976(10–14궤도 구간에서는 393 → 773, dt 절반)이고, 그 구간의 E_int 증가는 9.7e-4 → 3.1e-4.
- 같은 구간의 총에너지 RK 잔차(aud_rkh) 합은 3.5e-7, 면 유속 쌍 장부(aud_hyd)는 4e-13. 총에너지 뺄셈 오차가 아니다. 총에너지는 보존된 채 운동에너지 → 내부에너지 전환이 시간간격에 의존한다.
- 에너지 경로(SEDOV_PHASE1): ie 변화율 = die − m v·a = −Σ P* A (w − v_i)·n. W=0에서 w는 정확한 Voronoi 면 속도(`get2dUpqradRk4` + `voronoi_face_rotation`).
- 매 RK4 단계마다 `updateDenW2Pressure2DBlend`가 셀을 새로 만든다. 정렬 격자(재연결 없음)는 30궤도 동안 1e-6 수준으로 안정하다.
- 위상 계측(`GFS_TOPO_AUDIT`, 같은 스텝의 단계 1 대비 단계 2–4에서 면 이웃 집합이 바뀐 입자 수)을 지금 돌리고 있다.

## 가설
한 RK4 스텝 안에서 면이 생기거나 사라지면 우변이 불연속이 된다. RK4 조합이 O(dt) 속도 오차(잡음)를 남기고, 그 잡음이 HLLC에서 열로 바뀐다. 잡음이 음속을 따라가므로 가열이 궤도당 일정 비율로 자란다.

## 질문
1. 가설이 맞는가? 측정으로 확정하려면 무엇을 봐야 하는가(위상 변화 수와 가열의 스텝별 상관 외에)?
2. 정합한 시간 적분 구조는? 후보:
   - (가) 스텝 안 위상 고정: 단계 1의 면 연결(이웃 쌍)을 유지하고, 각 단계에서는 그 쌍들의 기하(면 끝점·길이·법선)만 다시 계산한다. 단계 중 사라질 면은 길이 0이 되고, 새 면은 다음 스텝에서 생긴다. 이것이 유효한 분할인가(면 길이 음수, 셀 부피 정합)?
   - (나) AREPO식: 셀을 스텝당 한 번(또는 반 스텝) 만들고 2차 시간 적분(MUSCL-Hancock 예측 + 보정, Heun). 현재의 RK4와 에너지·부피 장부를 어떻게 바꿔야 하는가?
   - (다) 위상 변화가 있는 스텝만 시간간격을 줄이거나 다시 계산한다(사건 기반). 정합한가?
   - (라) 기타.
3. 각 후보의 보존(질량·운동량·에너지·각운동량), 기하 보존 법칙(셀 부피 변화 = 면 swept volume), 정확도 차수를 비교해 권고해 달라. 입자 = 생성점, 셀 생성 알고리즘(반평면 깎아내기) 유지가 조건이다.
