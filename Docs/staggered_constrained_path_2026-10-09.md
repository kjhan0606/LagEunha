# 중간 시각의 질량을 제약하는 가중치 경로

## 1. 결과

이전 [스텝 끝 질량 제약](staggered_spacetime_ale_mass_2026-10-09.md)에서 남았던
중간 질량 변동을 줄이기 위해 가중치를 선형 보간하지 않고 각 평가 시각에서 제약을 풀었다.
**기존과 같은 6개 사례 모두 검사 통과**. 별도 정적 검사 2개도 통과했다.

| 진단 | 6건 전체 최대값 |
|---|---|
| 평가한 시각의 셀 질량 상대 오차 | 4.98e-13 |
| 순간 셀 순질량 유량 절대값 | 7.76e-17 |
| 시간 적분한 셀 순질량 유량 절대값 | 3.75e-18 |
| 끝점 변화와 ALE 질량·운동량·에너지·각운동량 수지 오차 | 2.88e-16 |
| 가중치 변화율과 중심 유한차분의 차이 | 1.90e-11 |

각 사례에서 157개 서로 다른 시각을 평가했다. 이전 선형 가중치 경로에서 표본 최대
5.32e-3(0.53%)였던 중간 질량 변동이 이번 제약 경로에서는 보이지 않았다.
이것은 평가 시각들의 수치 결과이며 모든 실수 시각에 대한 컴퓨터 검증을 뜻하지 않는다.

**현재 판정: 제조된 선형 전단에서 중간 질량 제약·가중치 변화율·ALE 수지의 일관성 통과.**
일반 유체 상태를 자체 진화시키는 해법은 아직 아니다.

## 2. 가중치 경로의 정의

생성점과 외부 물질 평행사변형은 `v=(.2+1.1 y,0)`의 물리 궤적을 따른다.
밀도 1, 압력 .6, gamma=5/3이다. 생성점 조향은 없다.

각 시각 tau에서 초기 질량 m_i에 대해 다음 제약을 푼다.

`M_i(x(tau), w(tau), domain(tau)) = m_i`.

이번 균일 밀도에서는 M_i가 셀 면적과 같다. 따라서 기하 capacity 풀이를 사용할 수 있다.
마지막 가중치는 0으로 고정하며, 평가할 때마다 Newton 반복으로 제약을 만족시킨다.
끝점만 푼 뒤 사이를 직선으로 연결하지 않는다.

이는 질량·에너지를 사후 보정하는 절차가 아니다. 상태에 압력 floor나 질량 재정규화를
적용하지 않고, 평가할 기하 자체를 제약 위에 놓는다. 일반 비균일 밀도나 압축 흐름에서는
실제 수송된 밀도의 질량 적분을 써야 하며 면적 제약으로 대체할 수 없다.

## 3. 가중치 변화율

가중치 변화율이 0인 상태에서의 셀 순질량 유량을 r_i라고 두면,
가중치 변화율 z가 추가하는 면 속도 때문에 유량은 `r-L z`가 된다.
이번 균일 밀도의 공유 면 계수는 `L_ij=-length_ij/(2 distance_ij)`이며,
대각 성분은 인접 계수 절대값의 합이다.

`L z = r`, `z_last=0`

을 풀고 z를 면 속도식에 사용한다. 이것은 질량 제약을 시간으로 미분한 접선 조건이다.
양의 셀과 연결된 이웃 그래프에서 게이지를 제거한 선형계가 풀린다는 조건 아래 적용한다.
계산이 실패하거나 capacity 풀이가 수렴하지 않으면 중단한다.

일부 내부 면의 순간 질량 수송은 0이 아니다(관측 최대 약 2.00e-3, tau 기준).
그 합이 각 셀에서 0이 된다. 각 면을 유체 접촉 속도와 같게 만드는 제약은 사용하지 않는다.

tau=.125,.375,.625,.875에서 h=1e-5의 중심 차분으로 구한 `dw/dtau`와 z를 비교했다.
최대 차이 1.90e-11로 일치했다. 이 검사는 가중치의 기하 제약과 유량 제약을 서로
독립적으로 잘못 풀고 있지 않은지 확인하는 대조이다.

## 4. 연결 전환과 시간 적분

w(tau)가 암시적 비선형 경로가 되었으므로 기존 선형 가중치 경로의 다항식 사건 검출기를
그대로 사용하지 않는다. 17개 및 33개 시각의 이웃 연결을 비교하고 변화가 있는 구간을
이분법으로 좁혔다. 두 표본망의 사건 개수와 위치가 일치하는지 검사했다.

| 배치 | T | 관측한 연결 전환 tau |
|---|---|---|
| 정사각형 | .02 | .904723703 |
| 정사각형 | .1 | .180944741 |
| 정사각형 | .3 | .060314914 |
| seed731 | .1 | .359366976 |
| seed731 | .3 | .119788992 |
| seed732 | .3 | .053988413 |

사건 위치로 구간을 나누고 적응형 벡터 적분으로 공유 ALE 플럭스를 적분했다.
압력 충격량·일과 외부 경계 교환도 같은 적분에서 계산한다.
독립적으로 구한 끝점 다각형 상태와 비교해 위 표의 수지 오차를 얻었다.

적분 허용오차 1e-9와 1e-12가 같은 결과를 냈지만, 두 설정에서 동일한 적분 노드를
사용할 수 있으므로 이를 독립적인 차수 수렴 검사로 보지는 않는다. 독립 검사는
끝점 상태 적분과의 수지 비교이다.

17/33 시각의 연결 비교도 모든 사건 검출의 증명은 아니다. 한 표본 구간 안에서
연결이 바뀌었다가 되돌아오는 사건은 놓칠 수 있다. 더 큰 문제에 적용하기 전에
이 문제를 다루는 검출기 또는 신뢰할 수 있는 오차 제어가 필요하다.

## 5. 검증 범위

- 6건은 T=.02,.1,.3의 정사각형과 T=.1,.3의 seed731, T=.3의 seed732이다.
- 정확한 선형 전단 상태가 플럭스 평가에 들어간다. 압력·속도·밀도의 일반 예측기는 미구현이다.
- 질량은 기하에서, 순간 유량은 공유 면에서, 최종 보존량은 끝점 적분에서 각각 검사한다.
- 내부 속도 모멘트와 양의 분포를 수치 플럭스로 갱신하는 과정은 아직 결합하지 않았다.
- 가중치 경로의 존재·양의 셀 유지·수렴은 이번 사례에서 확인했으며 일반적인 전역 보장은 없다.
- 정적 검사 2개: 한 중간 시각의 질량/유량 제약과 비영 면 교환, 가중치 변화율 비교.
  스레드 1·nice 19·timeout 30초로 실행한 작은 대수 검사이며 계산부 0.055초였다.
- 6개 경로 전체 계산은 Slurm 계산 노드에 제출했다.
