# 자문 요청 (22차): 진공 고리 Kepler의 안쪽 가장자리 열 폭주 — 원리적 해법

작성: 2026-10-02. 사용자 원칙: 패치 금지(근본 원인), 물리·수학적 정합, 입자 = 생성점(조향 금지), 셀 생성 알고리즘(반평면 깎아내기) 유지, 단계 압력 바닥값 1e-6 유지, Kepler DTETA 미사용, 부피는 기하가 정함, **총에너지 보존 강제**(최종 목표는 Laguerre). 비교 기준은 GIZMO MFM 진공 고리(Hopkins 2015 §4.2.4, Docs/gfs_scheme3_formulation.md §26.4).

## 기준 실행
256² 진공 고리(0.5≤r≤2, Σ=1, 같은 질량, P=1e-6, γ=5/3, Plummer ε=0.01), 쌍 구간 제한자 + 공통 접선 재구성 + 앵커 + 원판 ρ=Δ + 2패스 LSF, HLLC, RK4, 총에너지 형식(SEDOV_PHASE1). 작업 디렉터리 /gpfs/kjhan/LagForce/Kepler_res256_t120_pair_258413b (log, khout.*.dat).

## 관측
- t=20–50: 밀도장이 MFM 그림 6과 비슷하고 구멍이 깨끗하다. t≈50(r=0.5 기준 약 23궤도)부터 구멍이 저밀도 기체로 차고 안쪽 가장자리에 고밀도 고리가 생긴다. MFM은 t=120에도 건재(그림 6), t=600에 가장자리 고리(그림 7).
- 첫 고리(r₀<0.52, 244입자): t=50까지 j 손실 0.35%뿐. **비내부에너지는 2.8e-6(t=2) → 2.3e-5(t=22) → 1.7e-3(t=50) → 0.9(t=66)**, e-폴딩 약 6.5(r=0.5 기준 약 3궤도). 가장자리 음속이 t=66에 약 1(궤도 속도 1.4)에 이르러 가장자리가 구멍으로 퍼지고, 각운동량이 바깥으로 옮겨진다(첫 고리 −3.7%, 0.6–0.7 고리 +1%). t=66에 에너지 오차 4.9e-2, dt 1.7e-4.
- 비내부에너지 지도(t=66): r≲0.7이 초기보다 10⁵–10⁶배, 본체는 초기 수준.

## 앞선 진단 (§26.2–26.3, Fable 감사)
- Hill 띠(회전 격자): 흐름에 비스듬한 격자가 전단으로 바늘 셀로 퇴화 → 재구성 면 속도 점프 약 0.2c → HLLC 소산이 ie에 비례하는 가열(내부 셀 분해에서 가열의 거의 전부가 소산 항). 정렬 격자는 무가열. 총에너지는 보존된다(가열은 보존적 KE→열 전환).
- 중력만 적분하면 입자 궤도는 정확(반경 오차 1e-10)하지만 가까운 쌍 때문에 Voronoi 셀 밀도 m/V가 0.25–4배 출렁인다. 동심 고리 IC에서는 본체가 100배 조용하지만 안쪽 가장자리는 여전히 t≈50–60에 붕괴.
- 시도했으나 해법이 아니었던 것: 2차 LSF, 매끄러운 극값 제한, 2점 Gauss(25%), 원판 반경 키움(오히려 악화), 엔트로피 모드는 폭주를 없애지만(dK=0) 총에너지 보존을 깬다.
- GIZMO 예제 설정은 `ENERGY_ENTROPY_SWITCH_IS_ACTIVE`, CourantFac 0.025, 개별 시간간격.
