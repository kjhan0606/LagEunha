# 설계 결정 요청 (Astra, 7차): b′는 충격 통과, Gresho 실패

작성: 2026-10-04. 직전: `Docs/audit_impl6_astra.md`. 결과: `Docs/design_astra_audit.md` 마지막 절(부호 정정 포함).

## 요약
- b′(부호 정정 δ_f = (v_i − v_j)·e + d eᵀḠe)는 관문 1–3을 통과했다. 쌍 Mach 10 0.341h, Sod L1 0.0147/0.0413/0.0220, 최소 간격 ≥ 0.15h.
- Gresho에서는 면 Q와 같은 수준으로 감속시킨다(t=0.75 −7.8~−8.9%). b′ 열이 지배적이다.
- 운전자 해석:
  - Gresho 속도장은 0.2<r<0.4에서 v = (2/r − 5)(−y, x)로 비아핀이다. r=0.2, 0.4에서는 기울기가 불연속이다.
  - 따라서 δ_f ~ h²∇²v(꺾임 근처는 h|[∇v]|)가 실제로 남는다.
  - 여기에 C_f = A_f Z_f의 음향 항 μc_M이 곱해진다. 저마하(Gresho Mach ≈ 0.3)에서는 음향 임피던스가 지배하므로, 2차 잔차에도 큰 감쇠가 걸린다.
  - HG의 계수도 음향이지만, HG 연산자의 잔차가 더 작거나 가중이 다르다(h·W 대 A).

## 질문
1. 위 해석이 맞는지, 확인할 진단을 지정하라(예: 반경별 b′ 열, |δ_f|/(h|∇v|) 분포, Z의 음향/Hugoniot 비).
2. 충격(쌍 접근)과 매끄러운 비아핀 흐름을 문턱 없이 구별하려면 계수가 무엇에 비례해야 하는가?
   - 후보 (i): 음향 항 제거. C_f = A μ a_H 형태(|δ|에 비례하는 2차 Hugoniot만)로 두어 열이 |δ|³이 되게 한다(작은 잔차에 3차, 쌍 접근에 강함).
   - 후보 (ii): 기존 μ(c_M + max(δ,0))의 압축 측만 유지한다.
   - 후보 (iii): HG처럼 가중 W = Ad/4 및 h = d/2를 쓰는 형태.
   각각의 쌍 제동, 수렴 차수, 엔트로피 장부를 평가하고 하나를 선택하라.
3. 주기 완전성 관문 실패(t=0.917, 부피 합 오차 3.2e-8)의 의미와 처리 방법. 운전자는 이 관문을 완화하지 않고 원인 조사부터 하려 한다.
4. 시험 순서.
읽기 전용, 한국어, 결론 먼저.
