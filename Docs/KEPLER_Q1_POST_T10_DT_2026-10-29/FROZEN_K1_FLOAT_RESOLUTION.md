# Float internal-energy resolution at the t=10 K1 state

The existing diagnostic native K1 snapshot supplies the saved float `die`, double mass, velocities and hydro accelerations for all owned cells. The legacy thermal derivative `die - m*(vx*ax+vy*ay)` reconstructed from the full native payload matches all eight independently saved selected-ID K1 values exactly. The source checkpoint, diagnostic snapshot and selected native audit remain unchanged.

For each of the three previous timestep sizes, this analysis applies the frozen K1 derivative to a hypothetical RK4 first half-stage, `(float)(U + 0.5*h*Udot)`. In the disk 0.5<=r0<2, the nonzero predicted change rounds back to the original float U for 14.6% of the disk mass at the coarse median h, 54.1% at the half cap, and 73.2% at the quarter cap. The half-cap requested absolute fractional U change has mass mean 8.40e-8, while the absolute float rounding difference has mass mean 1.69e-8. Core cells in this frozen sample all have a representable nonzero predictor change. Details and hashes are in `FROZEN_K1_FLOAT_RESOLUTION.json`.

This is an instantaneous predictor calculation on an already damaged t=10 state. It does not claim that actual later-stage derivatives stay fixed, that all small predictor changes are irrevocably lost from the final RK4 combination, that their rounding is biased over time, or that this alone causes the observed entropy pattern. It does identify a concrete precision sensitivity that becomes stronger for smaller h; the separate native thermal64 run tests the full evolving path.
