# 자문 요청 (6차): Phase B(ω 상자)에서 ω 동역학이 stiff하다 — 적분 구조

작성: 2026-09-30. 사용자 원칙: 패치 금지, 정합한 solver. 이전 답: `Docs/consult_schemeH_shear_reply_astra.md`, `Docs/consult_schemeH_c_design_reply_astra.md`.

## 구현 (`e841584`, `878abf0`, 진단 `13741d1`)

- `W = h²ω`, `|ω| ≤ 0.4`. h는 4라운드의 매끄러운 하계(p=8, R_1=Δx, R_c=2.5Δx)다.
- ω가 RK4 상태다. ω̇는 `min ½ẆᵀKẆ − gᵀẆ`, `Ẇ = h²ω̇ + 2hḣω`를 상자의 접선 원뿔 안에서 푼다(활성집합 PCG).
- g = `Σ A(u*−ũ−ρ) + (V_vor−V^T)/τ_V + (V^T−V)/τ_C`이고, u*는 MUSCL 면 상태의 HLLC 접촉 속도다. τ_V=1, τ_C=0.02다.
- 스텝 조건: 단계 0의 ω̇로 `dt ≤ (0.45 − ω·sign ω̇)/|ω̇|`를 건다.
- 참고: 사용자 코드에는 원래 W 상한 `w2 ≤ w2ceil = d_nn²`(최근접 이웃 거리 제곱, `buildTree2D`·`det2d_dpqRK4`의 사후 자르기)이 있다. `GFS_DYN_W2`에서는 꺼진다.

## 관측 (GIZMO 입자판 Kepler, 1랭크 CPU)

- 한 스텝 안에서 단계별 max|ω̇|가 **17 → 41 → 19 → 106**(step 1)으로 변한다. step 2는 35 → 36 → 35 → 32였다.
- 단계 0 기준 dt 조건(0.026)으로는 막지 못해 ω가 0.43, 이어서 0.68까지 넘쳤다(0.5 초과 → 유효성 보장 상실).
- KKT 반복은 단계마다 6–7회였다. 위반 성분은 0개로 끝났다.
- t≈0.4 이후 셀의 절반 이상(1500–2000/3020)이 상한에 붙었다. `rms(V^T−V)/V`는 t=1.8에 21%였고, 에너지는 dE 1e-5로 유지됐다.
- ω가 전 범위를 가로지르는 시간은 약 0.005로, CFL dt 0.022보다 짧다.

## 질문

1. 이 stiffness의 근원은 무엇으로 보는가? τ_C=0.02 되먹임(τ_C < dt), 목표 g의 단계 간 급변(재구성·제한자 불연속), 제약 최소제곱의 비매끄러움(활성집합 전환) 중 어느 것인가? 판별 측정을 제안해 달라.
2. **정합한 적분 구조**를 권해 달라. 후보:
   - (a) W를 대수 변수로 둔다. 각 단계에서 `V(x, W) = V^T`를 상자 제약 안에서 푼다(G + 상자, Newton/active set). Ẇ는 제약 사슬 규칙으로 얻어 면 속도·에너지에 쓴다. 단계 사이 W의 "도약"은 어떻게 장부해야 하는가?
   - (b) τ_C를 없앤다. 실제 V가 V^T를 정확히 따르면 되먹임이 필요 없고, 적분 오차는 (a)처럼 대수적으로 흡수한다.
   - (c) ω를 암시적(또는 exponential) 적분으로 분리한다(IMEX). 유체는 RK4, ω는 암시적 Euler + 상자 사영으로 둔다. 에너지 항등식은 어떻게 유지되는가?
   - (d) 명시적 RK4를 유지하고 dt를 ω 시간척도로 줄인다. 비용이 크고, 개별 시간간격이 없는 전역 dt 코드라 비현실적이라고 본다.
3. 사후 자르기(사용자 코드의 w2ceil)는 에너지 장부를 깬다. 그러나 (a)의 대수 사영은 "상태공간을 허용 집합으로 선언하고 그 안에서 푼다"는 정당한 정식이 될 수 있다(귀하의 앞선 답). 둘을 가르는 기준을 짧게 정리해 달라.

읽기 전용, 한국어, 결론 먼저, 근거(유도·코드 위치·문헌) 포함.
