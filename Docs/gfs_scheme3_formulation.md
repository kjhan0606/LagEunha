# 방식 (3) Laguerre + 동적 가중치: 정식화 (2026-09-29, 초안)

대상: `Exam/exam.c`의 2D RK4 `av_mode=5`, `SEDOV_PHASE1=1` 경로와 `GFS_DYN_W2`(`1cc7e3f`). 기호와 목적은 `Docs/gfs_consistency_research.md`를 잇는다. 표기는 **[유도]**(이 문서에서 손으로 유도, 수치 확인 전), **[CODE]**(소스 확인), **[HYP]**(가설), **[판단]**(선택과 권고)로 나눈다. 이 문서의 식은 아직 수치로 검증하지 않았다. 검증 계획은 §9에 있다.

## 0. 요약

1. **[유도]** 현 GFS 이산식(면 힘 `−P* A n`, 셀 총에너지율 `−P* A w·n`)에서 셀 `i`의 엔트로피 생산은 정확히
   `m_i T_i ṡ_i = −Σ_f (P*_f − P_i) A_f (w_f − u_i^f)`, `u_i^f = v_i·n_if`
   이다. 면 속도 `w_f`가 Riemann 접촉 속도 `u*_f`와 같고 Riemann 해가 Lax 단조이면 모든 항이 0 이상이다. 그렇지 않으면 차이 `w_f − u*_f`에 `(P*_f − P_i)`가 곱해져 들어간다. 이 양은 뜨거운 이웃 옆의 차가운 셀에서 크다.
2. **[유도, HYP]** 실제 Voronoi/Laguerre 면 속도에는 회전 항 `t·(v_i−v_j)/d`가 있다. 케플러 공동 가장자리에서 이 값(`~Ω d/2 ≈ 2×10⁻²`)은 음속(`~10⁻³`)보다 한 자릿수 이상 크다. 따라서 1의 식에서 회전 항이 음의 엔트로피 생산을 만든다. 이 경로가 차가운 셀을 바닥값으로 떨어뜨리는 기전이라는 것이 가장 단순한 설명이다. 이것은 GFS의 **힘과 기하가 서로 맞지 않는 문제**다. 가중치로 없앨 수 없다.
3. **[유도]** VPH(Heß–Springel) 변분 힘에 Riemann 보정을 더한 정식을 제안한다.
   `f_ij = −A_ij [ P*_ij n_ij + (P_j − P_i) t_ij / d_ij ]`
   이 식은 현 GFS 힘에 **접선 방향 면 중심 항 하나를 더한 것**이다. 이 정식에서 셀 에너지는 `dU_i = −P_i dV_i^geo + σ_i`로 쓴다. 한 면이 만드는 총 소산은
   `D_f = A_f [ G_f + (P_i − P_j) ε_f ]`
   이다. `G_f ≥ 0`은 1D Godunov 소산이고, `ε_f`는 가중치가 만든 면 속도의 목표 대비 잔차다. **회전 항은 소산에 들어가지 않는다.** 1D에서 `ε=0`이면 정확히 라그랑지안 Godunov다.
4. **[유도]** 3의 정식에서는 에너지 보존과 셀별 열역학 정합성이 **Ẇ의 선택과 무관하게** 성립한다. Ẇ는 소산의 크기와 부호에만 영향을 준다. 그러므로 (3)의 최소제곱은 정확히 풀 필요가 없다. 조건 `D_f ≥ 0`만 지키면 된다. MPI, 개별 시간간격, 3D에서 전역 풀이를 근사 풀이로 바꿀 수 있다는 뜻이다.
5. **[판단]** 현 (3) 구현은 GFS 힘을 쓴다. 그 경우 목표에서 `rot`를 빼는 것은 일관적이다. 하지만 잔차가 `(P*−P_i)`와 곱해져 셀별 부호가 보장되지 않는다. 가중치(`A×100`)에는 원리가 없다. `hll_star_state`의 Lax 단조성도 보장되지 않는다. Noh와 Kepler에서 불안정했던 원인 후보가 여기에 있다(§7).

6. **[유도, RUN] (§11)** Ẇ를 적분하는 LS는 부피 조건을 미분한 식과 같다. 따라서 제약 오차를 되돌리는 항이 없다. W를 적분하지 않고 매 단계 `V(x,W) = V^G`를 OT Newton으로 푸는 정식 (G)를 제안한다. (G)는 질량, 운동량, 각운동량, 에너지를 보존하고, 셀별 엔트로피 생산이 0 이상이다. 그러나 운동학 시험에서 **전단이 있으면 W 자체가 커져 생성점이 셀 밖으로 나간다**(`|ΔW|/d²` 0.08→3.2). 입자 = 생성점 구조에서는 생성점 regularization을 쓸 수 없다(사용자 경험, §12). 사용자 지시로 (G)는 regularization 없이 먼저 물리 시험에 건다(§13). (F)는 그다음 후보다.

## 1. 기하: Laguerre(power) 셀

생성점 `x_i`, 속도 `v_i`, 가중치 `W_i = w_i²`. 면 `f=(i,j)`는

```text
|x − x_i|² − W_i = |x − x_j|² − W_j,     d = |x_j − x_i|,  n = (x_j − x_i)/d
```

이다. 면은 `n`에 수직이다. 면과 선분 `x_i x_j`의 교점(앵커)은 `a = x_i + φ_ij d n`이다. 여기서

```text
φ_ij = 1/2 + (W_i − W_j)/(2d²),   φ_ji = 1 − φ_ij
```

이다(코드의 `fact1`). 면 중심은 `c = a + t`로 쓰고, `t ⊥ n`이다. 따라서 `c − x_i = φ_ij d n + t`, `c − x_j = −φ_ji d n + t`이다.

**[유도] 면의 법선 속도.** 정의식을 시간 미분하면 면 위의 점 `x`에서

```text
ẋ·n = [(x − x_i)·v_i − (x − x_j)·v_j]/d + (Ẇ_i − Ẇ_j)/(2d).
```

면 중심에서는

```text
w_f ≡ ẋ(c)·n = ũ_f + ρ_f + δ_f,
ũ_f = φ_ij u_i + φ_ji u_j        (u_i = v_i·n, u_j = v_j·n)   앵커 속도
ρ_f = t·(v_i − v_j)/d                                          회전 항
δ_f = (Ẇ_i − Ẇ_j)/(2d)                                        가중치 항
```

이다. 법선 속도는 면을 따라 선형이다. 따라서 면 중심 값에 면적을 곱하면 정확한 부피율이 된다. `ũ`의 계수는 `φ`와 **교차**한다. 면이 j에 가까우면(`φ_ij → 1`) 앵커는 i의 속도를 더 따른다. `(W_i−W_j)ḋ/d²` 항이 이 교차를 만든다. 코드의 `b_f`에 있는 `dW·dd/d` 항이 바로 이것이다.

**[유도] 부피 미분.**

```text
∂V_i/∂x_i = Σ_j A_ij (c_ij − x_i)/d_ij,     ∂V_i/∂x_j = −A_ij (c_ij − x_j)/d_ij
∂V_i/∂W_i = Σ_j A_ij/(2 d_ij),               ∂V_i/∂W_j = −A_ij/(2 d_ij)
```

즉 `∂V/∂W = ½ L_{A/d}`이고, 이는 면 가중치 `A_f/d_f`의 그래프 라플라시안이다. `Σ_i ∂V_i/∂W_k = 0`, `Σ_k ∂V_i/∂x_k = Σ_j A_ij n_ij = 0`이므로 총부피가 보존된다(기하 보존 법칙). W에 상수를 더해도 아무것도 바뀌지 않는다. 식은 차원에 무관하다. 3D에서는 `A`가 면 넓이, `t`가 면 평면 안의 2-벡터다.

## 2. 현 GFS의 셀별 엔트로피 생산

**[CODE]** `Exam/exam.c` 6219–6286: 면 힘 `−P* dS`, 셀 총에너지율 `dte += −P* (u_a·dS)`, `SEDOV_PHASE1=1`이면 `die = dte`이다. `u_a`는 극단 면과 `riemann_vstar` 면에서 HLL `v*`이다. 그 밖의 면, 그리고 `GFS_GEOM_FACE_VEL=1`이나 `GFS_DYN_W2=1`이면 실제 면 속도(회전·가중치 항 포함)다.

**[유도]** `U_i = E_i − ½ m_i|v_i|²`로 두고 `Σ_f A_f n_if = 0`을 쓰면

```text
dU_i/dt = −Σ_f P*_f A_f (w_f − u_i^f)
dU_i/dt + P_i dV_i/dt = −Σ_f (P*_f − P_i) A_f (w_f − u_i^f)  ≡ σ_i^GFS
```

이다. 여기서 `dV_i/dt = Σ_f A_f w_f^geo·n_if`는 실제 기하의 부피율이다. 일에 쓰는 `w_f`가 기하 속도와 다르면 두 번째 식에 `P_i Σ A(w − w^geo)` 항이 더 붙는다. 이것이 연구 문서 §4의 잔차다.

**Lax 단조성.** 법선 방향 1D Riemann 문제(좌 `i`, 우 `j`)의 해 `(P*, u*)`가

```text
(P* − P_i)(u* − u_i) ≤ 0,     (P* − P_j)(u* − u_j) ≥ 0            (L)
```

을 만족한다고 하자. 그러면 `w_f = u*_f`인 면마다 `σ` 기여가 0 이상이다. 정확한 Riemann 해는 (L)을 만족한다. HLLC식 `P* = P_L + ρ_L(S_L − u_L)(u* − u_L) = P_R + ρ_R(S_R − u_R)(u* − u_R)`(`S_L < u_L`, `S_R > u_R`)도 구성상 만족하며, 이때

```text
G_f ≡ −(P* − P_i)(u* − u_i) + (P* − P_j)(u* − u_j)
    = ρ_i |S_L − u_i| (u* − u_i)² + ρ_j (S_R − u_j) (u* − u_j)²  ≥ 0.
```

**[CODE]** 그러나 `hll_star_state`(`exam.c:4346`)는 HLL 평균 보존량 `(ρ*, m*, E*)`에서 `P* = (γ−1)(E* − m*²/2ρ*)`로 압력을 구한다. 이 `P*`가 (L)을 만족한다는 보장은 없다. 평균 상태의 운동에너지가 볼록하므로 속도 점프가 있으면 `P*`가 커지는 쪽으로 치우친다. **먼저 면별로 (L) 위반 빈도를 세야 한다**(§9).

**잔차의 결과.** `w_f = u*_f + e_f`라 하면 셀 i의 면 기여는 `A[−(P*−P_i)(u*−u_i)] − A(P*−P_i) e_f`이다. 앞 항은 0 이상이다. 뒤 항은 부호가 정해지지 않고 `(P* − P_i)`에 비례한다. 뜨거운 이웃 옆의 차가운 셀(`P* ≫ P_i`)은 작은 `e_f`로도 음의 σ를 받는다. 방식별 `e_f`는 다음과 같다.

| 방식 | 극단·`riemann_vstar` 면 | 일반 면 |
|---|---|---|
| (1) 기본 | `e = 0`(일에 `v*`). 대신 일과 기하가 어긋나 `P_i Σ A(v* − w^geo)`가 생긴다 | `e = ũ + ρ − u*` |
| (1) `GFS_GEOM_FACE_VEL=1` | `e = ũ + ρ − u*` | 같음 |
| (3) 현 구현 | `e =` 최소제곱 잔차 | 같음 |

**[HYP] 케플러.** 공동 가장자리(`R≈2`, 256², `d≈0.094`)에서 `|ρ_f| ~ |t||v_i−v_j|/d ~ Ω d/2 ≈ 0.35×0.094/2 ≈ 1.6×10⁻²` (`Ω = v/R ≈ 0.35`)이다. 바닥 압력 `P=10⁻⁶`의 음속은 `≈10⁻³`이고, `|u* − u_i|`는 그 규모다. 따라서 `e_f ≈ ρ_f`가 Godunov 소산 몫보다 한 자릿수 이상 커서 σ의 부호를 결정한다. 이는 Grokbot이 이미 보고한 관찰과 같은 기전이다. "면 중심 회전 항 때문에 차가운 셀이 뜨거운 이웃의 압력에 맞서 팽창한다"(`exam.c:83` 주석과 `code_review_grokbot.md` 결론 2). 다만 그쪽은 그것을 "올바른 기하"로 두고 한도를 두려 했다. 여기서는 **힘 쪽이 기하와 맞지 않는 것**으로 본다(§3).

## 3. 제안: VPH 힘 + Riemann 보정

### 3.1 운동량

**[유도]** 고정 질량 라그랑지안 `L = Σ ½ m|v|² − Σ U_i(V_i(x,W), K_i)`에서 x에 대한 힘은 `F_i = Σ_k P_k ∂V_k/∂x_i = −Σ_j (P_j − P_i) A_ij (c_ij − x_i)/d_ij`이다. 여기에 `−P_i Σ_j A_ij n_ij = 0`을 더하면 쌍마다 반대칭인 형태가 된다.

```text
f_ij^VPH = −A_ij [ P̃_ij n_ij + (P_j − P_i) t_ij/d_ij ],     P̃_ij = φ_ij P_j + φ_ji P_i.
```

Riemann 압력 보정 `−A(P* − P̃) n`(반대칭, 중심력)을 더하면 다음이 된다.

```text
f_ij = −A_ij [ P*_ij n_ij + (P_j − P_i) t_ij/d_ij ].                           (F)
```

`P*`를 쓰는 **현 GFS 힘에 접선 항 `−A(P_j−P_i) t/d`를 더한 것**과 같다. 이 항은 두 셀 압력의 차이와 면 중심의 선분 이탈에 비례한다. 매끄러운 흐름에서는 2차 크기이고, 압력이 균일하면 0이다.

### 3.2 에너지

셀 에너지를 다음과 같이 쓴다.

```text
dU_i/dt = −P_i dV_i^geo/dt + σ_i,       dV_i^geo/dt = Σ_f A_f w_f·n_if  (w_f = ũ + ρ + δ, 실제 속도)
```

**[유도]** `Σ_i (m_i v_i·a_i + dU_i/dt) = 0`을 요구하면 면별 총소산이 정해진다.

```text
Σ_i σ_i = Σ_f D_f,
D_f = A_f [ (P_i − P_j) δ_f + (P*_f − P̃_f)(u_i − u_j) ].
```

유도의 요지는 이렇다. VPH 힘이 하는 일은 `Σ_k P_k (dV_k/dt − ∂V_k/∂W·Ẇ)`이므로 `−P_i dV_i`와 상쇄된다. 남는 것은 가중치 일 `Σ_k P_k (∂V_k/∂W)·Ẇ = Σ_f A(P_i−P_j)δ_f`와 보정 힘의 일이다. **회전 항 `ρ_f`와 접선 항은 D_f에 들어가지 않는다.** 둘은 가역적인 `−P dV`와 VPH 힘의 일로만 나타난다.

**[유도] 핵심 항등식.** `δ_f = (u*_f − ũ_f) + ε_f`로 쓰면

```text
D_f = A_f [ G_f + (P_i − P_j) ε_f ].
```

`G_f`는 §2의 1D Godunov 소산이다. 확인 과정: `ε=0`이면 `(P_i−P_j)(u*−ũ) + (P*−P̃)(u_i−u_j)`를 전개한 것이 `P*(u_i−u_j) + u*(P_i−P_j) − P_i u_i + P_j u_j = G_f`와 같다. `ũ`와 `P̃`의 `φ` 계수가 교차하기 때문에 `φ`와 무관하게 성립한다.

따라서 다음이 성립한다.

- **1D:** 순환이 없으므로 `ε ≡ 0`으로 둘 수 있다. 그러면 정확히 라그랑지안 Godunov다. 옛 `hllface`(ΔE 1.1e-6, 바닥값 0)와 같은 대상이다.
- **목표 면 속도:** Riemann 접촉에 맞춰야 할 것은 **앵커 속도** `ũ + δ`다. 면 중심 속도(`ũ + ρ + δ`)가 아니다. Riemann 문제 자체가 생성점을 잇는 선 위에서 정의되기 때문이다. 현 (3) 목표 `b_f = 2d(v* − ū − rot) + ΔW ḋ/d`에서 **`− rot`를 뺀 것**이 이 정식의 목표다.
- **방식 (1)을 이 정식으로(δ=0):** `D_f = A(P* − P̄)(u_i − u_j)`. 음향 근사와 같은 임피던스에서는 `Z(u_i−u_j)²/2 ≥ 0`이다. 임피던스가 다르면 음수가 될 수 있다.

### 3.3 셀별 분배

`σ_i`를 어떻게 나눠도 에너지 보존은 유지된다. 면마다 `g_i = A ρ_i|S_L−u_i|(u*−u_i)²`, `g_j = A ρ_j(S_R−u_j)(u*−u_j)²`, `r = A(P_i−P_j)ε_f`로 두고

```text
σ_i^f = g_i (1 + r/(g_i + g_j)),   σ_j^f = g_j (1 + r/(g_i + g_j))
```

로 나누면, `D_f ≥ 0`인 한 두 셀 모두 0 이상이다. `ε=0`이면 1D Godunov의 좌우 몫과 정확히 같다.

### 3.4 보존과 불변성

| 양 | (F) + §3.2 | 현 GFS |
|---|---|---|
| 질량 | 정확(고정) | 정확 |
| 선운동량 | 정확(쌍 반대칭) | 정확 |
| 총에너지(반이산) | 정확, Ẇ와 무관 | 정확 |
| 셀별 `dU + P dV` | `= σ_i`, 조건 `D_f ≥ 0`에서 0 이상 | 부호 불명(§2) |
| 각운동량 | **정확하지 않음**: 쌍 토크 `A(P_j−P_i)(n × t)`, 2차 | 정확(중심력) |
| 갈릴레이 불변 | 예(`u*−ũ`, `t`, 압력 차) | 예 |

**[판단]** 기하와 맞는 열역학을 얻는 대가로 정확한 각운동량 보존을 잃는다. 케플러에서는 `L_z` 장부를 따로 기록해 크기를 재야 한다. 둘을 동시에 정확히 얻는 식은 이 틀 안에서 찾지 못했다. 이것은 VPH의 알려진 성질과 같다.

## 4. Ẇ의 결정

**[유도]** 에너지와 정합성은 Ẇ와 무관하다(§3.2). Ẇ가 결정하는 것은 두 가지다. (a) 면이 접촉 속도를 얼마나 따르는지, 즉 충격파와 접촉면의 선명도와 과잉 소산. (b) `D_f ≥ 0`이 성립하는지. 따라서 문제는 다음 볼록 이차계획이다.

```text
min_Ẇ  Σ_f a_f ε_f²,         ε_f = (Ẇ_i − Ẇ_j)/(2d_f) − (u*_f − ũ_f)
s.t.   (P_i − P_j) ε_f ≥ −(1 − θ) G_f     (모든 f, 0 ≤ θ < 1 여유)
       |W_i − W_j| < (1 − δ_W) d_f²        (셀 유효성, Δt 한도로 강제)
```

- **가중치:** 잔차가 소산을 틀리게 만드는 양은 `A(P_i−P_j)ε`이다. 그러므로 `a_f = A_f (P_i − P_j)²/Z_f + λ A_f`가 원리 있는 선택이다. `λ`는 압력이 균일한 곳에서 Ẇ를 작게 유지하는 정규화다. 현 구현의 "극단 면 ×100"은 이것을 계단 함수로 근사한 것이다.
- **해의 존재:** 제약이 없는 최소제곱 해는 게이지를 고정하면 항상 존재한다. 잔차 0 해는 순환 조건이 있어야 존재한다. 부등식 제약까지 만족하는 해가 **항상** 있는지는 보이지 못했다(LP 실현 가능성 문제). 실현이 불가능한 면에는 두 가지 대안이 있다. (i) 한 셀의 σ를 면 사이에서 옮겨 셀 합 `σ_i ≥ 0`만 요구하는 약한 조건. (ii) 그 면에만 에너지 일관 인공점성 추가.
- **W의 표류:** W는 적분된 상태다. 압력이 균일해진 뒤에도 차이가 남는다. 일반 면의 목표에 `−(W_i − W_j)/(2d τ_W)`(Voronoi로 완화)를 더하는 것을 권한다. 보존에는 영향이 없다.
- **근사 풀이:** 제약 위반만 없으면 몇 번의 Jacobi나 국소 반복으로 충분하다. 수렴하지 않은 풀이는 소산을 늘릴 뿐 보존을 깨지 않는다. MPI 전역 CG와 개별 시간간격의 부담이 여기서 줄어든다(§8).

## 5. 시간적분과 양의 상태

두 가지를 선택할 수 있다.

1. **엔트로피 변수(권고):** `P = K ρ^γ`, `U_i = K_i m_i^γ V_i^{1−γ}/(γ−1)`이다. `dK_i/dt = (γ−1) σ_i /(m_i ρ_i^{γ−1})`로 적분하고, `V_i`는 매 단계 테셀레이션에서 직접 얻는다. RK4 단계 계수(`c = 0, ½, ½, 1`)와 결합 계수(`1/6, 1/3, 1/3, 1/6`)가 모두 0 이상이므로, 단계마다 `σ ≥ 0`이면 `K`는 줄지 않는다. **ie > 0이 Δt와 무관하게 보장**되고 바닥값이 필요 없다. 총에너지 오차는 RK4 절단 오차뿐이다(현 장부의 `rkh`에 해당).
2. **총에너지 변수:** 면 유속 형태로 총에너지를 정확히 보존한다. 양의 상태는 반이산 수준에서만 보장되므로 바닥값이나 이중 에너지가 여전히 필요하다.

**[판단]** 지금까지의 케플러 에너지 오차는 대부분 바닥값 장부(`floor_cum`, `sfl_cum`)였다. 그러므로 1을 기본으로 하고 총에너지를 감사 장부로 두는 편이 낫다. 충격파에서 엔트로피 변수만 쓰면 충격파 위치가 틀릴 수 있다는 일반적 우려는 여기서는 약하다. σ가 Riemann 소산에서 오고 운동량은 보존형이기 때문이다. 그래도 Noh와 Sedov로 확인해야 한다.

## 6. MUSCL

`G_f ≥ 0`은 Riemann 입력 상태에 대한 명제다. 반면 `D_f`는 셀 평균 `P_i`, `u_i`로 쓰인다. 재구성 상태 `P_L = P_i + ∇P·(a − x_i)` 등을 쓰면 차이 `D_f − A G_f(L,R)`는 `(P_L − P_i)(u* − u_L)` 꼴의 2차 항이 된다. 이 항은 매끄러운 곳에서 작지만 부호가 정해지지 않는다. **[판단]** `D_f < 0`인 면에서만 1차(셀 평균) 상태로 되돌리는 국소 제한이 가장 단순하다. 64² 4랭크에서 확인된 ghost 기울기 문제(`code_review_grok.md` §24)도 이 항으로 들어온다.

## 8. 3D와 개별 시간간격에 대한 함의

- **3D:** §1–5의 식은 차원에 무관하다. 3D에서 `t`는 면 넓이 중심의 앵커 이탈(2-벡터)이다. 면 수 약 7N, Ẇ N−1개, 순환 약 6N개라 잔차는 2D보다 크다. 그래서 근사 해와 부등식 제약을 받아들이는 설계가 더 중요하다.
- **개별 시간간격:** 한 면의 교환량(힘 (F), 소산 `D_f`와 그 분배)을 한 번 계산해 두 셀에 반대 부호로 기록하면 보존이 유지된다. Ẇ의 정확도가 보존과 무관하므로, 비활성 셀의 Ẇ를 고정하거나 예측값을 써도 된다. 대가는 소산이 조금 늘어나는 것뿐이다. 전역 PCG를 활성 셀 주변의 국소 반복으로 바꿀 수 있다.
- **GPU:** 면 루프에 (F)의 접선 항(`t`는 이미 `voronoi_face_rotation`이 쓰는 면 중심에서 나옴)과 `G_f`, `D_f` 계산이 추가된다. 전역 풀이가 없어지면 GPU 이식에 걸림돌이 없다.

## 11. W의 시간 발전: 왜 발산하는가, 대수적 대안 (2026-09-29 추가)

사용자 경험: 과거 구현에서 W의 시간적분이 자주 발산했다. drag 항, 엔트로피 변수를 모두 넣었지만 실패했다. 생성점을 셀 중심으로 옮기는 regularization은 노이즈로 작용해 이론값에서 멀어졌다. 이 절은 그 원인을 식으로 나누고, 남는 문제를 명시한다.

### 11.1 Ẇ의 LS는 미분된 부피 조건이다

**[유도]** 셀 부피가 목표 `V^G_i(t)`를 따르게 하는 조건 `V_i(x, W) = V^G_i`를 시간 미분하면

```text
½ L_{A/d} Ẇ = V̇^G − (∂V/∂x)·ẋ.
```

`V̇^G_i = Σ_f A_f u*_f`이면 오른쪽은 `Σ_j A_ij (u*_ij − ũ_ij − ρ_ij)`이다. 이것은 가중치 `a_f = A_f/(2d_f)`를 쓴 §4 LS의 정규방정식과 **정확히 같다**. 목표는 rot를 포함한다. 현 구현의 `a_f = A_f`는 d가 균일하면 상수배만 다르다.

**[유도]** 따라서 Ẇ를 적분하는 것은 제약 `e = V(x,W) − V^G`를 `ė = 0`으로 유지하는 것이다. **e를 0으로 되돌리는 항이 없다.** RK 절단 오차, 순환 잔차, 면 위상 변화가 모두 e와 W에 누적된다. W에 drag를 걸면 V가 바뀐다. 그러면 열역학 부피와 기하 부피가 어긋나고, `P dV` 장부에 가짜 일이 생긴다.

### 11.2 대수적 W: semi-discrete optimal transport

**[유도, 문헌]** 목표 부피 `V^G_i > 0`, `Σ V^G = V_box`가 주어지면, 생성점 `x`에 대해 `V_i(x,W) = V^G_i`를 만족하는 W는 상수 차이를 빼고 유일하게 존재한다. 이것은 오목 함수 `Φ(W)`의 최댓값 조건이고, `∇Φ = V^G − V(W)`, Hessian은 `−½ L_{A/d}`이다(Aurenhammer, Hoffmann & Aronov 1998, *Algorithmica*). 감쇠 Newton의 전역 수렴도 증명돼 있다(Kitagawa, Mérigot & Thibert 2019, *JEMS*). 비슷한 라그랑지안 유체 스킴으로 Gallouët & Mérigot 2018(*FoCM*, 비압축 Euler), de Goes et al. 2015(*ACM TOG*, "Power Particles")가 있다. 이 문헌 목록은 원문을 다시 대조해야 한다.

이로부터 **정식 (G)** 를 제안한다. 열역학 부피를 Godunov 부피로 둔다.

```text
V̇^G_i  = Σ_f A_f u*_f                      (셀별 ODE, Σ_i V̇^G_i = 0 정확)
m_i v̇_i = −Σ_f P*_f A_f n_if                (중심력, 현 GFS와 같음)
Ė_i    = −Σ_f P*_f A_f u*_f                 (총에너지 유속형)
W      : 매 단계 V(x, W) = V^G 를 Newton으로 풀어 얻는다 (적분하지 않음)
```

**[유도]** 성질:

- 질량, 운동량, 총에너지는 정확히 보존된다. 힘이 중심력이므로 각운동량도 정확하다. §3의 (F)보다 낫다.
- 기하 보존 법칙이 정확히 성립한다. 기하 부피가 V^G와 구성상 같기 때문이다.
- `dU_i + P_i dV^G_i = −Σ_f (P*_f − P_i) A_f (u*_f − u_i)`. 조건 (L)(HLLC식 `P*`)에서 면마다 0 이상이다. **잔차 ε가 없고, 회전 항이 열역학에 전혀 들어가지 않는다.** 면별 기하 속도는 어디에도 쓰이지 않는다.
- 엔트로피 변수 K와 함께 쓰면 §5처럼 ie > 0이 Δt와 무관하게 보장된다.
- 근사는 한 곳에만 있다. 셀의 모양(`A`, `n`, 이웃)을 면 운동학이 아니라 OT가 정한다는 점이다.

### 11.4 생성점 regularization: 남은 문제

(G)에서는 V가 제약으로 고정된다. 그래서 생성점을 옮겨도 `V`, `ρ`, `P`, `U`, 운동량이 1차에서 변하지 않는다. 이전 구현에서는 부피가 생성점 기하로 정해져, 생성점을 옮기면 압력이 직접 흔들렸다. 그 경로가 (G)에서는 없다. **그러나 셀 모양(`A`, `n`, 이웃)과 Riemann 문제의 방향이 바뀌므로 유속의 기하에는 영향이 남는다.** 사용자가 과거에 본 "노이즈로 이론값에서 멀어짐"이 이 경로로도 생기는지는 물리 시험으로만 판정할 수 있다.

4. Sod, Noh, Sedov: 충격파 위치와 뒤쪽 상태.

- 에너지를 기장하는 Brenier식 퍼텐셜 `ε⁻²|x − c|²/2`: 보존적이지만 진동이 생길 수 있다.
- 조건부 steering: `|ΔW|/d²`가 문턱을 넘을 때만 건다.
- V^G를 Voronoi 부피 쪽으로 보존적으로 재분배: 질량 교환(ALE)이 필요하다.

## 12. 입자 = 생성점 조건과 정식의 선택 (2026-09-29, 사용자 결정 반영)

**[사용자 결정]** 생성점을 셀 중심으로 옮기는 regularization(§11.4)은 쓰지 않는다. 사용자가 한 달 동안 시험한 결론은 인위적 노이즈가 증폭된다는 것이다. 원인은 AREPO와의 차이다. AREPO의 생성점은 메시 계측점이고, 유체는 질량 유속으로 옮겨진다. LagEunha에서 생성점은 **입자**다. 질량, 운동량, 중력이 모두 그 위치에 있다. 따라서 생성점 위치는 조정할 수 있는 자유도가 아니다.

**[유도] 결과.**

1. 기하에 남는 자유도는 W(N개)뿐이다.
2. 정식 (G)(§11.2)는 열역학 부피를 독립 상태로 적분한다. 그러면 입자 운동학과 V^G의 구조적 어긋남(전단에서 시간에 비례)을 W가 모두 떠안아야 한다. 이것은 W를 무한히 키운다(§11.3의 `|ΔW|/d²` 3.2). **[HYP] (G)는 입자 = 생성점과 장기적으로 양립하지 않을 수 있다.** 운동학 모형의 결과이므로 물리 시험(§13)으로 판정한다.
3. 면 속도를 u*에 계속 맞추는 모든 법칙은 누적하면 부피를 V^G에 맞추는 것과 같다. 따라서 같은 이유로 W가 발산한다. 1D `hllface`의 클램프 17,185회도 이 현상의 1D 형태로 해석한다. **면이 u*를 장기적으로 따르는 것은 이 구조에서 원리적으로 불가능하다.** 국소적이고 일시적인 추종(충격파 통과 구간)만 가능하다.
4. 남는 정식은 (F)(§3)다. 부피는 `V(x,W)`, 힘은 (F), 에너지는 `dU_i = −P_i dV_i^geo + σ_i`다. 에너지 보존과 셀별 정합성은 **어떤 Ẇ에서도** 성립한다(§9.1에서 수치로 확인). 허용 조건은 `D_f = A[G_f + (P_i − P_j) ε_f] ≥ 0` 하나다.

**[판단] (F) 안에서 W의 설계 원칙.**

- **W는 유계여야 한다.** 방법은 (a) 순간 상태의 대수 함수 `W_i = f(국소 상태)`로 두고 `Ẇ = df/dt`를 연쇄법칙으로 δ에 정확히 넣거나, (b) 적분하되 Voronoi로의 이완 항을 두는 것이다. (b)의 이완이 하는 일은 `Σ_f A(P_i − P_j) δ_relax`로 기장된다. 압력이 균일한 곳에서는 비용이 0이고, 압력 점프에서는 `D_f ≥ 0`으로 제한된다.
- **[HYP]** 과거 drag가 실패한 원인은 drag 자체보다, 가중치가 만든 부피 변화의 일이 힘과 맞게 기장되지 않은 데 있을 수 있다(힘 `−P* A n`, 일 `−P_i dV`, 접선 항 없음). (F)에서는 같은 drag가 정확히 기장된다. 이것은 시험으로 판정할 가설이다.
- 이 틀에서 세 방식은 하나의 정식의 특수한 경우다. (1)은 `W ≡ 0`, (2)는 `W = f(상태)`(B2의 선형 Ẇ가 (a)의 근사), (3)은 동적이지만 유계인 W다. 비교 기준은 `D_f < 0` 빈도, 소산의 크기, 해석해와의 차이다.
- (F)의 대가: 각운동량은 정확히 보존되지 않는다(§3.4, 접선 항 토크). 케플러에서 `L_z`를 측정해야 한다.

**다음 시험 후보.** 1D는 순환이 없고, 입자 = 생성점에서 면 추종이 가능한 한계(클램프)가 이미 알려져 있다. 따라서 W 법칙을 비교하기에 가장 싼 시험대다. Sod, blast, Noh에서 (F) + K 변수 + `D_f ≥ 0` 제약으로 W 법칙들((1), (2)의 mode 8, 이완형 (3))을 비교한다. 발표된 `gfs_*.dat`는 덮어쓰지 않는다.

## 14. W = f(ρ, P, T, s)가 HLL을 재현할 수 있는가

사용자 질문: W의 변화가 HLL을 따라야 한다는 제약이 있으니, 결국 어떤 `W = W(ρ, P, T, s)`가 HLL 속도를 재현하느냐의 문제가 아닌가.

**[유도] 필요조건.** 면 속도가 HLL을 따르면 각 셀에서 그 합, 곧 부피율도 따라야 한다. 1차에서

```text
½ L_{A/d}(x) Ẇ = r(t),     r_i = Σ_f A_f (u*_f − ũ_f − ρ_f)
```

이다(§11.1). `W_i = f(q_i)`, `q = (ρ, P, T, s)`라 하면 `Ẇ_i = ∇f(q_i)·q̇_i`이다.

**명제 1 (정상 흐름).** 모든 곳에서 `q̇ = 0`인 정상 흐름에서는 좌변이 0이다. 따라서 모든 i에서 `r_i = 0`이어야 한다. 그러나 일반적으로 `r_i ≠ 0`이다.

- **Riemann 부분:** 셀 평균 상태에서 `u* − ũ ≈ (P_i − P_j)/(Z_i + Z_j)`이다. 압력 기울기가 있는 정상 상태(Gresho의 원심 평형, 압력이 있는 Kepler 원반, 정수압 대기)에서 0이 아니다. MUSCL로 면 상태를 재구성하면 `O(d²)`로 줄지만 0은 아니다.
- **운동학 부분:** 정상 전단 흐름에서도 입자 배치는 변한다. 반경이 다른 입자가 서로 다른 각속도로 돈다. 그래서 Voronoi 부피율 `Σ A(ũ + ρ)`는 0이 아니다. 반면 연속체 부피는 일정하고(`∇·v = 0`), `Σ A u* ≈ 0`이다.

따라서 **열역학 상태의 함수인 W는 HLL을 정확히 재현할 수 없다.** 필요한 W는 입자 배치(메시)와 이력(`∫(P_i−P_j)/Z dt`)의 함수다.

**명제 2 (필요한 W의 정체).** 부피를 정확히 추적하도록 하면 W는 `W_OT(x, V^G)`, 곧 모든 입자 위치와 누적 Godunov 부피의 함수로 유일하게 정해진다(§11.2). 이것이 정식 (G)다. 상태 함수 W로 할 수 있는 최선은 `r`을 `{∇f·q̇}`의 공간에 투영하는 것이다. 남는 잔차는 정상 흐름에서 시간에 비례해 누적된다. 과거에 HLL을 맞추도록 W의 변화율을 적분했을 때 발산한 경험과 일치한다[HYP].

- `|ΔW|/d²`의 증가에는 W 증가와 이웃 거리 감소가 함께 작용한다.

**[유도] 상한이 있는 (G).** 사용자 지시에 따라 `|W_i − W_j| ≤ (1−δ) d_ij²`로 제한한다.

- Newton이 푸는 문제는 오목 함수 Φ(W)의 최대화이고, 상한은 선형 부등식이다. 따라서 해가 유일한 볼록 문제로 남는다.
- KKT 조건: 상한이 걸린 면 f에서만 두 셀 사이에 부피를 쌍으로 옮기는 양 `λ_f`가 생긴다(`V_i − V^G_i = −λ_f`, `V_j − V^G_j = +λ_f`). 나머지 셀에서는 `V = V^G`가 그대로 성립한다.
- 스텝 끝에 `V^G ← V`로 맞추고, 옮긴 부피의 일을 면 압력 `P_f = (P_i+P_j)/2`로 쌍마다 기장한다(`ΔU_i = +P_f λ_f`, `ΔU_j = −P_f λ_f`). 이렇게 하면 총에너지가 정확히 보존된다.
- 대가: i가 부피 λ를 잃으면 `ΔU_i + P_i ΔV_i = (P_f − P_i)λ`, `ΔU_j + P_j ΔV_j = (P_j − P_f)λ`이다. 산술평균 `P_f`에서는 둘 다 `(P_j − P_i)λ/2`다(부호 정정, Astra §3). 두 셀 모두 엔트로피가 줄지 않으려면 `P_i ≤ P_f ≤ P_j`여야 한다. **고압 셀에서 저압 셀로 부피가 옮겨 가면 어떤 `P_f`로도 불가능하다.** 음수 부분을 `cap_sneg`로 기록한다.
- 구현은 벌점 `κ = 1000`의 연성 상한이다. 잔차에 `κ · 초과량 · sign`을 더하고 Jacobian에 rank-1 항을 더한다.

**[유도]** 열역학 부피는 기하 부피 `V(x, W)`다. 힘은 Laguerre VPH에 Riemann 보정을 더한 `f = −A[P* n + (P_j − P_i) t/d]`이고, t는 앵커(`φ = ½ + ΔW/2d²`) 기준 면 중심의 이탈이다. 에너지는 `dU_i = −P_i dV_i/dt + θ D_f`, `D_f = A[(P_i − P_j)δ + (P* − P̃)(u_i − u_j)]`다(§3). W는 상태변수로 RK4에 넣어 적분하며, 법칙은 다음과 같다.

```text
V̇^T = Σ_f A u*_f + (V_vor − V^T)/τ_V           목표 부피: Godunov 부피율 + Voronoi로의 이완
½ L_{A/d} Ẇ = V̇^T − Σ_f A(ũ + ρ) + (V^T − V)/τ_C  기하 부피가 목표를 따르도록 (오차 되먹임)
```

- 부피를 옮기는 이벤트가 없다. W의 모든 변화는 δ를 통해 `−P dV`와 `D_f`로 기장되므로 총에너지는 정확히 보존된다.
- τ_V보다 빠른 부피 노이즈는 W가 상쇄한다. 더 느린 누적은 Voronoi 쪽으로 풀린다. τ_C 되먹임은 적분 오차가 쌓이지 않게 한다(§11.1의 "되돌림 항 없음"을 고친 부분).

**두 자문이 합의한 것**

1. 공동 중심은 거칠게 해상되어 있다(R_min = 0.265 < Δx = 0.375, c_s = 0.041). 이것이 Kepler 비교를 오염시킬 **강한 가설**이다. **판정의 첫 작업**은 기존 결과를 분해하는 것이다: 반경별 바닥값 주입과 `L_z`, 중심 면의 `Δu_n`과 `P*`, 최소 d와 V. 다만 Astra는 "세 방식의 실패 원인이 공동 하나"라는 확정에는 반대한다. Fable이 추정에 쓴 전단 속도차는 전체 상대속도이고, Riemann 압력에 필요한 것은 법선 성분이다. 순수 원궤도의 방사 방향 이웃에서는 그 성분이 0일 수 있다.
2. 시험 규약을 다시 짜야 한다: `r_in/Δx`를 키우고, 시간을 안쪽 궤도 수로 표기하고, 반경별 진단과 별도의 차가운 전단 상자를 둔다. Hopkins 2015 §4.2.4는 입자 방식에서 공동의 입자를 제거한다. Astra는 고정 질량 Voronoi 셀에서는 입자를 없애도 남은 셀이 빈 영역까지 뻗으므로 초기 상태와 경계를 다시 정의해야 한다고 유보한다.
3. **`W_i = h_i² ω_i`, `h_i ≤ min_j d_ij`, `|ω_i| ≤ ½(1−δ)`이면 모든 쌍에서 유효성이 항등적으로 성립한다**(Fable의 증명, Astra 수용). Astra가 지적한 구현상의 약점은 다음과 같다.
   - `h_i`는 최근접 이웃이 바뀔 때 미분 불가능하다. 매끄러운 하계와 연속적인 목록 처리가 필요하다.
   - 이 조건은 충분조건이라 강하게 제한적이다. 예: 두 근접 쌍 집단 사이의 유효한 W 차이를 표현하지 못한다.
   - `½L diag(h²) ω̇` 계는 대칭 SPD가 아니다.
4. 음의 면 소산 `D_f < 0`은 두 셀 사이 분배로 고칠 수 없다(`σ_i + σ_j = D_f`). 압력 부호와 무관한 부피 보정은 이것을 만든다. Astra는 "절반이 음", "양의 부호를 보장하는 법칙은 압력 기울기 흐름뿐", "셀별 λ_i 제한자가 σ_i ≥ 0을 자동 보장"은 증명되지 않았다고 본다.

6. **별도 물질 부피 V^G, W=0(Astra의 1차 대안)에는 압축 반례가 있다**: `V̇^G = θ V^vor`이므로 부피 불일치(비율 0.74)가 있으면 약 3.85배 압축에서 V^G = 0이 된다. Astra는 일반 해법 권고를 철회하고 전단 대조군으로만 남긴다.
7. 입자 = 생성점에서 W로 Riemann 면 속도를 따르는 직접 선례는 확인되지 않았다.
   - VPH와 Gallouët–Mérigot, Duque 2022의 **보존적 스프링 힘**(라그랑지안 벌점)은 사용자가 시험한 운동학적 steering과 다르다. 권고는 아니지만 구별해 둔다.
   - Zier & Springel 2022(MNRAS 515, 525)는 면 유속의 2점 Gauss 적분과 불규칙 셀의 과도한 기울기 제한을 분석한다. 전역 차가운 Kepler 원반에도 적용한다(Astra 정정).
   - Després 2024(CMAME 418, 116427)의 초록은 **1차 고정 질량 입자 Voronoi 방법**, 총에너지 보존, 엔트로피 부등식을 명시한다(Astra 확인). 본문을 확보할 가치가 가장 크다.

## 22. 검증 루프 결과 (Fable ↔ Astra, 5라운드, 2026-09-30)

원문: `consult_scheme_H_round2_fable.md`, `…_round3_astra.md`, `…_round4_fable.md`, `…_round5_astra.md`(§21의 1–2라운드 문서에 이어짐). 논증으로 닫을 수 있는 항목은 아래 문장으로 합의하고 루프를 종료했다. 실험적 판정은 끝나지 않았다.

**합의된 수학적 명제**

- **(5a) 매끄러운 하계.** 정의는 다음과 같다(0 < R_1 < R_c < L/2, 합은 주기 최소 영상, φ는 [0, R_1/R_c]에서 1인 C¹ 절단).
  ```text
  h_i = (R_1^{-p} + Σ_{d_ij<R_c} φ(d_ij/R_c) d_ij^{-p})^{-1/p}
  ```
  - 모든 쌍에서 `h_i ≤ d_ij`가 성립한다. 경우 1: `d* ≤ R_1`이면 최근접 항 때문에 `h ≤ d*`. 경우 2: `d* > R_1`이면 상수항 때문에 `h ≤ R_1 < d*`.
  - 생성점이 서로 다르면 h는 C¹이다. C^k는 절단점에서 해당 차수 도함수가 모두 0일 때만 성립한다.
  - 하한은 `h ≥ min(R_1, d*)(n_c+1)^{-1/p}`다. Fable이 처음 쓴 `h ≥ 0.78 d*`는 일반 보장이 아니다.
  - 따라서 `W_i = h_i² ω_i`, `|ω_i| ≤ ½(1−δ)`는 모든 쌍에서 유효성을 매끄러운 형태로 보장한다.
- **(6b) 엔트로피 부호.**
  - 총 W-일: 압력에 무관한 고정 q에 대해, 모든 양의 P에서 `P·q ≥ 0`이려면 `q = 0`이어야 한다. 일반 조건은 `P·q(P) ≥ 0`이다.
  - 선형 계열: `δ = Mg`가 실제로 성립하면(압력의 상수 이동에 δ가 불변일 때) 조건은 `sym(AM)`이 절단 공간 위에서 반정부호인 것과 동치다.
  - 대각 비음 이동도는 **충분조건 중 하나**다.
  - 총합 조건은 셀별 부호를 함의하지 않는다. 셀별 부호는 `σ_i^W`와 `σ_i^G`를 비교해야 한다. "충격파에서는 안전하다", "Kepler에서는 불안전하다"는 정리가 아니라 **시험할 가설**이다.
  - (H) 전체를 "압력에 눈먼 법칙"으로 분류할 수는 없다. 목표에 `u*` 같은 압력 의존 항이 있다.
- **(6c) POCS.**
  - 실현 가능하면 수렴한다. 잔여 위반이 있으면 실현 가능성을 인증하지 못한다. 부피 목표는 깨진다.
  - 같은 단계 상태와 같은 사영 Ẇ로 기하 부피율과 D_f를 다시 계산하면 δ 항이 면별로 상쇄되어 반이산 총에너지는 정확하다.
  - E_i를 상태로 쓰고 모든 RK4 단계에서 합을 일관되게 평가하면 한 스텝에서도 반올림 수준까지 보존된다. 스텝 뒤의 바닥값·클리핑은 예외다.
  - 비용은 `O(kE)`이고 k에 선험적 상한이 없다.
- **(8) 셀 부피의 미분 가능성.** 충돌이 없고 해당 셀들이 양의 면적을 유지하는 통상적인 면 전환에서는 부피와 1계 미분이 연속이다. 일반적인 횡단 면 전환에서는 C²가 실패한다. **셀이 붕괴하는 경우(Astra 반례: 가중치로 중앙 셀이 선으로 줄어드는 경우, 최근접 거리는 유지)와 생성점 충돌은 따로 다뤄야 한다.** Fable의 "충돌에서만 C¹ 실패"(정리 3, 5 원문)는 인용하지 않는다.

5. 내부에너지가 궤도당 일정 비율로 자란다(Hill 띠 e-폴딩 약 3궤도, Kepler 64² 약 3.9, 좁은 고리 약 3.4). P₀ 100배에도 같음 → ν∝cΔ 점성 아님.
6. 시간간격 의존: dt3 계수 절반이면 가열 4–6배 감소. 총에너지 RK 잔차·면 쌍 장부는 무시 가능. 면 속도 공식은 오프라인 수치 미분과 2e-6 일치. 그러나 RK 장부 부피와 실제 셀 부피의 차이가 회전 격자에서 장부값과 같은 크기(`GFS_VOL_AUDIT`).
7. **엔트로피 모드(P = Kρ^γ, ρ = m/V 기하 부피)에서는 폭주가 사라진다**: 격자 잡음이 약 0.2c에서 30궤도 동안 포화, 띠 유지.

**결론.** 격자 재연결 잡음 자체는 약 0.2c에서 포화하는 무해한 수준이다. 붕괴는 내부에너지 갱신 경로(총에너지 − 운동에너지, RK 장부 부피의 PdV)가 그 잡음을 열로 쌓아 음속을 올리고, 잡음이 음속을 따라 커지는 되먹임이다. 해법 방향(사용자 승인): 엔트로피 변수 K를 진화시키고 단열 부분은 기하 부피로, HLLC의 실제 엔트로피 생성만 dK에 넣는다(Astra 18차 자문 중).

**정정.** 64² 2차 LSF 단독 실행은 기울기가 2–6배 정확했지만 토크가 커졌다. 기울기 정확도는 주원인이 아니었다. Δ/r 가설과 "Hill 회전 격자는 포화한다"는 판단(20궤도까지만 관측)은 틀렸다.

### 26.3 정정: Fable 감사 (2026-10-01)

§26.2 항목 5–7과 결론을 다음과 같이 정정한다.
- **"RK 장부 부피 ≠ 기하 부피가 가짜 PdV를 만든다"는 틀렸다.** `GFS_VOL_AUDIT`의 잔차는 진단 결함이다. 면 루프가 원호(VORO_ARC_EDGE) 면을 건너뛰어 표면 셀에서 원호 항이 늘 남는다(완전 격자 스텝 1에서도 1.5%). 에너지 경로는 dke = v·F가 같은 항을 상쇄하므로 ie는 기하 −P dV를 따른다. 누적 부호 합은 음수(순 냉각)였다. 이 잔차가 시간간격에 무관한 것도 그 때문이다.
- **GCL 진단 보정(`GFS_GCL_DIAG`) 실행은 무효**(표면 셀에서 부호가 지속되는 r/V로 1궤도 만에 E_int 15만 배).
- **P₀=1e-4 비교의 "궤도당 성장률 같음"은 틀렸다**(e-폴딩 1.6 대 3.2궤도).
- **엔트로피 모드 실험은 통로를 구분하지 못한다**(av_mode 5에서 dK=0이면 K가 상수라 소산 가열과 단열 오차가 함께 막힌다).
- **가열의 실제 모양**: 궤도당 일정 비율이 아니라, 특정 격자 위상에서 계단식 주입(0.51궤도에 5스텝 만에 E_int 7.6배) + 그 사이 완만한 지수 성장.
- **기구(감사 의견)**: 37° 회전 격자는 선형 전단에서 주기적으로 폭 0.2Δ × 길이 5Δ의 바늘 셀(종횡비 약 25)로 퇴화하고, 원판 경계(R=Δ)가 내부 셀까지 자른다. 그 순간 재구성 면 속도 점프가 1e-7 → 0.28c로 튀고, 이후 격자 잡음이 0.15–0.25c로 남아 HLLC 소산(½ZAΔu²)이 ie에 비례하는 가열을 만든다. 시간간격 의존은 위상 사건을 가로지르는 RK4 차수 붕괴(1차).
- **총에너지는 이미 보존되고 있다**(RK 잔차 1e-7, 면 쌍 장부 1e-12). 가열은 보존적 KE → 열 전환이다. 그래프 퍼텐셜로 면 부피를 나누는 방식은 땜질이다.
- 다음 시험: 원호 없는 셀만의 가열 분해(`[VDEC]`, `58b71c8`)와 동심 고리 격자 Kepler 64²(전단과 정렬된 격자 IC).

### 26.4 비교 기준 확정 (2026-10-02, 사용자 승인)

- **GIZMO MFM 비교의 기준은 진공 고리**(Hopkins 2015 §4.2.4 입자 방법: −2<x,y<2에 균일 격자, r<0.5와 r>2 입자 제거, Σ=1, 같은 질량, P=1e-6, γ=5/3, 자체중력 없음)다. 식 (34)의 바탕 기체·부드러운 가장자리·연화 퍼텐셜은 각주 24대로 격자 코드용이다. ε는 0 또는 0.01(원반 안쪽 r=0.5의 힘 변화 0.06%). §26.1의 "논문 IC는 진공이 아니다"는 격자 코드 기준이었고, 입자 방법 기준으로는 진공 고리가 맞다(Astra 21차).
- 기준 실행: 256² 진공 고리(409790, `258413b`, 쌍 구간 제한자). t=20–50은 MFM 그림 6과 비슷하고, t≈50(r=0.5 기준 약 23궤도)부터 안쪽 가장자리가 무너진다. MFM은 t=120에 건재.
- **식 (34) 전체(사용자의 원래 LagEunha Kepler 설정: ε=0.1, 균일 간격, 질량 ∝ Σ, R<2.5만 진화)는 별도 시험**이다. 기본 수치 기법(`dcf3bac`)에서 구멍(연화 핵) 가열로 r=1 기준 약 2궤도에 붕괴. ε=0.1은 원반 안쪽 힘을 5.8% 바꾸는 타협으로 명시한다. 같은 질량 솎아내기는 Voronoi에서 저밀도부 해상도 저하(거대 셀)로 맞지 않는다.
- 공개 GIZMO 코드의 `GravAccel_KeplerianTestProblem`(r<0.216 척력)은 논문과 다른 판일 수 있어 쓰지 않는다.
- 다음 개선 대상: 진공 고리의 안쪽 가장자리 붕괴(t≈50).

## 10. 열린 결정

1. **힘:** (F)를 채택할지(각운동량 정확성을 포기), 아니면 GFS 중심력을 유지하고 셀별 σ 부호를 다른 방법으로 통제할지.
