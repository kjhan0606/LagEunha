# 감사·결정 요청 (Astra, 구현 2차): HG 안정 dt 제한이 전단 흐름에서 계속 줄어드는 문제

작성: 2026-10-02. 직전 감사: `Docs/audit_impl1_astra.md`. 운전자 기록: `Docs/design_astra_audit.md`.

## 1차 감사 P1 반영 (1fd7157)
HG 감쇠 안정 제한(입자별 행합 상계 Λ_a = Σ_f (C + qC′)|ℓ_a|/√m_a · Σ_b|ℓ_b|/√m_b, Δt ≤ 1.4/Λ_max), 면 기하 dt(0.25·h_f/(c_f + |Δv·e|)), 최소제곱 유사역행렬, 기하 패스마다 주기 완전성 검사(|ΣV/V_box − 1| < 1e-12), `SEDOV_PHASE1` 강제·Φ와 HG 배타, 면 상태 절삭·공유 면 길이 불일치 진단.
아직 안 한 것: 공통 분할(cap 경로), 원호·벽 HG, 단계 거부·반분, 엔트로피 적분 진단의 HG 열 포함.

## 결과
- **Sod 2D(m∝ρ, 면 Z + minmod + HG):** L1 ρ/u/P = 0.0152/0.0393/0.0240, 최소 간격/h 0.169·0.180, 에너지 6.7e-8(이전 1.2e-6), 단계 1437(이전 274; 면 기하 dt가 묶음), dt 끝/처음 0.32.
- **Gresho(같은 구성):**
  - 수정 전(10d4734): t=0.187, 277단계에서 H가 단계마다 5–10배 커지며 폭주했다(dt 4.7e-4 일정, 명시적 적분 불안정).
  - 수정 후(1fd7157): 폭주는 없고 에너지 7e-13이다. 그러나 HG 안정 제한 dt가 계속 준다: 5.7e-4(500단계), 9.6e-5(1000), 4.7e-5(1500), 3.2e-5(2000), 2.5e-5(2498, t=0.26). H는 4.9e-5에서 2.6e-4로 증가.
- **진단(57aabcb, t=0.25에서 재시작):** 행합 기여가 가장 큰 면은 d/√V = 2.3(먼 이웃, 길게 늘어난 셀), 1 − u = 0.74–0.77, |ℓ|·√V = 6.7 → 7.7(증가), C/음향 = 1.00, |r|h/c ≈ 3e-3, 스텐실 24–31개이다.
- t=0.25 스냅숏 전체에서 min(1 − u) = 0.74로 ln(1 − u)의 특이성은 원인이 아니다.

## 질문
1. 실제 감쇠 고유값 대신 행합 상계를 쓰는 것이 얼마나 과보수적인가? 멱반복(면별 ℓ 저장 후 Dv = Σ_f (C + qC′) ℓ_f(ℓ_f·v))로 바꿀지 결정해 달라.
2. 전단으로 늘어난 셀에서 2-hop 최소제곱 필터의 조건 악화(|ℓ| 증가)를 정합하게 다루는 방법은? 문턱·계수 조정 없이.
