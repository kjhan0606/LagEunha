# 자문 요청 (11차): 원호 진공 경계조건과 가장자리 속도 제한 — 구체 설계 검증

## 1. 현재 구현 (`95dcd37`)

- 셀 = `Voro2D_FindVC` 결과(Laguerre, W=0) ∩ 자기 원판(반경 ρ=Δ). 후처리로 고리를 다시 쓴다.
- 노출 원호는 **정확한 원호 변**(`VORO_ARC_EDGE`, 최대 π/2 조각)이다. `Area2DPolygon`이 활꼴을 더한다(검증 58경우, 최대 상대오차 6e-9).
- 원호의 법선 적분은 현과 같으므로 면 루프는 그대로다. 원호 변은 음수 id라 기울기, 제한자, 힘에서 모두 건너뛴다.
- 결과(현 근사판): 방식 (1)이 t=20(3.2궤도)까지 붕괴 없음, 총 dLz 4.5e-8, dE 1.4e-5. 안쪽 가장자리는 t≈15 이후 한 고리씩 깎인다.

- `av_mode==5`에는 주석과 달리 쌍별 clamp가 없다(Astra 10차 지적).

## 2. 제안 설계

**(A) 원호 경계 상태 (밀도·압력)**
- 자유표면(진공 경계)의 상태는 `P_b = 0`, `ρ_b = 0`(이상기체 단열)이다.
- 기울기: LSF에 원호 경계 표본을 넣는다. 표본점은 원호의 면적 가중 중심 `x_b`, 값은 `(ρ_b, P_b) = (0, 0)`, 가중치는 내부 면과 같은 형태 `ℓ_b/|x_b − x_i|²`다.
- 제한자: 밀도와 압력의 허용 범위 `[min, max]`에 경계값 0을 포함한다. 가장자리 셀은 경계 쪽으로 0까지 감소하는 재구성이 허용된다.

**(B) 속도**
- 자유표면은 벽이 아니므로 속도 경계값이 없다. 속도 LSF 표본에는 원호를 넣지 않는다.
- 가장자리 속도 극값 제한은 (ii) 매끄러움 판별형으로 다룬다. 예: 셀의 LSF 잔차 또는 2계 차분으로 매끄러움 지표를 정의하고, 매끄러운 극값에서는 제한을 풀고 불연속에서는 기존 Springel 제한을 쓴다.
- 대안: 속도에도 자유표면 조건을 쓴다. 1D 진공 팽창의 경계 속도 `u_n + 2c/(γ−1)`를 표본으로 넣는다. 차가운 원반(c ~ 1e-3)에서는 거의 `u_n`이다.

**(C) 원호의 Riemann 유속**
- 방식 (1)에서 원호는 입자와 함께 강체 이동하고(W=0, Ṙ=0) `P* = 0`이므로 운동량과 에너지 유속이 모두 0이다. 총에너지는 유속 형태로 보존된다.
- 자유표면의 실제 팽창(원호 바깥쪽 가스 운동)은 이 이산화에서 셀 해상도 이하이며, 이것을 1단계의 알려진 근사로 둔다.

**(D) 양성**
- 재구성 후 ρ, P에 기존 바닥값(1e-10) 대신, 제한자 범위에 경계값 0이 들어가므로 선형 재구성이 음수로 가지 않도록 α를 정한다(ρ, P ≥ 0이면 HLLC 입력이 유효).

## 3. 질문

1. (A)–(D)가 정합한가? 특히 (A)에서 `(ρ_b, P_b) = (0, 0)` 표본을 LSF에 넣는 것이 경계조건으로 정당한가? 아니면 "경계 표본"이 아니라 경계 적분(Green–Gauss식 경계 항)으로 넣어야 하는가? 가중치 선택은?
2. (B) 속도: 매끄러움 판별형을 비정렬·한쪽 stencil에서 어떻게 정의해야 신뢰할 수 있는가? 구체식을 권해 달라(예: LSF 잔차 기반, 이웃 기울기 비교, Barth–Jespersen의 Venkatakrishnan 매끄러운 판)을 비교해 달라. 대안(자유표면 속도 표본)은 타당한가?
3. (C)에서 방식 (1)의 원호 유속 0 처리와 에너지 보존 논리가 맞는가? 1단계의 근사로 남기는 것이 합당한가?
4. (D) 양성과 기존 1e-10 바닥값의 관계를 정리해 달라.
5. 구현 순서와 판정 측정(Sod·Sedov 충격 시험 포함)을 권해 달라.
