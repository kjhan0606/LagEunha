## 16차 처방 구현
- `EUNHA_IC_CELLVOL`(bfd170d): IC 질량 m_i = ρV_i, 내부에너지 U_i = P V_i/(γ−1). V_i는 원판으로 닫은 정확한 Voronoi 넓이(Python `Docs/arc_hg/arcgeom.py`로 계산, 파일 `/gpfs/kjhan/LagForce/ICcellvol/`)이다. t=0 RHS에서 모든 고리의 밀도가 1.0000이다(균일 질량 IC는 가장자리 0.69). 가장자리 초기 유체 가속도/g_K는 안쪽 −1.1e-5, 바깥 +1.75e-4(물리적 진공 쪽 압력).
- 정합 IC로 장기 실행(원호 HG 유·무): 첫 쌍 붙음 t=37.4 / 37.1로 붕괴 시작이 변하지 않는다. 가장자리 가열은 크게 줄었다(t=36 u_k0/u_int 1.3). **가열은 원인이 아니다.**

## 모드 진단
- 고리별 방위각 변위 푸리에: 가장자리 고리 0, 1에서 m ≈ 42–49가 지수 성장한다(고리 1 m=45: t=12/18/24/30/36에 0.002/0.007/0.021/0.062/0.193 × 간격, e배 시간 ≈ 5.4). 반경 변위도 같은 모드이다. 고리 2 이상에는 없다. 초기 가장자리 힘 변조(m=6, 13, 25)와 모드 번호가 다르다.
- t=24 재시작 분리 시험(m=45 진폭 t=24→32): 기준 0.021→0.090, Q 끔 →0.085, HG 끔 →0.091, **가역 힘만 →0.085**. 소산은 원인이 아니다.
- 압력 배율(t=24 스냅숏의 P, ie ×, c×√): ×0.1 → 성장률 ≈ 0.12, ×1 → 0.18, ×10 → 0.50. 음속에 대략 비례하므로 압력 구동이다.
- 원판 반지름(정합 IC, 처음부터): ρ = 0.7은 t=24에 m=49 진폭 0.15(빠름), ρ = 1.0은 0.021, ρ = 1.5는 t=36에 0.051(느림).
- 정적 에너지 곡률(`Docs/arc_hg/stiff.py`): 고리 0, 1에 m = 45, 13 방위각 변위를 주면 d²U/dε²가 +108과 +15.5이고(내부 고리 20, 21은 +185, +19), 상대 위상과 무관하다. 정적으로는 복원적이다.
- 힘 대 에너지 기울기(`Docs/arc_hg/fcheck.py`, t=24 상태, Q·HG 끔 RHS 덤프): C의 TCF 힘과 Python −∇U의 상대 차이는 고리 0/1/2/20에서 4.8e-10 / 1.1e-8 / 4.5e-9 / 4.4e-7이다. 셀 부피도 일치한다. **가역 이산계는 정확한 해밀토니안이다.**

## 질문

2. 이를 가를 해석적·수치적 시험(선형 안정성 분석: 고리 이산계의 회전 좌표계 선형화, 연속체 한계와 비교, 해상도 의존성)을 지정하라.
