# 설계 결정 요청 (Astra, 5차): 충격 전용 소산

작성: 2026-10-03. 직전: `Docs/audit_impl4_astra.md`. 결과: `Docs/design_astra_audit.md` 마지막 두 절.

## 사실
1. Gresho 감속의 원인은 Q이다. Q=0 + HG 분리는 HLLC와 같은 정확도이다(0.0329 / −5.7%).
2. HG만으로는 매끄러운 흐름의 쌍 붙음을 막는다(가역만 쓰면 t=0.35에 정지). 그러나 충격(2D Mach 10, Fable 감사)의 쌍 붙음은 막지 못한다(0.06h).
3. Sod·Noh에서 쌍 붙음을 막는 주역은 면 상태 Z의 Q였다.
4. 4차 감사의 bulk 후보(기하 D_i v = V̇_i/V_i의 압축 부분)는 무질서 격자의 무발산 전단에서도 반응한다(rms 0.19 × 전단율). "아핀 무발산 전단에서 0"은 Bravais 격자에서만 성립한다.

## 요청
충격에서는 쌍 붙음을 막고, 매끄러운 전단·회전에서는 소산하지 않는 소산을 설계해 달라(문턱·스위치 없이). 후보를 평가하고 하나를 선택해, 구현 가능한 수식으로 달라.
- (a) 최소제곱 아핀 발산 a_i = min(0, tr G_i)에 작용하는 bulk. G_i는 2-hop QR 아핀 적합(HG와 같은 연산자)이다. 힘은 같은 선형 연산자의 전치이고 열은 η a²이다. 선형 전단에서는 정확히 0이다. 홀짝 접근 모드는 보지 못하므로 HG와 결합해야 한다.
- (b) 면별 Q를 압축 아핀 성분(면 법선의 아핀 속도 점프 (G_i + G_j)/2 · d 등)으로 제한하는 형태.
- (c) 기타.
각 후보의 에너지·엔트로피 장부, 분리 적분(HG 모드와 같은 정확 흐름) 적용 가능성, 충격 관문(고립 쌍 Mach 1–1000, Sod, Noh)과 전단 관문(Gresho, Hill)에서의 예상 거동, 시험 순서를 제시해 달라.
읽기 전용, 한국어, 결론 먼저.
