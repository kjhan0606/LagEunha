## 요청
1. **공통 자유경계 설계**(17차 3번)를 구현 가능한 수준으로 확정하라.
   - 경계 Γ(t)의 표현: 예를 들어 가장자리 생성점을 잇는 다각형·스플라인, 또는 질량 가중 물질점.
   - 셀 닫힘 C_i = Vor_i ∩ D_Γ. 넓이, 1차 모멘트, 생성점 미분.
   - 경계 이동 조건 v_Γ·n = u_Γ·n과 P_Γ = 0의 이산 표현.
   - 변분적 힘 F_i = Σ_a P_a dV_a/dx_i(경계의 위치 의존성 포함). 에너지 장부. 기존 TCF 면 힘과의 관계, 원호 HG·QBP·χ와의 호환.
   - 정합 IC 질량 배정.
   - 진공 원판 시험(안쪽·바깥쪽)과 우주론(경계 없음)에서의 적용 범위.
2. 더 단순한 대안이 있다면 비교해 선택하라. 예: 경계 생성점만 원호 대신 이웃 가장자리 생성점의 접선으로 닫기, 원판 반지름을 국소 간격에 맞추기(변분 항 포함).
3. 판정 시험: 해상도 192/384/768에서 m ∝ r/h 모드가 사라지는지, 성장률, 물리적 희박(표면 압력) 거동, 에너지·질량 보존.
4. Sod의 희박파 열 단위 작은 간격에 대한 판정과 처방.
읽기 전용, 한국어, 결론 먼저, 구현 가능한 수식으로.
