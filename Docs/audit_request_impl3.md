# 감사·결정 요청 (Astra, 구현 3차): Gresho의 HG 강성은 실제이다

작성: 2026-10-02. 직전: `Docs/audit_impl2_astra.md`.

## 2차 감사 지시 반영 (916efd6, d3f385a)
- QR 아핀 필터: 가중 MGS를 두 번 하고, 순위 판정은 기계정밀도 × √ns 기준이다. S⁻¹은 만들지 않는다.
- 면 연산자 저장(전역 ID, ℓ, k_f)과 질량 정규화 연산자 B의 멱반복 진단(`GFS_HG_SPEC`, 60회, 진단 전용). 단일 면의 정확한 고유값 k_f Σ|z|², |gM^-1/2|, |ℓM^-1/2|, QR 조건수를 기록한다.
- 단계 거부: 단계 시작 상태(입자 배열, 엔트로피 적분)를 저장한다. 단계 중 어느 힘 평가의 제한이 실제 dt보다 작거나, 바닥값·비양성·입자 수 변화가 있으면 되돌린다. 제한 초과면 관측된 제한(이미 RK4 한계의 1/2)으로, 실패면 반분해 재시도한다. 처음에 반분으로 구현했더니 0.05%의 제한 감소마다 dt가 절반이 되어 낭비가 커서 바꿨다.
- 고정 dt가 제한을 넘으면 실행을 멈춘다. dt 제한별 기록과 묶임 통계를 남긴다. 엔트로피 적분에 HG 열을 포함한다.
- 행합 상계는 그대로 dt에 쓴다.

## 결과
- 에너지 항등식(32² 글래스, Q=0 + HG, 고정 dt 5e-4 → 6.25e-5): 1.0e-12, 6.7e-14, 8.9e-16, −2.8e-15. 재시도 0.
- **Gresho t=0.25 재시작(같은 상태):**
  - 행합 상계 4.79e4, 멱반복 λ 3.26e4(잔차 1.6e2), 상계/λ = 1.47.
  - |gM^-1/2| = 1.075e3, |ℓM^-1/2| = 1.072e3: 필터 증폭 없음.
  - QR 조건수 215, 순위 결손 0.
  - 단일 면 최대 고유값 5.1e3. 여러 면이 겹쳐 3.3e4가 된다.
  - dt 제한: CFL 3.9e-4, 면 기하 1.1e-4, dt3 1.3e-2, HG 2.9e-5. 매 단계 HG가 묶는다.
- 2차 감사의 구분으로 판정하면 **실제 고유값도 크다. 상계의 과보수성(1.47배)은 작고, 원래 g = ∇ξ가 크다.** 전단으로 늘어난 셀의 먼 이웃 면(d/√V ≈ 2.3)에서 C ∝ ρcAd²/8과 |g|가 함께 커진다.
- Sod·Gresho 전체 실행(d3f385a)은 진행 중이다.
