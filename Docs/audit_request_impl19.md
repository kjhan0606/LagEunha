# 감사 요청 (Astra, 19차): C 진화 코드에서 Kepler 가장자리 m-모드가 어디서 생기는가

작성: 2026-10-07. 직전: `Docs/audit_impl18_astra.md`. 운전자가 진화 코드 검토를 요청했다.

## 지금까지의 사실
1. 가장 빠른 가장자리 모드는 m ∝ r/h이다(192²: m=18, 384²: 45, 768²: 84→98). 성장률은 대략 0.2, 0.18, 0.31/시간.
2. 소산(Q, HG, QBP, χ, 원호 HG)을 모두 꺼도 성장은 같다(384² t=24 재시작).
3. C의 원판 Voronoi 셀 부피는 192²의 모든 셀, 모든 스냅숏(t=6–42)에서 정확한 기하(`Docs/arc_hg/arcgeom.py`)와 2e-15로 일치한다(`Docs/polybnd/vcheck.py`).
4. C의 가역 TCF 힘 = −∇U(원판 Voronoi 에너지, 고정 엔트로피). 384² t=24, 고리 0/1/2/20에서 1e-9–4e-7(유한차분 한계). `Docs/arc_hg/fcheck.py`.
5. 같은 해상도 0.15(입자 524개)에서 C 가역 실행과 Python 기준 동역학(`Docs/polybnd/dyn.py`: 원판 Voronoi, 고정 엔트로피, F = Σ P_a ∂V_a/∂x, 중심 질량, 고정 dt RK4)은 t=60까지 같은 결과를 냈다(모드 성장 없음).
6. 192²:
   - C 실행(Q + HG 분리 + QBP + χ, 정합 질량 IC)에서 고리 0 m=18 진폭은 t = 16/20/24/28에 0.002/0.005/0.014/0.038이다.
   - **Python 기준(가역만, 같은 IC 구조)은 처음부터 돌리면 t=22에 0.0002, t=42에 0.0012로 느리게 자란다.** 이때는 m = 6, 12, 18, 24가 함께 자란다(고리 0/1 입자 수 차이 6).
7. 한 단계 대조(`Docs/polybnd/onestep.py`, C t≈20 상태, 가역, 고정 dt 0.02, 3단계): C와 Python의 속도 차이는 3–7e-10(유체 속도 증가분의 1e-4), 위치 차이는 1e-11이다. C의 셀 엔트로피는 가역인데도 단계당 rms 1e-5–1e-4로 랜덤워크한다(가장자리가 크고 내부 고리 40은 1e-6).
8. 엔트로피 모드 1(K 고정, P = Kρ^γ)로 t=20부터 재시작해도 m=18 성장이 모드 0과 4자리까지 같다(t=40에 0.1477). **엔트로피 드리프트는 원인이 아니다.**
9. 진행 중인 판별: (a) C 192² 가역 설정을 IC부터, (b) Python을 C의 t=20 상태에서 시작.

## 검토 대상 코드 (Exam/exam.c)
- RK4 블렌드 적분기 `exam2d_vph_rk4_int_blend_inner`(14100–14700행): 단계 갱신이 누적형(x += k1/2; x += (k2 − k1)/2; x += k3 − k2/2; 되돌림 x −= k3; 최종 결합), `postStage`, `kepler_accel`(단계 위치), `phase1_ie_stage`(ie = (die − m v·a)dt), `gfs_kepler_frozen`, `targetBP`, `w2backup` 복원, `clamp_dK_rate_limiter`, `kepler_dt_limit`.
- 분리 래퍼 `exam2d_vph_rk4_int_blend`(HG(dt/2) → RK4 → HG(dt/2), 사전 평가 단계, 재시도).
- `updateDenW2Pressure2DBlend`(기하·압력·기울기·제한자, 원판 원호 `voro2d_restrict_disc`), `getAccVoro2DBlend` TCF 힘(8400–8500행).
- 시간 간격 결정(CFL, 면 기하 dt, Kepler dt).
- 재시작 경로(KH/kh.c) — 1스레드 비트 일치는 검증됨.

## 질문
1. C의 진화 경로에서 Python 기준(순수 RK4, 고정 엔트로피, 정확한 −∇U)과 **다른 점을 모두 나열**하고, 그중 셀 규모 가장자리 모드를 씨뿌리거나 키울 수 있는 것을 순위로 매겨라. 특히 다음을 검토하라.
   - 단계 사이 `postStage`가 하는 일
   - 단계마다 다시 만드는 Voronoi의 위상 변화(flip)가 RK4 단계 사이에서 같은 단계 내 일관성을 깨는지
   - `kepler_accel`과 TCF 힘의 단계 위치 일치
   - Q/HG가 꺼져도 남는 경로(재구성·제한자·w2·MUSCL dtold, `hg_apply` 압력 재계산)
   - 변동 dt와 고정 dt의 차이
2. 한 단계 대조에서 C와 Python의 속도 차이가 3–7e-10인데 장기 결과가 다르다면, 그 차이를 설명할 기제(씨앗 차이 대 성장률 차이)를 판정하고 검증 방법을 지정하라.
3. 원인을 확정할 최소 시험 세트와 순서.
