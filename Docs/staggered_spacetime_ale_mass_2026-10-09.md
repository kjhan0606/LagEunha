# 공유 면의 ALE 적분과 스텝 끝 질량 제약

## 1. 판정

[움직이는 생성점 기하 관문](staggered_moving_geometry_2026-10-09.md)을 확장하여
움직이는 물질 경계와 ALE 질량·운동량·총에너지·각운동량 수송을 함께 적분했다.

**6개 사례에서 적분 수지와 스텝 끝 질량 제약은 통과했다. 그러나 중간 시각의
질량 고정은 만족하지 않는다.** 이것을 완전한 고정 질량 유체 해법으로 판단하지 않는다.

최대 오차:

| 항목 | 값 |
|---|---|
| 셀별 적분 순질량 유량 절대값 | 8.98e-16 |
| 끝점 셀 질량 상대 오차 | 3.11e-15 |
| 끝점 상태 변화 + ALE 적분 플럭스 | 1.96e-16 |
| 전역 경계 교환 장부 오차 | 1.00e-17 |
| 시간 적분 8점·16점 결과 차이 | 7.50e-17 |
| 연결 전환 분할을 생략한 수지 오차 | 5.00e-6 |
| 중간 시각 표본의 질량 상대 변동 | **5.32e-3 (0.53%)** |

## 2. 계산 정의

정확한 선형 전단 `v=(.2+1.1 y,0)`, `rho=1`, `P=.6`, `gamma=5/3`을 사용한다.
생성점과 외부 사각형의 꼭짓점을 같은 물리 속도로 이동시킨다. 외부 경계는 전단된
물질 평행사변형이고 면적은 일정하다. 생성점 조향은 없다.

경로 변수 tau에 대해 생성점과 가중치를 선형으로 표현하고, 움직이는 경계선의
반평면 계수도 연결 전환 검출에 포함한다. 외부 경계 속도는 유체 속도를 단순히
대입하지 않고 움직이는 경계 방정식을 미분해 구한 뒤 유체 법선 속도와 비교했다.

물리 시간 길이 T와 tau 기준 면 속도 s를 사용한 바깥 방향 플럭스는

```
F_m = rho (T v·n - s)
F_p = v F_m + T P n
F_E = e (T v·n - s) + T P v·n
F_L = x F_py - y F_px
```

이다. `e`는 내부에너지와 점별 운동에너지를 포함한 총에너지 밀도이다.
내부 면의 같은 적분을 양쪽 셀에 반대 부호로 적용하고 외부 경계 교환을 별도 기록한다.
외부 물질 경계의 질량 유량은 0이지만 압력 충격량과 일은 장부에 포함한다.

## 3. 가중치 풀이와 독립 대조

초기 가중치는 (.01,0,0,0)이다. 마지막 가중치 증가량을 0으로 고정하고 나머지
세 증가량에 대해 **스텝 동안 적분한 셀 순질량 유량**을 잔차로 비선형 풀이를 한다.
끝점 면적이나 목표 밀도로 잔차를 대체하지 않는다. 모든 사례에서 풀이가 수렴했다.

이후 끝점의 실제 다각형에서 질량·운동량·에너지·각운동량을 독립적으로 적분해
`끝점 - 시작점 + 적분 플럭스 = 0`을 검사한다. 시간 규칙을 8점에서 16점으로 바꿔
적분 오차도 확인한다. 공간 방향은 3점 Gauss 적분을 쓴다.

각 면의 시간 적분 질량은 0이 아니다. 최대 면 교환량은 **1.83e-3**이지만,
각 셀로 들어오고 나간 합은 최대 8.98e-16이다. 따라서 개별 면의 물질 이동 조건과
셀별 순질량 제약을 구분해야 한다는 이전 정적 결과를 유한 경로에서도 확인했다.

## 4. 사례와 실행

정사각형 생성점 배치에서 T=.02,.1,.3을 검사했다. 추가로 ±.025 불규칙 변위를
넣은 seed731에서 T=.1,.3, seed732에서 T=.3을 검사했다. 모두 실제 연결 전환이 있었다.
6개 계산 모두 적분 수지·끝점 질량·적분 차수 비교 기준을 통과했다.

- Slurm **417915**, `LAGFORCE_ST_ALE`, a10, CPU 1, GPU 1 할당, mem 4 GB.
- 실행 스냅샷: `/gpfs/kjhan/LagForce/Codex_B_spacetime_ale_20261009_233507/`.
- 계산은 CPU로 수행했다. 로그인 노드에서 이 비선형 풀이를 실행하지 않았다.
- 별도의 작은 정적 단위 검사 2개 통과: 물질 경계의 방정식·속도,
  한 경로의 공유 플럭스와 끝점 수지. 계산부 0.128초.
- 중간 질량 감사는 저장된 끝점 가중치를 읽어 세 시각의 기하만 검사했다.

## 5. 중간 시각에서 남는 질량 변동

풀이가 제약하는 것은 경로 전체의 적분 순질량뿐이다. 두 끝점 사이의 가중치를
선형 보간하면, 그 중간의 실제 셀 면적/질량은 일정할 필요가 없다.
각 경로의 tau=.25,.5,.75에서 직접 적분했다.

| 배치 | T | 세 표본에서 최대 질량 상대 변동 |
|---|---|---|
| 정사각형 | .02 | 3.23e-5 |
| 정사각형 | .1 | 6.02e-4 |
| 정사각형 | .3 | 4.71e-3 |
| seed731 | .1 | 3.32e-4 |
| seed731 | .3 | 4.88e-3 |
| seed732 | .3 | 5.32e-3 |

이는 시간 적분 오차가 아니다. 정확한 상태와 기하를 적분해도 선형 가중치 경로
자체가 중간 질량 제약을 만족하지 않는 것이다. 세 표본의 최대값이며 경로 전체의
엄밀한 최대값을 구한 것은 아니다.

고정 질량을 매 단계에 요구하는 유체 구현에서는 이 차이를 무시하고 동일한 질량으로
압력·속도를 복원해서는 안 된다. 다음은 중간 단계에서도 질량 제약을 만족시키는
가중치 경로 또는 제약을 만족하는 하위 스텝 구성이다.

## 6. 아직 해결하지 않은 것

- 플럭스 상태는 정확한 전단 해에서 평가한다. 일반적인 초기 수치 상태에서 압력·속도·
  밀도를 자체 예측하는 닫힘을 구현한 것이 아니다.
- 끝점 상태는 독립 비교용 적분이다. 이를 사용해 수치 해를 해석해로 덮어쓰지 않는다.
- 현재 밀도와 압력은 균일하다. 비균일 밀도·압력에서의 비선형 제약 풀이와 양성은 미검증이다.
- 양의 내부 분포 또는 원시 모멘트를 플럭스로 갱신하고 복원하는 과정은 아직 결합하지 않았다.
- 총에너지에서 셀 평균 속도의 운동에너지만 빼면 압력이 최대 **.00924**만큼 높게
  계산된다(P=.6 대비 약 1.54%). 이는 실제 압력 오차가 아니라 내부 전단 운동에너지를
  빠뜨린 잘못된 복원식의 대조값이다. 내부 운동 모멘트를 계속 보관해야 한다.
- 연결 검출은 작은 선형 궤적용이며, 큰 격자·퇴화·일반 곡선 경로의 견고성은 미검증이다.
