# 아영역 압력 정식 (3.2판, 서명 요청) — Voronoi 셀의 hourglass 모드 제거

작성: 2026-10-02. 동기: `Docs/tcf_sod_diagnosis.md`(Voronoi 부피 라그랑지안의 에너지 0 홀짝 모드).
검토: 1판 `Docs/subzonal_derivation_review_{astra,fable}.md`, 2판 `Docs/subzonal_derivation_review2_{astra,fable}.md`(수치 확인·1D 충격 사슬 `Docs/subzonal_checks/`).
선행: Caramana–Shashkov 1998(JCP 142, 521), Heß & Springel 2010(VPH, §3.2 shape correction).
범위: W=0(Voronoi). Laguerre(W≠0)는 §8에서 제외 사유만 적는다.

## 0. 서술 원칙 (검토 반영)
이 항은 실제 물질 아영역을 추적하는 모형이 아니다. **중심 정렬을 선호하는 보존적 수치 정규화**이다. 생성점 속도는 물질 속도와 같다(운동학적 조향이 아님). 다만 격자 규모에서 Lloyd(CVT)와 같은 방향으로 역학을 바꾼다. VPH의 shape correction도 수정 라그랑지안에서 나온 보존력이므로, 독창성은 "위상 변화에 연속인 중심 기준 아영역 질량과 TCF 소산의 결합"에 둔다.

## 1. 기호
- 셀 i, 변 f(쌍 면·원호·상자 변). 일반 fan 부피: B_f(p) = ½ ∫_f (r − p)·n(r) ds.
  - 직선 변이면 ½ A_f h_f(p)이다. 생성점 중심 원호이면 B_f(x_i) = R A_f/2이다.
- W_{i,f} ≡ B_f(x_i)(현재 아영역 부피), Σ_f W_{i,f} = V_i(W=0이면 생성점이 셀 안에 있으므로 모두 양수).
- 중심 c_i = J_i/V_i, J_i = ∫_{C_i} r dV. 기준 부피 B_{i,f} ≡ B_f(c_i), Σ_f B_{i,f} = V_i.
- 아영역 질량 M_{i,f} = m_i B_{i,f}/V_i(Σ_f M_{i,f} = m_i). 아영역 밀도 ρ_{i,f} = M_{i,f}/W_{i,f}. 직선 변에서 ρ_{i,f} = ρ_i h_f(c_i)/h_f(x_i).
- 셀 비엔트로피 s_i(공유). 아영역 압력 P_{i,f} = P(ρ_{i,f}, s_i), 비엔탈피 𝓗_{i,f} = e_{i,f} + P_{i,f}/ρ_{i,f}, 온도 T_{i,f}.

## 2. 퍼텐셜과 힘
  U_i = Σ_f M_{i,f} e(ρ_{i,f}, s_i),   L = Σ½ m_i |v_i|² − Σ_i U_i
- dU_i = Σ_f [ −P_{i,f} dW_{i,f} + 𝓗_{i,f} dM_{i,f} ] + Θ_i ds_i,  Θ_i = Σ_f M_{i,f} T_{i,f}.
- dM_{i,f} = (m_i/V_i) dB_{i,f} − (M_{i,f}/V_i) dV_i. dB에는 면 길이·면 위치·법선·중심 c_i의 변화가 모두 들어간다. dc_i = (dJ_i − c_i dV_i)/V_i.
- 가역 힘: F_a^rev = −Σ_i ∇_a U_i = Σ_{i,f} [ P_{i,f} ∇_a W_{i,f} − 𝓗_{i,f} ∇_a M_{i,f} ].
- **(1판 정정)** 질량 이동 항은 −e dM이 아니라 **+𝓗 dM**이다. Σ_f dM = 0이어도 𝓗가 아영역마다 달라 사라지지 않는다.
- U_i는 i와 Voronoi 이웃 위치에만 의존한다.

## 3. 에너지 장부
- 셀 내부에너지: dU_i/dt = Σ_a (∇_a U_i)·v_a + H_i^Q, Θ_i ds_i/dt = H_i^Q.
- 총에너지: Σ_i dU_i/dt(가역 부분) = −Σ_a F_a^rev·v_a는 항등식이다. 같은 기하 미분을 힘과 장부에 쓰면 반대칭 면 분해 없이 반이산 총에너지가 정확하다. 셀별 장부는 위의 dU_i/dt를 그대로 쓴다. 기존 "dU_i = −P_i dV_i"와 G1 면별 교환식은 이 항에는 적용하지 않는다.
- 소산 Q(TCF): 힘 −AQe, 열 H_i^Q = ½ Σ_f A Q Δu_cell(반씩). 셀별 엔트로피 비음수는 **Q_f Δu_cell ≥ 0(면마다)과 Θ_i > 0**에서 유지된다. T_i^eff = Θ_i/m_i.
- 상자(벽) 변: 고정 벽은 외부 반력과 일을 주므로 폐쇄계 운동량 보존을 요구하지 않는다. 벽 반력·일을 장부에 따로 적는다.
- **셀 상태(1판 정정):** Q·재구성·Riemann에 넘기는 셀 압력은 **P_i^0 = P(ρ_i, s_i)**(이상기체 K_i ρ_i^γ)이다. (γ−1)U_i/V_i로 계산하면 Φ가 열압력으로 새어 바늘 셀에 가짜 압력이 생긴다. 이상기체에서 K_i는 선형으로 역산한다: K_i = (γ−1) U_i / Σ_f M_{i,f} ρ_{i,f}^{γ−1}.

## 4. 성질
- Φ_i ≡ U_i − m_i e(ρ_i, s_i) ≥ 0(e가 비부피에 대해 볼록하면 Jensen). 등호는 x_i = c_i일 때뿐이다(평행하지 않은 변이 둘 이상).
- 작은 이탈 δ_i = x_i − c_i, q_{i,f} = δ_i·n_f/h_f(x_i)에서 Φ_i ≈ ½ ρ_i c_i² Σ_f W_{i,f} q_{i,f}²(이상기체 계수 γP_i/2). 셀 에너지 규모는 P V (δ/h)².
- **Bravais 격자는 균일 전단에서도 Φ ≡ 0이다**(Voronoi 셀이 중심대칭이므로 c_i = x_i). 균일 전단 자체는 Φ 힘을 만들지 않는다. 위험은 무질서 격자와 차등 전단이다.
- 1D: c_i = 셀 중점이므로 M_{i,L} = M_{i,R} = m_i/2(고정), ∂M/∂x = 0이다. 균일 m, s에서는 von Neumann–Richtmyer 엇갈림 격자, Caramana–Shashkov와 같다. Nyquist 강성 4ρc²/Δ, 분산 k(q) = (4ρc²/Δ) sin²(qΔ/2)(Fable 수치 확인). **1D 시험으로는 ∂M/∂x와 위상 연속성을 검증할 수 없다.**
- **위상 변화:** 비퇴화 flip에서 U는 연속(C⁰)이다(소멸 면의 A, M, W = O(A)). 그러나 **C¹이 아니다.** 힘이 유한하게 점프한다(2D 수치에서 국소 힘의 약 5%, x_i = c_i이면 상쇄). 반이산 보존은 유지되지만 RK4 국소 차수가 flip에서 1차로 떨어진다. 생성점 충돌·셀 붕괴·외심 퇴화까지 포함한 전역 유계성은 없고, 장벽은 A, M, h_x의 동시 소멸률로 판단한다.
- **시간 간격:** 최고 진동수 c/Δ → 2c/Δ이다. 시간 간격의 **상한 제약** Δt ≲ min_f h_f(x_i)/c_{i,f}(아영역 음속, 압축되면 커짐)를 더한다. 질량으로 정규화한 퍼텐셜 Hessian의 최대 고유값으로 검증한다(1D에서는 CFL 0.25·min 간격/(c+|Δv|)로 안정, Fable).
- **G2 항등식(정정):** 기존 셀 압력 힘의 균일·선형 압력 정확성은 그대로 시험한다. Φ 힘은 x_i ≠ c_i인 불규칙 격자에서 균일 압력이어도 0이 아니므로 별도로 계측한다. 전체 힘의 기존 항등식은 중심형 격자(x_i = c_i)에서만 성립한다.
- **flip을 가로지르는 RK4 단계:** 상태 오차는 O(Δt)까지 나빠질 수 있다. 그러나 각 단계 우변의 총에너지 합이 0이면 총에너지(선형 불변량)는 유지된다. 비용은 엔트로피 장부 오차로 나타나므로 2D에서 flip률 × 힘 점프 × Δt를 계측한다.

## 5. 변형 (나′) — 비교용
  Φ_i^lin = ½ κ Σ_f M_{i,f} c_i² (B_f(c_i)/B_f(x_i) − 1)²,  κ ∈ (0, 1]  (원호 포함 일반식)
- c_i² = c²(ρ_i, s_i)이므로 상태방정식에 의존한다(2판의 "무관"은 정정).
- Φ^lin을 **셀 내부에너지 안에 두는 경우**: Ũ_i = m_i e(ρ_i, s_i) + Φ_i^lin, Θ̃_i = m_i T_i^0 + ∂_{s_i}Φ_i^lin, Θ̃_i ṡ_i = H_i^Q. 이상기체에서 Ũ_i = K_i G_i(x)이다.
- c²를 엔트로피와 무관한 상수로 영구 고정하고 전체 기하 미분을 포함하면, 이것은 보존적인 **다른 모형**(고정 계수 퍼텐셜)이다. 보존을 깨는 것은 상태에 따라 c²를 갱신하면서 그 미분과 에너지 변화를 빠뜨리는 경우이다.
- 장벽은 M과 h_c가 함께 소멸하는 경우까지 보장되지는 않는다.
- 1D 실험에서 (나)와 (나′)는 모든 지표가 잡음 범위에서 같았다. **기본은 (나)**(매개변수 없음, 장벽이 실제 EOS 압력), (나′)는 `GFS_SUBZONE=2` 비교용이다.

## 6. 충격과의 관계 (사용자 지적: 충격 포착과 얽혀 까다롭다)
- **역할 분담:** 접근을 멈추는 일은 보존 퍼텐셜 Φ가, 접근 운동에너지를 열로 바꾸는 일은 Q가 맡는다. 문턱(예: 평균 간격의 1/5)이나 압축 스위치는 두지 않는다.
- **균일 압축은 Φ = 0**(c_i = x_i)이다. 충격면에 걸친 셀에서는 x_i ≠ c_i라 Φ가 충격 구조에 국소적으로 참여한다.
- **1D 결과(Fable, Q = Z_F δ, Z_F = ρ̄[a + √(a² + c̄²)], a = ¼(γ+1)|δ|로 시험):**
  - Noh(ρ=1, |u|=1, P₀=1e-6, 유입 Mach ≈ 770): 도약 오차 ≤ 1e-4, 평탄부 울림 < 1e-4, 최소 간격 0.65h(선형 Z이면 0.175h, 충돌 없음). 셀 부피 모형은 선형 Z에서 t=0.003에 충돌했다. 충격 폭은 2셀에서 4셀로 넓어졌다. 충격면 셀의 Φ/U_cell은 최대 10–14%이고, 전체 ΣΦ/ΣU는 0.1%이다.
  - Sod(등질량): 충격 뒤 편향 −0.3%, 울림 0.2%(셀 부피 모형 +0.2%, 2.0%), 홀짝 패턴 0.003(셀 부피 모형 0.15).
  - Sod(질량 ∝ 밀도, 2D 붕괴 설정): 최소 간격 0.70h(셀 부피 모형 0.077h).
  - P₀=1e-10(유입 Mach ≈ 7.7e4)과 해상도 N=100/200/400에서도 **시험한 조건에서는** 최소 간격이 0.65h로 같았다.
  - 원·후방에서 Φ가 사라지는지는 2D에서 확인한다.
- **차가운 강한 충격의 정지 간격:** Q가 없는 고립 쌍의 반전 간격은 에너지로 d_min/d_0 ~ M^{−2/(γ−1)}(γ=5/3, M=100에서 약 7e-6)이다(2판의 M^{−2/γ}는 균형 척도로 정정). 실제 충격에서는 압축이 여러 셀에 걸치고 음속이 ρ^{1/3}로 커지며 Q 가열이 따라붙어 위 1D 결과가 된다. P = 0 정확한 영온도에서는 가역 장벽이 없다.
- **Q의 Hugoniot형 임피던스:** 같은 상태(ρ, c)의 대칭 두 충격에서 전체 속도 점프 δ에 대한 정확한 압력 상승은
  p_* − p_0 = ρ (δ/2) [ a′ + √(a′² + c²) ],  a′ = (γ+1)δ/8
  이다(한쪽 충격의 속도 변화 δ/2). 이를 **Hugoniot형 인공점성**으로 쓴다. 비대칭 상태의 정확한 두 충격 해는 아니다.
  δ = minmod(Δu_rec, Δu_cell), Z_H = (ρ̄/2)[a′ + √(a′² + c̄²)], a′ = (γ+1)|δ|/8, Q = max(Z_eff, Z_H)·δ
  - 약한 극한 Q → ρcδ/2는 현 Davis HLLC의 Z_eff = ρ_Lρ_R/(ρ_L+ρ_R)(c_max + Δu_rec)(같은 상태에서 (ρ/2)(c + δ))와 같다.
  - 강한 극한에서 바닥항 Z_H δ → (γ+1)ρδ²/8(vNR 2차 척도)이다. Davis 항은 ρδ²/2(같은 상태, Δu_rec = δ)로 더 크므로, **최종 Q = max(Z_eff, Z_H)δ는 같은 상태 압축에서 Davis 극한을 따른다.** Z_H는 Davis 분기가 실패하거나 작아질 때만 작동한다.
  - Z_H는 solver 분기(압력비·진공·Roe fallback)와 무관하게 보장되는 **바닥**이다.
  - Q·Δu_cell ≥ 0, 0 근처 연속, 문턱 없음.
  - Fable의 Z_F는 Z_H의 약 2배(약한 극한)에서 4배(강한 극한)이다. **1D 결과는 Z_F로 얻은 것**이므로, max(Z_eff, Z_H)와 `QLAW=2`(Q = Z m²/Δu_cell)의 결합은 2D와 1D에서 다시 검증한다(충격 폭, 가열, 시간 간격).
- **울림:** Φ가 저장한 에너지의 되튐은 1D에서 Q가 흡수했다. 2D에서 minmod Q = 0인 면(Hill에서 26–50%)에서는 감쇠가 없으므로 계측한다.
- **엔트로피의 홀짝 패턴:** 충격 뒤 K의 홀짝 패턴은 라그랑주적이라 감쇠 기제가 없다(Noh 벽 근처 밀도 패턴의 원인). 계측 대상이다.

## 7. 시험 계획
**1D(완료, Fable `Docs/subzonal_checks/`):** Hessian(Nyquist 강성 4ρc²/Δ, sin² 분산), Sod(등질량, 질량 ∝ 밀도), Noh(M 770, 1e4), 해상도 계열, F = −∇U 유한차분, dE/dt ≈ 1e-7.
**2D 단위(Python, 구현 전):**
(b) 격자·균일 전단 격자 Φ = 0
(c) 교란 격자 Φ_i > 0, 유한차분 힘 대 해석 힘(∂c/∂x, 꼭짓점 항, 𝓗 dM 항) 1e-6
(d) ΣF = 0, 각운동량(원판), 벽 반력 장부
(e) flip 횡단: U 연속, 힘 점프 유계
(f) 정지 글래스 균일 P: 진동수 ~c/h, 닫힌 장부 Δ ΣU^0 = −ΔKE − ΔΣΦ(누적 Q열과 동일시하지 않음)
(g) 불균일 질량·엔트로피, 원호 미분
**코드 관문(`GFS_SUBZONE=1`, 기본 꺼짐):** G2(위 정정), Sod(2D, 질량 ∝ 밀도), Noh, Sedov, 2D 경사 충격(글래스), Hill 회전 격자(30궤도, 원판 있음·없음), Kepler 진공 고리(Φ/U(t), 가열률, 해상도 수렴, Rankine–Hugoniot).

## 8. 제외: Laguerre(W≠0)
생성점이 셀 밖이면 W_{i,f} < 0이 될 수 있어 양의 질량·밀도와 Jensen 논증이 무너진다. 동적 W의 에너지 조건도 전체 U에 대해 Σ_l ∂U/∂W_l Ẇ_l = 0으로 다시 유도해야 한다. 별도로 설계한다.

## 9. 서명 요청 사항
2판 검토의 정정(정지 간격, (나′) 장부, 글래스 장부, 벽, CFL 상한, G2 비고, Hill/Kepler 관문, Q·Δu_cell ≥ 0)과 1D 실험에 근거한 §6의 역할 분담·Wilkins Z 바닥이 정합한지 확인하고 서명해 달라.


## 10. 추가안(서명 요청): Φ에 켤레인 hourglass 점성 (28차 자문)
동기: 2D Noh(t=0.2)에서 충격 뒤 std ln K가 0.45로 HLLC의 0.20보다 크다. 1D 무질서 Noh에서도 0.060 대 0.035로 재현된다(Fable). 엇갈림 구조에서는 홀짝 K 패턴이 힘에 보이지 않는 영 모드이다. 2D에서 더 커지는 것은 minmod Q=0 면에서 Φ 진동이 감쇠되지 않기 때문으로 추정한다.

- **변형 변수:** ξ_f ≡ ln(B_f(c_i)/W_f) = ln(ρ_f/ρ_i).
- **아핀 불변:** 위상이 바뀌지 않으면 임의 격자의 모든 아핀 운동(병진, 회전, 균일 압축, 균일 전단)에서 ξ̇_f = 0이다. 아핀 사상은 면적비와 중심을 보존하기 때문이다. 따라서 해상된 매끄러운 흐름에는 1차로 작용하지 않고, 비아핀(격자 규모) 운동에만 작용한다.
- **변화율:** ξ̇_f = Σ_a ∇_a ξ_f · v_a. 여기서 ∇ξ_f = ∇B_f/B_f − ∇W_f/W_f이고, 이는 `sub_eval`이 이미 쓰는 dB(중심 연쇄 포함)와 dW(꼭짓점 야코비안)이다.
- **Rayleigh 소산 함수:** R_i = ½ Σ_f Z_f h_f W_f ξ̇_f². Z_f = ρ_f c_f(아영역 임피던스), h_f = h_f(x_i).
- **힘:** F_a^hg = −∂(Σ_i R_i)/∂v_a = −Σ_i Σ_f Z_f h_f W_f ξ̇_f ∇_a ξ_f.
- **열(셀별 정확):** H_i^hg = Σ_f Z_f h_f W_f ξ̇_f² = 2R_i ≥ 0. Σ_a F_a^hg · v_a = −Σ_i H_i^hg이므로 총에너지가 보존된다. 열은 그 모드가 있는 셀에 남는다.
- **성질:** 문턱 없음, 엔트로피 부호 보장(H ≥ 0), 갈릴레이·회전 불변. 계수는 1(임피던스 정규화)이다.
- **2D 구현:** `sub_eval`의 기울기를 Φ용 g 대신 면별 ∇B_f, ∇W_f로 꺼내 ξ̇_f를 셀에서 계산하고, 힘을 Φ와 같은 야코비안 경로로 흩어 쌓는다. 셀 에너지에 H_i^hg를 더한다.
- **질문:** (1) 식과 장부가 맞는가? (2) Z_f h_f W_f의 규모(셀당 ρ c h V)가 적절한가? Q(면 소산)와 중복되지 않는가? (3) 위상 변화에서 ξ가 점프하지는 않는가(소멸 면은 B, W → 0인데 ξ는 유한)? ξ̇의 연속성은? (4) 1D 엔트로피 흩어짐 1.7배는 이것으로 줄지 않는다는 Fable의 판단(엇갈림 구조의 대가)과, P⁰ 대신 면 아영역 압력 ½(P_{i,f} + P_{j,f})을 Q·재구성에 넘기는 완화책의 정합성.

## 11. 유입 경계 Noh (시험 정의, 사용자 승인 2026-10-02)
- 주기 상자 Noh에서는 상자 가장자리가 비어 진공·상자 변 셀이 생긴다. 이를 막기 위해 반경 R_b(기본 0.45) 밖의 입자를 **정확해로 구동**한다.
  - 매 단계 끝에 v = −r̂ |u₀|, ρ = ρ₀(1 + |u₀|t/r)(기하 부피에서 나옴), P = P₀(ρ/ρ₀)^γ(차가운 기체의 단열 압축)로 둔다.
  - ie는 P와 기하 부피(g 포함)에서 다시 계산한다.
- 구동이 넣은 에너지는 `drive_cum`으로 장부에 따로 적는다. 분석은 r < R_b − 0.05에서 한다.
