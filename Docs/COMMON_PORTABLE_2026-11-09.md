# Current common operator: Ada/H200 portability qualification

The qualified Noh/common periodic, reflected and fixed-solid executable was extended to H200 by rebuilding only `exam_gpu.o` and `gfs_unified_gpu.o` with sm_89, sm_90 and compute_90 PTX. All host archive members, libcyl and three existing sm_80/PTX material units are retained. Baseline SHA256: 47ef8b9704c4970a24760461f07d37bd2f4658518d18660c760a6b46f39232ea. Candidate: 11a0234acc882f6f2fc405b0053c2e5210262863be665f88cc5ae91b821ddf4e.

The initial build stopped because its frozen source bundle omitted the standalone unified CUDA source. The dependency-generated completion copies only missing files and asserts equality for every already-frozen local dependency. The failure log remains. A subsequent disassembly check initially rejected changed CUB symbol namespaces caused by adding the architecture list; after explicitly normalizing only `CUB_300001_SM_890_900` to `CUB_300001_SM_890`, the Ada function/instruction streams agree exactly for both objects. This is not a physics-source change. Build, dependency and disassembly evidence is preserved in `common_portable_20261109_v1`.

Six sequential same-Ada gates pass: KH, RT, Sedov, stationary cylinder, Noh endpoint and Noh stages. All 13 saved fields match their existing qualified reference bitwise; fixed masses, positive U/V, endpoint times and volume residual <=1e-11 were also required. Existing cylinder and KH runs were not restarted. These are short portability checks, not whole-test accuracy or speed qualification.

Slurm job 456829 was submitted on syntax with `--partition=h200 --gres=gpu:H200:1`, 2 CPUs, 8 GiB, 15 minutes, no exclusive-node request. All work/output paths are under /gpfs. It runs the same six gates sequentially, checks the actual H200 device and uses allocated CPUs/CUDA visibility. Cross-device field agreement uses rtol=1e-8 and atol=1e-10 with exact masses/IDs and unchanged geometric tolerance; those are numerical comparison gates, not a new physical tolerance. Latest scheduler observation: PENDING, QOSGrpGRES, no restart. H200 execution remains unqualified until the actual logs pass. Job 454560 is an older-method benchmark and remains unchanged; it cannot prove performance of this new operator.

General MPI, 3D and matched-accuracy runtime <=2x GIZMO are not established. The first astronomy-paper draft retains priority over writing the second fluid-mechanics paper.
