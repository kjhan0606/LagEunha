## 확정된 사실 (19차 이후)
1. C 진화 코드는 Python 기준과 같다.
   - 192², 가역 설정, IC부터: 고리 0의 m=18이 C는 t=22/42에 0.0002/0.0012, Python도 0.0002/0.0012.
   - Python을 C의 t=20 상태에서 시작: t=22/24에 0.008/0.013. C는 0.0083/0.0128.
   - Kepler 중심과 eps는 같다((3,3), 0.01).
2. 차이는 소산 경로가 가장자리를 가열해서 생긴다. 192², IC부터 t=20까지 K/K(t=2):

3. 면 덤프(t=10, Q 실행; `/gpfs/kjhan/LagForce/KepQdump_t10_d34515e/tcf.faces`, 열 20=χ 이전 δ, 21=χ):
   - 가장자리 가열은 전부 고리 0–1 사이 면에서 나온다. 고리 0 가열/U = 5.3e-2/시간, 고리 2는 2e-4, 고리 10은 2e-5.
   - 가열의 63%는 δ, 37%는 χ다(χ 중앙값 0.002이지만 δ보다 14배 큰 du_cell에 곱해짐).
   - 고리 0–1 면에서는 |δ| 중앙값이 1.9e-4이고 δ·du>0 비율이 **0.78**이다. 고리 1–2, 2–3, 10–11 면에서는 0.08–0.10이다. minmod가 같은 부호만 통과시키므로 가열이 생긴다.
   - 해석적 Kepler 기울기로 δ를 다시 계산하면 고리 0–1 면에서도 |δ| 0.6e-4, 같은 부호 비율 0.13으로 내부와 같다.
   - C 맞춤 기울기 오차 성분 |δ_C − δ_exact|의 중앙값: 고리 0–1 2.4e-4, 1–2 4.7e-6, 10–11 8e-7. 고리 1 셀의 기울기는 정상(1–2 면)이므로 **오차는 고리 0(진공에 닿은 셀)의 맞춤 기울기 G에 있다.** 이웃이 한쪽에만 있는 맞춤(`exam.c` 4955–5150행, quadratic/cubic, Q2_RANK 껍질 확장)이 Kepler 전단 기울기를 체계적으로 틀리게 낸다.

## 질문
1. 진공 경계 셀의 Q 입력을 어떻게 정의해야 하는가? 아래 후보의 정당성과 위험을 판정하고, 더 나은 안이 있으면 제시하라. 원칙: 증상 패치 금지, 임의 문턱 금지, 에너지 보존 유지, 순수 강체 회전과 순수 전단에서 Q=0, 압축에서 Q>0.
   - (a) 경계 셀은 원호 경계를 포함하는 기울기 정의를 쓴다. 예: 셀 적분 ∮ v n ds에서 원호 부분을 자기 속도(또는 경계 운동학)로 닫는 Green–Gauss 형태.
   - (b) 고리 0–1 면에서는 δ를 내부 셀 j의 기울기만으로 만든다(δ = du + d eᵀG_j e).
   - (c) 진공 경계 셀은 맞춤에서 반대편 껍질 정보가 없으니 QBP를 무효로 처리하고 qin=0(현재 invalid 경로)으로 둔다. 압축 충격이 진공 경계에 닿을 때의 위험을 판정하라.
   - (d) χ의 압축 판정(−tr G)도 같은 기울기를 쓰므로 함께 오염된다. χ를 경계 셀에서 어떻게 정의할지.
2. HG만 켠 실행이 내부까지 균일 가열(고리 10에서 20시간에 7%)하는 것은 별개의 문제로 남는다. 순수 Kepler 전단에서 HG 모드가 0이 아닌 이유를 코드 위치로 판정하라.
3. 가역 모형의 느린 m=18 성장(시간당 약 0.09, 두 코드 공통)에 대한 판단.
