# 선형 속도 재구성과 운동에너지 모멘트: 정적 일관성 관문

2026-10-09. 이전 단계: `staggered_shear_baseline_2026-10-09.md`.

## 1. 판정

**선형 전단을 정확히 재현하는 면 재구성, 고정 셀 질량, 일정 압력, ALE 모멘트
변화율이 한 시점에서 양립함을 확인했다.** 곡률이 있는 전단에서는 이웃 평균의
최소제곱 기울기와 운동에너지를 단순히 결합하는 것만으로 충분하지 않았다.
위치–운동량 모멘트를 보존하는 직교 투영이 더 명확한 상태 표현을 준다.

이번 결과는 정적 재구성과 변화율 검사다. 새 모멘트 모델의 시간 진화, 일반적인
양성 보존, 충격파, 장기 전단 안정성을 검증한 것은 아니다.

## 2. 셀 평균과 생성점의 점별 속도를 구분

질량 m, 질량 중심 c, 평균 속도 vbar=p/m에 대해

`v_rec(x)=vbar+B(x-c)`.

이 표현은 질량 평균 운동량을 보존한다. 일정 밀도의 이번 패치에서는 c가 셀의
기하학적 중심이다. 인접 셀 평균 차이를 **셀 중심 사이의 거리**에 맞춰 최소제곱하면
선형장을 정확히 재현한다. 평균값을 생성점 위치에 놓은 표본으로 취급하면 일반적으로
선형 재현성이 깨진다.

생성점 운동의 정의는 `dot(x_i)=v_rec(x_i)`로 둔다. 별도 조향항은 없다.
이것은 이전 셀 상수 모델의 `dot(x_i)=p_i/m_i`에서, 공간 표현을 선형으로 확장하며
점별 속도를 명시한 변화다. 이번 선형 전단에서 두 속도의 최대 차이는 4²에서
.037683, 8²에서 .017533이었다. 재구성한 점별 속도와 정확한 점별 속도는 1.12e-15
이내로 일치한다.

**여기서 고정질량은 적분 셀 질량 m_i를 뜻한다.** 점입자 운동량 `m_i dot(x_i)`와
셀 적분 운동량 p_i를 동일시하지 않는다. 그 동일성까지 추가로 요구하면 별도의
정식화가 필요하다. 비균일장에 셀 평균 속도와 점별 속도의 동일성을 가정하지 않았다.

## 3. 운동에너지 분해와 직교 투영

위치–속도 중심 모멘트를 다음과 같이 정의한다.

- `S = integral rho (x-c)(x-c)^T dV`
- `C = integral rho (x-c)(v-vbar)^T dV`
- `T = integral rho (v-vbar)(v-vbar)^T dV`

S가 양의 정부호이면 질량 가중 L2 직교 투영은

`B = C^T S^(-1)`, `R = T - B S B^T`.

실제로 표현 가능한 속도 분포에서 R은 잔차 속도의 공분산 적분이므로 양의 준정부호다.
블록 모멘트 행렬 [[S,C],[C^T,T]]의 Schur complement로도 같은 조건을 얻는다.
이 행렬의 양성만으로 임의의 모멘트가 해당 셀 내부의 양의 밀도 분포로 표현 가능하다는
충분조건을 얻은 것은 아니다.

운동에너지를

`K = |p|²/(2m) + trace(B S B^T)/2 + trace(R)/2`

로 두고, `U=E-K`, `P=(gamma-1) U/A`로 열역학 상태를 계산한다.
첫째 항은 평균 운동, 둘째는 선형장 내부 운동, 셋째는 선형장으로 해상하지 못한
운동이다. 이 셋을 처음부터 구분하면 내부 운동을 압력으로 잘못 더하지 않는다.
직교 투영은 `S B^T=C`도 유지하므로 내부 각운동량 `C_xy-C_yx`를 보존한다.

### 이웃 최소제곱 기울기를 임의로 넣을 때의 교차항

일반적인 기울기 G에 대해서 `T-GSG^T`를 실제 잔차 공분산이라고 부르면 안 된다.

`C_res=C-SG^T`,
`R_actual=T-GC-C^T G^T+GSG^T`,
`T=GSG^T+G C_res+C_res^T G^T+R_actual`.

R_actual은 실제 잔차 공분산이며 양성이다. 교차항은 부호가 정해져 있지 않다.
따라서 `T-GSG^T`의 음수는 최소제곱 재구성이 무조건 불가능하다는 증거가 아니라,
**교차항을 버리고 양의 에너지만 더하는 분해가 성립하지 않는다는 증거**다.

## 5. ALE 모멘트 변화율까지 검증

원시 적분량 `m,q,Q,p,D,Pi,E`를 정의한다.

`q=integral rho x`, `Q=integral rho xx^T`,
`D=integral rho x v^T`, `Pi=integral rho vv^T`.

위 S,C,T와의 관계는 `S=Q-qq^T/m`, `C=D-qp^T/m`, `T=Pi-pp^T/m`이다.
행렬의 대칭 성분을 중복 저장한 이번 검사 배열은 18개 수를 사용한다.

면 법선 n, 면 법선 속도 s에 대해 공유 ALE 유량을 Fm,Fp,FE라 쓰면,
Reynolds 수송 정리와 매끄러운 Euler 식에서 다음을 얻는다.

- `m_dot = -integral_boundary Fm`
- `q_dot = -integral_boundary x Fm + p`
- `Q_dot = -integral_boundary xx^T Fm + D+D^T`
- `p_dot = -integral_boundary Fp`
- `D_dot = -integral_boundary x Fp^T + Pi + integral_cell P I`
- `Pi_dot = -integral_boundary [vv^T Fm + P(vn^T+nv^T)]
             + integral_cell P(grad(v)+grad(v)^T)`
- `E_dot = -integral_boundary FE`

위 식을 이번 선형장에 직접 적용했다. Pi 식은 매끄러운 Euler 장의 항등식이며,
충격파나 불연속 수치 상태에서 소산·열화를 처리하는 일반적인 모멘트 수치 유량을
완성했다는 뜻은 아니다.

독립 검사에서는 x±epsilon dot(x), w±epsilon dot(w)의 셀을 다시 구성하고,
동일한 정상 연속장의 모든 모멘트를 적분하여 중앙차분했다. 최대 성분 오차:

| epsilon | 4² | 8² |
|---:|---:|---:|
| 1e-4 | 3.22e-9 | 3.38e-9 |
| 1e-5 | 3.19e-11 | 3.03e-11 |
| 1e-6 | 1.22e-10 | 3.90e-10 |

첫 구간에서 약 100배 줄었고, 더 작은 차분에서는 반올림 오차가 커졌다.
이 패치의 총운동량·에너지·각운동량 변화율도 약 1e-15 수준이었다.
이는 경계 유량과 정상 해가 상쇄한 결과이며, 임의의 열린 경계에서 총량이 항상
일정하다는 주장은 아니다.

## 6. 사인 전단장에서 단순 에너지 분해의 한계

앞선 주기 불규칙 배치에서 `v=(.5 sin(2 pi y),0)`, rho=1, P=.6의 정확한 셀 모멘트를
적분했다. 이웃 평균의 최소제곱 기울기와 각 셀의 C,S로 얻은 직교 투영을 비교했다.
후자의 C,T는 이번 정적 기준장에서 얻은 것으로, 기존 저차 코드가 이미 갖고 있는
변수에서 자동으로 복원한 값이 아니다.

| 격자 | T-GSG^T가 음의 고유값을 갖는 셀 | 최소 고유값 | 잘못된 단순 분해의 최대 냉각 압력 문턱 |
|---:|---:|---:|---:|
| 4² | 0/16 | 0 | 0 |
| 8² | 7/64 | -7.97e-6 | 1.62e-4 |
| 16² | 50/256 | -5.18e-7 | 4.29e-5 |

음의 셀 수는 고유값<-1e-14로 판정했다. 마지막 열은
`(gamma-1) max(trace(GSG^T-T)/2,0)/A`의 최대값이다.
그 셀에서 초기 P가 이 값보다 작을 때, 동일한 속도장·총에너지에서 교차항과 잔여분을
버리고 기울기 운동에너지만 빼면 열에너지가 음수가 된다. P=.6의 이번 검사에서
실제 음의 압력이 생겼다는 뜻은 아니다.

실제 최소제곱 잔차 공분산 R_actual은 양성이었으며 교차항을 포함한 항등식은
최대 4.34e-19의 오차로 성립했다. 최소제곱법 전체를 기각할 근거는 아니다.
다만 교차항을 버린 에너지 장부는 일관되지 않는다.

직교 투영 B=C^T S^(-1)에서는 잔여 공분산 R이 모든 사례에서 양성이었고,
압력 오차는 2.23e-16 미만, 내부 각운동량 재현 오차는 1.09e-19 미만이었다.

## 7. 다음 구현 관문

다음은 **모멘트를 실제 진화 변수로 둔 작은 시간 진화 패치**다. 일반 전단 계산으로
확대하기 전에 다음을 구체화해야 한다.

1. m,p,E에 더해 q,Q,D,Pi를 일관되게 수송하고, 열에너지는
   `U=E-trace(Pi)/2`로 구한다. 기울기는 수송한 C,S의 직교 투영으로 정한다.
2. 현재 셀 안에서 질량·위치 모멘트를 재현하는 밀도 표현을 정한다.
   진화한 q,Q를 유지하면서 밀도를 무조건 셀 상수로 놓으면, 일반적으로 기하 중심과
   질량 중심이 달라져 모순이 생긴다. 양의 모멘트 행렬만으로 이 문제가 해결되지 않는다.
3. 면의 운동량·에너지 유량과 Pi 유량을 함께 정의한다. 잔여 공분산의 수송과
   충격파 소산을 열에 어떻게 반영할지도 필요하다. 저장한 R을 근거 없이 열로
   재분류하거나 음의 U를 floor로 숨기지 않는다.
4. 먼저 매끄러운 선형 전단의 짧은 시간 진화에서 질량·운동량·에너지·내부 각운동량,
   일정 압력, 모멘트의 실현 가능성을 검사한다. 이후 주기 사인 전단을 비교한다.

현재 결과는 이 방향의 정적 일관성을 지지하지만, 완성된 고차 유체 해법이나
장기 Kepler 안정성을 입증하지 않는다.
