# 설계 결정 요청 (Astra, 6차): 후보 (a) 기각 이후

작성: 2026-10-03. 직전: `Docs/audit_impl5_astra.md`. 결과: `Docs/design_astra_audit.md` 마지막 절.

## 사실
- (a) 아핀 발산 bulk + HG(Q=0)는 관문 1을 통과했으나, 2D 쌍 접근 Mach 10에서 0.062h(HG만 0.060h)이고 Sod에서 쌍 붙음(0.035h, dt 24배 붕괴)이 나서 실패했다.
- 쌍 붙음을 막은 것은 지금까지 면 상태 Z(ρ_if = m_i/d 발산)의 면별 Q뿐이다. 같은 Q가 Gresho를 −12%까지 감속시킨다.

## 운전자 제안 (검토 요청)
(b') **면별 비아핀 잔차 Q.** 면 법선 속도 점프에서 아핀 예측을 뺀 잔차를 쓴다.
  δ_f = (v_i − v_j)·e − e·Ḡ_f d_f, Ḡ_f = (G_i + G_j)/2 (같은 2-hop QR 연산자).
  δ_f는 v에 선형인 연산자 δ_f = ℓ_f·v이다. Q 힘은 F = −Σ_f C_f δ_f ℓ_fᵀ, 열은 C_f δ_f²이다(HG와 같은 구조, 분리 적분 가능).
  C_f = A_f Z_f(면 상태 임피던스, ρ_if 발산 유지)로 둔다. 압축만 적용할지(δ_f < 0, 단방향 모드)는 결정을 요청한다.
  - 선형 장(전단·회전·균일 압축 포함)에서 δ_f = 0이므로 Gresho의 선형 부분에서는 소산하지 않는다. 쌍 접근은 아핀 적합으로 설명되지 않으므로 δ_f에 남는다.
  - 다만 충격 자체(아핀 압축)는 이 항이 보지 못한다. 충격 엔트로피는 (a) bulk가 맡는 결합 (a) + (b')를 제안한다. HG는 유지하거나 (b')로 대체한다.
  - 위험: 충격면에서는 아핀 적합이 불연속을 가로지르므로 δ_f가 크다. 이는 오히려 바람직할 수 있으나 검토가 필요하다.
질문:
1. (b')의 정합성(에너지·엔트로피·운동량), 단방향 여부, HG와의 중복·대체 관계.
2. Z_f 정의: 면 상태 Z 그대로인가, δ_f에 맞춘 다른 형태인가.
3. 대안이 더 나으면 지시하라.
4. 시험 순서(2D 기준 코드 쌍 시험 → C 구현 → Sod → Gresho).
읽기 전용, 한국어, 결론 먼저.
