# 압력 충격량과 일의 보존적 갱신: 정적 관문

## 1. 결과

양의 수송 다음에 사용할 **기하를 고정한 압력 부분 단계**를 구현했다.
정적 검사 5개 통과. 압력 힘·운동에너지 변화·내부에너지·경계 교환의 수지를
같은 이산 갱신으로 계산하며, 양의 분포와 유한 잔여 공분산을 보관한다.

그러나 이 압력 단계와 기존 독립 조각 이동을 단순히 연결할 수는 없다.
압력 갱신 후 같은 면에서 양쪽의 법선 속도가 달라지는 경우를 직접 확인했다.
**공유 면의 기하와 수송을 결합하는 것이 다음 우선순위**이다.
완성된 유체 해법, 일반적인 양성·엔트로피 보장, 시간 정확도는 아직 주장하지 않는다.

## 2. 상태와 압력 힘

셀마다 양의 적분점 질량 m_k, 위치 x_k, 속도 v_k, 내부에너지 U_k를 저장한다.
이번 부분 단계에서는 위치·기하·적분점 질량을 고정한다.
질량 중심 c, 질량 m, 위치 공분산 S로 선형 속도 공간을 구성한다.

셀 압력 적분 `PV = (gamma-1) sum U_k`와 공유 면 압력 P*를 사용한다.
기본 면 압력은 양쪽 셀 평균 압력의 산술 평균이며, 압력은 이 단계 동안 고정한다.
제조해 검사에서만 정확한 선형 면 압력을 별도 입력한다.

```
F = -sum_faces integral P* n ds
H = PV I - sum_faces integral (x-c) (P* n)^T ds
A = H^T S^{-1}
delta_v(x) = dt [F/m + A(x-c)]
```

이것은 선형 시험함수에 대한 압력 힘의 약형을 양의 질량 분포로 올리는 갱신이다.
`PV I` 항은 부분적분에서 나오며, 빠뜨리면 균일 압력에서도 가짜 선형 가속이 생긴다.
공유 면의 충격량과 1차 모멘트는 양쪽에서 반대 부호로 들어간다.
따라서 운동량과 각운동량의 내부 교환은 상쇄되고 외부 경계 교환만 남는다.

## 3. 압력 일과 에너지

운동에너지 변화는 갱신 전후 속도의 중간값으로 정확히 계산한다.

```
delta_K = sum_k m_k (v_old + delta_v/2) dot delta_v
v_face = (v_mid,left(x_face) + v_mid,right(x_face))/2
delta_E_i = -dt sum_faces integral P* v_face dot n_i ds
U_new,i = U_old,i + delta_E_i - delta_K_i
```

공유 면의 에너지 교환도 양쪽에서 상쇄된다. 외부 경계는 정지 벽의 일 0 또는
중간 속도 trace를 사용하고, 운동량·각운동량·에너지 교환을 별도 장부에 기록한다.

셀 내부의 양의 U_k 분포는 `U_new,i/U_old,i`를 곱해 유지한다.
이는 이번 대수 관문의 배분 규칙이다. 일반적인 국소 열역학 정확도나 엔트로피 조건을
증명한 규칙은 아니다. `U_new<=0`이면 입력 상태를 바꾸지 않고 스텝을 거부한다.
압력 floor나 내부에너지 절단은 없다. 자동 재시도·시간 간격 제어는 아직 없다.

선형 속도만 더하므로 질량 가중 선형 투영에서 남는 속도 잔차는 그대로이다.
유한 R을 열로 전환하거나 지우지 않는다. 에너지 보존은 이 사실과 별도로 검사한다.

## 4. 완료한 검사

불규칙 2×2 Laguerre 셀의 작은 정적 검사 5개:

1. 균일 압력·선형 전단: 속도와 내부에너지가 유지된다.
2. 선형 압력 제조해: `delta_v=-dt grad(P)/rho`와 일치한다.
   이 경우에만 면 압력에 해석적 값을 입력한다.
3. 균일 압력·선형 압축: `delta_U=-dt P div(v) V`와 일치한다.
4. 정지 벽·비균일 압력·비선형 표본 속도: 경계 장부를 포함한 보존량 수지,
   유한 잔여 공분산 유지, 입력 상태 불변을 확인한다.
5. 과도한 팽창 스텝: 음의 내부에너지가 예상되면 거부하고 입력을 보존한다.

5개 모두 통과. 테스트의 보존량 오차 조건은 2e-15 이하,
유한 R 변화 조건은 2e-17 이하이다. 임의의 큰 dt에 대한 양성은 주장하지 않는다.
스냅샷의 검사 계산부는 0.043초였다. 로그인 노드에서 스레드 1·nice 19·timeout 30초로
작은 대수 검사를 수행했다. 이 모듈의 시간 진화 계산은 실행하지 않았다.

## 5. 새로 확인한 결합 문제

초기 속도 0, 압력 `P=.6+.2 x`의 적분 상태에 기본 셀 평균 면 압력 규칙을 적용했다.
압력 부분 단계 후 내부 면 중앙의 양쪽 법선 속도 차이를 측정했다.

| 압력 단계 dt | 최대 법선 속도 차 | 독립 이동 시 간격 추정 dt×차 |
|---|---|---|
| .01 | 2.46520e-4 | 2.46520e-6 |
| .005 | 1.23260e-4 | 6.16299e-7 |

같은 검사에서 보존량 수지 오차는 각각 2.22e-16, 4.83e-19였다.
즉 **보존량 수지 통과와 공간을 빈틈없이 나누는 이동은 별개의 조건**이다.
표의 간격은 속도 차에서 계산한 1차 이동 추정이며, 실제 결합 시간 진화를 수행한
측정값은 아니다. 이 사례에서는 압력 갱신이 dt에 비례하므로 추정 간격은 dt²로 줄었다.

원래 수송 관문은 모든 조각이 공통 선형 속도를 가져 영역 분할을 유지했다.
압력 갱신을 셀별로 붙이면 이 가정이 깨진다. 틈·중복을 질량 재정규화나 볼록껍질
채우기로 감추지 않는다. 이 관측은 이번 조합의 한계이며 모든 압력 이산화의 불가능성을
뜻하지 않는다.
