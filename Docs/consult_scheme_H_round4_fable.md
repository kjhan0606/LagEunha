## (5a) 매끄럽고 증명 가능한 하계 `h_i ≤ min_j d_ij`

**Astra의 반례 인정.** `h = (Σ_j φ(d_ij/R_c) d_ij^{-p})^{-1/p}`에서 최근접 이웃이 `0 < φ < 1`인 구간에 있고 다른 항이 없으면 `h = d_nn φ^{-1/p} > d_nn`이다. 합이 0이면 정의되지 않는다. "φ ≈ 1"은 증명을 대신하지 못한다. 인정한다.

**수정된 구성.** 상수 `0 < R_1 < R_c`와 C¹ 절단 함수 φ를 다음과 같이 둔다: `φ(s) = 1 (0 ≤ s ≤ R_1/R_c)`, `R_1/R_c < s < 1`에서 단조 감소 C¹, `φ(1) = 0, φ′(1) = 0`(예: 3차 Hermite). 정의:

```text
h_i = ( R_1^{-p} + Σ_{j: d_ij < R_c} φ(d_ij/R_c) d_ij^{-p} )^{-1/p},   p ≥ 1.
```

합은 주기 최소 영상 거리로 R_c 안의 모든 생성점(주기 영상 포함)에 대해 취한다(`R_c < L/2`).

**정리 1 (하계).** 모든 i와 모든 j ≠ i(주기 영상 포함)에 대해 `h_i ≤ d_ij`. 특히 `h_i ≤ min_j d_ij`.

*증명.* `d* = min_j d_ij`, 최근접 이웃 j*. (i) `d* ≤ R_1`이면 j*는 합에 들어 있고 `φ(d*/R_c) = 1`이므로 `Σ ≥ d*^{-p}`, 따라서 `h_i ≤ (d*^{-p})^{-1/p} = d*`. (ii) `d* > R_1`이면 `Σ ≥ 0`이고 상수항으로 `h_i ≤ (R_1^{-p})^{-1/p} = R_1 < d*`. 두 경우 모두 `h_i ≤ d* ≤ d_ij`. ∎

**정리 2 (매끄러움).** 생성점이 서로 다르면(`d_ij > 0`) h_i는 모든 생성점 위치의 C¹ 함수이고, 이웃이 R_c를 드나들 때 h_i와 ḣ_i가 연속이다. φ가 C^k면 h_i도 C^k.

*증명.* 각 항 `φ(d/R_c) d^{-p}`는 `d > 0`에서 C¹이고, `d → R_c⁻`에서 값 0(φ(1)=0), 도함수 `φ′(1)d^{-p}/R_c − pφ(1)d^{-p-1} = 0`이므로 항이 0 값·0 기울기로 들어오고 나간다. 합 S는 C¹이며 `S ≥ R_1^{-p} > 0`이므로 `S^{-1/p}`는 그 영역에서 C^∞. ∎ 시간 도함수는 닫힌 형태다:
`ḣ_i = h_i^{p+1} Σ_j [ φ(d_ij/R_c) d_ij^{-p-1} − φ′(d_ij/R_c) d_ij^{-p}/(p R_c) ] ḋ_ij`.

**얼마나 빡빡한가.** R_c 안의 이웃 수를 n_c라 하면 `h_i ≥ d* (n_c + 1)^{-1/p}` (모든 항이 `d*^{-p}` 이하이므로). p = 8, n_c = 6이면 `h_i ≥ 0.78 d*`; 고립 입자(이웃 없음)면 `h_i = min` 꼴로 `R_1`에 부드럽게 포화한다. 즉 ω 매개화가 잃는 W 규모는 최대 인자 `(n_c+1)^{2/p}` ≈ 1.6(p=8)이다.

**R_1의 선택.** 증명은 임의의 양의 R_1에 대해 성립한다. R_1이 너무 작으면 `h_i ≤ R_1`이 W를 `R_1²/2`로 추가 제한하므로(5b의 과잉 제한을 키움) `R_1 ≈ d̄`(평균 간격), `R_c ≈ 2–3 d̄`가 자연스럽다. R_1을 입자별 C¹ 국소 척도 `R_{1,i}(x)`로 두어도 정리 1·2는 그대로 성립한다(평탄 구간이 `[0, R_{1,i}]`이고 `R_{c,i} ≥ R_{1,i}`이기만 하면 됨).

**대안(동치 구조).** log-sum-exp 형 `h_i = −β^{-1} ln( e^{−βR_1} + Σ_j φ e^{−β d_ij} )`도 같은 두 경우 증명으로 `h_i ≤ min(R_1, d*)`를 준다. 다만 β가 절대 길이 척도를 가지므로 상대 오차가 척도에 의존한다. 거듭제곱 합은 척도 불변(상대 오차 `(n_c+1)^{-1/p}`)이므로 이쪽을 권한다.

**결론.** Astra가 요구한 "최근접 이웃이 φ = 1 평탄 구간에 반드시 들어온다는 인증"은 일반적으로 불가능하지만(고립 입자), **상수항 `R_1^{-p}`가 그 인증을 대신한다**: 최근접 이웃이 평탄 구간 밖이면 하계는 R_1로 자동 전환된다. 이것으로 §3.3(1라운드)의 유효성 정리가 매끄러운 h에 대해 복구된다.

## (6b) 압력에 눈먼 W 법칙과 부호: 정확한 특성화

**Astra의 반례 인정.** 3-셀 선 그래프, `g = (P_1−P_2, P_2−P_3)`, `δ = Mg`, `M = [[1,2],[2,4]]`: 모든 P에 대해 `gᵀMg = (g_1+2g_2)² ≥ 0`이지만 `P = (2,1,2)`에서 `δ_1 g_1 < 0`이고 선 그래프에는 순환 흐름이 없다. 따라서 나의 "모든 P에 안전한 일반형은 `δ_f = Γ_f g_f + δ⁰_f`, `Γ_f ≥ 0`, `div δ⁰ = 0`"은 **틀렸다**. 철회한다.

**기호.** B: 면–셀 접속 행렬(E×N, 면 f=(i,j)에 +1/−1), `g = BP`(면 압력차), `A = diag(A_f)`, `Λ = diag(1/2d_f)`, `δ = Λ B Ẇ`, `K = ½L_{A/d} = Bᵀ A Λ B`(대칭 반정부호, 연결 그래프에서 핵 = span(1)). W-일: `D_W = Σ_f A_f g_f δ_f = gᵀAδ = Pᵀ Bᵀ A δ = Pᵀ q`, `q ≡ BᵀAδ = KẆ` = W가 만드는 셀 부피율.

### (i) 총 W-일에 대한 명제

**명제 1 (P에 눈먼 법칙; 증명됨, Astra 동의).** Ẇ(따라서 q)가 P에 의존하지 않을 때, `D_W(P) = P·q ≥ 0`이 모든 `P ∈ ℝ^N_{>0}`에서 성립 ⇔ `q = 0` ⇔ `Ẇ ∈ span(1)`(연결 그래프) ⇔ W가 어떤 셀 부피도 바꾸지 않는다. (`q_i ≥ 0 ∀i`는 P를 셀 i에 집중시켜 얻고, `Σ q_i = 1ᵀBᵀAδ = 0`이므로 `q = 0`.)

**명제 2 (일반 법칙의 정확한 조건).** Ẇ = Ẇ(P)일 때 주어진 P에서 총 W-일이 비음이 되는 필요충분조건은 단순히
```text
P · q(P) ≥ 0,    q(P) = K Ẇ(P).
```
"모든 P > 0에 대해"를 요구하면 `P·KẆ(P) ≥ 0 ∀P > 0`이다. 이것이 총합 조건의 전부이며 더 간단한 면별 형태로 환원되지 않는다.

**명제 3 (선형·평행이동 불변 계열의 정확한 특성화).** `Ẇ = G P`, 곧 `δ = M g`(M: E×E, `M = ΛBG`의 꼴)라 하자. `D_W = gᵀ A M g`이고, P > 0 전체에서 g는 절단 공간 `𝒞 = range(B)`(차원 N−1) 전체를 훑는다(상수 이동은 g를 바꾸지 않으므로). 따라서
```text
D_W ≥ 0 ∀P > 0  ⇔  sym(AM) = ½(AM + MᵀA) 가 𝒞 위에서 반정부호.
```
- 충분조건 1(대각 양의 이동도): `M = diag(Γ_f)`, `Γ_f ≥ 0` ⇒ `D_W = Σ A_f Γ_f g_f² ≥ 0`. Astra의 표현대로 충분조건 중 하나이며 필요하지 않다(반례의 M은 비대각 PSD).
- 충분조건 2: `AM`의 대칭부가 ℝ^E 전체에서 PSD.
- 게이지: `AM g`에 `A δ⁰`(`Bᵀ A δ⁰ = 0`, 곧 A-가중 순환 흐름)를 더해도 `D_W`는 불변. 이것은 D_W에 기여하지 않는 성분의 서술이지 안전한 법칙의 "일반형"이 아니다.

**명제 4 (음향 근사 목표).** `δ_f = (u* − ũ)_f ≈ g_f/(Z_i + Z_j)`는 충분조건 1(`Γ_f = 1/(Z_i+Z_j) > 0`)에 속한다. (H)의 회전 상쇄·τ_V·τ_C·장벽 성분은 P에 눈멀고 `q ≠ 0`이므로 명제 1의 대상이다: 어떤 양의 압력장에서는 총 W-일이 음이다.

### (ii) 셀별 σ_i ≥ 0에 대한 명제 (총합 조건과 분리)

`D_f = A_f[g_f δ_f + (P* − P̃)_f(u_i − u_j)] ≡ D_f^W + D_f^G`, `σ_i = Σ_{f∋i} θ_f^i D_f`, `θ ∈ [0,1]`, `θ_f^i + θ_f^j = 1`.

**명제 5.** (a) `D_f ≥ 0 ∀f` ⇒ 임의의 분배에서 `σ_i ≥ 0 ∀i`. (b) 어떤 f에서 `D_f < 0`이면 그 면의 두 몫을 모두 비음으로 할 수 없다(`σ_i^f + σ_j^f = D_f < 0`). 그래도 셀의 다른 면이 보상하면 `σ_i ≥ 0`일 수 있다 — 분배 θ에 의존한다. (c) 총합 `D_W ≥ 0`(명제 2·3)은 셀별 부호에 대해 아무것도 함의하지 않는다. (d) 충분조건 1(면별 `Γ_f ≥ 0`)만이 **면별 `D_f^W ≥ 0`, 따라서 셀별 W-몫 ≥ 0**을 준다; 1차 Lax 상태에서 `D_f^G = G_f ≥ 0`과 합치면 `σ_i ≥ 0`.

**명제 6 (P에 눈먼 법칙의 셀별 결과).** `q ≠ 0`이면 명제 1에 의해 `D_W(P) < 0`인 P > 0이 존재하고, 그 P에서 `Σ_i σ_i^W = D_W < 0`이므로 어떤 분배에서도 `σ_i^W < 0`인 셀이 있다. 그 셀의 전체 부호는 `σ_i = σ_i^W + σ_i^G ≥ 0 ⇔ σ_i^W ≥ −σ_i^G`. 즉 **Godunov 소산이 큰 곳(충격파)에서는 P에 눈먼 부피 보정도 셀별로 안전할 수 있고, `σ_i^G ≈ 0`인 매끄러운 차가운 흐름(케플러 원반)에서는 안전하지 않다.** Astra의 "다른 Godunov 소산의 상쇄 가능성"이 정확히 이 항이다.

**최종 명제 (6b).** 총 W-일의 정확한 조건은 `P·q(P) ≥ 0`; 선형 계열에서는 `sym(AM)|_𝒞 ⪰ 0`; 대각 양의 이동도는 총합과 셀별 W-몫을 동시에 보장하는 충분조건; P에 눈먼 부피 변경 법칙은 총합에서 반드시 어떤 P에 음이고 셀별로는 `σ_i^G`가 보상하는 곳에서만 안전하다.

## (6c) POCS가 보장하는 것과 보장하지 않는 것

Astra의 여섯 지적을 항목별로 받아들이고 정확히 적는다.

**설정.** RK 단계 상태(기하, P, P*, u, u*, 재구성값)를 고정. 미지수 `Ẇ ∈ ℝ^N`. 면 제약 `C_f = {Ẇ : A_f[g_f(Ẇ_i − Ẇ_j)/(2d_f) + G′_f] ≥ 0}`, `G′_f = (P* − P̃)_f(u_i − u_j)`: 닫힌 반공간(`g_f ≠ 0`), 또는 `g_f = 0`이면 Ẇ와 무관하게 `G′_f ≥ 0`이거나 즉시 실현 불가. 셀 제약 `S_i = {Ẇ : Σ_{f∋i} θ_f^i D_f(Ẇ) ≥ 0}`: `deg(i)+1`개 변수의 닫힌 반공간. `C = ∩_f C_f`(또는 `∩_i S_i`).

1. **수렴.** 인정. `C ≠ ∅`이면 최소제곱 해 Ẇ⁰에서 시작한 순환 사영은 C의 어떤 점 Ẇ*로 수렴한다(유한 개 닫힌 볼록집합의 POCS; 반공간이므로 선형 수렴, 비율은 반공간들 사이의 각/Hoffman 상수에 의존). 일반적으로 `Ẇ* ≠ Π_C(Ẇ⁰)`; 최근접점을 원하면 Dykstra. `C = ∅`이면 반복은 극한 순환에 접근하며 수렴하지 않는다.
2. **유한 k 인증 없음.** 인정. k회 순회 뒤에도 일부 제약이 위반될 수 있고, "위반량이 줄지 않음"은 불가능성 증명이 아니다. 불가능성 인증은 Farkas 계수(제약의 비음 결합이 `0 ≥ 양수`를 줌)이며 LP로만 얻는다. 따라서 단계 끝에 제약을 정확히 만족시켜야 하면 허용오차까지 반복한 뒤 잔여 위반에 대한 **후퇴 규칙**(K 변수 클리핑 + 에너지 감사, 또는 dt 축소)이 반드시 필요하다.
3. **부피 추종 파괴.** 인정. `KẆ* = b + r`, `r = K(Ẇ* − Ẇ⁰)`; r은 `V^T − V`로 들어가 τ_C가 처리하는 부피 표류다. 크기는 `‖K‖·‖Ẇ* − Ẇ⁰‖`로 유계.
4. **반이산 총에너지.** 인정하되 정확히: (H)의 힘 `f = −A[P* n + (P_j − P_i)t/d]`는 Ẇ에 의존하지 않는다. Ẇ는 `w_f = ũ + ρ + δ`와 `D_f`의 δ에만 들어가며, 한 면의 총에너지율 합에서 δ 항은 `−(P_i − P_j)Aδ + A(P_i − P_j)δ = 0`으로 **면별로 정확히 상쇄**된다(나머지 `−A(P_i u_i − P_j u_j)`는 셀별 `Σ_f A_f n_f = 0`으로 상쇄). 따라서 **사영된 Ẇ*로 δ를 w_f와 D_f 양쪽에 일관되게 다시 계산하면** 어떤 Ẇ*에서도 각 단계의 `Σ_i Ė_i = 0`이 정확히 성립한다. 재계산하지 않으면 깨진다.
5. **RK4 단계 보존.** 인정하되 구분: 셀 총에너지 `E_i`를 상태로 적분하면 `Σ_i E_i`는 상태의 선형 함수이고 각 단계에서 `Σ_i k_i = 0`이므로 RK4 한 스텝에서도 반올림 정밀도로 보존된다(프로토타입의 기계 정밀도 dE가 이것). 엔트로피 변수 K를 상태로 쓰면 반이산 보존만 성립한다.
6. **비용.** 인정. 한 순회 `O(E)`, 전체 `O(kE)`, k의 선험적 상한 없음; QP 대비 우위는 측정 전까지 주장하지 않는다.
7. **셀별 제약.** 인정. `S_i`는 `deg(i)+1`개 변수에 걸친 반공간이므로 "면당 2변수"가 아니다. 다만 단일 반공간 `{aᵀẆ ≥ c}`의 사영은 여전히 닫힌 형태 `Ẇ ← Ẇ + (c − aᵀẆ)_+ a/‖a‖²`이고 비용 `O(deg(i))`다.

**최종 명제 (6c).** 고정된 단계 상태에서 `C ≠ ∅`이면 순환 사영은 C의 한 점으로(선형 속도로) 수렴하고, `C = ∅`이면 수렴하지 않으며 유한 반복은 실현 가능성도 불가능성도 인증하지 않는다. 사영은 부피 목표 `KẆ = b`를 일반적으로 깨고 그 잔차는 `V^T − V`로 이월된다. Ẇ-의존 항이 면별로 상쇄되므로 δ를 일관되게 재계산하면 반이산 총에너지는 어떤 Ẇ*에서도 정확하고, E_i를 상태로 쓰면 RK4 스텝에서도 정확하다(K 변수면 반이산만). 비용은 `O(kE)`, k 무상한. 셀별 제약은 `deg(i)+1` 변수 반공간이며 사영은 닫힌 형태다. **따라서 POCS는 "실현 가능할 때 싼 실현 도구"이지 보장·보존·정확도를 자동으로 주는 해법이 아니다.** `g_f = 0`이고 `G′_f < 0`인 면(MUSCL·Lax 위반)은 Ẇ로 고칠 수 없으므로 1차 후퇴가 선행돼야 한다.

## (8) `V_i`의 C¹성: 정확한 진술과 예외의 이름

**Astra의 지적 인정.** 보통의 4점 공원 Delaunay 전환은 면이 길이 0을 지나 생기고 사라지는 사건이므로 C¹ 예외가 아니다. 나의 "4점 공원 제외"는 틀렸다. "2계 도함수 점프가 노이즈 시간척도를 만든다"는 증명되지 않았다 — 인정하고 아래에서 가설로 분리한다.

**설정.** 주기 상자, 생성점 `x_1..x_N`, 가중치 W. Voronoi는 W ≡ 0. 면 공식 `∂V_i/∂x_j = −A_ij(c_ij − x_j)/d_ij (j≠i)`, `∂V_i/∂x_i = Σ_j A_ij(c_ij − x_i)/d_ij`, `∂V_i/∂W_j = −A_ij/(2d_ij)`, `∂V_i/∂W_i = Σ_j A_ij/(2d_ij)`.

**정리 3 (연속성과 C¹).** 생성점이 서로 다르면(`d_min = min_{i≠j} d_ij > 0`) `V_i(x, W)`는 (a) 연속이고, (b) 모든 배치에서 — **모든 정점 퇴화(공원·co-power 정점, 차수 ≥ 4)를 포함하여** — C¹이며 그 기울기는 위 면 공식으로 주어진다.

*증명 개요.* 면의 조합 구조가 바뀌는 사건은 모두 정점 분열·합병이고, 그때 생기거나 사라지는 면은 길이 `A_f = 0`을 지난다. 남은 면들의 `A_f`, `c_f`, `d_f`는 사건을 가로질러 연속이다(정점 좌표가 생성점의 연속 함수이고, 면 길이는 정점 사이 거리). 면 공식의 각 항은 `A_f`에 비례하므로 사라지는·생기는 면의 기여는 양쪽에서 0으로 수렴한다. 따라서 기울기가 연속이고 조각별 C¹ 함수가 연속 기울기를 가지면 C¹이다. 차수 5 이상의 정점(두 면 이상이 동시에 생김)도 같은 논증에 포함된다. W에 대해서도 동일(`∂V/∂W = ½L`의 항이 A에 비례). ∎

**정리 4 (C² 실패, 일반적).** 전환 다양체(면 생성 사건) 위에서 V_i는 일반적으로 C²가 아니다. 새 면 (i,l)의 길이는 전환 다양체를 가로지르는 변위 s에 대해 한쪽에서 `A_new = κ s + O(s²)`, 다른 쪽에서 0이며, 일반 위치에서 `κ > 0`(정점이 갈라지는 각의 사인의 역수에 비례; κ = 0은 접선 접촉의 비일반 경우). `∂V_i/∂x_i`의 새 면 기여 `A_new(c_new − x_i)/d_new`는 법선 성분이 `A_new·φ_il`(Voronoi에서 `A_new/2`)이므로 s-방향 2계 도함수가 `κ φ_il n_il`만큼 점프한다. 따라서 **일반 위치에서 점프는 0이 아니다**; 대칭 배치나 접선 접촉에서는 0일 수 있다. 결론: `d_ij ≥ d_min`인 영역에서 V_i는 `C^{1,1}`(기울기 Lipschitz)이지만 C²는 아니다.

**정리 5 (C¹의 진짜 실패).** 주기 상자에서 C¹이 깨지는 것은 오직 `d_ij → 0`(생성점 충돌)뿐이다. (a) Voronoi: 면 공식의 `A_ij/d_ij ~ H/d`가 발산해 기울기가 무계이고, 정확한 일치점에서는 이등분선 방향이 `x_j − x_i`의 방향에 의존하므로 V_i의 극한이 방향 의존적이다 — 그 점에서는 연속성도 없다. (b) Laguerre, `ΔW ≠ 0`: 앵커 `φd = (d² + ΔW)/(2d)`가 `d → 0`에서 발산해 낮은 가중치의 셀이 일치 전에 빈다(부피는 연속적으로 0에 감). 그 과정에서 `∂V/∂x ~ A ΔW/d²`로 기울기가 무계. 이것이 사용자의 충돌 사건이다. (c) 경계·비볼록 영역의 효과는 주기 상자에서는 없다.

**격자에 대한 언급.** 정사각 격자는 모든 정점이 차수 4(공원)이므로 전환 다양체 위에 놓여 있다. 정리 3에 의해 그 위에서도 C¹이지만, 방향에 따라 2계 도함수가 다르다. 사용자의 초기조건(10⁻³Δx 흔들림)은 전환 다양체에서 O(10⁻³Δx) 떨어져 있으므로 초기 운동에서 면 전환 빈도가 매우 높다. **이것이 관측된 부피 노이즈의 시간척도를 만든다는 것은 증명되지 않은 가설**이며, 판정은 단계당 면 전환 수와 부피 노이즈 스펙트럼을 함께 재는 것이다(현 스냅숏 자료로 가능). 증명된 것은 정리 3–5뿐이다.

**최종 명제 (8).** `d_ij > 0`이면 Voronoi·Laguerre 셀 부피는 모든 배치(모든 정점 퇴화 포함)에서 C¹이고 일반 위치에서 C²가 아니며(2계 점프 `κ φ n ≠ 0`), C¹의 유일한 실패는 생성점 충돌 `d_ij → 0`(Voronoi에서는 불연속, Laguerre에서는 기울기 무계)이다. 노이즈 시간척도와의 연결은 가설.
