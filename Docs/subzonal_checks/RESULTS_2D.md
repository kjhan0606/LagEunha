# 아영역 정식 2D 단위 시험 결과 (2026-10-02)

기준 구현: `sub2d.py`(주기 3×3 타일 Voronoi, 해석 기울기: 꼭짓점 외심 미분 + 중심 미분 + 𝓗dM 항).
- 아영역 밀도는 ρ_f = (m/V)·h_f(c)/h_f(x)로 계산한다. 이웃 방향 법선을 쓰므로 길이 0인 면에서도 유한하다.
- 셀 꼭짓점은 Delaunay 삼각형의 이웃 관계를 따라 정렬한다. 각도 정렬은 퇴화 배치에서 겹친 꼭짓점의 순서가 임의로 정해져 깨진다.
시험: `sub2d_tests.py`(b, c, d, g), `sub2d_tests2.py`(f), `sub2d_tests2e.py`(e). (e)와 (f)는 Slurm에서 실행했다.

| 시험 | 결과 |
|---|---|
| (b) 정사각 격자(퇴화 4점 공원) | Φ = 0, 힘 0 |
| (b) 균일 전단 격자(행 이동 1/8, 3/8) | Φ = 0, max|F| ≤ 2e-15 |
| (c) 교란 격자(±0.25h): 해석 힘 대 유한차분 | 상대 오차 ≤ 3e-9, Φ/U = 8.5e-3, min Φ_i = 4e-6 > 0 |
| (g) 불균일 질량(×0.5–2)·엔트로피(×0.5–2) | 상대 오차 ≤ 1.5e-9, min Φ_i > 0 |
| (d) ΣF | ≤ 3e-16 (상대) |
| (e) 위상 변화 4회 횡단 | U 연속(점프 ≤ 4e-11, |U| = 1.5), 힘 점프 0.1–0.8%, 매끄러운 구간 F = −dU/ds (5e-4, 유한차분 한계) |
| (f) 정지 글래스(±0.2h, P=1, 소산 없음, RK4, 2h/c 동안) | 총에너지 2.4e-8 → 8.0e-10 → 3.3e-9 (dt 절반씩). Φ는 1.0e-2에서 KE와 주고받으며 1.5e-3–1.0e-2로 진동. 위치의 dt 수렴은 1차(3.5e-6 → 1.8e-6). 위상 변화의 C¹ 결여 때문으로 추정되나 확인하지 않음 |
