## 성능 개선 후보 및 검사

`all_geom`의 삼각형 순회를 다음 두 후보로 분리했다.

- NumPy: 삼각형 좌표, 부호 넓이와 꼭짓점별 넓이 미분을 배열 연산으로 계산.
- OpenMP C: 같은 연산을 삼각형별 독립 루프로 실행. 공유 노드 힘의 합산이나
  재배치 루프는 바꾸지 않아 병렬 누적 경쟁을 만들지 않는다.

OpenMP는 gcc `-fopenmp`, 부동소수점 결합 제한 `-ffp-contract=off`로 빌드한다.
단일 스레드 정적 검사에서 원본과 두 후보의 부호 넓이/미분/좌표가 1e-15 이내로 일치했다.
역방향 및 퇴화 삼각형도 포함했다. 이후 계산 노드에서 실제 스레드 수를 기록한다.
아직 전체 실행 가속도는 측정 전이며, OpenMP 4스레드가 항상 빠르다고 가정하지 않는다.

작업 **417978**: CPU 4개, GPU 1개, 메모리 4 GB, a10, 20분 제한.
64², T=.2, dt=.01의 독립 성능 테스트를 다섯 번 실행한다.
프로파일 원본 1회 + 비프로파일 원본/NumPy/OpenMP 1스레드/OpenMP 4스레드 각 1회.
프로파일 타이밍은 가속비 계산에서 제외한다. 실제 원본의 T=100 실행을 재시작한 것이 아니다.

`performance_summary.json`에서 위치, 속도, 고정 노드 질량, 셀 상태, 위상,
재배치/에너지 장부를 비교한다. 실수 허용오차 rtol=1e-10, atol=1e-12,
위상 인덱스는 정확 일치. 통과한 후보 중 측정 실행 시간이 가장 짧은 것을 표시한다.
짧은 1회 측정이며 장기 재현성이나 일반적인 병렬 확장성을 증명하지 않는다.
