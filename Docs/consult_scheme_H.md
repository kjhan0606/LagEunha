## 1. 문제와 고정 조건

- 고정 질량 입자 유체다. 2D Voronoi/Laguerre 셀을 쓰며, 3D와 개별 시간간격으로 확장할 예정이다.
- **생성점이 곧 입자다.** 질량, 운동량, 중력이 그 위치에 있다. 생성점을 셀 중심으로 옮기는 regularization(AREPO, Power Particles)은 쓰지 않는다. 사용자가 한 달 동안 시험했고, 인위적 노이즈가 증폭됐다.
- 면 힘은 법선 방향 1D Riemann의 `P*`다. 1차 HLLC식 `P* = P_L + ρ_L(S_L−u_L)(u*−u_L)`에 `P* ≥ 0`을 걸었고, MUSCL 재구성(최소제곱 기울기 + Barth–Jespersen)을 쓴다. 시간적분은 RK4다.
- 원래 설계 의도는 "Voronoi + HLL = 가중치를 설계한 Laguerre"다. 즉 Laguerre 가중치 W를 움직여 면이 Riemann 접촉 속도로 움직이게 하는 것이다.

## 2. 지금까지 시험한 정식

| 정식 | 열역학 부피 | W | 결과 요약 |
|---|---|---|---|
| (1) GFS | Voronoi `V(x)` | 0 | 에너지 일에 실제 면 속도 사용. Kepler에서 바닥값 폭주(코드와 같음) |
| (G) | Godunov `V^G`(ODE `V̇^G = Σ A u*`) | 매 단계 OT Newton `V(x,W) = V^G` | 정확하지만 전단에서 W 발산 → 붕괴 |
| (G)+상한 | 같음 | `|ΔW| ≤ 0.9 d²`, 쌍 부피 이동 | 부피 이동이 엔트로피 감소 → Kepler 악화 |
| (F) W=0 | 기하 `V(x)` | 0 | VPH 힘 `−A[P* n + (P_j−P_i)t/d]`, `dU = −P dV_geo + σ`. Voronoi 부피 노이즈 → (1)보다 나쁨 |
| **(H)** | 기하 `V(x,W)` | 상태변수로 RK4 적분(아래) | 가장 좋지만 중심에서 dt 붕괴 |

(H)의 W 법칙:

```text
V̇^T = Σ_f A u*_f + (V_vor − V^T)/τ_V
½ L_{A/d} Ẇ = V̇^T − Σ_f A(ũ+ρ) + (V^T − V)/τ_C + [장벽]
장벽: |ΔW|/d² > 0.5인 면에 목표 Ẇ_a−Ẇ_b = (ΔW/d²)·2dḋ − sign(ΔW)(|ΔW|−0.5d²)/τ_B, 가중치 1000·A/d
dt ≤ ½ min_f (0.9d² − |ΔW|)/(sign·ΔẆ − 1.8 d ḋ)
```

총에너지는 어떤 Ẇ에서도 보존된다(유한차분으로 확인). 면 소산은 `D_f = A[(P_i−P_j)δ + (P*−P̃)(u_i−u_j)]`, `δ = ΔẆ/2d`이며, 좌우 Godunov 몫 비율로 분배한다.

## 3. 핵심 측정

**Gresho 와류, L1(v_φ)**

| 실행 | (1) | (G) | (H) 장벽 없음 | (H) 장벽 | (F) W=0 |
|---|---:|---:|---:|---:|---:|
| 32², t=3 | 0.179 | 0.052 | 0.048 | 0.074–0.098 | 0.129 (t=1) |

**순수 전단 진단 (Gresho 32², t=1)**
- Godunov 부피는 0.3% 이내로 일정하다. 같은 입자의 Voronoi 부피는 26%(와류 안 32%) 흔들린다.
- (G)의 W는 이 차이를 상쇄한다(상관 0.99). 유입·유출 이력과는 무관하다.
- 상태 함수 `W = f(ρ, P, s)`로는 정상 흐름에서 이 상쇄가 불가능하다는 것을 유도했다(§14).

**Kepler 원반 64²** (코드 초기조건: 옛 1/R 프로파일, ε=0.047, `P = 10⁻⁶`, Courant 0.4, `dt ≤ 0.06(R²+ε²)^{3/4}`, 바닥값은 `ie ≤ 0 → P = 10⁻⁶`). dE/|E₀|이며 전부 바닥값 주입이다.

|---:|---:|---:|---:|
| 4 | 1.05e-3 | 1.0e-5 | 2.3e-6 |
| 5 | 1.23e-3 | 1.9e-4 | 5.0e-6 |
| 7 | 1.6e-3 | 4.0e-4 → 붕괴 | — |
| 17.8 | 0.35 | | |

**(H)의 현재 정지 원인(진단)**
- t≈5.19에서 **중심 질점 바로 옆(R = 0.009)의 두 입자가 거의 충돌한다**(d: 0.02 → 0.0039).
- `|ΔW|/d²`가 20스텝 사이에 0.54에서 12.6으로 뛰고, 유효성 dt 제한이 5.7e-6으로 떨어져 Zeno 정지가 된다.
- 이 쌍은 원래 Voronoi 이웃이었다. 가까운 쌍 1.5만 개 가운데 0.9를 넘는 것은 이 하나뿐이다.
- 장벽은 연속 시간에서 비율을 유지하는 목표를 주지만, dt 동안 d가 너무 빨리 줄어 따라가지 못한다.

## 4. 질문

1. **물리:**
   - 입자 = 생성점 조건에서 "부피 노이즈 제거"(정확도)와 "W 유계"가 근본적으로 충돌하는가?
   - 정상 전단에서 이산 Voronoi 부피가 26% 흔들리는 것을 열역학 부피로 쓰지 않으면서, 에너지 보존과 셀별 엔트로피 부호를 동시에 지키는 정식이 가능한가?
   - (H)의 음의 면 소산(음의 합이 양의 합의 수십 %)은 원리적으로 문제인가?
2. **알고리즘:**
   - (H)처럼 W를 상태변수로 두고 `½L Ẇ = …`를 푸는 방식의 안정성은 어떤가?
   - 장벽, 유효성 dt 제한, 오차 되먹임(τ_C) 설계에 원리적 결함이 있는가?
   - 입자 충돌(d → 0) 근처에서 무엇을 해야 하는가? 예: W를 d에 비례해 강제로 줄이는 사상, 그 쌍만 Voronoi로 되돌리기, 암시적 처리.
3. **기하:**
   - Laguerre 셀 유효성 `|W_i − W_j| < d_ij²`는 이웃 쌍만으로 충분한가?
   - W의 크기를 국소 간격 `h_i²`에 묶는 더 자연스러운 매개화가 있는가? 예: `W_i = h_i² ω_i`에서 `ω`를 유계로 둔다.
   - 가중치 대신 다른 기하 자유도(면 곡률, 셀 내부 질량 분포 등)로 같은 목적을 달성할 수 있는가?
