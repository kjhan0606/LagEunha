# 결정 요청 (Astra, 13차): QBP 2차 적합 실패 셀의 처리 규칙

작성: 2026-10-05. 직전: `Docs/audit_impl12_astra.md`.

## 결과 (38e4cca, GFS_TCF_QBP=1, EUNHA_LSF_ORDER=2, 면 Z Q + HG 분리)
- Kepler 고리 IC, t≈1.8 RHS: 가장자리 H_Q/U가 0.324 → 0.016(고리 0), 0.423 → 0.025(고리 1), 0.0026 → 0.00006(바깥 가장자리)으로 줄었다. 내부는 같다. 회전 불변(입자별 8e-9), 적합 실패 0.
- Sod 128²: L1 0.0151/0.0384/0.0236, 에너지 2.7e-8. 관문 C 유지.
- Kepler 장기 실행(`Kepler_res256_ringIC_tcf_qbp_38e4cca`): 안쪽 가장자리 rms v_r/v_K가 t=10/20/30/40에 1.2e-5/1.5e-5/1.6e-5/8.3e-6이고 가열은 거의 없다(u 2.5e-6 → 3.8e-6). 이전 TCF는 t=20에 3e-3, 이전 세대는 3e-3(t=40)이었다. **그러나 t=42.4(1174단계)부터 2차 적합 실패 면이 생긴다**(처음 24개, 이후 단계당 170–1500개). 이어 t=50에 4.2e-3, t=52에 7.1e-3이 되고, 새는 질량은 0.0018로 무너진다.
- 현재 실패 처리: `qin = du_cell`(임시). Kepler 전단에서 |du_cell|/c ≈ 10이라 최대 Q가 걸린다. 12차 지시("처리 규칙 전에는 채택 금지")를 어긴 임시 대체였고, 붕괴의 직접 원인으로 보인다.
- 2차 적합 조건(코드 4741행 부근): 고정점(셀 값) 기준 5계수 가중 LSQ, 반경 rs = min(2.5√V, R_searched·cellsize), npt ≥ 8, Cholesky 대각 > 1e-8·tr. 실패가 npt 부족 때문인지 조건수 때문인지는 아직 분리하지 않았다.

## 질문
1. 실패 셀 처리 규칙을 정해 달라(문턱 없이, 회전 불변, 아핀 정확성 유지). 후보:
   - (a) 순위·조건수가 충족될 때까지 stencil 확장(2-hop, 보안 반경). 탐색 범위 한계에 닿으면 관문 실패로 처리.
   - (b) 실패 셀은 제한 전 선형 적합 기울기 사용(1차 정확, 아핀 정확).
   - (c) 그 면의 Q 입력을 반대쪽 셀 기울기만으로 구성.
   - 기타.
2. 고정 반경 2.5√V와 npt ≥ 8, 1e-8 조건이 문턱인지 판정하고, 대체할 수 있는 순위 판정을 제시하라.
3. 실패 원인 분리에 필요한 계측(npt, 조건수, 셀 종횡비, 반경)을 지정하라.
읽기 전용, 한국어, 결론 먼저, 구현 가능한 수식으로.
