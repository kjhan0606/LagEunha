## 2. 1차원 공유 면 갱신

셀 경계 f_i, 생성점 x_i, 고정 셀 질량 m_i, 운동량 p_i, 총에너지 E_i를 보관한다.
양의 밀도·압력을 가진 셀별 상수 유한체적 상태이다.

```
V_i = f_{i+1}-f_i
u_i = p_i/m_i
P_i = (gamma-1)(E_i-p_i^2/(2m_i))/V_i
Z_i = sqrt(gamma rho_i P_i)
```

내부 면의 음향 근사 Riemann 상태:

```
u* = (Z_L u_L + Z_R u_R + P_L-P_R)/(Z_L+Z_R)
P* = (Z_R P_L + Z_L P_R + Z_L Z_R (u_L-u_R))/(Z_L+Z_R)
```

각 면에서 위 상태를 한 번만 계산한다.

```
df_i/dt = u*_i
dx_i/dt = u_i
dp_i/dt = P*_i - P*_{i+1}
dE_i/dt = P*_i u*_i - P*_{i+1} u*_{i+1}
```

명시적 중간점 RK2의 같은 단계에서 면 이동과 압력 일을 계산한다.
따라서 셀 길이 변화는 양쪽 공유 면의 이동량 차이와 일치하며, 내부 운동량·에너지
교환은 상쇄된다. 외부 경계의 압력 충격량과 일은 별도 장부에 넣는다.
조각별 독립 이동으로 발생했던 면의 틈·중복이 이 1차원 표현에는 없다.

생성점은 셀 상태의 물리 속도 u_i로 움직이고 재중심화하지 않는다.
완료된 스텝에서 생성점 순서와 자기 셀 내부 위치를 검사한다.

셀 질량은 갱신 변수가 아니다. 출력의 `mass_error=0`은 이 구조적 제약을 나타내며,
별도 수송 적분의 측정 오차는 아니다. 여기서는 면 자체가 물질 경계여서 면 질량
유량이 0이다. 이 조건을 2차원 Laguerre 면 전체에 그대로 요구할 수는 없다(§5).

## 3. 가중치 표현과 양성 처리

정렬된 생성점 사이에서 공유 면 위치를 나타내는 가중치를 구성한다.

`w_{i+1}-w_i = x_{i+1}^2-x_i^2 - 2(x_{i+1}-x_i) f_{i+1}`

w_0=0으로 게이지를 고정한다. 재구성한 면 위치의 오차를 매 스텝 기록한다.
1차원 비주기 열린 사슬에는 폐회로 제약이 없어 이 차이를 순서대로 적분할 수 있다.
정적 검사에서는 각 셀 내부 점이 실제 power distance의 최소 셀에 속하는지도 확인했다.

셀 길이·내부에너지·면 압력이 양수가 아니면 스텝을 거부하고 dt를 절반으로 줄인다.
20회 축소 후에도 불가능하면 실패한다. floor, 질량 재정규화, 압력 절단은 없다.
초기 상태 자체의 음향 star 압력이 음수이면 dt 축소로 해결되지 않을 수 있다.
이것은 강한 충격이나 임의 상태에 대해 양성을 보장하는 Riemann 해법이 아니다.

이번 상수 상태에는 셀 내부 선형 속도·유한 R이 없다. 압축 초기 속도도 셀 평균으로
표현한다. 따라서 전단의 내부 운동에너지 보존이나 2차원 각운동량을 검증하지 않는다.
음향 임피던스 항의 수치 소산도 존재한다. 엔트로피 보장을 주장하지 않는다.

## 5. 2차원 가중치의 폐회로 조건

정지한 생성점에 대해 i→j 방향 면의 법선 속도를 s_ij로 정하면,
Laguerre 가중치 변화율 z_i는 다음을 만족해야 한다.

`z_i-z_j = 2 |x_j-x_i| s_ij`

따라서 임의의 닫힌 셀 이웃 회로에서 오른쪽 항의 합은 0이어야 한다.
움직이는 생성점의 경우에는 s_ij에서 생성점 운동이 이미 만드는 면 속도를 빼야 한다.
가중치의 차이로 표현되는 추가 속도에는 같은 폐회로 조건이 남는다.

정적 반례:

- 생성점 (0,0), (1,0), (.2,.8), 초기 물리 속도 0.
- 압력 .6,.8,.7; 밀도 1,3,2.
- 각 면에 독립적으로 계산한 음향 접촉 속도를 사용.
- 회로 0→1→2→0의 요구 가중치 차이 합: **-0.0039367642**.
- 최소제곱으로 맞춰도 최대 차이 잔차: **0.0013122547**.

반올림 오차가 아닌 유한한 불일치다. 최소제곱은 불일치를 측정하는 데만 사용했고
면 속도나 생성점 속도를 수정하지 않았다. 정적 대수 진단이며 진화 계산이 아니다.

이 반례는 **정해진 물리 생성점 운동·Laguerre 기하·각 면의 음향 접촉 속도 일치**를
동시에 요구하는 경로의 제약을 보여준다. 모든 조향 없는 유체 해법의 불가능성이나,
순질량 보존 가중치 풀이의 불가능성을 뜻하지 않는다.
