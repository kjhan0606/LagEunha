# 자문 요청 (12차): 시험 실패 사례·원인 정리와 다음 구현 방향

작성: 2026-10-01. 사용자 원칙: 패치 금지, 물리·수학적으로 정합한 self-consistent solver, 입자 = 생성점(생성점을 셀 중심으로 옮기지 않음), 셀 생성 알고리즘(`Voro2D_FindVC` 반평면 깎아내기) 유지, 단계 압력 바닥값 1e-6 유지(GIZMO IC 압력과 같음), Kepler DTETA 미사용, W에는 물리적 의도 없음(두 입자 거리보다 작아야 한다는 기준만).

자료: `Docs/gfs_scheme3_formulation.md` §24–26, 이전 자문 답 `Docs/consult_*_reply_astra.md`(1–11차), Fable 답(이 문서 아래 요약).

## B. 결과 요약 (GIZMO 입자판 Kepler, 1랭크 CPU, DTETA 없음)

| 구성 | 64² t=20 안쪽 [0.5,0.75) 질량 | 바깥 [1.75,2) | L1(v_φ) | 붕괴 |
|---|---:|---:|---:|---|
| 원판 + 2패스 + 면 중심 제한 + IC 수정 | 0.63 | 0.958 | 6.5e-3 | t≈28 |
| 같은 구성 + 쌍 중점 제한 + 양성 | **0.93** | **0.995** | **1.8e-4** | t≈32 (안쪽 14궤도) |
| 128² 면 중심 제한 | 0.91 | 0.985 | 4.5e-4 | t≈27 악화 시작 |

- 진단: M1(부호 분해 토크)에서 손실은 "압축 × 앞쪽" 칸에 몰린다(HLLC 압축·팽창 비대칭). M2(가장자리 해석적 기울기)는 t=10까지 침식을 없앤다.
- 셀 기하 열화(생성점–무게중심 0.2Δ, 종횡비 1.8)는 원반 전체에서 같은 수준으로 포화 → 침식 원인 아님.
- 충격: Sod 정상(L1 ρ 0.011, 바닥값 0). 정사각 격자에서는 두 제한자가 같은 결과.
- 진공 팽창(IC 수정 후): 희박파 몸통은 해석적 Lagrangian 궤적의 1–1.3Δ 이내. 가장 바깥 열은 4Δ 뒤처지고 속도 57%.
- ~~GIZMO MFM(Hopkins 2015)은 같은 64²에서 안쪽 수백 궤도를 유지한다.~~ **정정(2026-10-01, 원문 확인):** 논문은 유효 256²(−2<x,y<2에 256² 입자)이고, 그림 6은 t=120(r=1 기준 약 20궤도)을 보인다. MFM은 "≫100궤도"까지 유지, MFV는 30–50궤도부터 안쪽 원반 열화, PSPH 5–8궤도, TSPH 약 2궤도, 고정 격자 약 1궤도. 또한 논문 IC(식 34)는 진공이 아니라 Σ≥0.01 바탕 기체와 부드러운 가장자리를 쓴다(각주 24: 입자 방법은 진공 가장자리로도 할 수 있으나 결과가 정성적으로 같다고 서술). 따라서 64² 진공판과 논문 수치는 직접 비교할 수 없다.

## C. 관계없다고 판단한 구현 (근거)

| 구현 | 판단 근거 |
|---|---|
| 쌍 압력(`gfs_pair.h`) | 토크 기여 ~1e-6 |
| 극단 면 HLL 분기 | 토크 몫 작음(가장자리 일부) |

| 좌표 의존 제한(v_x,v_y 성분별) | 좌표 불변 제한도 비슷하게 깎임 |

| 진공 BC(ρ,P 경계값 0) | 2패스 뒤 이득 없음 |
| W/(H) | 차가운 원반(P/ρv²~1e-6)에서 P* 인공 점성 성분을 바꾸지 못함(Astra 5차, Fable) |

## D. 질문

1. A–C의 원인 판정과 "관계없음" 판정이 맞는가? 틀리거나 성급한 것이 있으면 코드·측정 근거로 짚어 달라.
2. **12번(남은 실패)의 가장 유력한 원인**은? 후보: (a) 쌍 중점 제한 뒤에도 남는 한쪽 stencil 곡률 편향(1차 오차) → HLLC 비대칭, (b) 쌍별 1D 단조 제한 부재(`av_mode==5`, 주석과 달리 없음), (c) 원판 반경 고정(가장자리 셀 부피·밀도 기하 오차, IC에서 가장자리 밀도 0.69Σ), (d) 2점 Gauss 등 면 적분 정확도, (e) 시간 적분(RK4, CFL, 입자가 공동으로 들어간 뒤 중심 질점 근처 dt), (f) 기타. 판별할 결정적 측정을 제안해 달라.
3. 중심 질점 접근 → 중력 RK 오차 → 붕괴(DTETA 미사용)는 결과인가 원인인가? 침식이 막히면 자연히 사라지는 현상으로 보는가?
4. **앞으로 어떤 구현으로 시험해야 하는가?** 우선순위와 각 시험의 판정 기준을 달라. 후보: 쌍별 단조 제한(Hopkins B4 구조), 가장자리 확장 stencil 또는 2차 LSF, 2점 Gauss 면 적분, Venkatakrishnan/조건수 β, 자유표면 운동 법칙(원판 반경의 동역학, 2단계), (H) DAE 재결합, 해상도 수렴(M3), 차가운 전단 상자 시험.
5. 시험 체계 권고: 기준선 고정과 수용 기준(예: 64²에서 안쪽 N궤도 유지, 수렴 차수).

읽기 전용, 한국어, 결론 먼저, 근거(코드 위치·유도·측정·문헌) 포함.
