## 418243: 수치 예측 상태를 이용한 시공간 유량 감사 6건

이전 기하 검사의 2차 generator/weight 경로 위에 질량·운동량·총에너지
공유 면 플럭스를 올린다. 각 면은 실제 다항식 경로의 법선 속도를 사용한다.
정규화 경로 시간과 실제 시간을 구분하여 면 속도를 h로 나누고 적분에 h를 곱한다.

밀도·선형 속도·잔여 속도 표본·선형 압력은 수치 중간 단계의 상태에서 복원한 뒤
이번 감사 구간에서 고정한다. 각 시간의 새 셀에 질량을 다시 맞춰 복원하지 않는다.
따라서 셀별 누적 질량 유량은 독립적으로 측정된다.
외부 경계는 이동 벽 반사를 적용하며 내부 면 플럭스는 정확히 반대 부호로 기록한다.

전단/음파 각각 N2 h=.01, N3 h=.01, N2 h=.05, 총 6건.
기하 사건을 분할하고 시간 quadrature 8/16/32점 결과를 비교한다.
유량 부호 전환은 기하 사건과 다를 수 있으므로 quadrature 수렴을 별도 판정한다.

판정은 세 가지를 분리한다.

- 보존 장부: 절대 잔차 <1e-11.
- 적분 수렴: 16/32점 최대 차이 <1e-9.
- 고정 질량: 누적 질량 유량 / 원래 질량의 최대값 <1e-10.

현재 코드는 이 세 조건을 강제로 맞추지 않는다. 특히 고정 질량이 실패하면
시공간 질량 제약을 아직 풀어야 한다는 진단으로 남긴다. 진화 상태를 갱신하거나
보정하지 않으므로 일반 유체 해법의 결합 완료로 주장하지 않는다.
이 경로는 두 수치 단계로 만든 예측 경로이며 모든 시간의 물리 속도 ODE를
정확하게 푼 경로라는 뜻도 아니다. 내부 참조 유체해를 주입하지 않는다.

정적 검사 2개 통과: 균일 정지 상태에서 이동 면의 질량/에너지 유량이 기하
쓸림과 일치하고 압력 합력이 0임을 확인; 기하 Reynolds 미분 검사도 재확인.

## 07:48 예측 경로와 유량 식 대조 수정

418243의 첫 6건은 기존 donor RHS로 만든 경로와 kinetic 면 유량을 결합한
혼합식 감사였다. 셀별 질량 불일치에 닫힘 차이가 섞이므로 이를 목표 결합식의
검증으로 해석하지 않는다. 원 결과는 대조군으로 보존한다.

QuadraticPath에 RHS/인수 적분기 선택 인자를 추가하고, FluxAudit에서는
kinetic RHS와 Sylvester 손실 보완식을 사용하도록 맞췄다. 기존 기본 기하 검사는
원래 동작을 유지한다. 정적 검사 2개 재통과.
동일한 6건을 일치된 예측/유량 식으로 비교하는 **418245**를 새로 제출했다.
이 비교 뒤에도 셀별 질량 결함이 남으면 고정 예측장과 시공간 가중치 제약의
시간 결합 문제를 다음 원인으로 분석한다. 이 경우도 질량을 사후 재정규화하지 않는다.

## 07:49 일치된 유량 결과와 누적 질량 제약

418245의 6건 모두 실행 완료, 적분 수렴/전체 보존은 통과했지만 고정 질량은
모두 실패했다. 상대 누적 질량 결함: 전단 N2 h=.01 5.19e-8,
N3 h=.01 1.37e-7, N2 h=.05 1.35e-4; 음파는 각각 7.78e-10,
1.58e-6, 1.94e-8이다. 혼합식 차이를 제거해도 제약이 저절로 만족되지 않는다.

이에 **418246**으로 끝점 누적 질량 제약 시험 4건을 제출했다.
동일한 고정 수치 예측장을 사용하면서 가중치 경로에 s² delta_w를 추가한다.
초기 가중치와 초기 가중치 미분은 유지하고, 마지막 셀의 delta_w=0으로 gauge를 고정한다.
32점 시공간 질량 적분을 Newton+선탐색으로 0에 맞추고 64점 적분으로 재확인한다.
질량 자체를 재정규화하지 않으며 생성점 경로의 계수는 정확히 동일한지 검사한다.

구간 전체 누적 질량이 맞는 것과 중간 시각의 고정 질량은 다르므로
s=.25,.5,.75의 순간 질량 유량도 별도 보고한다. 이 단계는 끝점 제약의
수치적 해결 가능성 검사이며 모든 시간의 제약이나 전체 Euler 진화의 완성이 아니다.
실패는 실패로 남긴다. 통과 기준: 상대 누적 질량 <1e-10,
32/64 적분 차이 <1e-9, 장부 잔차 <1e-11.

418246 실행 경로: `/gpfs/kjhan/LagForce/Codex_F_integrated_weights_20261010_074905`
